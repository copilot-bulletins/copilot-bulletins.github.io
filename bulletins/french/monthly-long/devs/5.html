Monthly (Long) #5 · Août 2026 · Devs Edition

🎯 Le fil de cette édition

Août 2026 confirme deux dynamiques pour les développeurs. D'abord, le choix de modèles s'élargit encore : Kimi K3, Gemini 3.7 Flash, Grok 4.6 et MAI-Code-1.1-Flash rejoignent le catalogue, pendant que MAI-Code-1-Flash amorce sa sortie. Ensuite, l'outillage agentique gagne en maturité : Agent Plugins 1.0 unifie VS Code, la CLI et l'appli Copilot, l'agent de codage expose ses niveaux de raisonnement, et la revue de code passe en disponibilité générale. JetBrains, Visual Studio et VS Code reçoivent leurs mises à jour mensuelles. Concrètement, vous avez plus de leviers pour adapter Copilot à chaque tâche.

⚠️ Attention

  • Upcoming deprecation of MAI-Code-1-Flash — Deadline : 10 septembre 2026 — Le modèle sera retiré de toutes les expériences Copilot ; basculez vos usages vers MAI-Code-1.1-Flash via le sélecteur de modèle.
  • Upcoming deprecation of GitHub Spark on github.com — Deadline : 31 août 2026 — Plus de nouveaux utilisateurs ni de nouvelles apps ; exportez vos applications existantes avant la date limite.
  • Upcoming changes to GitHub Copilot policies and billing — Deadline : 1er octobre 2026 — Des changements de facturation et de règles entrent en vigueur ; vérifiez leur impact sur votre organisation.

🚀 Passez à l'action

  • Essayez les nouveaux modèles (Kimi K3, Gemini 3.7 Flash, Grok 4.6) depuis le sélecteur de modèle Copilot.
  • Déléguez une tâche à l'agent de codage et ajustez son niveau de raisonnement.
  • Installez et pilotez Copilot en terminal avec la Copilot CLI.
  • Activez la revue de code Copilot sur vos pull requests.
  • Une question ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Quatre nouveaux modèles rejoignent Copilot

Le catalogue s'étoffe avec Kimi K3, Gemini 3.7 Flash, Grok 4.6 et MAI-Code-1.1-Flash. Plus de choix pour arbitrer entre vitesse, raisonnement et coût selon la tâche, directement depuis le sélecteur de modèle de votre IDE.

→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot

→ Changelog: MAI-Code-1.1-Flash available in GitHub Copilot

2. Agent Plugins 1.0 unifie VS Code, la CLI et l'appli Copilot

Agent Plugins 1.0 apporte un format d'extension cohérent partout : VS Code, Copilot CLI et l'appli Copilot. Vous packagez et réutilisez les mêmes capacités agentiques quel que soit l'environnement, sans réécrire d'intégrations.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

3. Copilot pour JetBrains monte en puissance

JetBrains gagne la mémoire Copilot, la prise en charge d'Ollama pour des modèles locaux, et le harness désormais en disponibilité générale. Une expérience agentique plus complète et personnalisable pour les développeurs IntelliJ et consorts.

Sources:
→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains
→ Changelog: Copilot harness generally available in Copilot for JetBrains

4. L'agent de codage devient plus pilotable

Vous choisissez désormais le niveau de raisonnement de l'agent de codage cloud pour arbitrer profondeur et rapidité, et vous déclenchez des automatisations Copilot directement via des commentaires. Deux leviers concrets pour intégrer l'agent dans vos flux.

Sources:
→ Changelog: Customize the reasoning level for Copilot cloud agent
→ Changelog: Trigger Copilot automations with comments

5. La revue de code Copilot passe en disponibilité générale

Les niveaux d'effort de la revue de code sont désormais généralement disponibles, complétés par des raisons de résolution et des capacités étendues. Vous calibrez la profondeur d'analyse et comprenez mieux pourquoi chaque commentaire a été résolu.

Sources:
→ Changelog: Copilot code review effort levels are generally available
→ Changelog: Copilot code review: Resolution reasons and expanded capabilities

6. Mises à jour mensuelles de VS Code et Visual Studio

VS Code et Visual Studio reçoivent leurs lots de nouveautés d'août : améliorations agentiques, ergonomie du chat et corrections. À installer pour profiter des derniers raffinements dans votre éditeur au quotidien.

Sources:
→ Changelog: GitHub Copilot in VS Code, August 2026 releases
→ Changelog: GitHub Copilot in Visual Studio — August update

7. Copilot arrive dans Slack et Microsoft Teams

Copilot investit vos espaces de collaboration : une nouvelle expérience dans Slack et le travail agentique partagé dans Microsoft Teams. Lancez et suivez des tâches Copilot sans quitter la conversation d'équipe.

Sources:
→ Changelog: The new GitHub Copilot experience in Slack
→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams

8. L'onglet Customize de l'appli Copilot en disponibilité générale

L'onglet Customize de l'appli Copilot devient généralement disponible, pour ajuster le comportement et les préférences de Copilot en un seul endroit. Une personnalisation plus accessible, sans plonger dans des fichiers de configuration.

→ Changelog: GitHub Copilot app Customize tab is generally available
