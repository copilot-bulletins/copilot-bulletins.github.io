Monthly (Long) #4 · Juillet 2026 · Devs Edition

🎯 Le fil de cette édition

Juillet 2026 a été porté par deux dynamiques majeures pour les développeurs : une vague de nouveaux modèles et une montée en puissance de l'agentique intégrée à vos outils du quotidien. Copilot élargit son catalogue de modèles pour ajuster puissance et rapidité à chaque tâche, tandis que le CLI, les IDE JetBrains et VS Code gagnent en autonomie et en interopérabilité via MCP. En parallèle, la revue de code et la correction des alertes de sécurité s'automatisent davantage. Concrètement, vous disposez de plus de contrôle sur le modèle utilisé et d'agents capables d'agir directement dans votre environnement.

⚠️ Attention

  • Gemini 2.5 Pro et Gemini 3 Flash dépréciés — Deadline : 31 juillet 2026 — Ces modèles ont été retirés de toutes les expériences Copilot. Basculez vos usages vers un modèle pris en charge.

🚀 Passez à l'action

  • Comparez et choisissez le bon modèle pour chaque tâche via la liste des modèles pris en charge.
  • Automatisez vos revues de code avec les agent skills et serveurs MCP dans Copilot code review.
  • Prenez en main l'agent en ligne de commande avec Copilot CLI.
  • Étendez Copilot avec vos propres outils via MCP dans votre IDE.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Une vague de nouveaux modèles pour chaque tâche

Le catalogue s'étoffe fortement : GPT-5.6 (Sol, Terra, Luna), Claude Opus 5, Grok 4.5, Gemini 3.6 Flash et Kimi K2.7 arrivent dans Copilot. Vous pouvez désormais aligner précisément puissance, rapidité et coût sur la nature de chaque tâche.

Sources:
→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot
→ Changelog: Gemini 3.6 Flash is now available in GitHub Copilot
→ Changelog: Kimi K2.7 is now available in GitHub Copilot

2. Copilot code review : agent skills et MCP en disponibilité générale

La revue de code Copilot prend en charge les agent skills et les serveurs MCP en disponibilité générale pour Pro, Pro+, Business et Enterprise. Vos revues automatisées peuvent désormais s'appuyer sur vos outils et votre contexte spécifiques.

→ Changelog: Copilot code review agent skills and MCP now generally available

3. Copilot CLI : plus autonome et plus intégré

Le CLI route automatiquement vers le meilleur modèle selon la tâche, ne nécessite plus de PAT dans GitHub Actions et gagne une skill de configuration du language server C#. L'agent en ligne de commande devient plus fluide dans vos pipelines.

Sources:
→ Changelog: Copilot CLI auto model selection routes based on task
→ Changelog: Copilot CLI no longer needs a personal access token in GitHub Actions
→ Changelog: New C# language server config skill for Copilot CLI

4. JetBrains : Codex, BYOK et personnalisation avancée

Les IDE JetBrains accueillent Codex comme nouveau fournisseur d'agent en preview, un éditeur de personnalisations enrichi (Hooks, gestion MCP) et des capacités BYOK étendues. Vous gardez la main sur les modèles et les outils utilisés.

Sources:
→ Changelog: Codex as agent provider and agentic enhancements in JetBrains IDEs
→ Changelog: GitHub Copilot for JetBrains expands BYOK capabilities

5. Copilot Vision en disponibilité générale

Vous pouvez désormais joindre images et PDF directement à vos prompts pour que Copilot raisonne sur ce qu'il voit en plus de votre code. Idéal pour partager maquettes, diagrammes ou captures d'écran d'erreurs.

→ Changelog: Copilot vision is generally available

6. Browser tools dans VS Code en disponibilité générale

Les outils de navigation dans VS Code passent en disponibilité générale : les agents peuvent piloter un vrai navigateur, parcourir des applications web et réinjecter leurs observations dans le chat. Le test et le débogage d'applications web s'automatisent.

→ Changelog: Browser tools for GitHub Copilot in VS Code are generally available

7. Autofix agentique pour les alertes de code scanning

Un correctif agentique en preview publique accélère la résolution des alertes de code scanning. Copilot propose des corrections directement exploitables, réduisant le temps entre détection et remédiation des failles.

→ Changelog: Agentic autofix for code scanning alerts in public preview

8. Le serveur GitHub MCP adopte la nouvelle spécification

Le protocole MCP passe en mode stateless le 28 juillet 2026, et le serveur GitHub MCP prend déjà en charge la dernière spécification. Vos intégrations MCP gagnent en robustesse et restent alignées sur le standard.

→ Changelog: GitHub MCP server supports the next MCP specification
