Monthly (Long) #1 · Mai 2026 · Devs Edition

🎯 Le fil de cette édition

Mai 2026 marque un tournant dans la relation développeur-agent : Copilot s'impose comme l'interface centrale du développement. L'application native inaugure des sessions parallèles sur branches isolées, intégrées nativement à GitHub. L'API Agent Tasks ouvre la programmabilité à grande échelle. VS Code et JetBrains enrichissent leur support d'agent. L'arrivée de Claude Opus 4.8 et le routage intelligent de la sélection automatique par type de tâche élèvent la qualité et l'efficacité des interactions. Mai pose les fondations d'un workflow agentique end-to-end, de la création d'issue jusqu'à la merge request.

⚠️ Attention

  • Upcoming deprecation of GPT-4.1 — Deadline : 1er juin 2026 — Migrez vers GPT-5.5 ; mettez à jour vos automations et consultez les modèles supportés.
  • Upcoming deprecation of GPT-5.2 and GPT-5.2-Codex — Deadline : 1er juin 2026 — Migrez vers GPT-5.5 et GPT-5.3-Codex respectivement ; consultez les modèles supportés.
  • Upcoming deprecation of Grok Code Fast 1 — Action requise — Déprécié le 15 mai ; migrez vers GPT-5 mini ou Claude Haiku 4.5 et consultez les modèles supportés.

🚀 Passez à l'action

  • Téléchargez et installez l'application GitHub Copilot (préversion technique) — disponible pour Business et Enterprise avec les préversions activées et Copilot CLI autorisé dans les politiques.
  • Sélectionnez Claude Opus 4.8 dans votre sélecteur de modèles (votre admin Business/Enterprise doit activer la politique correspondante).
  • Activez la sélection automatique de modèle dans VS Code pour bénéficier d'un routage par type de tâche et d'une réduction de 10 % sur le multiplicateur.
  • Automatisez vos workflows agentiques grâce à l'API Agent Tasks — déclenchables depuis un script ou votre portail développeur interne.
  • Des questions ou besoin de support ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. L'application GitHub Copilot arrive en préversion technique

L'application GitHub Copilot est un espace natif pour le développement agentique : sessions parallèles sur branches isolées, intégration directe des issues et PRs, review de diffs et soumission de pull requests sans changer d'outil. Disponible pour Business et Enterprise, sur liste d'attente pour Pro/Pro+.

→ Changelog: GitHub Copilot app is now available in technical preview

2. Claude Opus 4.8 disponible dans GitHub Copilot

Claude Opus 4.8, le nouveau modèle phare d'Anthropic, est disponible dans tous les IDEs, Copilot CLI, cloud agent et l'application Copilot. Progrès nets sur la compréhension de code et la navigation dans de grandes bases de code. Disponible pour Pro+, Business et Enterprise, avec un multiplicateur de 15x.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

3. VS Code : les sorties d'avril, une salve de fonctionnalités agentiques

Quatre releases (v1.116–v1.119) : indexation sémantique dans tous les workspaces, BYOK (apportez votre propre clé API) pour Business et Enterprise, accès lecture/écriture aux terminaux ouverts depuis l'agent, et supervision des sessions Copilot CLI depuis GitHub.com ou l'app mobile.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

4. Agent CLI Copilot et vue unifiée des sessions dans JetBrains

L'agent CLI arrive en préversion publique dans JetBrains IDEs : déléguez des tâches longues directement depuis l'IDE, avec isolation worktree ou workspace. Une vue unifiée centralise toutes les sessions actives. Nouveautés : outil « Ask question », agents globaux (~/.copilot/agents) et connexion GHES.

→ Changelog: Introducing Copilot CLI agent and unified sessions view in GitHub Copilot for JetBrains IDEs

5. Déclenchez des tâches d'agent cloud via l'API REST

Business et Enterprise peuvent désormais programmer des tâches d'agent cloud via l'API REST (préversion publique). Refactoring à grande échelle, provisionnement depuis un portail développeur, génération automatique de notes de release : la progression est traçable par la même API. PAT et OAuth supportés.

→ Changelog: Start Copilot cloud agent tasks via the REST API

6. La sélection automatique de modèle s'enrichit dans VS Code et l'agent cloud

VS Code route désormais selon la complexité réelle de la tâche vers le modèle optimal — plus seulement selon la disponibilité. L'agent cloud adopte aussi le mode « Auto ». Les deux offrent une réduction de 10 % sur le multiplicateur de coût et aucune limite de débit hebdomadaire.

Sources : → Changelog: Auto model selection now routes based on your task in VS Code
→ Changelog: Copilot cloud agent supports auto model selection

7. « Fix with Copilot » : appliquez les retours de code review en un clic

Le bouton « Implement suggestion » devient « Fix with Copilot » et s'accompagne d'un dialogue de configuration : choix du modèle, application directe à la PR ou via une nouvelle PR, instructions complémentaires. Un nouveau « Fix batch with Copilot » traite plusieurs commentaires en une seule opération.

→ Changelog: Easily apply Copilot code review feedback with Copilot cloud agent

8. Recherche sémantique d'issues dans Copilot Chat

Copilot Chat sur le web prend en charge la recherche d'issues en langage naturel. Retrouvez une issue sans en connaître le titre exact, filtrez par contexte ou environnement : les résultats sont indexés sémantiquement. Disponible pour tous les plans Copilot.

→ Changelog: Semantic issue search in Copilot Chat
