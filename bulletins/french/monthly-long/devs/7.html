Monthly (Long) #7 · Octobre 2026 · Devs Edition

🎯 Le fil de cette édition

Octobre, marqué par GitHub Universe, fait passer Copilot d'un assistant que l'on sollicite à un ensemble d'agents qui travaillent en continu : dans le cloud, sur votre machine, ou déclenchés par des événements de vos dépôts. Le choix du modèle se délègue désormais au routage intelligent, et le contexte (mémoire, outils connectés) se configure une seule fois.

Pour les développeurs, l'enjeu se déplace : moins de configuration et de micro-pilotage, plus de définition d'objectifs, de garde-fous et de revue des résultats produits par les agents.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Échéance : 16 novembre 2026 — Claude Opus 4.8, Claude Opus 5 et GPT-5.6 Terra seront retirés ; migrez vos workflows vers Claude Opus 5.5, GPT-6.1 Sol ou GPT-6 Luna à l'aide de la liste des modèles pris en charge.

🚀 Passez à l'action

  • Sélectionnez Copilot Fusion dans le sélecteur de modèles et choisissez un niveau d'effort, en suivant la documentation Copilot Fusion.
  • Automatisez une tâche récurrente de votre dépôt (triage, reproduction de bugs) en créant une automatisation Copilot avec une limite de crédits IA.
  • Activez « Watch and fix » sur vos pull requests grâce à Agent Merge.
  • Connectez Slack, Figma ou Sentry une seule fois via les connecteurs Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Copilot Fusion : le routage de modèles devient la norme

Plutôt que de choisir un modèle, choisissez un niveau d'effort (Standard, High, Max) : Copilot Fusion sélectionne et orchestre les modèles pour chaque requête. Disponible dans VS Code, JetBrains, Copilot CLI et l'app, avec un routage expérimental vers des modèles locaux.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot Fusion now supports selection of local models

2. Copilot Automations : des workflows d'équipe pilotés par événements

Les automatisations peuvent désormais être partagées au niveau du dépôt, déclenchées par 24 nouveaux événements ou par l'API REST, utiliser des outils MCP et être plafonnées en crédits IA. Elles se gèrent aussi depuis VS Code et tournent dans le cloud.

Sources:
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: New tools, triggers, and cost controls for Copilot Automations
→ Changelog: Create and manage Copilot Automations in Visual Studio Code

3. De la revue au merge : Max, approbations et Agent Merge

Le niveau de revue Max combine plusieurs agents de fournisseurs différents pour les changements critiques, et les approbations Copilot comptent désormais dans les approbations requises. Agent Merge surveille vos PR sur github.com et corrige workflows en échec et conflits.

Sources:
→ Changelog: Copilot code review: Merge with confidence with Max and approvals
→ Changelog: Agent Merge watches and fixes pull requests in the cloud

4. Une session cloud, sur toutes vos surfaces

Démarrez une tâche depuis GitHub Mobile, Slack, Teams ou la CLI, puis reprenez la même session dans VS Code ou l'app. Chaque session s'exécute dans une sandbox cloud sécurisée, sans limite d'une heure, avec reprise par snapshot.

→ Changelog: Work from anywhere with a new, connected Copilot cloud experience

5. Connecteurs : vos outils branchés en un clic

Les serveurs MCP vérifiés par GitHub (public preview) permettent de connecter 26 services, dont Slack, Figma, Notion, Sentry et Linear, une seule fois pour l'app, la CLI, VS Code, le cloud et Mobile. Aucun serveur à installer, aucun identifiant à gérer.

→ Changelog: Connect your tools to Copilot without all the setup

6. Copilot Memory en GA et « dreaming » en preview

Copilot retient vos préférences et les conventions de vos dépôts d'une session et d'un client à l'autre. Le « dreaming », opt-in, analyse le travail passé pour curer la mémoire et proposer, via pull request, des améliorations de skills et d'instructions.

→ Changelog: GitHub intelligence puts your code, context, and history to work

7. L'app Copilot gagne les Projects, le computer use et la sécurité

Les Projects (public preview) regroupent contexte, agents et résultats sur plusieurs dépôts. Le computer use permet à Copilot de piloter des applications de bureau avec votre accord, et l'extension sécurité explique et corrige les alertes de code scanning en local.

Sources:
→ Changelog: GitHub Copilot app, Universe releases
→ Changelog: GitHub Copilot can now interact with desktop apps with computer use
→ Changelog: Security extension for the GitHub Copilot app

8. Trois nouveaux modèles dans le sélecteur

GPT-6.1 Terra cible le codage agentique quotidien à moindre coût, Gemini 4 Argon les tâches complexes et le raisonnement, et Claude Haiku 5.5 les travaux rapides à fort volume comme les sous-agents. Tous sont disponibles dans les principaux IDE et la CLI.
