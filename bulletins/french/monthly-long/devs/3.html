Monthly (Long) #3 · Juin 2026 · Devs Edition

🎯 Le fil de cette édition

Juin 2026 confirme une bascule : Copilot n'est plus un assistant d'éditeur, mais un partenaire agentique présent partout où vous codez. Terminal, application de bureau et IDE JetBrains passent en disponibilité générale avec des capacités d'agent natives. En parallèle, le choix de modèles s'élargit, les fenêtres de contexte franchissent le million de tokens et l'extensibilité s'ouvre via le SDK, les agent apps et les workflows agentiques. Pour les développeurs, cela signifie déléguer davantage de tâches de fond tout en gardant la main sur le modèle, le contexte et les garde-fous.

⚠️ Attention

  • GPT-4.1 retiré — En vigueur depuis le 1er juin 2026 — migrez vos workflows vers un modèle pris en charge.
  • GPT-5.2 et GPT-5.2-Codex retirés — En vigueur depuis le 5 juin 2026 — basculez vers les modèles disponibles.
  • Opus 4.6 (fast) retiré — En vigueur depuis le 29 juin 2026 — vérifiez vos configurations pour éviter toute interruption.

🚀 Passez à l'action

  • Essayez les nouveaux modèles (Claude Sonnet 5, Opus 4.8 fast, MAI-Code-1-Flash) via la documentation des modèles pris en charge.
  • Installez ou mettez à jour Copilot CLI et explorez la nouvelle interface à onglets.
  • Activez Copilot code review sur vos dépôts pour automatiser les revues.
  • Déléguez vos tâches de fond à l'agent cloud Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Claude Sonnet 5, Opus 4.8 et MAI-Code-1-Flash enrichissent le catalogue de modèles

Le catalogue s'étoffe : Claude Sonnet 5 et Claude Fable 5 passent en disponibilité générale, Claude Opus 4.8 (fast) arrive en préversion et MAI-Code-1-Flash rejoint Copilot. Plus de choix pour équilibrer vitesse, coût et qualité selon vos tâches.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: MAI-Code-1-Flash is now available for GitHub Copilot

2. Copilot CLI : la nouvelle interface terminal passe en disponibilité générale

La refonte du terminal est généralement disponible : mise en page à onglets, configuration centralisée via /settings, commande de revue de sécurité dédiée, saisie vocale et « rubber duck ».

Sources:
→ Changelog: Copilot CLI: New terminal interface is generally available
→ Changelog: Dedicated security review command now available in Copilot CLI

3. L'app GitHub Copilot, l'expérience bureau agent-native, passe en disponibilité générale

L'application de bureau est généralement disponible : lancez des sessions parallèles par dépôt, chacune sur sa branche et son worktree, validez dans le terminal et le navigateur intégrés, puis ouvrez une pull request. Le BYOK est désormais pris en charge.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

4. Copilot devient un agent natif dans les IDE JetBrains

Sélectionnez GitHub Copilot comme agent dans JetBrains AI Assistant, choisissez votre modèle et ajustez la profondeur de raisonnement dans le chat. Claude arrive en préversion comme fournisseur d'agent et l'agent cloud passe en disponibilité générale.

Sources:
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs

5. Copilot code review gagne en profondeur et en efficacité

Copilot code review explore le code avec les outils grep, rg, glob et view du CLI, réduisant les coûts d'environ 20 % à qualité constante. S'ajoutent la prise en charge d'AGENTS.md, un niveau de revue par défaut d'organisation et une préversion pour Azure Repos.

Sources:
→ Changelog: Copilot code review: Analysis depth and efficiency updates
→ Changelog: Copilot code review: AGENTS.md support and UI improvements
→ Changelog: Copilot code review: New configurations and controls

6. Un million de tokens de contexte, raisonnement configurable et routage automatique

Copilot gère désormais une fenêtre de contexte d'un million de tokens dans VS Code, Copilot CLI et l'app, avec des niveaux de raisonnement configurables. Le mode auto, qui route vers le meilleur modèle, est ouvert à tous les utilisateurs.

Sources:
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot
→ Changelog: Auto mode in Copilot Chat available for all users

7. Automatisez avec l'agent cloud : planification, sandboxes et API

Déléguez les tâches répétitives à l'agent cloud grâce aux automatisations planifiées, sécurisez leur exécution avec les sandboxes cloud et locales et intégrez le tout via l'API REST des tâches d'agent.

Sources:
→ Changelog: Schedule and automate tasks with Copilot cloud agent
→ Changelog: Cloud and local sandboxes for GitHub Copilot now in public preview
→ Changelog: Agent tasks REST API now available for Copilot Pro, Pro+, and Max

8. Construisez sur Copilot : SDK en disponibilité générale, agent apps et workflows agentiques

Le Copilot SDK passe en disponibilité générale et offre un accès programmatique au runtime d'agent (planification, outils, éditions, streaming) dans six langages. Ajoutez-y les agent apps installables depuis la Marketplace et GitHub Agentic Workflows en préversion publique.

Sources:
→ Changelog: Copilot SDK is now generally available
→ Changelog: Extend GitHub with agent apps
→ Changelog: GitHub Agentic Workflows is now in public preview
