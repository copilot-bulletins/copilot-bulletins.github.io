Monthly (Long) #3 · Avril 2026 · Devs Edition

🎯 Le fil de cette édition

Avril 2026 marque un tournant décisif dans la maturation de Copilot comme partenaire de développement autonome. VS Code gagne un mode Autopilot qui laisse les agents s'exécuter sans interruption, JetBrains introduit le mode agent inline en préversion et Visual Studio intègre le cloud agent directement depuis l'IDE. L'arrivée de GPT-5.5 et les nouvelles capacités BYOK du CLI offrent un contrôle inédit sur le choix du modèle. En toile de fond, la transition vers la facturation à l'usage, effective le 1er juin, annonce une nouvelle ère pour l'ensemble des plans Copilot.

⚠️ Attention

  • GitHub Copilot passe à la facturation à l'usage — Délai : 1er juin 2026 — Les unités de requête premium (PRU) seront remplacées par des crédits IA GitHub. Consultez la documentation sur la facturation à l'usage pour préparer la transition.
  • Le code review Copilot consommera des minutes GitHub Actions à partir du 1er juin 2026 — Délai : 1er juin 2026 — Vérifiez vos entitlements Actions et ajustez vos budgets depuis vos paramètres de tarification Copilot.

🚀 Passez à l'action

  • Activez le mode Autopilot dans VS Code pour laisser les agents s'exécuter jusqu'à la complétion sans intervention manuelle.
  • Explorez GPT-5.5 pour les tâches agentiques complexes — consultez les modèles disponibles selon votre plan.
  • Essayez les sessions CLI distantes avec copilot --remote pour piloter vos tâches depuis le web ou GitHub Mobile.
  • Configurez le BYOK dans Copilot CLI pour utiliser vos propres clés Azure OpenAI, Anthropic ou Ollama.
  • Des questions ou besoin d'aide ? Contactez votre équipe GitHub, nous sommes là pour vous accompagner.

🏆 Top 8 des mises à jour du mois

1. VS Code : Autopilot et nouvelles capacités agentiques

Le mode Autopilot, désormais en préversion dans VS Code, laisse les agents approuver leurs propres actions et travailler jusqu'à la complétion sans interruption. La mise à jour couvre aussi le débogage navigateur intégré, images et vidéos dans le chat, les sous-agents imbriqués et un éditeur unifié de personnalisation des instructions.

→ Changelog: GitHub Copilot in Visual Studio Code, March Releases

2. GPT-5.5 disponible sur GitHub Copilot

GPT-5.5, dernier modèle phare d'OpenAI, est désormais accessible aux plans Pro+, Business et Enterprise. Il excelle sur les tâches agentiques multi-étapes et résout des défis de code inédits pour les modèles GPT précédents. À noter : un multiplicateur 7,5× s'applique dans le cadre de la tarification promotionnelle.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

3. Copilot CLI : sessions distantes et modèles BYOK

Deux avancées majeures pour le CLI en avril : copilot --remote diffuse votre session vers GitHub en temps réel, permettant de la piloter depuis n'importe quel navigateur ou l'app GitHub Mobile. Le BYOK permet d'utiliser vos propres clés (Azure OpenAI, Anthropic, Ollama) sans passer par le routage GitHub.

Sources:
→ Changelog: Remote control CLI sessions on web and mobile in public preview
→ Changelog: Copilot CLI now supports BYOK and local models

4. JetBrains : mode agent inline, NES amélioré et auto-approbation globale

Le mode agent inline arrive en préversion publique dans JetBrains, apportant les capacités d'agent directement dans le chat inline sans changer de panneau. NES gagne les aperçus d'édition inline et le suivi des modifications distantes. L'auto-approbation globale permet d'automatiser l'ensemble des appels d'outils en une seule option.

→ Changelog: Inline agent mode in preview and more in GitHub Copilot for JetBrains IDEs

5. Visual Studio : mise à jour d'avril 2026

Visual Studio intègre désormais les sessions cloud agent directement depuis l'IDE, avec la sélection Cloud dans le sélecteur d'agent. Un agent débogueur valide les correctifs contre le comportement d'exécution réel. Les agents personnalisés gagnent le niveau utilisateur et l'historique de chat dispose d'un panneau dédié.

→ Changelog: GitHub Copilot in Visual Studio — April update

6. Cloud agent : résolution de conflits de fusion et démarrage 20 % plus rapide

Un bouton "Fix with Copilot" apparaît dans la boîte de fusion sur github.com en cas de conflit : Copilot résout les conflits, vérifie le build et pousse les changements depuis son environnement cloud. En parallèle, le cloud agent démarre désormais 20 % plus vite grâce aux images GitHub Actions personnalisées (après le gain de 50 % en mars).

Sources:
→ Changelog: Fix merge conflicts in three clicks with Copilot cloud agent
→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images

7. Copilot Chat : contexte enrichi pour les pull requests

Copilot Chat intègre une compréhension approfondie des pull requests — commentaires, modifications de fichiers, commits et revues sont inclus dans le contexte. Depuis github.com/copilot ou la navigation globale, vous pouvez demander une revue structurée ou un résumé concis de n'importe quelle PR.

→ Changelog: Copilot Chat improvements for pull requests

8. Sélection de modèle pour les agents Claude et Codex tiers

La sélection de modèle est désormais disponible pour les agents de coding tiers Claude et Codex sur github.com. Choisissez parmi les variantes Sonnet et Opus d'Anthropic (4.5 et 4.6) ou GPT-5.2-Codex, GPT-5.3-Codex et GPT-5.4 pour Codex — avec la même expérience de sélection que le cloud agent natif Copilot.

→ Changelog: Model selection for Claude and Codex agents on github.com
