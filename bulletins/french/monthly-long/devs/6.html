Monthly (Long) #6 · Septembre 2026 · Devs Edition

🎯 Le fil de cette édition

Septembre a été rythmé par une vague de nouveaux modèles et par l'industrialisation des flux agentiques. Côté modèles, le choix s'élargit fortement (familles GPT-6, Claude 5.5, Gemini et Grok), tandis que HydraFusion orchestre plusieurs modèles automatiquement. En parallèle, GitHub renforce l'exécution sûre du code assisté : sandboxing local, exclusions de contenu et revues de code plus intelligentes. Pour les développeurs, la direction est claire : plus de puissance de modèle, mais encadrée par des garde-fous concrets et intégrée directement dans l'IDE, le CLI et le flux de pull request.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in mid-October — Deadline : 19 octobre 2026 — Plusieurs modèles (dont Gemini 3.7 Flash) seront retirés de toutes les expériences Copilot. Basculez vers les alternatives suggérées via le sélecteur de modèle.
  • mai-code-1-flash deprecated — Action requise — Le modèle mai-code-1-flash n'est plus disponible ; vérifiez vos configurations et migrez vers un modèle pris en charge.

🚀 Passez à l'action

  • Testez les nouveaux modèles et choisissez celui adapté à votre tâche depuis le sélecteur de modèle Copilot.
  • Sécurisez vos sessions agentiques locales en configurant les exclusions de contenu pour vos dépôts sensibles.
  • Intégrez Copilot code review à vos pull requests en suivant le guide use Copilot code review.
  • Accélérez votre terminal avec le Copilot CLI et ses capacités d'intelligence de code.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Une vague de nouveaux modèles dans Copilot

Le catalogue s'élargit massivement : GPT-6 Astra passe en disponibilité générale, rejoint par GPT-6 Sol, GPT-6 Luna et GPT-6.1 Sol, Claude Opus 5.5 et Claude Sonnet 5.5, Claude Fable 5.1, Gemini 3.8 Flash et Grok 4.7. De quoi choisir le bon modèle selon la tâche.

2. HydraFusion dans VS Code et l'app Copilot

La preview de recherche HydraFusion s'étend au-delà du CLI, vers VS Code et l'app Copilot. Plutôt qu'un modèle unique, elle orchestre plusieurs modèles et traite la sélection du flux comme un problème d'optimisation, en s'appuyant sur des signaux de capacité.

→ Changelog: HydraFusion in VS Code and the GitHub Copilot app

3. Copilot code review gagne en intelligence

La revue de code Copilot peut désormais approuver des pull requests, propose une auto-résolution et une analyse enrichies, un suivi plus clair de la progression, des messages de commit intelligents, et davantage de façons de demander et configurer les revues.

Sources:
→ Changelog: Copilot code review can now approve pull requests
→ Changelog: Auto-resolution and analysis updates in Copilot code review
→ Changelog: Copilot code review: An improved review experience
→ Changelog: Copilot code review: more ways to request and configure reviews

4. Sandboxing local dans l'app Copilot

Le sandboxing local réduit l'impact de commandes non intentionnelles en limitant l'accès aux fichiers, au réseau et aux identifiants de votre machine. Vous le configurez par projet pour les sessions sur dépôt local, avec contrôle fin du système de fichiers, du réseau et des credentials.

→ Changelog: Local sandboxing in the GitHub Copilot app

5. Exclusions de contenu dans l'app et le CLI

L'app Copilot et le Copilot CLI respectent désormais les politiques d'exclusion de contenu définies par les administrateurs. Copilot n'utilise plus les fichiers exclus comme contexte, ce qui protège le code sensible dans vos flux agentiques, y compris en ligne de commande.

→ Changelog: Content exclusions generally available in Copilot app and CLI

6. Intelligence de code C++ plus rapide via l'indexation complète

Le Copilot CLI prend en charge l'indexation de l'ensemble du code pour le C++. Sur des dépôts de millions de lignes, cet index réutilisable accélère la recherche de définitions, de références et la compréhension du projet, sans redécouvrir les informations à chaque navigation.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

7. Nouveautés de Copilot pour JetBrains

Copilot pour JetBrains reçoit un lot de nouveautés : nouvelles fonctionnalités, améliorations de l'expérience utilisateur et de la qualité, et un bac à sable managé pour l'entreprise. De quoi rapprocher l'expérience JetBrains des autres IDE.

Sources:
→ Changelog: New features and improvements in Copilot for JetBrains
→ Changelog: Enterprise managed sandbox in Copilot for JetBrains

8. L'autofix agentique s'appuie sur Copilot Memory

L'autofix agentique exploite désormais Copilot Memory : il consulte les mémoires existantes pour contextualiser la résolution d'alertes de sécurité, puis enregistre les correctifs comme mémoires réutilisables pour accélérer les corrections futures.

→ Changelog: Agentic autofix now uses Copilot Memory
