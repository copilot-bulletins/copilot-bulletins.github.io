Monthly (Long) #4 · Juin 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

En juin, Copilot a franchi un cap : d'assistant de code, il devient une plateforme agentique sur laquelle standardiser. Un poste de travail dédié, un moteur embarquable et des workflows automatisés placent l'agent au cœur du développement, tandis que l'offre de modèles reste à la frontière technologique.

Pour les décideurs, l'enjeu devient la valeur mesurable : de nouveaux indicateurs d'adoption et des budgets par centre de coûts permettent enfin de prouver le retour sur investissement et d'en maîtriser la dépense.

⚠️ Attention

  • Facturation à l'usage désormais active et revue de code décomptée en minutes GitHub Actions — Action requise — anticipez l'impact budgétaire avec la facturation à l'usage pour les organisations et entreprises.
  • GPT-5.2 et GPT-5.2-Codex retirés de Copilot — Effectif : 5 juin 2026 — comme pour GPT-4.1 et Opus 4.6 (fast), assurez-vous que vos équipes sont passées à un modèle pris en charge.

🚀 Passez à l'action

  • Téléchargez et évaluez l'app GitHub Copilot pour offrir à vos équipes un poste de travail dédié à l'agentique.
  • Pilotez le ROI : suivez l'adoption avec les métriques d'usage Copilot et cadrez la dépense via des budgets par centre de coûts.
  • Donnez accès aux derniers modèles en les activant depuis la liste des modèles pris en charge.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. L'app GitHub Copilot, un poste de travail natif pour l'agentique

L'app GitHub Copilot passe en disponibilité générale sur macOS, Windows et Linux. Pensée pour le développement piloté par agents, elle offre un point d'entrée dédié, signe du basculement de Copilot vers une expérience agent-native au cœur des équipes.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

2. Une plateforme agentique ouverte et automatisable

Le SDK Copilot devient GA : les entreprises peuvent intégrer le moteur agentique de Copilot dans leurs propres applications. En parallèle, les Agentic Workflows (préversion publique) et la planification du cloud agent automatisent triage, analyse de CI et documentation.

Sources:
→ Changelog: Copilot SDK is now generally available
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Schedule and automate tasks with Copilot cloud agent

3. Mesurer l'adoption, gouverner les coûts

La mesure du ROI se renforce : les rapports couvrent plus d'utilisateurs actifs, l'API expose les crédits IA par personne et les fusions de PR par phase d'adoption. Des budgets de crédits IA par utilisateur s'appliquent aux centres de coûts.

Sources:
→ Changelog: Copilot usage metrics now include more of your active users
→ Changelog: AI credits consumed per user now in the Copilot usage metrics API
→ Changelog: Track total merges by adoption phase in enterprise and organization reports
→ Changelog: Per-user AI credit budgets available for cost centers

4. Le choix des modèles à la frontière

Copilot élargit son catalogue de modèles de pointe : Claude Sonnet 5 en disponibilité générale, Claude Opus 4.8 (fast) en préversion, MAI-Code-1-Flash de Microsoft et deux modèles Gemini. Ce choix évite la dépendance à un fournisseur unique.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: MAI-Code-1-Flash is now available for GitHub Copilot
→ Changelog: Gemini models in Copilot CLI, cloud agent, and the Copilot app

5. Copilot code review : un investissement soutenu

GitHub accélère sur la revue de code automatisée : analyse plus efficace en coût, prise en charge des fichiers AGENTS.md, nouveaux contrôles d'organisation et préversion technique pour Azure Repos. De quoi maintenir la qualité au rythme du code généré par IA.

Sources:
→ Changelog: Copilot code review: Analysis depth and efficiency updates
→ Changelog: Copilot code review: New configurations and controls
→ Changelog: Copilot code review: AGENTS.md support and UI improvements
→ Changelog: GitHub Copilot code review for Azure Repos is now in technical preview

6. GitHub Copilot for Jira en disponibilité générale

Copilot for Jira passe en disponibilité générale. Depuis la préversion de mars, l'intégration a gagné la sélection de modèles et d'autres améliorations. Les équipes délèguent des tâches au cloud agent depuis Jira, là où le travail est planifié.

→ Changelog: GitHub Copilot for Jira is now generally available

7. Plus de valeur par crédit

Copilot optimise la gestion du contexte et le routage des modèles pour que chaque crédit produise plus de travail utile. S'y ajoutent des fenêtres de contexte élargies et des niveaux de raisonnement configurables : davantage de performance à budget maîtrisé.

Sources:
→ Blog: Getting more from each token: How Copilot improves context handling and model routing
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot

8. La preuve par l'usage : un agent d'analytique interne

GitHub détaille Qubot, son agent d'analytique propulsé par Copilot qui permet à tout collaborateur d'interroger les données en langage naturel. Un cas concret d'agents qui transforment l'accès à l'information en valeur métier.

→ Blog: How we built an internal data analytics agent
