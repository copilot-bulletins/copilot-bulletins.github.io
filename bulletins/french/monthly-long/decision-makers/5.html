Monthly (Long) #5 · Juillet 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

Juillet confirme une trajectoire claire : GitHub industrialise l'IA en entreprise. Le mois est marqué par une explosion du choix de modèles, une gouvernance des coûts renforcée et une nouvelle génération de métriques d'impact mesurant le retour sur investissement. En parallèle, la revue de code et la sécurité passent en disponibilité générale, et l'application GitHub Copilot s'ouvre à tous. Pour les décideurs, le signal est net : Copilot devient une plateforme mesurable, gouvernable et pilotable financièrement, prête à un déploiement à l'échelle avec des garde-fous et des indicateurs de valeur concrets.

⚠️ Attention

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Date limite : 31 juillet 2026 — Ces modèles sont retirés ; basculez vos équipes vers les modèles récents via la référence des modèles pris en charge.
  • Copilot Billing Preview app will be retired on August 3 — Date limite : 3 août 2026 — Migrez vers l'expérience de facturation standard et vérifiez vos paramètres de facturation.

🚀 Passez à l'action

  • Alignez votre stratégie de modèles et définissez une politique d'entreprise via la gestion pour l'entreprise et la liste des modèles pris en charge.
  • Mesurez le ROI de votre déploiement avec les métriques d'usage en configurant la gestion pour l'organisation.
  • Activez la revue de code Copilot pour accélérer vos cycles qualité — voir la documentation de la revue de code.
  • Maîtrisez vos dépenses IA en structurant vos centres de coûts et votre facturation.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Un choix de modèles sans précédent

Copilot élargit massivement son catalogue avec Claude Opus 5, GPT-5.6, Grok 4.5, Gemini 3.6 Flash et Kimi K2.7. Cette diversité réduit la dépendance à un fournisseur unique et permet d'aligner performance, coût et cas d'usage à l'échelle de l'entreprise.

→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot
→ Changelog: Gemini 3.6 Flash is now available in GitHub Copilot
→ Changelog: Kimi K2.7 Code is generally available in GitHub Copilot

2. Mesurer l'impact réel de Copilot

Un nouveau tableau de bord d'impact et des métriques d'usage plus fiables et détaillées offrent enfin une lecture claire de l'adoption et de la valeur générée. Les décideurs disposent d'indicateurs vérifiables pour justifier et étendre leurs investissements.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: Add review cycles and time to adoption phases in the usage API

3. La revue de code Copilot passe à l'échelle

Les compétences d'agent et le support MCP de la revue de code Copilot sont désormais en disponibilité générale, complétés par de nouvelles options de personnalisation. Un levier direct pour améliorer la qualité et raccourcir les cycles de livraison.

Sources:
→ Changelog: Copilot code review: Agent skills and MCP now generally available
→ Changelog: Copilot code review: Customization and configurability improvements

4. L'application GitHub Copilot ouverte à tous

L'application GitHub Copilot est désormais accessible à l'ensemble des utilisateurs. Cette généralisation abaisse la barrière d'entrée et accélère l'adoption transversale au sein des organisations, un facteur clé pour maximiser la valeur du déploiement.

→ Changelog: GitHub Copilot app available to all

5. Sécurité renforcée par l'IA

Les corrections agentiques pour les alertes de code scanning entrent en préversion publique et les revues de sécurité arrivent dans l'application Copilot. L'IA passe de la détection à la remédiation, réduisant l'exposition au risque et la charge des équipes sécurité.

Sources:
→ Changelog: Agentic autofix for code scanning alerts in public preview
→ Changelog: Security reviews now available in the GitHub Copilot app

6. Gouvernance financière de l'IA

Pools de crédits IA, budgets par utilisateur et plafonds d'usage : les centres de coûts s'enrichissent d'outils FinOps concrets. Les organisations peuvent piloter la dépense IA avec précision et éviter les dérives budgétaires.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: Cost centers now support included usage caps

7. Gouvernance des modèles pour l'entreprise

Les entreprises peuvent désormais définir la sélection automatique de modèle par défaut, activer des modèles par défaut et cibler des politiques de modèles par équipe. Un contrôle centralisé qui concilie liberté des développeurs et cadrage stratégique.

Sources:
→ Changelog: Enterprises can default to auto model selection
→ Changelog: Default model enablement for Copilot Business and Enterprise
→ Changelog: Enterprise teams model policy targeting in public preview

8. L'agentique s'étend à vos outils

Le Copilot cloud agent pour Linear passe en disponibilité générale, les contrôles d'automatisation d'agents arrivent dans GitHub Issues et le streaming de session entre en préversion. Copilot s'intègre au cœur des flux de travail d'entreprise.

Sources:
→ Changelog: Copilot cloud agent for Linear is now generally available
→ Changelog: Agent automation controls in GitHub Issues in public preview
→ Changelog: Copilot agent session streaming is now in public preview
