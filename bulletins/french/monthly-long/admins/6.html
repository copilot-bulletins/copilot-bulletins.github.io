Monthly (Long) #6 · Septembre 2026 · Admins Edition

🎯 Le fil de cette édition

Septembre a placé la gouvernance au cœur de Copilot. Les équipes d'administration gagnent un contrôle plus fin : permissions centralisées des agents, paramètres gérés par l'entreprise et politique d'activation par défaut encadrent désormais le déploiement à grande échelle. En parallèle, l'observabilité progresse nettement, avec des métriques d'usage enrichies et un tableau de bord d'impact plus lisible pour piloter l'adoption. La revue de code et la maîtrise des coûts poursuivent leur montée en maturité. Pour les administrateurs, le message est clair : outiller l'adoption tout en gardant la main sur la sécurité, la conformité et la dépense.

⚠️ Attention

  • Dépréciation de certains modèles Copilot à la mi-octobre — Date limite : 19 octobre 2026 — Ces modèles seront retirés de toutes les expériences Copilot (chat, édition inline, modes ask et agent, complétions). Informez vos équipes et vérifiez votre modèle par défaut dans vos politiques Copilot.

🚀 Passez à l'action

  • Révisez vos politiques Copilot au niveau de l'entreprise avant l'arrivée de la nouvelle politique d'activation par défaut.
  • Configurez les exclusions de contenu, désormais respectées par l'app Copilot et la CLI.
  • Pilotez l'adoption grâce aux métriques d'usage Copilot et au tableau de bord d'impact.
  • Maîtrisez la dépense avec les budgets et le suivi des coûts.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Permissions centralisées des opérations d'agents

Les administrateurs Copilot Business et Enterprise peuvent désormais contrôler centralement quelles opérations d'agents sont bloquées, nécessitent une approbation humaine ou s'exécutent sans invite. Un levier clé pour encadrer l'autonomie des agents à l'échelle de l'organisation.

→ Changelog: Enterprise managed permissions for GitHub Copilot agent operations

2. Activation par défaut des fonctionnalités Copilot

Une nouvelle politique globale active par défaut les fonctionnalités Copilot en disponibilité générale pour Business et Enterprise. Vous disposez d'une fenêtre de 28 jours pour ajuster les réglages avant leur prise d'effet — vérifiez vos paramètres dès maintenant.

→ Changelog: Default Enablement of Copilot features for Copilot Business and Enterprise

3. Copilot code review gagne en maturité

La revue de code franchit un cap pour les admins : Copilot peut approuver les pull requests (sur autorisation), auto-résout et analyse mieux les commentaires, offre une expérience de revue améliorée et de nouvelles options de configuration avec un réglage par défaut au niveau entreprise.

Sources:
→ Changelog: Copilot code review can now approve pull requests
→ Changelog: Auto-resolution and analysis updates in Copilot code review
→ Changelog: Copilot code review, an improved review experience
→ Changelog: Copilot code review, more ways to request and configure reviews

4. Des métriques d'usage plus riches

L'observabilité progresse : l'API de métriques détaille le temps passé à chaque étape de revue des PR, intègre l'activité des agents VS Code et les personnalisations de la CLI agentique, tandis que le tableau de bord d'impact révèle l'engagement réel sur chaque fonctionnalité.

Sources:
→ Changelog: Usage metrics API adds pull request review stages
→ Changelog: Add VS Code agents to Copilot usage metrics
→ Changelog: Agentic CLI customizations now in the usage metrics API
→ Changelog: Copilot impact dashboard now shows feature engagement

5. Paramètres gérés par l'entreprise renforcés

Les enterprise managed settings s'étoffent : définissez n'importe quel modèle comme défaut pour les nouvelles conversations, validez votre configuration via un validateur intégré qui détecte JSON malformé et mappages d'équipes invalides, et gérez le sandbox dans Copilot pour JetBrains.

Sources:
→ Changelog: Enterprise managed settings support any default model
→ Changelog: Enterprise managed settings in product validator
→ Changelog: Enterprise managed sandbox in Copilot for JetBrains

6. Contrôle plus souple des budgets

La gestion des coûts s'affine : fixez une date d'expiration optionnelle sur un budget individuel, automatiquement supprimé à l'échéance. Et lorsqu'un membre épuise ses crédits, un flux de demande d'augmentation de budget, désormais en disponibilité générale, évite le blocage.

Sources:
→ Changelog: Set an expiration date for individual user budgets
→ Changelog: Copilot budget increase requests are generally available

7. Exclusions de contenu dans l'app Copilot et la CLI

L'app GitHub Copilot et la Copilot CLI respectent désormais les politiques d'exclusion de contenu définies par les administrateurs d'entreprise, d'organisation et de dépôt. Une couverture étendue pour protéger les fichiers sensibles sur davantage de surfaces.

→ Changelog: Content exclusions generally available in Copilot app and CLI

8. Agentic autofix s'appuie sur Copilot Memory

Pour les clients ayant activé Copilot Memory, l'agentic autofix exploite désormais les mémoires existantes afin de mieux contextualiser et résoudre les alertes de sécurité. Des corrections plus pertinentes, alignées sur les pratiques de votre organisation.

→ Changelog: Agentic autofix now uses Copilot Memory
