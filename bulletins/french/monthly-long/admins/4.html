Monthly (Long) #4 · Juillet 2026 · Admins Edition

🎯 Le fil de cette édition

Juillet a placé la gouvernance au cœur de Copilot. Les administrateurs disposent de leviers plus fins pour piloter les modèles, propager des paramètres managés via MDM et encadrer l'accès à l'app GitHub Copilot. En parallèle, la mesure de l'adoption franchit un cap : métriques d'usage plus précises, tableau de bord d'impact et gestion des coûts par centre de coûts et crédits IA. Le message est clair : outiller le déploiement à grande échelle tout en gardant la maîtrise des dépenses, de la sécurité et de la conformité.

⚠️ Attention

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Action requise — Ces modèles ne sont plus disponibles ; vérifiez vos politiques de modèles et basculez vos utilisateurs vers les modèles pris en charge dans vos paramètres de disponibilité des modèles.
  • Copilot Billing Preview app will be retired on August 3 — Échéance : 3 août 2026 — Migrez vers les fonctionnalités de facturation intégrées et vérifiez vos contrôles budgétaires.

🚀 Passez à l'action

  • Affinez vos règles de modèles au niveau organisation dans vos politiques Copilot.
  • Standardisez la configuration de vos postes avec les paramètres managés d'entreprise.
  • Suivez l'adoption et l'impact via les métriques d'usage Copilot.
  • Maîtrisez vos dépenses avec les contrôles budgétaires par centre de coûts.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Gouvernance des modèles à l'échelle de l'entreprise

Le contrôle des modèles se précise : ciblage des politiques par équipe d'entreprise, activation par défaut des nouveaux modèles pour Business et Enterprise, et sélection automatique du modèle par défaut. Les administrateurs gardent la main sur ce que leurs équipes utilisent.

Sources:
→ Changelog: Enterprise teams model policy targeting in public preview
→ Changelog: Default model enablement for Copilot Business and Enterprise
→ Changelog: Enterprises can default to auto model selection

2. Paramètres managés et déploiement MDM

Le fichier managed-settings.json d'entreprise passe en GA et se déploie via MDM dans VS Code et le CLI. Ces paramètres s'appliquent aussi à l'app GitHub Copilot et à l'agent cloud, pour une configuration cohérente et centralisée du parc.

Sources:
→ Changelog: Enterprise managed-settings.json is generally available
→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI
→ Changelog: Enterprise managed settings in the GitHub Copilot app and Copilot cloud agent

3. Métriques d'usage et d'adoption enrichies

Les métriques franchissent un cap : nouveau tableau de bord d'impact, métriques par dépôt en GA, et cycles de revue et délais d'adoption exposés dans l'API d'usage. De quoi mesurer la valeur et cibler vos actions d'enablement.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: Add review cycles and time to adoption phases in the usage API

4. Gouvernance des coûts et crédits IA

La maîtrise des dépenses s'outille : pools de crédits IA et budgets par utilisateur pour les centres de coûts, et visibilité pour chaque utilisateur sur les crédits IA consommés par cycle. Un cadre plus fin pour piloter le coût de Copilot.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: Copilot users can now see AI credits used per billing cycle

5. Copilot code review : compétences, MCP et personnalisation en GA

La revue de code Copilot mûrit : compétences d'agent et support MCP passent en GA, complétés par des options de personnalisation. Les organisations adaptent la revue automatisée à leurs standards de qualité et de conformité.

Sources:
→ Changelog: Copilot code review: Agent skills and MCP now generally available
→ Changelog: Copilot code review: Customization and configurability improvements

6. Sécurité : autofix agentique et revues de sécurité

La sécurité progresse : l'autofix agentique pour les alertes de code scanning entre en préversion publique, et des revues de sécurité arrivent dans l'app GitHub Copilot. Deux leviers pour réduire la dette de sécurité au plus près du code.

Sources:
→ Changelog: Agentic autofix for code scanning alerts in public preview
→ Changelog: Security reviews now available in the GitHub Copilot app

7. Contrôle des accès à l'app et aux appareils

L'app GitHub Copilot devient disponible pour tous, et son accès se gouverne via une politique dédiée. Le contrôle à distance peut être restreint aux terminaux managés, renforçant la conformité des usages agentiques.

Sources:
→ Changelog: Manage GitHub Copilot app access with a dedicated policy
→ Changelog: GitHub Copilot app available to all
→ Changelog: Limit remote control to managed devices

8. Observabilité : export OpenTelemetry managé

L'export OpenTelemetry managé arrive pour VS Code et le CLI, et JetBrains améliore sa configuration OpenTelemetry. Les administrateurs peuvent centraliser la télémétrie Copilot dans leurs outils d'observabilité existants pour un suivi conforme.

Sources:
→ Changelog: Enterprise-managed OpenTelemetry export for VS Code and CLI
→ Changelog: GitHub Copilot for JetBrains adds improved OpenTelemetry configuration and model management
