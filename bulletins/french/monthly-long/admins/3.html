Monthly (Long) #3 · Avril 2026 · Admins Edition

🎯 Le fil de cette édition

Avril 2026 marque une étape décisive pour les administrateurs Copilot. La résidence des données US/EU et la conformité FedRAMP passent en disponibilité générale, offrant les fondations d'un déploiement conforme aux réglementations les plus strictes. La revue de code Copilot atteint la GA avec plus d'un million d'utilisateurs, tandis que les métriques d'adoption s'étendent à l'ensemble des surfaces — cloud agent, CLI, revue de code. De nouveaux modèles et capacités agentiques élargissent le périmètre à piloter, transformant Copilot d'un outil à activer en une plateforme à gouverner avec rigueur et confiance.

⚠️ Attention

  • Enforcing new limits and retiring Opus 4.6 Fast from Copilot Pro+ — Retrait immédiat — Le modèle Opus 4.6 Fast est retiré des abonnements Copilot Pro+. Utilisez Opus 4.6 comme alternative ; de nouveaux plafonds d'utilisation sont progressivement appliqués sur tous les plans.
  • Pausing new GitHub Copilot Pro trials — Action requise — Les nouveaux essais Copilot Pro sont suspendus en raison d'abus détectés. Orientez les nouveaux utilisateurs vers Copilot Free ou un abonnement payant en attendant le rétablissement.
  • GitHub Copilot code review will start consuming GitHub Actions minutes on June 1, 2026 — Deadline : 1er juin 2026 — Chaque revue de code Copilot consommera des minutes GitHub Actions sur dépôts privés à partir du 1er juin. Vérifiez vos quotas et configurez vos budgets de dépenses avant cette date.

🚀 Passez à l'action

  • Activez la résidence des données (US ou EU) ou la conformité FedRAMP depuis la documentation de résidence des données Copilot de votre entreprise.
  • Anticipez le changement de facturation de la revue de code : vérifiez vos quotas GitHub Actions et configurez vos budgets et limites de dépenses avant le 1er juin 2026.
  • Activez la politique GPT-5.5 dans les paramètres AI controls de votre entreprise pour donner accès à ce modèle avancé à vos équipes.
  • Activez la politique « Remote Control » pour permettre à vos utilisateurs de piloter leurs sessions CLI à distance.
  • Des questions ou besoin d'aide ? Contactez votre équipe GitHub, nous sommes là pour vous accompagner.

🏆 Top 8 des mises à jour du mois

1. Résidence des données US/EU et conformité FedRAMP : disponibilité générale

La résidence des données garantit que tous les traitements d'inférence Copilot restent dans votre région désignée — US ou EU. Les clients gouvernementaux américains bénéficient également de la conformité FedRAMP Moderate. Les politiques s'activent depuis les paramètres Copilot de l'entreprise, avec une majoration de 10 % sur le multiplicateur de requêtes premium.

→ Changelog: Copilot data residency in US + EU and FedRAMP compliance now available

2. Métriques d'adoption Copilot : vue unifiée sur le cloud agent, la revue de code et le CLI

Quatre mises à jour d'analytics en avril unifient la vue administrateur : comptages d'utilisateurs actifs du cloud agent (quotidiens, hebdomadaires, mensuels), métriques de fusion pour les PR révisées par Copilot, et activité CLI intégrée aux totaux de haut niveau. Les tableaux de bord couvrent désormais l'ensemble du cycle de vie Copilot sans agrégation manuelle.

Sources:
→ Changelog: Copilot usage metrics now aggregate Copilot cloud agent active user counts
→ Changelog: Copilot-reviewed pull request merge metrics now in the usage metrics API
→ Changelog: Copilot CLI activity now included in usage metrics totals and feature breakdowns
→ Changelog: Copilot cloud agent fields added to usage metrics

3. La revue de code Copilot passe en disponibilité générale

Disponible sur GitHub.com, VS Code, Visual Studio, Xcode et JetBrains, la revue de code Copilot détecte bugs et problèmes de performance, et suggère des correctifs en moins de 30 secondes. Les organisations Business/Enterprise l'activent via la politique « Copilot in github.com ». Plus d'un million de développeurs l'ont déjà utilisée depuis la preview.

→ Changelog: Copilot code review is now generally available

4. GPT-5.5 : le modèle d'OpenAI le plus avancé, désormais disponible sur Copilot

GPT-5.5 est désormais disponible en GA sur GitHub Copilot avec un multiplicateur promotionnel de 7,5×. Ce modèle excelle sur les tâches agentiques complexes et multi-étapes. Les administrateurs Enterprise et Business doivent activer la politique GPT-5.5 dans les paramètres Copilot pour en autoriser l'accès.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

5. Le cloud agent s'étend au-delà des pull requests : recherche, planification et code

Le cloud agent n'est plus limité aux workflows pull request. Il peut désormais travailler sur une branche sans créer de PR, générer un plan d'implémentation avant d'écrire du code, ou mener une recherche approfondie dans la base de code. Les administrateurs doivent activer le cloud agent depuis les paramètres d'entreprise.

→ Changelog: Research, plan and code with Copilot cloud agent

6. Sélection de modèle pour les agents tiers Claude et Codex

Comme le cloud agent Copilot, les agents tiers Claude (Anthropic) et Codex (OpenAI) supportent désormais la sélection de modèle sur github.com. Les administrateurs Business/Enterprise doivent activer la politique correspondante depuis les paramètres AI controls de l'entreprise pour en autoriser l'accès aux utilisateurs.

→ Changelog: Model selection for Claude and Codex agents on github.com

7. Contrôle à distance des sessions Copilot CLI depuis le web et le mobile

Les utilisateurs peuvent piloter une session Copilot CLI en cours depuis GitHub.com ou l'app mobile GitHub (public preview). Pour les équipes Business/Enterprise, les administrateurs doivent activer la politique « Remote Control » (désactivée par défaut) depuis les paramètres d'administration du CLI.

→ Changelog: Remote control CLI sessions on web and mobile in public preview

8. Cloud agent 40 % plus rapide : validation parallèle et démarrage optimisé

Deux améliorations successives réduisent significativement les délais du cloud agent : les outils de validation (CodeQL, secret scanning, revue de code) s'exécutent désormais en parallèle (−20 % sur la validation), et l'environnement cloud démarre plus de 20 % plus vite grâce aux images Actions personnalisées.

Sources:
→ Changelog: Copilot cloud agent's validation tools are now 20% faster
→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images
