Monthly (Long) #7 · Octobre 2026 · Admins Edition

🎯 Le fil de cette édition

Octobre marque un tournant dans le pilotage de Copilot : le modèle de licence se simplifie autour d'un budget d'usage unique, tandis que les contrôles centralisés s'étendent aux postes des développeurs, aux plugins et aux identités applicatives.

En parallèle, la mesure gagne en précision : les rapports couvrent désormais davantage d'outils, nomment vos personnalisations internes et permettent de vous comparer à vos pairs. Pour les administrateurs, l'enjeu est clair : revoir les politiques par défaut, encadrer l'autonomie croissante des agents et s'appuyer sur des données fiables pour piloter l'adoption.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Échéance : 16 novembre 2026 — Claude Opus 4.8, Claude Opus 5 et GPT-5.6 Terra seront retirés. Vérifiez que les alternatives sont activées dans vos politiques de modèles.
  • Update your IDE to restore agent activity in Copilot usage metrics — Action requise — L'activité agent de certains IDE n'était plus comptabilisée. Demandez à vos équipes de mettre à jour leurs IDE (déploiement des correctifs d'ici novembre 2026) avant d'analyser vos métriques d'usage.

🚀 Passez à l'action

  • Vérifiez votre politique « Default policy for new features », désormais appliquée aux fonctionnalités non configurées, en consultant la documentation sur la disponibilité par défaut.
  • Imposez ou bloquez des plugins, le sandboxing et les modes de permission via les paramètres gérés par l'entreprise.
  • Auditez les GitHub Apps autorisées à consommer le Copilot de votre organisation avec le guide Manage GitHub Apps that use your organization's Copilot.
  • Exploitez les nouveaux champs totals_by_client et les personnalisations nommées décrits dans les données disponibles des métriques d'usage.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 8 des mises à jour du mois

1. Copilot inclus dans GitHub Enterprise

Les entreprises accompagnées par une équipe GitHub ou Microsoft peuvent inclure Copilot pour chaque utilisateur licencié GitHub Enterprise. Fini la double gestion sièges/consommation : seul le budget d'usage IA de l'entreprise est à piloter. La complétion de code reste disponible même budget épuisé.

→ Changelog: GitHub Enterprise now includes access to GitHub Copilot

2. Paramètres gérés : plugins, permissions et sandboxing sous contrôle

Les administrateurs peuvent imposer ou bloquer des plugins et restreindre les marketplaces, encadrer les permissions assistées, exiger le sandboxing local (désormais GA) et forcer le rafraîchissement des politiques au démarrage des clients. Les paramètres gérés priment sur les choix locaux.

Sources:
→ Changelog: Repository plugin defaults and enterprise plugin controls generally available
→ Changelog: GitHub Copilot assisted permissions generally available
→ Changelog: Local sandboxing for GitHub Copilot now generally available
→ Changelog: Enterprise managed settings enforcement updates

3. Politiques de fonctionnalités et de modèles : défaut global et API

La politique par défaut globale est appliquée depuis le 26 octobre aux fonctionnalités GA non configurées ; vos choix explicites sont préservés. Une nouvelle API REST (GET/PATCH) permet aussi d'automatiser les politiques de modèles aux niveaux entreprise, équipes, apps et organisations.

Sources:
→ Changelog: Global default for Copilot features generally available
→ Changelog: Copilot model policy API for enterprise, orgs, and teams

4. Métriques d'usage plus complètes et comparaisons sectorielles

L'API de métriques couvre désormais des outils tiers comme OpenCode, Claude Code ou Codex, et affiche le nom de vos skills, agents et serveurs MCP internes. Le tableau de bord d'impact propose des comparaisons sectorielles anonymisées, sur la base du volontariat.

Sources:
→ Changelog: Usage metrics API adds usage from tools like OpenCode
→ Changelog: Custom skills, agents, and MCP servers in usage metrics API
→ Changelog: Industry comparisons in the Copilot impact dashboard

5. Copilot code review : Max, approbations et contrôle de facturation

Le niveau d'effort Max (preview) combine plusieurs modèles pour les changements critiques, et Copilot peut désormais approuver une pull request (GA). Les organisations peuvent facturer les revues à leur centre de coûts et lancer des revues via API.

Sources:
→ Changelog: Copilot code review: Merge with confidence with Max and approvals
→ Changelog: Copilot code review: New organization billing options and controls
→ Changelog: Copilot code review: API support and new default effort level

6. Sécurité : détection de secrets par IA et remédiation agentique

Un modèle dédié détecte les identifiants non structurés, avec push protection IA en private preview. L'autofix agentique des alertes code scanning est GA et valide ses correctifs via CodeQL. Une extension sécurité arrive dans l'app Copilot.

Sources:
→ Changelog: Purpose-built model for leaked secret detection
→ Changelog: Agentic autofix for code scanning alerts general availability
→ Changelog: Security extension for the GitHub Copilot app

7. Authentification serveur à serveur pour les GitHub Apps

En public preview, les services bâtis sur le Copilot SDK peuvent agir pour une organisation sans identifiants utilisateur. L'usage est attribué et facturé à l'organisation, soumis à ses politiques et budgets, et traçable via le champ app_client_id.

→ Changelog: GitHub Copilot supports server-to-server authentication

8. Automatisations encadrées : limites de coûts et Agentic Workflows GA

Copilot Automations ajoute des plafonds de crédits IA par exécution, jour, semaine ou mois, ainsi que de nouveaux déclencheurs. GitHub Agentic Workflows passe en GA et réutilise vos runners et contraintes de politiques GitHub Actions existants.

Sources:
→ Changelog: New tools, triggers, and cost controls for Copilot Automations
→ Changelog: GitHub Agentic Workflows generally available

📊 Le mois en chiffres

  • 24 nouveaux déclencheurs et 20 nouveaux outils GitHub disponibles pour Copilot Automations
  • 25 entrées par rapport pour les personnalisations dans l'API de métriques, contre cinq auparavant
