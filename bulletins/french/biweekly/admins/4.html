Biweekly #4 · Du 15 avril au 30 avril 2026 · Admins Edition

🎯 Le fil de cette édition

Cette quinzaine marque un tournant dans la gouvernance financière de Copilot : la revue de code commencera à consommer des minutes GitHub Actions dès le 1er juin. Simultanément, deux nouveaux modèles — GPT-5.5 et Claude Opus 4.7 — exigent une activation explicite par les administrateurs, consolidant leur rôle clé dans le contrôle des capacités IA à l'échelle de l'organisation.

⚠️ Attention

  • La revue de code Copilot va consommer des minutes GitHub Actions à partir du 1er juin 2026 — Deadline : 1er juin 2026 — Vérifiez vos budgets GitHub Actions et ajustez vos paramètres de runners via la documentation dédiée.

🚀 Passez à l'action

  • Configurez vos budgets GitHub Actions avant le 1er juin pour anticiper la facturation des revues de code Copilot sur dépôts privés.
  • Activez GPT-5.5 et Claude Opus 4.7 dans vos paramètres de politique de modèles Copilot pour donner accès à vos équipes.
  • Mettez à jour vos intégrations pour adopter le nouveau champ used_copilot_cloud_agent disponible dans les métriques d'utilisation Copilot.
  • Des questions ou besoin d'aide ? Contactez votre équipe GitHub, nous sommes là pour vous accompagner.

🏆 Top 5 des mises à jour

1. La revue de code Copilot consommera des minutes GitHub Actions à partir du 1er juin 2026

À partir du 1er juin 2026, chaque revue de code Copilot sur des dépôts privés consommera des minutes GitHub Actions en plus des crédits IA. Les administrateurs doivent vérifier leurs budgets, ajuster les paramètres de runners et sensibiliser leurs équipes avant cette date.

→ Changelog: GitHub Copilot code review will start consuming GitHub Actions minutes on June 1, 2026

2. Nouvelles métriques d'adoption pour l'agent cloud Copilot

L'API des métriques d'utilisation Copilot intègre désormais un champ used_copilot_cloud_agent dans les rapports par utilisateur. Ce champ booléen reflète le renommage de l'agent et coexiste avec l'ancien champ used_copilot_coding_agent, maintenu jusqu'au 1er août 2026 pour assurer la rétrocompatibilité.

→ Changelog: Copilot cloud agent fields added to usage metrics

3. GPT-5.5 disponible pour GitHub Copilot

GPT-5.5, le dernier modèle OpenAI, est désormais disponible pour les plans Copilot Pro+, Business et Enterprise. Conçu pour les tâches agentiques complexes et multi-étapes, il nécessite une activation explicite de la politique GPT-5.5 par les administrateurs dans les paramètres Copilot.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

4. Claude Opus 4.7 disponible pour GitHub Copilot

Claude Opus 4.7, le dernier modèle Anthropic, est en déploiement pour les plans Pro+, Business et Enterprise. Plus performant sur les tâches agentiques longues, il remplacera progressivement Opus 4.5 et 4.6. Les administrateurs doivent activer la politique correspondante dans les paramètres Copilot.

→ Changelog: Claude Opus 4.7 is generally available

5. L'agent cloud Copilot démarre 20% plus vite grâce aux images Actions personnalisées

Grâce à des environnements de runners préconfigurés avec des images personnalisées GitHub Actions, l'agent cloud Copilot démarre désormais 20% plus rapidement. Cumulé à l'amélioration de 50% obtenue en mars, le délai avant que l'agent commence à travailler sur le code continue de se réduire significativement.

→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images
