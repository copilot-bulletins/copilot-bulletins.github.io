Biweekly #9 · Du 1er juillet au 14 juillet 2026 · Admins Edition

🎯 Le fil de cette édition

Cette quinzaine confirme une orientation nettement axée gouvernance d'entreprise. GitHub a industrialisé le contrôle centralisé de Copilot : configuration managée déployable à grande échelle, télémétrie encadrée, budgets par utilisateur et revues de sécurité intégrées. Pour les administrateurs, l'enjeu passe de l'activation à la maîtrise — standardiser les politiques, tracer l'usage et cadrer les coûts sans friction pour les équipes.

⚠️ Attention

  • Dépréciation prochaine de Gemini 2.5 Pro et Gemini 3 Flash — Échéance : 31 juillet 2026 — Ces modèles seront retirés de toutes les expériences Copilot. Vérifiez vos politiques de modèles dans la gestion de la disponibilité des modèles.
  • Retrait de l'application Copilot Billing Preview — Échéance : 3 août 2026 — Basculez votre suivi des dépenses vers l'interface de facturation native et les budgets d'usage.

🚀 Passez à l'action

  • Standardisez vos règles d'entreprise via le fichier managed-settings.json.
  • Cadrez les dépenses avec les budgets d'usage et des budgets par utilisateur.
  • Activez les revues de sécurité Copilot pour vos équipes.
  • Révisez vos politiques d'entreprise avant les échéances de dépréciation.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. La configuration managée d'entreprise passe en disponibilité générale

Les clients GitHub Enterprise Cloud peuvent définir leurs standards d'IA via un fichier managed-settings.json maintenu dans un dépôt .github-private. Un point de contrôle unique pour appliquer gouvernance et politiques Copilot à toute l'organisation, désormais production-ready.

→ Changelog: Enterprise managed-settings.json is generally available

2. Déploiement des paramètres Copilot managés via MDM

Les administrateurs peuvent désormais distribuer les paramètres Copilot managés directement aux postes via la gestion native des appareils (MDM) et la configuration par fichier, en complément du canal serveur. Idéal pour appliquer vos standards jusque sur les machines des développeurs.

→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI

3. Export OpenTelemetry managé par l'entreprise

Les organisations peuvent imposer la destination des données OpenTelemetry de Copilot, vers un collecteur approuvé, sans que chaque développeur configure les variables OTEL_*. Une télémétrie centralisée et conforme pour mesurer l'usage et alimenter vos tableaux de bord d'observabilité.

→ Changelog: Enterprise-managed OpenTelemetry export for VS Code and CLI

4. Budgets par utilisateur pour les centres de coûts

Les administrateurs d'entreprise peuvent créer des budgets au niveau utilisateur pour les centres de coûts, directement dans l'interface de facturation. Un contrôle fin des dépenses par personne, sans passer par l'API, pour prévenir les dérives de consommation.

→ Changelog: Per-user budgets for cost centers in the billing UI

5. Revues de sécurité dans l'application GitHub Copilot

La commande /security-review arrive en préversion publique dans l'application Copilot : lancez une revue de sécurité sur vos modifications en cours de développement. Détection des vulnérabilités plus tôt dans le cycle, au bénéfice de votre posture de sécurité.

→ Changelog: Security reviews now available in the GitHub Copilot app
