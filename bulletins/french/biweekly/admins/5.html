Biweekly #5 · Du 1er mai au 14 mai 2026 · Admins Edition

🎯 Le fil de cette édition

Entre le 1er et le 14 mai 2026, GitHub Copilot consolide les outils d'administration : métriques d'utilisation désormais ventilées par équipe, rapports de facturation à l'usage disponibles avant le basculement du 1er juin, et gouvernance élargie pour les agents cloud et CLI à l'échelle de l'organisation. Les administrateurs disposent de leviers concrets pour piloter l'adoption et anticiper les transitions imminentes.

⚠️ Attention

  • Upcoming deprecation of GPT-4.1 et Upcoming deprecation of GPT-5.2 and GPT-5.2-Codex — Deadline : 1er juin 2026 — Activez GPT-5.5 et GPT-5.3-Codex dans les politiques de modèles Copilot de votre entreprise avant cette date.

  • Claude Sonnet 4 deprecated — Action requise — Déprécié le 6 mai 2026 ; migrez vers Claude Sonnet 4.6 et vérifiez vos politiques de modèles pour activer le modèle de remplacement.

  • Upcoming deprecation of Grok Code Fast 1 — Deadline : 15 mai 2026 — Migrez vers GPT-5 mini ou Claude Haiku 4.5 ; mettez à jour vos politiques de modèles en conséquence.

🚀 Passez à l'action

  • Téléchargez votre rapport d'utilisation d'avril pour estimer l'impact du passage à la facturation par crédits IA le 1er juin 2026.
  • Explorez les métriques d'utilisation Copilot par équipe via l'API pour identifier les équipes les plus actives et cibler vos actions d'accompagnement.
  • Configurez les secrets et variables de l'agent cloud Copilot au niveau de l'organisation pour faciliter les déploiements à grande échelle.
  • Définissez des standards de plugins pour Copilot CLI pour unifier les configurations et les agents dans toute votre entreprise.
  • Des questions ou besoin d'assistance ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Métriques d'utilisation Copilot par équipe disponibles via l'API

L'API de métriques d'utilisation Copilot expose désormais un rapport user-teams permettant de croiser l'appartenance aux équipes avec l'activité par utilisateur. Les administrateurs peuvent produire des métriques par équipe — utilisateurs actifs, complétions, chats, revues de code — ventilées par langue, IDE, feature ou modèle, sans infrastructure externe.

→ Changelog: Team-level Copilot usage metrics now available via API

2. Rapports d'avril disponibles pour préparer la facturation à l'usage

Les rapports de consommation d'avril sont disponibles avant le basculement vers les crédits IA GitHub le 1er juin 2026. Téléchargez le rapport CSV pour identifier vos principaux consommateurs, analyser l'utilisation par modèle et surface, et calibrer votre budget avant la transition.

→ Changelog: April reports are now available to prepare for usage-based billing

3. Types de commentaires de revue de code dans l'API de métriques

L'API de métriques intègre désormais un détail des suggestions Copilot Code Review par type de commentaire (security, bug_risk, etc.). Les administrateurs peuvent mesurer quelles catégories Copilot détecte le plus souvent et comparer le volume de suggestions au taux d'adoption par type.

→ Changelog: Copilot code review comment types now in usage metrics API

4. Secrets et variables au niveau organisation pour l'agent cloud Copilot

Les secrets et variables de l'agent cloud Copilot disposent désormais d'une section dédiée « Agents » (aux côtés d'Actions, Codespaces et Dependabot). Ils peuvent être configurés au niveau de l'organisation et partagés entre plusieurs dépôts, éliminant la duplication de configuration.

→ Changelog: More flexible secrets and variables for Copilot cloud agent

5. Plugins gérés par l'entreprise dans GitHub Copilot CLI en préversion publique

Les administrateurs d'entreprise peuvent désormais configurer et distribuer des plugins Copilot CLI via un fichier settings.json centralisé. Des agents personnalisés, des hooks et des configurations MCP peuvent être déployés automatiquement à tous les utilisateurs Copilot Business ou Enterprise.

→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview
