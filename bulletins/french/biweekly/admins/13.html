Biweekly #13 · Du 1er au 14 septembre 2026 · Admins Edition

🎯 Le fil de cette édition

Cette quinzaine place la gouvernance d'entreprise au cœur de Copilot. Les nouveautés renforcent le contrôle centralisé des opérations d'agents, l'observabilité de l'adoption et la protection du code sensible. Pour les administrateurs, la tendance est claire : déployer les agents à grande échelle tout en gardant des garde-fous fermes, mesurables et non contournables par les utilisateurs.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models — Deadline : 2 octobre 2026 — Vérifiez vos politiques de modèles et activez les modèles de remplacement dans vos paramètres de modèles Copilot.
  • MAI-Code-1-Flash deprecated — Action requise — Ce modèle est déjà retiré ; assurez-vous qu'un modèle pris en charge est autorisé dans vos politiques.

🚀 Passez à l'action

  • Définissez vos garde-fous d'agents via les paramètres gérés par l'entreprise.
  • Activez les exclusions de contenu pour protéger votre code sensible.
  • Suivez l'adoption avec les métriques d'usage Copilot.
  • Configurez les sandbox locaux pour vos équipes JetBrains.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Contrôle centralisé des opérations d'agents

Les administrateurs Copilot Business et Enterprise peuvent désormais bloquer, exiger une approbation humaine ou autoriser les opérations d'agents (commandes shell, lectures/écritures de fichiers, domaines réseau). Ces restrictions gérées ne peuvent pas être affaiblies par les utilisateurs ni par une approbation automatique.

→ Changelog: Enterprise managed permissions for GitHub Copilot agent operations

2. Copilot code review gagne en autonomie

La revue de code Copilot résout désormais ses propres commentaires une fois traités, rédige des messages de commit intelligents et valide le code avec un ensemble d'agents plus complet au niveau Lite. Résultat : une revue plus fiable et un bruit réduit pour vos équipes.

→ Changelog: Auto-resolution and analysis updates in Copilot code review

3. Métriques d'usage pour VS Code Agents

Les rapports de métriques d'usage Copilot incluent désormais l'activité de la fenêtre dédiée VS Code Agents, sur les périodes 1 jour et 28 jours, aux niveaux entreprise et organisation. Un levier concret pour mesurer l'adoption des agents et cibler vos actions d'accompagnement.

→ Changelog: Add VS Code Agents to Copilot usage metrics

4. Sandbox géré par l'entreprise pour JetBrains

Les administrateurs peuvent désormais configurer de façon centralisée le comportement du sandbox Copilot dans les IDE JetBrains : activation, accès système de fichiers et réseau, proxy et outils de développement. Une gouvernance homogène pour vos développeurs JetBrains.

→ Changelog: Enterprise-managed sandbox in Copilot for JetBrains

5. Exclusions de contenu généralisées à l'app et au CLI

L'app GitHub Copilot et le Copilot CLI respectent désormais les politiques d'exclusion de contenu définies au niveau entreprise, organisation et dépôt. Copilot n'utilise plus les fichiers exclus comme contexte, protégeant votre code sensible dans les workflows agentiques.

→ Changelog: Content exclusions generally available in Copilot app and CLI
