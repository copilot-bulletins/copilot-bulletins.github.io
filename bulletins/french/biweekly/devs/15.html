Biweekly #15 · Du 1er au 14 octobre 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine confirme la montée en puissance du développement agentique en local. Entre les workflows dynamiques orchestrés par code, le sandboxing local généralisé et la découverte de modèles locaux dans la CLI, Copilot gagne en contrôle, en fiabilité et en sécurité d'exécution sur votre propre machine. Pour les développeurs, cela signifie automatiser des tâches plus complexes tout en gardant la maîtrise de l'environnement.

⚠️ Attention

  • Selected models in GitHub Copilot deprecated — Action requise — Mettez à jour vos workflows et intégrations pour utiliser des modèles pris en charge.

🚀 Passez à l'action

  • Activez le sandboxing local pour sécuriser vos sessions agentiques et explorez les fonctionnalités Copilot.
  • Testez les nouveaux modèles via le sélecteur de modèle dans votre IDE.
  • Une question ou besoin d'aide ? Contactez votre équipe GitHub, nous sommes là pour vous accompagner.

🏆 Top 5 des mises à jour

1. Des workflows dynamiques pour orchestrer vos agents

Les workflows dynamiques arrivent dans Copilot CLI, l'application Copilot et le SDK. Vous définissez une orchestration en code — étapes séquentielles ou parallèles, agents impliqués au bon moment — pour obtenir la fiabilité et l'observabilité qu'exigent les tâches complexes multi-agents.

→ Changelog: Dynamic workflows in Copilot CLI and the Copilot app

2. Le sandboxing local désormais disponible

Le sandboxing local est généralement disponible dans Copilot CLI, l'application Copilot et les sessions VS Code via Agent Host. Les commandes lancées par Copilot s'exécutent avec un accès restreint au système de fichiers, au réseau et aux identifiants, selon vos politiques. Une frontière d'exécution sûre pour les workflows agentiques.

→ Changelog: Local sandboxing for GitHub Copilot now generally available

3. VS Code : les sorties de septembre 2026

Ce changelog couvre VS Code v1.136 à v1.140. Les nouveautés fluidifient le développement piloté par agents, de l'implémentation jusqu'au merge : fenêtre Agents repensée, automatisations des tâches répétitives, aide au merge et meilleure gestion des sessions à travers workspaces et Dev Containers.

→ Changelog: GitHub Copilot in VS Code, September 2026 releases

4. Copilot interagit avec vos applications de bureau

En préversion publique dans Copilot CLI et l'application Copilot (macOS et Windows), le « computer use » permet à Copilot de piloter des applications de bureau : lire le contenu, cliquer, saisir du texte, naviguer. Idéal pour automatiser des logiciels GUI sans API ni intégration MCP. Vous gardez le contrôle via des approbations.

→ Changelog: GitHub Copilot can now interact with desktop apps with computer use

5. Découvrez les modèles locaux dans Copilot CLI

Depuis la version 1.0.94-0, la commande /model détecte les modèles d'une instance Ollama locale en cours d'exécution, aux côtés de vos modèles configurés et des modèles cloud. Choisissez un modèle, vérifiez son fournisseur et son endpoint, puis utilisez-le sans redémarrer la CLI.

→ Changelog: Discover local models in GitHub Copilot CLI
