Biweekly #6 · Du 15 mai au 31 mai 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine est placée sous le signe du contrôle développeur : choisir quel modèle Copilot utilise, selon quelle tâche, et le piloter depuis n'importe quelle surface. Sélection automatique dans VS Code, contrôle à distance des sessions CLI depuis mobile ou VS Code, commandes mémoire en CLI — Copilot devient un assistant multi-surface, toujours plus contextuel et prévisible.

⚠️ Attention

  • Grok Code Fast 1 deprecated — Action requise — Ce modèle n'est plus disponible dans aucune interface Copilot. Migrez vos workflows vers GPT-5 mini ou Claude Haiku 4.5. Consultez la liste des modèles supportés.
  • Updates to available models in Copilot on web — Action requise — Les modèles Gemini, GPT-5.2 Codex et GPT-5.4 nano ont été retirés de Copilot Chat sur github.com. Adaptez vos habitudes de travail web en conséquence.

🚀 Passez à l'action

  • Activez le contrôle à distance de vos sessions Copilot CLI via les réglages de pilotage à distance pour piloter vos sessions depuis GitHub Mobile ou VS Code.
  • Choisissez Auto dans le sélecteur de modèle VS Code pour bénéficier de l'optimisation automatique selon vos tâches.
  • Utilisez /memory on|off|show dans Copilot CLI pour gérer vos préférences de mémoire, ou consultez vos réglages Copilot Memory.
  • Activez Claude Opus 4.8 dans vos paramètres de modèles Copilot (Copilot Business/Enterprise).
  • Questions ou besoin d'assistance ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Contrôle à distance des sessions Copilot CLI : disponibilité générale

Le contrôle à distance des sessions Copilot CLI passe en disponibilité générale sur GitHub Mobile, github.com, VS Code et JetBrains. Lancez une session dans votre terminal, puis guidez-la depuis votre téléphone : progression en temps réel, réponses aux questions Copilot et ajustement du plan à la volée.

→ Changelog: Remote control for Copilot CLI sessions now generally available on mobile, web, and VS Code

2. Sélection automatique de modèles selon la tâche dans VS Code

Copilot Auto dans VS Code sélectionne maintenant le modèle optimal selon la complexité de votre tâche — génération de code, débogage, orchestration d'outils. Les requêtes simples vont vers des modèles légers, les tâches complexes vers des modèles de raisonnement. En prime, une remise de 10 % sur les requêtes premium en mode Auto.

→ Changelog: Auto model selection now routes based on your task in VS Code

3. Claude Opus 4.8 disponible dans GitHub Copilot

Claude Opus 4.8, le nouveau modèle phare d'Anthropic, est maintenant disponible dans GitHub Copilot. Il surpasse ses prédécesseurs en compréhension de code et en navigation dans de grandes bases de code. Disponible sur VS Code, JetBrains, Copilot CLI, github.com, GitHub Mobile et plus encore. Multiplicateur : 15x en attendant la facturation à l'usage.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

4. Copilot Memory s'enrichit de nouveaux contrôles et commandes CLI

Copilot Memory étend ses contrôles : les admins de dépôt peuvent désactiver la mémoire au niveau du dépôt, la commande /memory on|off|show est disponible dans Copilot CLI, et le prompt de capture précise si la donnée stockée est une préférence personnelle ou un fait partagé au niveau du dépôt.

→ Changelog: Copilot Memory has more controls for deletion, scope, and the Copilot CLI

5. GPT-5.3-Codex devient le modèle de base pour Business et Enterprise

GPT-5.3-Codex remplace GPT-4.1 comme modèle de base pour toutes les organisations Copilot Business et Enterprise depuis le 17 mai. Premier modèle LTS de Copilot, il est garanti disponible jusqu'au 4 février 2027 — un gage de stabilité pour les équipes qui gèrent des processus de validation internes.

→ Changelog: GPT-5.3-Codex is now the base model for Copilot Business and Enterprise
