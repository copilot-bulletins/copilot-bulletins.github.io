Biweekly #8 · Du 15 juin au 30 juin 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine, deux dynamiques structurent l'actualité pour les développeurs : un élargissement du choix de modèles, entre nouvelles disponibilités générales et préversions, et la maturation des surfaces agentiques — application de bureau, terminal et IDE. Résultat concret : davantage de latitude pour sélectionner le bon modèle selon la tâche, et plus d'environnements où déléguer un travail multi-étapes à un agent.

⚠️ Attention

  • Opus 4.6 (fast) est déprécié — Déprécié depuis le 29 juin 2026 — Basculez vos workflows et intégrations vers Opus 4.8 (fast) ; consultez la référence des modèles disponibles.

🚀 Passez à l'action

  • Sélectionnez Claude Sonnet 5 (disponibilité générale) ou Opus 4.8 (fast, en preview) dans le sélecteur de modèles de VS Code, Visual Studio, Copilot CLI ou JetBrains — voir Changer de modèle.
  • Téléchargez l'application GitHub Copilot pour piloter vos agents depuis le bureau, en suivant le guide de démarrage.
  • Mettez à jour Copilot CLI pour profiter de la nouvelle interface à onglets (issues, pull requests, gists) : suivez le guide d'installation de Copilot CLI.
  • Essayez le mode auto dans Copilot Chat pour laisser Copilot router automatiquement vers le meilleur modèle : découvrez la sélection automatique de modèle.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Claude Sonnet 5 et Opus 4.8 (fast) élargissent le choix de modèles

Claude Sonnet 5 passe en disponibilité générale et Opus 4.8 (fast) arrive en preview. Le premier vise de solides performances de codage, notamment sur les tâches CLI ; le second accélère la génération pour les workflows interactifs. Disponibles dans VS Code, la CLI et JetBrains.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot

2. L'application GitHub Copilot en disponibilité générale

L'application de bureau (macOS, Windows, Linux) pour le développement piloté par agent est désormais GA. Lancez des sessions depuis une issue, une pull request ou un prompt, exécutez des sessions parallèles par branche et worktree, validez dans le terminal intégré, puis ouvrez une pull request.

→ Changelog: GitHub Copilot app generally available

3. Copilot CLI : la nouvelle interface terminal en disponibilité générale

L'interface repensée dévoilée à Microsoft Build 2026 est GA. Une disposition à onglets permet de parcourir issues, pull requests et gists sans quitter le terminal ; appuyez sur « c » pour référencer un élément dans votre prompt. Configuration des outils simplifiée et accessibilité renforcée.

→ Changelog: Copilot CLI: New terminal interface is generally available

4. Le mode auto disponible pour tous dans Copilot Chat

La sélection automatique de modèle est en disponibilité générale dans Copilot Chat sur github.com et l'application mobile, pour tous les plans. Copilot choisit le modèle selon la complexité de la tâche et la disponibilité en temps réel, optimisant coût et qualité. Vous gardez la main à tout moment.

→ Changelog: Auto mode in Copilot Chat available for all users

5. Copilot s'étend dans les IDE JetBrains

Copilot pour JetBrains gagne le support des agents d'organisation et d'entreprise, Claude comme fournisseur d'agent en preview, et le cloud agent en disponibilité générale. En parallèle, Copilot devient une option native dans le sélecteur d'agents de JetBrains AI Assistant, avec choix du modèle et de la profondeur de raisonnement.

Sources:
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant
