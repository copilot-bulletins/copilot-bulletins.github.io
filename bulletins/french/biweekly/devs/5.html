🏆 Top 5 des mises à jour

1. L'application GitHub Copilot arrive en préversion technique

L'application GitHub Copilot est une expérience de bureau native pour démarrer le développement agentique depuis vos issues, PRs ou sessions précédentes. Chaque session dispose de sa propre branche, terminal et navigateur intégrés. L'Agent Merge traite les retours de review et fusionne automatiquement une fois vos conditions remplies.

→ Changelog: GitHub Copilot app is now available in technical preview

2. GitHub Copilot dans VS Code : les sorties d'avril (v1.116–v1.119)

Quatre releases couvrant avril et début mai : indexation sémantique dans tous les workspaces, BYOK (apportez votre propre clé API) pour Business et Enterprise, accès lecture/écriture aux terminaux ouverts, et navigateur intégré pour les agents. Les sessions Copilot CLI sont désormais pilotables depuis GitHub.com ou l'app mobile.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

3. Agent Copilot CLI et vue unifiée des sessions dans JetBrains

L'agent Copilot CLI arrive en préversion publique dans JetBrains IDEs, avec deux modes d'isolation (worktree ou workspace). Une vue unifiée affiche le statut de toutes les sessions en direct. L'outil "Ask question" réduit les ambiguïtés en cours de tâche, et les agents globaux (~/.copilot/agents) s'appliquent à tous les workspaces.

→ Changelog: Introducing Copilot CLI agent and unified sessions view in GitHub Copilot for JetBrains IDEs

4. Démarrez des tâches d'agent cloud via l'API REST

Les utilisateurs Business et Enterprise peuvent désormais déclencher des tâches d'agent cloud Copilot par API (préversion publique). Cas d'usage : refactoring à grande échelle sur de nombreux repos, portails développeur internes, génération automatisée de notes de release. La progression est traçable via la même API.

→ Changelog: Start Copilot cloud agent tasks via the REST API

5. Sélection automatique de modèle pour l'agent cloud

L'agent cloud prend en charge la sélection automatique de modèle ("Auto"). Copilot sélectionne le meilleur modèle disponible selon les performances système, avec à la clé une réduction de 10 % sur le multiplicateur de coût et l'absence de limites de débit hebdomadaires.

→ Changelog: Copilot cloud agent supports auto model selection
