Biweekly #17 · Du 1er novembre au 14 novembre 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine, Copilot s'installe là où les développeurs travaillent déjà : nouveaux environnements natifs, outils de conversation d'équipe et nouveaux modèles disponibles dans tous les clients. Pour les développeurs, l'enjeu est concret : déléguer et suivre le travail des agents sans changer d'outil, tout en choisissant le modèle adapté à chaque tâche.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in December — Échéance : 14 décembre 2026 — Claude Fable 5, Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6 et Kimi K3 seront retirés. Mettez à jour vos workflows et intégrations à l'aide de la liste des modèles pris en charge.

🚀 Passez à l'action

  • Testez Claude Fable 5.2 et Gemini 4 Hydrogen depuis le sélecteur de modèles, et comparez les modèles dans la liste des modèles pris en charge.
  • Centralisez la configuration de vos plugins et serveurs MCP avec /settings dans Copilot CLI.
  • Capitalisez sur vos tâches répétitives en créant des agent skills réutilisables.
  • Ajustez le niveau d'effort et l'usage des instructions personnalisées dans la configuration de la revue de code Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Copilot arrive dans JetBrains Air

Déléguez des tâches à Copilot dans JetBrains Air via l'Agent Client Protocol : suivez plusieurs sessions d'agents en parallèle, relisez les changements dans l'IDE, et exécutez des tâches dans le cloud via Air Teams avec votre abonnement Copilot existant.

→ Changelog: GitHub Copilot is now available in JetBrains Air

2. Copilot intégré à l'assistant de code natif de Xcode

En préversion publique à partir de Xcode 27.3 beta, Copilot fonctionne directement dans l'assistant de code intégré de Xcode (Settings > Intelligence). Tous les plans Copilot sont pris en charge, et l'extension Copilot for Xcode reste disponible en parallèle.

→ Changelog: GitHub Copilot is now available in Xcode's coding assistant

3. Trois nouveaux modèles dans le sélecteur

Claude Fable 5.2 cible les tâches complexes et multi-étapes sur de grandes bases de code. Gemini 4 Carbon vise le raisonnement et la génération de code sécurisée, et Gemini 4 Hydrogen l'agentique rapide. Pour Fable 5.2, la politique est désactivée par défaut côté Business/Enterprise.

Sources:
→ Changelog: Claude Fable 5.2 in GitHub Copilot
→ Changelog: Gemini 4 Carbon in GitHub Copilot
→ Changelog: Gemini 4 Hydrogen in GitHub Copilot

4. VS Code, CLI et Copilot app : les nouveautés de la semaine

VS Code 1.145 ajoute des modes d'affichage du chat, des automatisations locales planifiées via cron et la prévisualisation d'applications distantes. Copilot CLI regroupe plugins et serveurs MCP dans /settings. L'app Copilot améliore Agent Merge et la gestion des sessions.

→ Changelog: GitHub Copilot weekly releases — November 2

5. @GitHub dans Slack et Teams en disponibilité générale

Depuis une conversation Slack ou Teams, enquêtez sur un bug, créez une issue ou ouvrez une pull request. Dans Teams, Canvas permet de relire plans, changements de code et aperçus aux côtés de la discussion. Le dépôt est désormais détecté automatiquement.

→ Changelog: @GitHub in Slack and Teams is generally available and more
