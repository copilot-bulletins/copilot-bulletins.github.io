Biweekly #16 · Du 15 octobre au 31 octobre 2026 · Devs Edition

🎯 Le fil de cette édition

Avec Universe 2026, Copilot devient un environnement de travail continu plutôt qu'un simple assistant dans l'éditeur. Le choix du modèle peut désormais être délégué, les sessions passent d'un outil à l'autre et le contexte externe s'intègre sans configuration. Pour les développeurs, cela signifie moins de friction et davantage de tâches confiées aux agents, sans perdre le contrôle.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Deadline: 16 novembre 2026 — Claude Opus 4.8, Claude Opus 5 et GPT-5.6 Terra seront retirés : basculez vos workflows vers Claude Opus 5.5 ou GPT-6.1 Sol en consultant les modèles pris en charge.
  • Turn notifications into code with GitHub Copilot in Teams — Deadline: 16 novembre 2026 — L'ancienne application GitHub pour Microsoft Teams sera retirée : installez l'application GitHub unifiée pour continuer à utiliser Copilot dans Teams.

🚀 Passez à l'action

  • Sélectionnez Copilot Fusion dans le sélecteur de modèles et choisissez un niveau d'effort en vous appuyant sur la documentation Copilot Fusion
  • Activez « Watch and fix » sur vos pull requests en suivant le guide Agent Merge
  • Connectez Slack, Figma ou Sentry une seule fois grâce aux connecteurs Copilot
  • Demandez à Copilot de retenir vos conventions avec Copilot Memory
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Copilot Fusion : le modèle se choisit tout seul

Copilot Fusion, désormais en disponibilité générale, sélectionne et orchestre automatiquement les modèles à chaque prompt (single, cascade, critique). Vous choisissez seulement l'effort : Standard, High ou Max. Disponible dans VS Code, JetBrains, Copilot CLI et l'app Copilot, avec 30 % de remise temporaire.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot in JetBrains Universe releases

2. Une session cloud, toutes les surfaces

Lancez une tâche depuis github.com, GitHub Mobile, la CLI, l'app Copilot, VS Code, Slack ou Teams, puis reprenez-la ailleurs. Chaque session s'exécute dans une sandbox cloud sécurisée, sans limite d'une heure, avec un snapshot pour reprendre là où vous vous étiez arrêté.

→ Changelog: Work from anywhere with a new, connected Copilot cloud experience

3. Connecteurs : vos outils sans configuration MCP

Les serveurs MCP vérifiés par GitHub arrivent en préversion publique : 26 services, dont Slack, Figma, Notion, Sentry et Linear. Connectez-vous une fois et le service fonctionne partout, de l'app Copilot à la CLI (/mcp) en passant par VS Code et le cloud.

→ Changelog: Connect your tools to Copilot without all the setup

4. Agent Merge débloque vos pull requests

Avec « Watch and fix », Copilot surveille votre pull request et corrige automatiquement les workflows Actions en échec et les conflits de merge dans le cloud. Combiné à l'auto-merge, il garde la PR prête à être fusionnée sans intervention manuelle.

→ Changelog: Agent Merge watches and fixes pull requests in the cloud

5. Copilot Memory retient vos conventions

Copilot Memory passe en disponibilité générale : préférences personnelles et conventions de dépôt sont conservées entre les sessions et les clients. « Dreaming », en préversion, s'appuie sur les sessions passées pour actualiser les mémoires et proposer, via des pull requests, des améliorations de vos instructions et skills.

→ Changelog: GitHub intelligence puts your code, context, and history to work
