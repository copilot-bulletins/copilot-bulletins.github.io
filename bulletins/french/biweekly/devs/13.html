Biweekly #13 · Du 1 au 14 septembre 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine place le choix et le contrôle des modèles au cœur de l'expérience développeur. Nouveaux modèles disponibles, sélection automatique désormais réglable selon le coût et la qualité, et retraits programmés : Copilot vous demande d'être plus intentionnel sur le modèle utilisé pour chaque tâche. En parallèle, la revue de code et les agents gagnent en autonomie dans vos outils du quotidien.

⚠️ Attention

  • MAI-Code-1-Flash deprecated — Action requise — Le modèle est retiré de toutes les expériences Copilot depuis le 10 septembre 2026 ; basculez vos workflows vers un modèle pris en charge.
  • Upcoming deprecation of selected GitHub Copilot models — Échéance : 2 octobre 2026 — Plusieurs modèles seront retirés ; migrez vos intégrations vers un modèle supporté avant cette date.

🚀 Passez à l'action

  • Réglez la sélection automatique de modèle selon vos priorités via le choix du modèle de chat.
  • Activez la revue de code Copilot sur vos pull requests pour bénéficier de l'auto-résolution.
  • Protégez votre code sensible dans l'app et la CLI avec les exclusions de contenu.
  • Explorez les nouveaux modèles disponibles dans la liste des modèles pris en charge.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Un cran de plus pour la sélection automatique de modèle

La sélection automatique propose désormais trois niveaux — efficacité, équilibre et intelligence — pour arbitrer entre coût, qualité et temps de réponse. Copilot évalue chaque prompt individuellement et choisit le modèle le mieux adapté selon le niveau retenu.

→ Changelog: Configure cost and quality in Copilot auto model selection

2. GPT-6 Astra en disponibilité générale

Le dernier modèle généraliste d'OpenAI arrive dans Copilot. Conçu pour les tâches de codage autonomes et agentiques de longue haleine, GPT-6 Astra se distingue par sa façon de planifier et de valider son travail, pas seulement par le résultat produit.

→ Changelog: GPT-6 Astra is generally available in GitHub Copilot

3. Une revue de code plus autonome

La revue de code Copilot résout désormais ses propres commentaires une fois traités et rédige des messages de commit lorsque vous appliquez ses suggestions. En coulisses, un ensemble d'agents et un jeu élargi d'outils shell produisent une analyse plus complète dès le niveau Lite.

→ Changelog: Auto-resolution and analysis updates in Copilot code review

4. Les agents s'invitent dans vos outils

Les livraisons hebdomadaires apportent l'intégration Jira dans l'app Copilot, l'orchestration adaptative de modèles (Project HydraFusion) dans la CLI, de nouvelles automatisations d'agent dans VS Code et des contrôles d'entreprise étendus côté JetBrains.

→ Changelog: GitHub Copilot weekly releases — September 7

5. Les exclusions de contenu couvrent l'app et la CLI

L'app Copilot et la CLI respectent maintenant les politiques d'exclusion de contenu définies par les administrateurs. Copilot n'utilise plus les fichiers exclus comme contexte, ce qui protège votre code sensible dans les workflows agentiques.

→ Changelog: Content exclusions generally available in Copilot app and CLI
