Biweekly #12 · Du 15 août au 31 août 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine met l'accent sur le contrôle et l'organisation du travail agentique dans vos environnements du quotidien. VS Code, Visual Studio et JetBrains gagnent en maturité — sessions d'agents mieux organisées, serveurs MCP intégrés, agents personnalisés partagés. Pour les développeurs, l'enjeu est clair : orchestrer plusieurs agents et outils de façon plus fiable, sans quitter votre IDE.

⚠️ Attention

  • Changements à venir sur les politiques et la facturation de Copilot — Échéance : 1er septembre 2026 — La revue de code Copilot passe par défaut au niveau d'effort « Balanced » et les expériences de chat convergent vers une politique unique. Vérifiez vos paramètres de revue de code si vous dépendez du comportement actuel.

🚀 Passez à l'action

  • Testez les nouvelles sessions d'agents dans votre IDE avec Copilot Chat.
  • Connectez vos outils via un serveur MCP dans Copilot Chat.
  • Ajustez vos paramètres de revue de code Copilot avant le changement de valeur par défaut.
  • Vérifiez les modèles disponibles pour votre plan.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. VS Code : mieux organiser vos sessions d'agents

Les versions d'août (v1.132 à v1.135) facilitent l'organisation des sessions d'agents : disposition des chats côte à côte, suivi de l'activité de l'agent, navigation entre prompts et changements de fichiers. Le navigateur intégré et la dictée gagnent aussi de nouvelles capacités.

→ Changelog: GitHub Copilot in VS Code, August 2026 releases

2. Visual Studio : agents personnalisés au niveau organisation

Les propriétaires d'organisation et d'entreprise peuvent publier des agents personnalisés utilisables dans tous les dépôts. Visual Studio les détecte automatiquement et affiche leur description et leur source dans le sélecteur d'agents, avec plus de contrôle sur le raisonnement et les modèles.

→ Changelog: GitHub Copilot in Visual Studio — August update

3. Copilot harness disponible pour JetBrains

Copilot harness passe en disponibilité générale dans JetBrains, avec une livraison de fonctionnalités plus rapide et une meilleure qualité de code. Le support du serveur MCP JetBrains intégré arrive en préversion publique, exposant les capacités de l'IDE aux workflows agentiques sans configuration externe.

→ Changelog: Copilot harness generally available in Copilot for JetBrains

4. Onglet Customize dans l'app GitHub Copilot

L'onglet Customize passe en disponibilité générale et réunit au même endroit serveurs MCP, plugins, skills et canvases. Un point d'entrée unique pour configurer et étendre votre environnement Copilot sans jongler entre plusieurs écrans.

→ Changelog: GitHub Copilot app Customize tab is generally available

5. Revue de code Copilot : couverture élargie

La revue de code Copilot couvre désormais deux cas jusque-là ignorés : les pull requests créées par des bots (dont l'agent cloud Copilot) et les très grandes pull requests. Vous pouvez aussi indiquer la raison de résolution d'un commentaire de revue.

→ Changelog: Copilot code review: Resolution reasons and expanded capabilities
