Biweekly #14 · Du 15 au 30 septembre 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine, l'actualité Copilot s'est concentrée sur l'expérience des développeurs dans leurs outils du quotidien. Orchestration intelligente de modèles, agents plus sûrs et mieux contrôlés, indexation de code plus rapide et vague de nouveaux modèles : l'objectif est de réduire les frictions tout en laissant le développeur aux commandes des décisions importantes.

⚠️ Attention

  • Dépréciation de certains modèles Copilot mi-octobre — Date limite : 19 octobre 2026 — Mettez à jour vos workflows et intégrations vers les modèles pris en charge avant cette date.

🚀 Passez à l'action

  • Découvrez et activez les derniers modèles disponibles dans la documentation des modèles pris en charge.
  • Essayez HydraFusion dans VS Code (version 1.140 ou ultérieure) via le sélecteur de modèle.
  • Accélérez vos projets C++ dans la Copilot CLI grâce à l'indexation complète du code.
  • Partagez des instructions personnalisées pour guider l'agent sur vos conventions.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. HydraFusion arrive dans VS Code et l'app Copilot

HydraFusion, en preview de recherche, s'étend au-delà de la CLI vers VS Code et l'app GitHub Copilot. Plutôt qu'un modèle unique, il orchestre plusieurs modèles et sélectionne le workflow le plus efficace pour chaque requête. Un pas vers une sélection automatique et coordonnée des modèles.

→ Changelog: HydraFusion in VS Code and the GitHub Copilot app

2. Copilot pour JetBrains 1.18 : approbations assistées et reprise de conversation

La version 1.18.0 introduit les approbations assistées (preview) : les actions à faible risque sont validées automatiquement, les plus sensibles restent à votre main. Vous pouvez aussi ré-éditer un message précédent, Copilot rembobinant conversation et modifications de fichiers, et utiliser skills et instructions partagées.

→ Changelog: New features and improvements in Copilot for JetBrains

3. Sandboxing local dans l'app GitHub Copilot

Le sandboxing local limite l'accès de l'agent aux fichiers, au réseau et aux identifiants de votre machine, réduisant l'impact de commandes involontaires. Configurable par projet, désactivé par défaut : activez-le dans les paramètres, ou tapez /sandbox on pour une session active.

→ Changelog: Local sandboxing in the GitHub Copilot app

4. Intelligence de code C++ plus rapide dans la CLI

L'indexation complète du code (WCI) crée un index persistant des symboles de votre projet C++, y compris les fichiers non ouverts. Résultat : définitions, références et recherches de symboles bien plus rapides sur les gros dépôts. Activé par défaut, suivez la progression avec /lsp logs.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

5. Une vague de nouveaux modèles disponibles

La quinzaine a enrichi le catalogue : GPT-6.1 Sol, GPT-6 Sol et GPT-6 Luna d'OpenAI, Claude Sonnet 5.5 et Claude Opus 5.5 d'Anthropic, ainsi que Grok 4.7. Plus de choix pour arbitrer entre raisonnement, rapidité et coût selon vos tâches.
