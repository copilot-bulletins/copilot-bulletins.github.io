Biweekly #10 · Du 15 juillet au 31 juillet 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine a été marquée par l'accélération autour des modèles et des agents. Trois nouveaux modèles rejoignent Copilot, tandis que l'écosystème agentique se stabilise : MCP et les agent skills passent en disponibilité générale, et l'agent cloud gagne de nouveaux points d'entrée. Pour les développeurs, cela signifie davantage de choix et des workflows autonomes plus fiables au quotidien.

⚠️ Attention

  • Gemini 2.5 Pro et Gemini 3 Flash dépréciés — Deadline : 31 juillet 2026 — Ces modèles ont été retirés de toutes les expériences Copilot. Basculez vers un modèle pris en charge depuis les paramètres de modèle de Copilot Chat.
  • Le serveur MCP GitHub passe à la nouvelle spécification MCP — Action requise — Le protocole MCP devient sans état (stateless) le 28 juillet 2026 ; vérifiez que vos intégrations MCP sont compatibles avec la dernière spécification.

🚀 Passez à l'action

  • Testez les nouveaux modèles (Claude Opus 5, Grok 4.5, Gemini 3.6 Flash) en changeant de modèle dans Copilot Chat.
  • Connectez vos serveurs MCP à Copilot Chat en suivant la documentation MCP.
  • Enrichissez vos revues avec les agent skills et MCP via Copilot code review.
  • Déléguez des tâches de fond à l'agent de codage Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Visual Studio Code enchaîne les versions de juillet

Les versions v1.127 à v1.131 améliorent le travail avec les agents, la revue des modifications, le chat et la navigation. Un lot dense qui affine l'expérience agentique au cœur de l'éditeur le plus utilisé par les développeurs.

→ Changelog: GitHub Copilot in Visual Studio Code, July 2026 releases

2. Trois nouveaux modèles arrivent dans Copilot

Claude Opus 5 (tâches longues et raisonnement), Grok 4.5 (codage agentique rapide) et Gemini 3.6 Flash (développement web et tâches à long horizon) élargissent votre choix. Sélectionnez le modèle adapté à chaque tâche directement dans Copilot.

Sources:
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot
→ Changelog: Gemini 3.6 Flash is now available in GitHub Copilot

3. Le serveur MCP GitHub adopte la nouvelle spécification

Le serveur MCP GitHub prend en charge le nouveau cœur sans état (stateless) avant sa sortie officielle, en amont du passage du protocole le 28 juillet. De quoi préparer vos intégrations agentiques et garantir leur compatibilité.

→ Changelog: GitHub MCP Server supports the next MCP specification

4. Copilot code review : agent skills et MCP en disponibilité générale

Le support des agent skills et des serveurs MCP dans Copilot code review est désormais généralement disponible pour tous les utilisateurs Pro, Pro+, Business et Enterprise. Vos revues gagnent en contexte et en personnalisation.

→ Changelog: Copilot code review: Agent skills and MCP now generally available

5. L'agent cloud Copilot pour Linear est généralement disponible

Assignez une issue Linear à l'agent cloud Copilot : il analyse le contenu, travaille en arrière-plan et propose une solution de façon autonome. Un nouveau point d'entrée pour intégrer l'agent asynchrone dans vos flux de travail.

→ Changelog: Copilot cloud agent for Linear is now generally available
