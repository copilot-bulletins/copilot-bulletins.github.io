Biweekly #7 · Du 1er juin au 14 juin 2026 · Devs Edition

🎯 Le fil de cette édition

Cette quinzaine confirme une tendance de fond : l'assistance de Copilot devient résolument agentique et s'étend à chaque surface de développement — terminal, IDE, cloud et automatisations. En parallèle, des fenêtres de contexte élargies et des niveaux de raisonnement configurables donnent aux développeurs les moyens de traiter des tâches plus complexes et multi-fichiers, sans perdre le fil de projets volumineux.

⚠️ Attention

  • GPT-4.1 est déprécié — Déprécié depuis le 1er juin 2026 — Basculez vos intégrations vers un modèle pris en charge ; consultez la référence des modèles disponibles.
  • GPT-5.2 et GPT-5.2-Codex sont dépréciés — Déprécié depuis le 5 juin 2026 — Mettez à jour vos workflows vers un modèle pris en charge (GPT-5.2 reste disponible pour la revue de code Copilot).

🚀 Passez à l'action

  • Exploitez la fenêtre de contexte d'un million de tokens et les niveaux de raisonnement configurables pour vos tâches multi-fichiers, dans VS Code, Copilot CLI ou l'application Copilot — détails dans la documentation sur les modèles.
  • Installez ou mettez à jour Copilot CLI pour profiter de la nouvelle interface, du rubber duck et de la saisie vocale : suivez le guide d'installation de Copilot CLI.
  • Automatisez le tri d'issues ou l'analyse d'échecs CI avec GitHub Agentic Workflows, désormais en preview publique.
  • Si vos intégrations utilisent encore GPT-4.1 ou GPT-5.2, migrez-les vers un modèle pris en charge en suivant Changer de modèle.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Des fenêtres de contexte d'un million de tokens et un raisonnement configurable

Copilot gère désormais des fenêtres de contexte d'un million de tokens et des niveaux de raisonnement configurables : traitez de larges bases de code multi-fichiers sans perdre le fil, en dosant rapidité et profondeur. Disponible dans VS Code, Copilot CLI et l'application Copilot.

→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot

2. Copilot CLI : nouvelle interface, rubber duck et saisie vocale

Copilot CLI reçoit une refonte majeure dévoilée à Microsoft Build 2026 : le rubber duck (second avis) et la saisie vocale passent en disponibilité générale. Une interface terminal expérimentale ajoute des onglets pour vos issues, pull requests et gists, ainsi qu'un support d'accessibilité renforcé.

→ Changelog: Copilot CLI: Improved UI, rubber duck, prompt scheduling, and voice input

3. GitHub Agentic Workflows en preview publique

Décrivez vos automatisations en Markdown : GitHub Agentic Workflows les compile en YAML Actions standard pour confier à des agents le tri d'issues, l'analyse d'échecs CI ou la mise à jour de docs. Exécution en lecture seule par défaut, dans un conteneur sandboxé.

Sources:
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Agentic workflows no longer need a personal access token

4. GitHub Copilot dans VS Code : versions de mai

La fenêtre Agents débarque en préversion dans VS Code Stable pour travailler par tâches plutôt que fichier par fichier, avec agents distants via SSH ou Dev Tunnels et synchronisation des sessions de chat sur votre compte GitHub. Le BYOK s'étend aux environnements air-gapped.

→ Changelog: GitHub Copilot in Visual Studio Code, May releases

5. Le SDK Copilot est en disponibilité générale

Le SDK Copilot passe en disponibilité générale : intégrez le moteur agentique de Copilot dans vos propres applications et services via une API stable, prête pour la production. Disponible dans six langages avec support officiel, pour des outils internes pilotés par agents.

→ Changelog: Copilot SDK is now generally available
