Biweekly #10 · Du 15 juillet au 31 juillet 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

Cette quinzaine confirme une orientation stratégique claire : mesurer et gouverner la valeur de Copilot. Nouveaux tableaux de bord d'impact, métriques d'usage détaillées et visibilité financière donnent aux dirigeants les moyens de démontrer le retour sur investissement, tandis que l'arrivée de modèles de pointe maintient l'organisation à la frontière technologique sans compromettre le contrôle des coûts.

⚠️ Attention

  • Gemini 2.5 Pro et Gemini 3 Flash retirés — Échéance : 31 juillet 2026 — Ces modèles ne sont plus disponibles dans toutes les expériences Copilot. Vérifiez les modèles par défaut de votre organisation via la gestion des modèles.

🚀 Passez à l'action

  • Racontez l'impact de Copilot grâce au suivi de l'usage et de l'adoption.
  • Activez la revue de code Copilot pour renforcer la qualité à grande échelle.
  • Maîtrisez les dépenses en suivant la consommation d'IA.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Un tableau de bord pour prouver l'impact de Copilot

Un nouveau tableau de bord d'impact, destiné aux administrateurs d'entreprise et propriétaires d'organisation, va au-delà du simple usage pour raconter une histoire de valeur plus profonde. Un atout décisif pour justifier l'investissement et orienter le déploiement auprès des directions.

→ Changelog: New Copilot usage metrics impact dashboard

2. Claude Opus 5 disponible dans Copilot

Le nouveau modèle Opus d'Anthropic arrive dans Copilot. Conçu pour les tâches de développement complexes et longues nécessitant un raisonnement rigoureux, il maintient votre organisation à la pointe sans changer d'outil ni de cadre de gouvernance.

→ Changelog: Claude Opus 5 is now available in GitHub Copilot

3. Revue de code Copilot : agent skills et MCP en disponibilité générale

La prise en charge des agent skills et des serveurs MCP par la revue de code Copilot est désormais généralement disponible pour les offres Pro, Pro+, Business et Enterprise. De quoi industrialiser la qualité du code et réduire les risques à l'échelle de l'organisation.

→ Changelog: Copilot code review: Agent skills and MCP now generally available

4. Métriques d'usage au niveau des dépôts

L'API de métriques d'usage Copilot expose désormais l'activité par dépôt, avec une ventilation quotidienne de l'activité des pull requests pour l'agent de développement et la revue de code. Une granularité précieuse pour cibler l'adoption là où elle compte.

→ Changelog: Repository-level GitHub Copilot usage metrics generally available

5. L'agent cloud Copilot pour Linear en disponibilité générale

Vous pouvez désormais assigner des tickets Linear à l'agent cloud Copilot, qui les analyse et travaille de façon autonome en arrière-plan. L'automatisation s'étend aux outils tiers de gestion de projet, accélérant la livraison sans quitter vos flux existants.

→ Changelog: Copilot cloud agent for Linear is now generally available
