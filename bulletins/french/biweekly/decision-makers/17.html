Biweekly #17 · Du 1er au 14 novembre 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

Cette quinzaine, GitHub a nettement renforcé la mesure de la valeur de Copilot : les métriques couvrent désormais l'efficacité réelle des revues de code, le chat, les agents et les modèles BYOK. Pour les décideurs, cela permet de fonder les arbitrages budgétaires sur des données d'adoption et d'impact plus complètes, plutôt que sur des estimations.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in December — Deadline: 14 décembre 2026 — Claude Fable 5, Claude Haiku 4.5, Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6 et Kimi K3 seront retirés. Vérifiez que vos workflows utilisent les alternatives recommandées dans la liste des modèles pris en charge.

🚀 Passez à l'action

  • Demandez à vos équipes de suivre le taux de commentaires de revue traités par repository via l'API de métriques d'usage Copilot.
  • Consultez l'adoption par fonctionnalité, désormais étendue au chat et aux agents, dans le tableau de bord d'impact Copilot.
  • Identifiez les utilisateurs dont la télémétrie manque ou dont les IDE sont obsolètes grâce aux exigences des métriques d'usage.
  • Automatisez l'attribution des licences à l'échelle de l'entreprise avec les API de gestion des utilisateurs Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Mesurer l'efficacité réelle de la revue de code par l'IA

L'API de métriques d'usage indique désormais, par repository, combien de commentaires de Copilot code review sont effectivement traités par les développeurs et combien de pull requests fusionnent sans nouvelle demande de modification humaine. Un indicateur concret pour objectiver le retour sur investissement.

→ Changelog: Usage metrics API adds code review details and addressed rate

2. Une vision plus complète de l'adoption

Le tableau de bord d'impact intègre Copilot Chat et la fenêtre Agents de VS Code, soit neuf expériences suivies. Le segment « Passive users » devient « Chat-first users » : un usage centré sur le chat n'est plus assimilé à un désengagement.

→ Changelog: Copilot impact dashboard adds chat and VS Code agent usage

3. Trois nouveaux modèles de pointe, sous contrôle administrateur

Claude Fable 5.2, Gemini 4 Carbon et Gemini 4 Hydrogen sont disponibles. Fable 5.2 nécessite une activation explicite et implique une rétention de données par défaut chez Anthropic, un point à arbitrer avec vos équipes conformité.

Sources:
→ Changelog: Claude Fable 5.2 in GitHub Copilot
→ Changelog: Gemini 4 Carbon in GitHub Copilot
→ Changelog: Gemini 4 Hydrogen in GitHub Copilot

4. De la conversation au code, dans Slack et Teams

@GitHub dans Slack et Teams est disponible en général : les équipes peuvent analyser un bug, créer une issue et ouvrir une pull request sans quitter leur outil de collaboration. Canvas dans Teams permet de relire plans et changements collectivement.

→ Changelog: @GitHub in Slack and Teams is generally available and more

5. Copilot s'étend à Xcode et JetBrains Air

Copilot arrive dans l'assistant natif d'Xcode (preview publique) et dans JetBrains Air, où les tâches cloud utilisent l'abonnement Copilot existant. Un seul investissement couvre ainsi davantage d'environnements de développement.

Sources:
→ Changelog: GitHub Copilot is now available in Xcode's coding assistant
→ Changelog: GitHub Copilot is now available in JetBrains Air
