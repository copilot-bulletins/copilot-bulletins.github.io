🎯 Le fil de cette édition

Cette quinzaine marque le passage de l'IA agentique du stade expérimental à l'industrialisation : une application desktop dédiée, une API pour déclencher des agents par programmation, et des métriques d'adoption au niveau des équipes. GitHub Copilot s'impose comme une plateforme opérationnelle dont les résultats sont désormais mesurables et pilotables à l'échelle.

⚠️ Attention

  • GitHub Copilot bascule vers la facturation à l'usage le 1er juin 2026 — Échéance : 1er juin 2026 — Les crédits IA remplacent les requêtes premium ; téléchargez votre rapport d'avril et ajustez vos budgets en consultant la documentation de préparation.

🚀 Passez à l'action

  • Demandez l'accès à la préversion technique de l'application GitHub Copilot pour votre organisation et commencez à travailler avec plusieurs agents en parallèle.

  • Explorez l'API Agent Tasks pour intégrer l'agent cloud Copilot dans vos automatisations internes et portails développeurs.
  • Consultez les métriques d'utilisation Copilot par équipe pour identifier les équipes championnes et celles qui nécessitent un accompagnement.
  • Une question ou besoin d'aide ? Contactez votre équipe GitHub, nous sommes là pour vous accompagner.

🏆 Top 5 des mises à jour

1. L'application GitHub Copilot en préversion technique

L'application GitHub Copilot est une expérience desktop native conçue pour piloter le développement agentique : sessions parallèles sur des branches isolées, intégration GitHub directe (issues, pull requests, CI) et gestion complète du cycle de vie d'une PR sans quitter l'application. Un changement de paradigme pour les organisations voulant industrialiser les agents.

→ Changelog: GitHub Copilot app is now available in technical preview

2. L'agent cloud Copilot accessible via l'API REST

Les équipes peuvent désormais déclencher des tâches d'agent cloud par programmation : migrations en masse sur plusieurs dépôts, mise en place automatique de projets depuis un portail interne, génération de notes de release. Cette API ouvre de nouveaux cas d'usage pour multiplier le retour sur investissement de Copilot à l'échelle.

→ Changelog: Start Copilot cloud agent tasks via the REST API

3. Métriques Copilot au niveau des équipes disponibles via l'API

L'API de métriques expose désormais un rapport par équipe : utilisateurs actifs, complétions, chats, ventilés par IDE, modèle et langage. Les responsables peuvent identifier les équipes championnes, cibler les investissements d'activation et démontrer le ROI de Copilot à la granularité équipe.

→ Changelog: Team-level Copilot usage metrics now available via API

4. Rapports d'avril disponibles pour préparer la transition de facturation

À trois semaines du basculement vers les crédits IA, GitHub met à disposition les rapports d'utilisation d'avril. Ces données permettent d'identifier les équipes les plus consommatrices, de comprendre l'usage par modèle et d'estimer les volumes mensuels — un outil concret pour anticiper l'impact budgétaire avant le 1er juin.

→ Changelog: April reports are now available to prepare for usage-based billing

5. Sélection automatique de modèle pour l'agent cloud

L'agent cloud Copilot prend désormais en charge la sélection automatique de modèle : Copilot choisit le meilleur modèle disponible en temps réel, avec une remise de 10 % sur le multiplicateur et sans limite hebdomadaire de taux. Une optimisation immédiate des coûts pour les équipes utilisant l'agent cloud à grande échelle.

→ Changelog: Copilot cloud agent supports auto model selection
