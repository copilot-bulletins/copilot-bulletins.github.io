Biweekly #12 · Du 15 août au 31 août 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

Cette quinzaine confirme une bascule stratégique : Copilot sort de l'IDE pour devenir une plateforme agentique à l'échelle de l'organisation, présente là où les équipes échangent déjà. En parallèle, la gouvernance des modèles et les contrôles de coûts se renforcent. Pour les décideurs, l'enjeu n'est plus l'adoption individuelle, mais le pilotage d'un usage collaboratif, maîtrisé et mesurable.

⚠️ Attention

  • Upcoming changes to GitHub Copilot policies and billing — Action requise — Trois évolutions à venir : réouverture des inscriptions Business/Enterprise avec mise à jour de facturation, convergence de plusieurs expériences vers une politique unique, et passage du niveau d'effort par défaut de la revue de code à « Balanced ». Anticipez l'impact via la gestion des dépenses.

🚀 Passez à l'action

  • Cadrez votre stratégie de modèles avant l'entrée en vigueur en configurant la disponibilité des modèles par défaut.
  • Alignez vos politiques d'entreprise sur ces nouveaux usages collaboratifs via les politiques Copilot au niveau entreprise.
  • Mesurez le retour sur investissement avec les métriques d'usage Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. Copilot arrive dans Slack

L'intégration GitHub apporte les capacités agentiques de Copilot directement dans Slack, en préversion publique. Les équipes planifient, investiguent et délèguent des tâches de code depuis leurs conversations. GitHub est aussi partenaire de lancement de Slack Code, un nouveau type de canal conçu pour les agents.

→ Changelog: The new GitHub Copilot experience in Slack

2. Travail agentique partagé dans Microsoft Teams

Transformez une discussion Teams en session d'agent Copilot visible et pilotable par tous. Chacun peut poser des questions, ajouter du contexte et orienter le travail, tandis que les membres disposant d'un accès en écriture déclenchent les changements — avec un maintien de la conformité.

→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams

3. La politique globale de modèles devient générale

L'application de la politique de modèles par défaut est désormais déployée sur les plans Business et Enterprise. Les administrateurs gardent la main modèle par modèle, tandis que les modèles à poids ouverts ou nécessitant une rétention de données restent désactivés par défaut — une gouvernance claire et durable.

→ Changelog: Global model policy generally available

4. La revue de code Copilot élargit sa couverture

Copilot code review couvre désormais les pull requests créées par des bots (dont l'agent cloud) et les très grandes pull requests, avec des motifs de résolution de commentaires. Un levier direct de qualité et de vélocité à l'échelle, sans surcharger les équipes.

→ Changelog: Copilot code review: Resolution reasons and expanded capabilities

5. Des canevas pour des workflows agentiques maîtrisés

GitHub détaille comment les canevas rendent les workflows agentiques visibles, pilotables et efficients en coûts. Pour les décideurs, c'est la promesse d'une automatisation transparente et contrôlable, où l'investissement en agents reste lisible et orienté vers la valeur.

→ Blog: How canvases make agentic workflows visible, steerable, and cost-efficient
