Biweekly #7 · Du 1er juin au 14 juin 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

Durant cette quinzaine, GitHub a assemblé les briques d'une plateforme agentique : une application dédiée, l'automatisation des workflows, des agents partenaires, un SDK à intégrer et un modèle de facturation à l'usage. Pour les décideurs, le développement assisté par agents passe à l'échelle, avec les contrôles de gouvernance et la structure tarifaire nécessaires pour l'adopter sereinement.

⚠️ Attention

  • GPT-4.1 deprecated — Action requise — Retiré de Copilot depuis le 1er juin ; migrez vos workflows et intégrations vers GPT-5.5 (voir les modèles pris en charge).
  • GPT-5.2 and GPT-5.2-Codex deprecated — Action requise — Retirés depuis le 5 juin ; basculez vers GPT-5.5 et GPT-5.3-Codex. Les administrateurs activent les alternatives dans leurs politiques de modèles.
  • Claude Fable 5 is generally available for GitHub Copilot — Action requise — Annoncé le 9 juin puis suspendu le 12 juin sur l'ensemble de Copilot ; sélectionnez un autre modèle disponible (Claude Opus 4.8, Sonnet 4.6).

🚀 Passez à l'action

  • Évaluez la nouvelle application GitHub Copilot pour vos équipes, avec vos plans Copilot existants.
  • Maîtrisez vos coûts : passez en revue la facturation à l'usage et définissez des budgets.
  • Automatisez le travail d'ingénierie répétitif en testant GitHub Agentic Workflows en préversion publique.
  • Intégrez le moteur agentique de Copilot dans vos outils avec le SDK Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour

1. L'application GitHub Copilot, pensée pour les agents

Présentée à Microsoft Build 2026, cette application native réunit le pilotage de plusieurs agents et la revue du code généré en un seul endroit. Elle répond à la dispersion des workflows agentiques et fonctionne avec vos plans Copilot existants.

→ Blog: GitHub Copilot app: The agent-native desktop experience

2. GitHub Agentic Workflows en préversion publique

Automatisez des tâches d'ingénierie à base de raisonnement — tri des tickets, analyse des échecs CI, mises à jour de documentation — grâce à des agents dans GitHub Actions. Décrits en Markdown, ces workflows réutilisent vos runners et politiques existants. Carvana les exploite déjà à l'échelle.

→ Changelog: GitHub Agentic Workflows is now in public preview

3. Des agents partenaires intégrés à GitHub

Installez depuis le GitHub Marketplace des agents IA conçus par des partenaires (Amplitude, Sonar, PagerDuty, LaunchDarkly, Endor Labs...) et intégrés à vos workflows. Assignez-leur un ticket, mentionnez-les dans une pull request ou pilotez-les depuis l'interface Agents, sous le contrôle d'un administrateur.

→ Changelog: Extend GitHub with agent apps

4. Le SDK GitHub Copilot en disponibilité générale

Intégrez le moteur agentique de Copilot — planification, appels d'outils, édition de fichiers, sessions multi-tours — directement dans vos applications et services, sans bâtir votre propre orchestration. API stable, support de production et six langages (TypeScript, Python, Go, .NET, Rust, Java).

→ Changelog: Copilot SDK is now generally available

5. Facturation à l'usage et nouveaux contrôles budgétaires

Depuis le 1er juin, tous les plans Copilot sont facturés selon les GitHub AI Credits consommés, avec une enveloppe mensuelle incluse. De nouveaux contrôles de budget au niveau utilisateur et la possibilité de passer à Copilot Max accompagnent ce changement de modèle économique.

→ Changelog: Updates to GitHub Copilot billing and plans
