Monthly #5 · Août 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

Ce mois-ci, GitHub fait passer Copilot du statut d'outil de productivité à celui de plateforme pilotable. Le fil conducteur : rendre la valeur mesurable et la gouvernance actionnable à l'échelle de l'entreprise. Retour sur investissement chiffré, politiques de modèles centralisées, revue de code étendue et extensibilité standardisée dessinent une trajectoire claire vers un déploiement à la fois justifiable et maîtrisé.

⚠️ Attention

  • Évolutions à venir des politiques et de la facturation Copilot — Échéance : 1er octobre 2026 — Les mises à jour de facturation s'appliqueront aux clients Copilot Business et Enterprise existants ; anticipez avec la documentation de facturation.
  • Dépréciation à venir de MAI-code-1-flash — Échéance : 10 septembre 2026 — Migrez vos flux vers un modèle alternatif et vérifiez son activation via la politique de disponibilité des modèles.
  • Dépréciation à venir de GitHub Spark sur github.com — Action requise — Les applications utilisant llm() doivent remplacer l'inférence par un fournisseur distinct ; les autres ne sont pas affectées.

🚀 Passez à l'action

  • Évaluez le retour sur investissement de Copilot avec la nouvelle section du tableau de bord d'impact.
  • Standardisez le choix des modèles à l'échelle via la gestion de la disponibilité des modèles.
  • Étendez la revue de code automatisée à vos dépôts avec Copilot code review.
  • Pilotez l'adoption par agent grâce aux métriques d'usage Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. Le tableau de bord d'impact chiffre le retour sur investissement

Le tableau de bord d'impact compare désormais les développeurs selon leur niveau d'adoption et met en regard coût et production. Un sélecteur de salaire recalcule instantanément les métriques, permettant de modéliser un ROI sur vos propres hypothèses de paie et de justifier l'investissement.

→ Changelog: Copilot impact dashboard adds a return on investment section

2. La revue de code Copilot gagne en portée et en qualité

Copilot code review supprime la limite de 300 fichiers ou 20 000 lignes, prend en charge les pull requests des bots et des agents cloud, et introduit des raisons de résolution. Les niveaux d'effort passent en disponibilité générale : une qualité mieux gouvernée à grande échelle.

Sources:
→ Changelog: Copilot code review: Resolution reasons and expanded capabilities
→ Changelog: Copilot code review effort levels are generally available

3. La politique de modèle globale en disponibilité générale

La politique de modèle globale permet aux organisations et entreprises de définir de façon centralisée quels modèles sont disponibles, chaque modèle affichant un état explicite. Un levier de gouvernance clé pour maîtriser les coûts, la conformité et la cohérence des usages à l'échelle.

→ Changelog: Global model policy generally available

4. Agent plugins 1.0 : une extensibilité standardisée

Le standard Agent plugins 1.0 unifie l'empaquetage des compétences et serveurs MCP à travers VS Code, Copilot CLI, le SDK et l'application Copilot, sur tous les forfaits. Moins de duplication, une portabilité accrue : un signal fort sur la maturité de l'écosystème agentique.

→ Changelog: Agent plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

5. Le travail agentique partagé arrive dans Teams et Slack

Copilot s'invite dans les outils de collaboration : déléguez une tâche depuis une réunion Teams ou un canal Slack, suivez la progression dans le fil et récupérez les artefacts dans votre IDE. Copilot étend sa portée bien au-delà de l'éditeur.

Sources:
→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams
→ Changelog: The new GitHub Copilot experience in Slack
