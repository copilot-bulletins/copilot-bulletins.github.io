🏆 Top 5 des mises à jour du mois

1. GitHub Copilot passe à la facturation à l'usage le 1er juin

Le modèle de facturation évolue : les requêtes premium cèdent la place aux crédits IA (1 crédit = 0,01 $), avec une enveloppe promotionnelle triplée jusqu'en septembre pour les clients Business et Enterprise. Ce changement offre aux dirigeants une visibilité directe sur le coût réel par fonctionnalité IA utilisée.

Sources:
→ Blog: GitHub Copilot is moving to usage-based billing
→ Changelog: April reports are now available to prepare for usage-based billing

2. L'application GitHub Copilot en préversion technique

L'application GitHub Copilot est un client desktop natif pour le développement agentique : sessions parallèles sur branches isolées, intégration directe avec GitHub (issues, PRs, CI) et gestion complète du cycle de vie sans changer d'outil. Un levier clé pour industrialiser les agents IA à l'échelle.

→ Changelog: GitHub Copilot app is now available in technical preview

3. Mesurer la maturité IA des équipes avec les cohortes d'adoption

L'API d'utilisation Copilot classe désormais chaque utilisateur dans une phase d'adoption IA (code-first, agent-first, multi-agent) sur une fenêtre glissante de 28 jours. Les dirigeants peuvent ainsi mesurer objectivement la progression de leurs équipes vers des usages avancés et cibler les investissements d'activation.

→ Changelog: Copilot usage metrics API adds cohorts for AI adoption

4. Claude Opus 4.8, nouveau modèle phare disponible dans Copilot

Le dernier modèle d'Anthropic est désormais accessible dans GitHub Copilot (Pro+, Business et Enterprise). Avec des capacités améliorées en compréhension de code et résolution de problèmes complexes, il renforce la compétitivité de l'offre Copilot face aux alternatives du marché.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

5. L'agent cloud Copilot accessible via l'API REST

Les équipes peuvent désormais déclencher des tâches d'agent cloud par programmation : migrations en masse sur plusieurs dépôts, génération automatisée de PRs, notes de release. Cette API ouvre la voie à une multiplication du ROI Copilot en intégrant l'IA directement dans les pipelines de développement existants.

→ Changelog: Start Copilot cloud agent tasks via the REST API
