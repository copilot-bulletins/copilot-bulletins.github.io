Monthly #3 · Juin 2026 · Decision-Makers Edition

🎯 Le fil de cette édition

En juin, GitHub fait passer Copilot du statut d'assistant à celui de plateforme d'agents d'entreprise : de nouvelles surfaces atteignent la disponibilité générale et le moteur d'agents s'ouvre aux développeurs comme aux partenaires. Des contrôles budgétaires et des indicateurs d'adoption renforcés donnent aux dirigeants les moyens de déployer l'IA à grande échelle, avec des coûts maîtrisés et un impact mesurable.

⚠️ Attention

  • GPT-4.1 deprecated — Action requise — Modèle retiré de toutes les expériences Copilot depuis le 1er juin 2026 ; vérifiez que vos équipes sont basculées vers un modèle pris en charge via la gestion des modèles par défaut.
  • GPT-5.2 and GPT-5.2-Codex deprecated — Action requise — Modèles retirés depuis le 5 juin 2026 (GPT-5.2 reste disponible pour Copilot code review) ; sélectionnez un modèle pris en charge.
  • Upcoming deprecation of Opus 4.6 (fast) — Échéance : 29 juin 2026 — Opus 4.6 (fast) est retiré ; migrez vos flux vers un modèle actif tel qu'Opus 4.8 (fast mode).

🚀 Passez à l'action

  • Anticipez vos dépenses d'IA en définissant des budgets d'AI Credits par centre de coûts, dans le cadre de la facturation à l'usage.
  • Objectivez le ROI de Copilot grâce aux indicateurs d'utilisation et au suivi des fusions par phase d'adoption.
  • Cadrez votre déploiement à grande échelle avec le guide d'adoption de Copilot en entreprise.
  • Évaluez la nouvelle application GitHub Copilot pour offrir à vos équipes un poste de travail piloté par agents.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. L'application Copilot pour bureau atteint la disponibilité générale

L'application GitHub Copilot est désormais en disponibilité générale sur macOS, Windows et Linux. Ce poste de travail natif pour le développement piloté par agents permet de lancer des sessions parallèles sur plusieurs dépôts. Un jalon produit qui confirme l'orientation « agent-first » de GitHub.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

2. Copilot devient une plateforme d'agents programmable

Le SDK Copilot passe en disponibilité générale et permet d'intégrer le moteur d'agents de GitHub dans vos propres outils. Couplé aux workflows agentiques (préversion publique) et aux agent apps du Marketplace, Copilot s'ouvre pour automatiser le travail d'ingénierie à grande échelle.

Sources:
→ Changelog: Copilot SDK is now generally available
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Extend GitHub with agent apps

3. Une gouvernance des coûts d'IA à l'échelle de l'entreprise

Depuis le 1er juin, tous les plans sont facturés à l'usage sur la base des AI Credits. Les administrateurs peuvent définir un budget par utilisateur au niveau des centres de coûts, qui suit automatiquement les mouvements d'équipe — une maîtrise budgétaire prévisible et granulaire.

Sources:
→ Changelog: Updates to GitHub Copilot billing and plans
→ Changelog: Per-user AI credit budgets available for cost centers
→ Changelog: AI credits consumed per user now in the Copilot usage metrics API

4. Mesurer l'adoption et l'impact réels

Les rapports d'utilisation intègrent désormais la télémétrie côté serveur et comptabilisent davantage d'utilisateurs actifs. Les rapports d'organisation et d'entreprise suivent le nombre total de pull requests fusionnées par phase d'adoption — un lien direct entre l'usage de Copilot et le ROI livré.

Sources:
→ Changelog: Copilot usage metrics now include more of your active users
→ Changelog: Track total merges by adoption phase in enterprise and organization reports

5. Le choix de modèles de pointe s'élargit encore

Copilot enrichit son catalogue avec la disponibilité générale de Claude Sonnet 5, la préversion d'Opus 4.8 (fast mode), les modèles Gemini et MAI-Code-1-Flash, plus une fenêtre de contexte d'un million de tokens. De quoi rester à la frontière technologique sans dépendance à un fournisseur unique.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot
→ Changelog: Gemini models in Copilot CLI, cloud agent, and the Copilot app
→ Changelog: MAI-Code-1-Flash is now available for GitHub Copilot
