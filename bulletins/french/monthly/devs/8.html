Monthly #8 · Octobre 2026 · Devs Edition

🎯 Le fil de cette édition

Octobre, marqué par GitHub Universe, fait passer Copilot d'assistant de session à système d'agents persistant. Le choix des modèles s'automatise, les tâches répétitives deviennent des workflows déclenchés par des événements, et le contexte (mémoire, outils externes) suit le développeur d'un client à l'autre. Pour les développeurs, cela réduit la configuration manuelle et les changements de contexte.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Deadline: 16 novembre 2026 — Claude Opus 4.8, Claude Opus 5 et GPT-5.6 Terra seront retirés : migrez vos workflows vers Claude Opus 5.5, GPT-6.1 Sol ou GPT-6 Luna en consultant les modèles pris en charge.
  • GitHub Copilot in Visual Studio — September update — Action required — Le BYOM exige désormais le nouveau mode Agent (Preview) : les anciens modes Ask et Agent ne le prennent plus en charge, et les modèles Ollama doivent être ajoutés à nouveau après la mise à jour.

🚀 Passez à l'action

  • Sélectionnez Copilot Fusion dans le sélecteur de modèles et choisissez un niveau d'effort, après avoir lu la documentation Copilot Fusion.
  • Automatisez une tâche récurrente (triage, reproduction de bugs) en créant une automation avec le cloud agent.
  • Activez Watch and fix dans la merge box de vos pull requests avec Agent Merge.
  • Connectez Slack, Figma ou Sentry en une fois grâce aux Copilot connectors.
  • Des questions ou besoin d'aide ? Contactez votre équipe GitHub, nous sommes là pour vous accompagner.

🏆 Top 5 des mises à jour du mois

1. Copilot Fusion : plus besoin de choisir son modèle

Copilot Fusion, désormais en disponibilité générale, route et orchestre plusieurs modèles à chaque prompt (Single, Cascade, Critique). Vous choisissez seulement l'effort (Standard, High, Max). Le routage vers des modèles locaux est aussi proposé en preview expérimentale. Remise de 30 % pour une durée limitée.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot Fusion now supports selection of local models

2. Copilot Automations : des workflows d'équipe qui s'améliorent seuls

Les automations deviennent partagées au niveau du dépôt, gagnent 24 nouveaux déclencheurs, un déclenchement par API REST, 20 nouveaux outils et des plafonds de crédits IA. Elles peuvent proposer des améliorations de leur propre prompt et se gèrent depuis VS Code 1.144.

Sources:
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: New tools, triggers, and cost controls for Copilot Automations
→ Changelog: Copilot Automations now learn from outcomes and self-improve
→ Changelog: Create and manage Copilot Automations in Visual Studio Code

3. De la pull request au merge : Agent Merge et code review Max

Agent Merge surveille vos PR sur github.com et corrige automatiquement les workflows Actions en échec et les conflits de merge. Côté revue, le niveau Max (preview) combine plusieurs agents multi-modèles, et Copilot peut désormais approuver une PR prête (GA).

Sources:
→ Changelog: Agent Merge watches and fixes pull requests in the cloud
→ Changelog: Copilot code review: Merge with confidence with Max and approvals

4. Une session cloud unique, accessible partout

Lancez une tâche depuis github.com, Mobile, la CLI, l'app Copilot, VS Code, Slack ou Teams, puis reprenez-la ailleurs. Chaque session s'exécute par défaut dans une sandbox cloud sécurisée, financée par votre quota Actions inclus. Disponible en GA sur les plans payants.

Sources:
→ Changelog: Work from anywhere with a new, connected Copilot cloud experience
→ Changelog: GitHub Copilot in VS Code, Universe releases

5. Mémoire et connecteurs : Copilot garde le contexte

Copilot Memory passe en GA : préférences et conventions de dépôt persistent entre sessions et clients. Le « dreaming » (preview) affine ce contexte. Les connecteurs MCP vérifiés (26 services, dont Slack, Figma, Sentry) se configurent une seule fois pour tous les clients.

Sources:
→ Changelog: GitHub intelligence puts your code, context, and history to work
→ Changelog: Connect your tools to Copilot without all the setup
