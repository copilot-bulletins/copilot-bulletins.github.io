L'agent s'adapte à votre contexte — vous restez dans votre flux de travail.

🏆 Top 5 des mises à jour du mois

1. VS Code en avril : Autopilot et Copilot intégré nativement

La publication VS Code du 8 avril introduit Autopilot : l'agent approuve ses propres actions et travaille de façon autonome jusqu'à la fin, sans interruption. VS Code 1.116 (mi-avril) va plus loin : GitHub Copilot est désormais intégré nativement à l'éditeur, sans extension à installer.

Sources : → Changelog: GitHub Copilot in Visual Studio Code, March Releases
→ Blog: VS Code 1.116 release notes

2. Copilot CLI : BYOK et support des modèles locaux

Copilot CLI accepte désormais vos propres clés de fournisseur : Azure OpenAI, Anthropic, Ollama ou tout endpoint compatible OpenAI. Définissez COPILOT_OFFLINE=true pour les workflows air-gap. L'authentification GitHub devient optionnelle quand vous apportez vos propres modèles.

→ Changelog: Copilot CLI now supports BYOK and local models

3. Pilotez vos sessions CLI depuis n'importe quel appareil

Démarrez une session Copilot CLI avec copilot --remote : votre session est streamée vers GitHub en temps réel. Obtenez un lien et un QR code pour superviser et piloter votre tâche depuis n'importe quel navigateur ou depuis GitHub Mobile — sans rester à la machine.

→ Changelog: Remote control CLI sessions on web and mobile in public preview

4. Résolvez les conflits de fusion en trois clics avec l'agent cloud

Un bouton « Fix with Copilot » apparaît dans la merge box lorsqu'une PR est en conflit. Cliquez, soumettez le commentaire pré-rempli, et l'agent cloud résout les conflits, vérifie que le build passe et pousse directement — depuis son environnement cloud isolé.

→ Changelog: Fix merge conflicts in three clicks with Copilot cloud agent

5. Visual Studio avril 2026 : agent cloud depuis l'IDE et agent débogueur

Visual Studio 2026 (avril) permet de lancer des sessions cloud agent directement depuis l'IDE. Un nouvel agent débogueur reproduit les bugs depuis une issue GitHub ou Azure DevOps, instrumente l'exécution réelle et propose un correctif ciblé. Les agents personnalisés passent en définitions de niveau utilisateur.

→ Changelog: GitHub Copilot in Visual Studio — April update
