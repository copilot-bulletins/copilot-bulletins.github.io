Monthly #6 · Août 2026 · Devs Edition

🎯 Le fil de cette édition

Août 2026 confirme une orientation claire pour les développeurs : rendre Copilot plus modulaire et adaptable à chaque flux de travail. Standardisation des plugins d'agents, élargissement du catalogue de modèles, revue de code plus autonome et progrès continus dans les IDE dessinent un écosystème où vous composez votre environnement de développement plutôt que de le subir.

⚠️ Attention

  • Dépréciation prochaine de MAI-Code-1-Flash — Date limite : 10 septembre 2026 — Migrez vos flux de travail et intégrations vers MAI-Code-1.1-Flash avant cette date ; au besoin, activez le modèle de remplacement via vos politiques de modèles.
  • Dépréciation de GitHub Spark sur github.com — Date limite : 31 août 2026 — Spark n'accepte plus de nouveaux utilisateurs ni de nouvelles apps ; les utilisateurs existants ont jusqu'au 31 août pour exporter leurs apps déjà créées.

🚀 Passez à l'action

  • Testez les nouveaux modèles agentiques (Grok 4.6, Gemini 3.7 Flash, Kimi K3) en changeant de modèle dans Copilot Chat.
  • Étendez vos agents avec des serveurs MCP en suivant le guide étendre Copilot Chat avec MCP.
  • Automatisez vos revues avec la revue de code Copilot sur vos pull requests.
  • Installez et essayez Copilot CLI pour piloter des agents depuis votre terminal.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. VS Code : sessions d'agents et revue plus fluides

Les versions v1.132 à v1.135 facilitent l'organisation des sessions d'agents, la revue des changements et la navigation dans les longues conversations. L'Agent Host, le navigateur intégré et la dictée gagnent aussi en robustesse pour les workflows agentiques du quotidien.

→ Changelog: GitHub Copilot in VS Code, August 2026 releases

2. Agent Plugins 1.0 : construire une fois, utiliser partout

Vous pouvez désormais écrire un plugin une seule fois et l'exécuter sur tous les clients d'agents compatibles (VS Code, Copilot CLI, application Copilot). Publiée avec AWS, Anysphere, Microsoft, OpenAI, Vercel et Google, cette norme ouverte simplifie la construction et la migration de vos extensions.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

3. Un catalogue de modèles élargi

Le choix s'étoffe côté modèles agentiques : Grok 4.6 (xAI) pour les workflows complexes multi-étapes, Gemini 3.7 Flash et Kimi K3 rejoignent Copilot, tandis que MAI-Code-1.1-Flash remplace la version précédente. De quoi adapter le modèle à chaque tâche de code.

Sources:
→ Changelog: Grok 4.6 is now available in GitHub Copilot
→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot
→ Changelog: Kimi K3 is now available in GitHub Copilot
→ Changelog: MAI-Code-1.1-Flash available in GitHub Copilot

4. La revue de code Copilot monte en puissance

Copilot couvre maintenant les pull requests ouvertes par des bots (dont l'agent cloud) et les très grosses PR. Vous pouvez indiquer la raison de résolution d'un commentaire, et les niveaux d'effort passent en disponibilité générale pour ajuster la profondeur d'analyse.

Sources:
→ Changelog: Copilot code review: Resolution reasons and expanded capabilities
→ Changelog: Copilot code review effort levels are generally available

5. JetBrains : harness agentique et mémoire

L'expérience JetBrains progresse : le Copilot harness passe en disponibilité générale pour des interactions agentiques plus fiables, tandis que la mémoire Copilot et la prise en charge d'Ollama arrivent pour conserver le contexte et exécuter des modèles locaux.

Sources:
→ Changelog: Copilot harness generally available in Copilot for JetBrains
→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains
