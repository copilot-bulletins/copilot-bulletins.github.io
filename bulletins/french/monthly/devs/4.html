Monthly #4 · Juin 2026 · Devs Edition

🎯 Le fil de cette édition

En juin, l'expérience agentique de Copilot a gagné en maturité pour les développeurs. Nouveaux modèles, application de bureau, interface CLI stabilisée et environnements d'exécution isolés convergent vers un même objectif : déléguer davantage de travail à des agents, sur plus de surfaces, sans perdre le contrôle. Choisir le bon modèle et la bonne surface devient un réflexe quotidien.

⚠️ Attention

  • GPT-4.1 est déprécié — Échéance : 1 juin 2026 — Basculez vers GPT-5.5 depuis le sélecteur de modèle de Copilot Chat.
  • GPT-5.2 et GPT-5.2-Codex sont dépréciés — Échéance : 5 juin 2026 — Migrez vers GPT-5.5 et GPT-5.3-Codex ; vérifiez les modèles pris en charge.
  • Dépréciation à venir d'Opus 4.6 (fast) — Échéance : 29 juin 2026 — Remplacez-le par Opus 4.8 (fast) via vos paramètres de modèle.

🚀 Passez à l'action

  • Essayez Claude Sonnet 5 et Opus 4.8 (fast) depuis le sélecteur de modèle de Copilot Chat.
  • Installez l'application GitHub Copilot pour lancer vos sessions d'agents depuis le bureau.
  • Adoptez la nouvelle interface en installant ou mettant à jour Copilot CLI.
  • Expérimentez l'exécution isolée avec les sandboxes du cloud agent.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. De nouveaux modèles et des fenêtres de contexte d'un million de tokens

Claude Sonnet 5 passe en disponibilité générale et Opus 4.8 (fast) en préversion. En parallèle, les fenêtres de contexte atteignent un million de tokens avec des niveaux de raisonnement configurables : de quoi traiter de plus grandes bases de code et ajuster vitesse et profondeur selon la tâche.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot

2. L'application GitHub Copilot est disponible pour tous

L'application de bureau GitHub Copilot passe en disponibilité générale sur macOS, Windows et Linux. Conçue pour le développement piloté par agents, elle lance des sessions depuis une issue, une pull request ou un prompt, en parallèle sur plusieurs dépôts, et prend désormais en charge le BYOK.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

3. Copilot CLI : nouvelle interface de terminal en disponibilité générale

La nouvelle interface du terminal Copilot CLI passe en disponibilité générale : navigation par onglets dans les issues, pull requests et gists, et affichage plus lisible. Le mois ajoute aussi la configuration centralisée via /settings, une commande dédiée de revue de sécurité et la prise en charge des modèles BYOK.

Sources:
→ Changelog: Copilot CLI: New terminal interface is generally available
→ Changelog: Copilot CLI: Configure everything from one place with /settings
→ Changelog: Dedicated security review command now available in Copilot CLI

4. Des sandboxes et une orchestration d'agents plus poussée

Copilot introduit des sandboxes cloud et locales en préversion publique pour exécuter le code des agents de façon isolée. S'y ajoutent la planification de tâches pour le cloud agent et la commande /chronicle, qui offre une vue d'ensemble de vos sessions d'agents.

Sources:
→ Changelog: Cloud and local sandboxes for GitHub Copilot now in public preview
→ Changelog: Schedule and automate tasks with Copilot cloud agent
→ Changelog: Gain insights across your agent sessions with /chronicle

5. Copilot s'étend dans les IDE JetBrains, VS Code et Visual Studio

L'agent Copilot arrive dans JetBrains AI Assistant, avec Claude en préversion comme fournisseur d'agent et de nouvelles capacités agentiques dans les IDE JetBrains. VS Code et Visual Studio reçoivent par ailleurs leurs mises à jour de mai, consolidant l'expérience directement dans l'éditeur.

Sources:
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs
→ Changelog: GitHub Copilot in Visual Studio Code, May releases
→ Changelog: GitHub Copilot in Visual Studio — May update
