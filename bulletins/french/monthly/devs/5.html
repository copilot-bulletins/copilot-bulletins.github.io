Monthly #5 · Juillet 2026 · Devs Edition

🎯 Le fil de cette édition

Ce mois-ci, le choix s'impose comme fil conducteur. GitHub a élargi son catalogue de modèles de pointe et consolidé son écosystème agentique — CLI, IDE, MCP et revue de code désormais extensibles. Pour les développeurs, l'enjeu devient d'associer le bon modèle et le bon agent à chaque tâche, tout en gardant la maîtrise de leur environnement de travail.

⚠️ Attention

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Deadline : 31 juillet 2026 — Ces deux modèles sont retirés de toutes les expériences Copilot. Migrez vos workflows vers un modèle pris en charge et vérifiez la disponibilité via la documentation sur les modèles.

🚀 Passez à l'action

  • Testez les nouveaux modèles et basculez selon la tâche depuis le sélecteur de modèle de Copilot Chat.
  • Installez et essayez la sélection automatique de modèle avec Copilot CLI.
  • Étendez vos agents avec des serveurs MCP et personnalisez la revue de code Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. Une nouvelle vague de modèles de pointe

Le catalogue s'enrichit fortement : Claude Opus 5, GPT-5.6 (Sol, Terra, Luna), Grok 4.5, Gemini 3.6 Flash et Kimi K2.7 Code rejoignent Copilot. De quoi arbitrer entre raisonnement lourd, rapidité et coût selon chaque tâche de codage.

Sources:
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot
→ Changelog: Gemini 3.6 Flash is now available in GitHub Copilot
→ Changelog: Kimi K2.7 Code is generally available in GitHub Copilot

2. Copilot CLI monte en puissance

La CLI gagne en autonomie : sélection automatique du modèle selon la tâche, plus besoin de token personnel dans GitHub Actions, nouvelle compétence de configuration du serveur de langage C++, et limites de crédits IA par session pour maîtriser la consommation.

Sources:
→ Changelog: Copilot CLI auto model selection routes based on task
→ Changelog: Copilot CLI no longer needs a personal access token in GitHub Actions
→ Changelog: New C++ language server config skill for Copilot CLI
→ Changelog: Set AI credit session limits in Copilot CLI and SDK

3. Des IDE plus visuels et multimodaux

Copilot Vision et les outils de navigateur passent en disponibilité générale dans VS Code : joignez des captures, laissez Copilot inspecter une page et itérer sur l'UI. Les mises à jour mensuelles de VS Code et Visual Studio suivent la cadence.

Sources:
→ Changelog: Copilot vision is generally available
→ Changelog: Browser tools for GitHub Copilot in VS Code are generally available
→ Changelog: GitHub Copilot in Visual Studio Code, July 2026 releases
→ Changelog: GitHub Copilot in Visual Studio — July update

4. Des agents toujours plus autonomes

Le streaming des sessions d'agent arrive en préversion publique pour suivre le travail en temps réel, l'agent cloud pour Linear passe en disponibilité générale, et de nouveaux contrôles d'automatisation encadrent les agents dans GitHub Issues.

Sources:
→ Changelog: Copilot agent session streaming is now in public preview
→ Changelog: Copilot cloud agent for Linear is now generally available
→ Changelog: Agent automation controls in GitHub Issues in public preview

5. MCP et revue de code deviennent extensibles

Le serveur MCP de GitHub adopte la prochaine spécification MCP, et la revue de code Copilot ouvre les compétences d'agent et MCP en disponibilité générale : branchez vos propres outils et contextes pour des revues sur mesure.

Sources:
→ Changelog: GitHub MCP Server supports the next MCP specification
→ Changelog: Copilot code review: Agent skills and MCP now generally available
