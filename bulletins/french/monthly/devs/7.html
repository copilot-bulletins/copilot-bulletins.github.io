Monthly #7 · Septembre 2026 · Devs Edition

🎯 Le fil de cette édition

Septembre a été marqué par une accélération sur les modèles : nouvelle vague de modèles disponibles, orchestration multi-modèles avec HydraFusion et réglage fin du compromis coût/qualité. Pour les développeurs, l'enjeu n'est plus seulement d'avoir le bon modèle, mais de choisir intelligemment lequel utiliser selon chaque tâche, directement dans l'IDE et la CLI.

⚠️ Attention

  • Dépréciation de plusieurs modèles Copilot mi-octobre — Date limite : 19 octobre 2026 — Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini et Grok 4.5 seront retirés de toutes les expériences Copilot. Basculez vers les alternatives suggérées et vérifiez les modèles pris en charge.

🚀 Passez à l'action

  • Essayez HydraFusion depuis le sélecteur de modèles de VS Code et de l'app Copilot pour vos tâches complexes.
  • Réglez le compromis coût/qualité en choisissant un palier dans la sélection automatique de modèle.
  • Mettez à jour vos workflows avant le 19 octobre en consultant les modèles pris en charge.
  • Protégez vos dépôts en configurant les exclusions de contenu dans l'app et la Copilot CLI.
  • Des questions ou besoin d'aide ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. HydraFusion arrive dans VS Code et l'app Copilot

La préversion de recherche HydraFusion s'étend au-delà de la CLI vers VS Code et l'app Copilot. Plutôt qu'un modèle unique, elle orchestre plusieurs modèles et traite la sélection du bon workflow comme un problème d'optimisation, pour une qualité de pointe sur les tâches exigeantes.

Sources:
→ Changelog: HydraFusion in VS Code and the GitHub Copilot app
→ Blog: Project HydraFusion: frontier quality via multi-model orchestration

2. Une nouvelle vague de modèles disponibles

Le choix de modèles s'enrichit fortement : GPT-6 Astra en disponibilité générale, GPT-6 Sol et Luna, GPT-6.1 Sol, Claude Opus 5.5 et Sonnet 5.5, Grok 4.7 et Gemini 3.8 Flash. De quoi ajuster chaque tâche au modèle le plus adapté.

Sources:
→ Changelog: GPT-6 Astra is generally available in GitHub Copilot
→ Changelog: Claude Opus 5.5 is now available in GitHub Copilot
→ Changelog: GPT-6.1 Sol in GitHub Copilot

3. Réglez le compromis coût et qualité de la sélection automatique

La sélection automatique de modèle propose désormais trois paliers : efficacité, équilibre et intelligence. Choisissez comment Copilot pondère coût, qualité et latence pour chaque prompt : efficacité pour les tâches rapides, intelligence pour les tâches complexes.

Sources:
→ Changelog: Configure cost and quality in Copilot auto model selection
→ Blog: How we make AI coding more cost-efficient without sacrificing task quality

4. L'expérience IDE progresse : JetBrains et C++

Copilot pour JetBrains 1.18.0 apporte les approbations d'outils assistées par l'IA, plus de contrôle sur les conversations d'agent et le partage de skills et d'instructions. Côté CLI, l'intelligence de code C++ gagne en vitesse grâce à l'indexation complète du dépôt.

Sources:
→ Changelog: New features and improvements in Copilot for JetBrains
→ Changelog: Faster C++ code intelligence with whole codebase indexing

5. Sandboxing local dans l'app Copilot

Le sandboxing local réduit l'impact de commandes involontaires en limitant l'accès aux fichiers, au réseau et aux identifiants de votre machine. Vous le configurez par projet pour les sessions de dépôt local, pour exécuter les agents avec plus de sérénité.

→ Changelog: Local sandboxing in the GitHub Copilot app
