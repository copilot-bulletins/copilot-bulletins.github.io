🏆 Top 5 des mises à jour du mois

1. L'application GitHub Copilot arrive en préversion technique

L'application GitHub Copilot est une interface desktop native dédiée au développement agentique. Lancez plusieurs agents en parallèle sur des branches isolées, gérez vos issues et PRs sans quitter l'application. L'Agent Merge traite les retours de review et fusionne automatiquement selon vos conditions.

→ Changelog: GitHub Copilot app is now available in technical preview

2. Le contrôle à distance des sessions Copilot est désormais disponible

Le contrôle à distance arrive en disponibilité générale sur GitHub.com, GitHub Mobile, VS Code et JetBrains. Démarrez une session dans le CLI ou VS Code, puis utilisez /remote on pour la suivre depuis n'importe quel appareil, approuver des permissions et envoyer des instructions en cours de route.

→ Blog: Take your local GitHub sessions anywhere

3. Claude Opus 4.8 disponible dans GitHub Copilot

Le dernier modèle Opus d'Anthropic est désormais disponible dans toutes les surfaces Copilot (VS Code, CLI, application, GitHub.com, mobile, JetBrains). Opus 4.8 se distingue par une meilleure compréhension du code et une navigation renforcée dans les grandes bases de code. Disponible pour Pro+, Business et Enterprise.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

4. VS Code : les releases d'avril apportent BYOK et accès terminal

Quatre releases consécutives (v1.116–v1.119) couvrant avril et début mai : BYOK (apportez votre propre clé API) pour Business et Enterprise, indexation sémantique dans tous les workspaces, accès lecture/écriture aux terminaux ouverts, et navigateur intégré pour la validation en direct.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

5. Copilot Memory s'enrichit de nouveaux contrôles

Disponible en préversion publique pour tous les plans payants. Nouveautés : suppression guidée des souvenirs, désactivation par repository pour les admins, commande /memory dans Copilot CLI, et étiquetage explicite de la portée (préférence utilisateur ou fait du dépôt) au moment de la capture.

→ Changelog: Copilot Memory has more controls for deletion, scope, and the Copilot CLI
