Monthly #5 · Juillet 2026 · Admins Edition

🎯 Le fil de cette édition

Juillet a placé la gouvernance au cœur de Copilot. Métriques d'usage plus fines, contrôle budgétaire par centre de coûts, politiques d'entreprise ciblées et paramètres gérés étendus à l'application Copilot : GitHub outille les administrateurs pour piloter l'adoption, maîtriser les coûts et encadrer l'IA à grande échelle, sans freiner les équipes.

⚠️ Attention

  • Gemini 2.5 Pro et Gemini 3 Flash retirés — Action requise — Ces modèles ne sont plus disponibles ; vérifiez vos politiques de modèles et migrez les utilisateurs concernés via la gestion des modèles par défaut.
  • L'app Copilot Billing (preview) sera retirée le 3 août — Échéance : 3 août 2026 — Basculez vers les outils de facturation intégrés et les budgets d'usage.

🚀 Passez à l'action

  • Cadrez votre stratégie avec le guide de gouvernance de l'IA en entreprise.
  • Affinez vos politiques d'entreprise Copilot pour encadrer agents et modèles.
  • Suivez l'adoption réelle avec les métriques d'usage Copilot.
  • Déployez des paramètres gérés d'entreprise pour l'application Copilot.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. Des métriques d'usage plus riches et fiables

GitHub muscle son offre de mesure : nouveau tableau de bord d'impact, métriques au niveau des dépôts désormais en disponibilité générale et agrégation étendue de l'usage de l'application Copilot. De quoi objectiver l'adoption et le ROI par équipe.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: GitHub Copilot app usage metrics now expand across report rollups

2. Maîtrise des coûts par centre de coûts

La facturation gagne en granularité : pools de crédits IA et budgets par utilisateur rattachés aux centres de coûts, directement dans l'interface. Les administrateurs allouent, plafonnent et suivent la dépense IA par équipe sans tableur externe.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI

3. Politiques et paramètres gérés renforcés

Le ciblage des politiques de modèles par équipe d'entreprise entre en préversion publique, tandis que les paramètres gérés et une politique d'accès dédiée s'appliquent désormais à l'application Copilot. Le contrôle d'accès se centralise et se précise.

Sources:
→ Changelog: Enterprise teams model policy targeting in public preview
→ Changelog: Enterprise managed settings now apply to the GitHub Copilot app
→ Changelog: Manage GitHub Copilot app access with a dedicated policy

4. Sécurité pilotée par l'agent Copilot

Copilot renforce la posture de sécurité : autofix agentique pour les alertes de code scanning en préversion publique, revues de sécurité dans l'application Copilot, et l'agent de revue de code (skills et MCP) en disponibilité générale. Une remédiation plus rapide, gouvernée.

Sources:
→ Changelog: Agentic autofix for code scanning alerts in public preview
→ Changelog: Security reviews now available in the GitHub Copilot app
→ Changelog: Copilot code review agent skills and MCP now generally available

5. Déploiement et supervision à l'échelle

L'administration s'industrialise : déploiement des paramètres Copilot via MDM pour VS Code et la CLI, export OpenTelemetry géré par l'entreprise, et restriction du contrôle à distance aux seuls appareils gérés. Distribution maîtrisée et observabilité centralisée.

Sources:
→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI
→ Changelog: Enterprise managed OpenTelemetry export for VS Code and CLI
→ Changelog: Limit remote control to managed devices
