Monthly #7 · Septembre 2026 · Admins Edition

🎯 Le fil de cette édition

En septembre, GitHub a consolidé l'outillage de gouvernance autour de Copilot. Permissions d'agents pilotées au niveau entreprise, politique d'activation par défaut des fonctionnalités, validateur de paramètres managés et métriques d'adoption enrichies convergent vers un même objectif : donner aux administrateurs des leviers fermes, mesurables et non contournables pour déployer l'IA à grande échelle tout en maîtrisant le risque et les coûts.

⚠️ Attention

  • Dépréciation de plusieurs modèles Copilot à la mi-octobre — Échéance : 19 octobre 2026 — Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini et Grok 4.5 seront retirés. Vérifiez que les modèles de remplacement sont bien activés dans vos politiques de modèles d'entreprise.

🚀 Passez à l'action

  • Configurez la nouvelle politique d'activation par défaut pendant la fenêtre de 28 jours, avant qu'elle ne s'applique à vos utilisateurs.
  • Définissez des garde-fous sur les opérations d'agents via les permissions managées d'entreprise.
  • Analysez l'adoption réelle de Copilot dans votre organisation grâce au tableau de bord d'usage et d'adoption.
  • Revoyez vos budgets Copilot pour gérer les demandes d'augmentation désormais disponibles.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. Permissions d'agents pilotées au niveau entreprise

Les administrateurs Business et Enterprise contrôlent désormais de façon centralisée quelles opérations d'agents sont bloquées, exigent une approbation humaine ou s'exécutent sans invite : commandes shell, lectures et écritures de fichiers, domaines réseau. Ces restrictions ne peuvent pas être affaiblies par un utilisateur ou l'auto-approbation.

→ Changelog: Enterprise managed permissions for GitHub Copilot agent operations

2. Politique d'activation par défaut des fonctionnalités Copilot

Une nouvelle politique globale régit l'accès aux fonctionnalités Copilot généralement disponibles pour les paramètres d'entreprise et d'organisation. Pendant 28 jours, vous pouvez la configurer sans impact sur les utilisateurs : l'occasion d'arbitrer entre activation automatique et contrôle explicite avant son entrée en vigueur.

→ Changelog: Default Enablement of Copilot features for Copilot Business and Enterprise

3. Gouvernance renforcée de la revue de code Copilot

La revue de code Copilot gagne des contrôles de niveau entreprise : effort de revue par défaut pour les dépôts d'organisation, page de paramètres personnels dédiée, auto-résolution et analyses améliorées. De quoi standardiser la rigueur de revue sans dépendre des réglages individuels.

Sources:
→ Changelog: More ways to request and configure Copilot code reviews
→ Changelog: Copilot code review: an improved review experience
→ Changelog: Auto-resolution and analysis updates in Copilot code review

4. Métriques d'adoption plus fines

Le tableau de bord d'impact affiche désormais l'engagement par fonctionnalité sur 28 jours, et les API de reporting entreprise et organisation s'enrichissent : étapes de revue des pull requests, agents VS Code et personnalisations de la CLI agentique. Les administrateurs identifient enfin ce qui est réellement adopté.

Sources:
→ Changelog: Copilot impact dashboard now shows feature engagement
→ Changelog: Usage metrics API adds pull request review stages
→ Changelog: Add VS Code agents to Copilot usage metrics

5. Paramètres managés et bacs à sable durcis

La gouvernance opérationnelle se fiabilise : un validateur in-product détecte JSON malformé, configurations non supportées et mappages d'équipes invalides dans les paramètres managés d'entreprise, tandis que les politiques de bac à sable managé arrivent pour Copilot dans JetBrains, avec diagnostics de politique.

Sources:
→ Changelog: Enterprise managed settings in-product validator
→ Changelog: Enterprise-managed sandbox in Copilot for JetBrains

📌 Également ce mois-ci

  • Copilot budget increase requests are generally available — Approuvez, ajustez ou refusez les demandes d'augmentation de budget sans quitter vos paramètres.
  • Agentic autofix now uses Copilot Memory — La correction automatique des alertes de sécurité réutilise les schémas de correction mémorisés propres à votre dépôt.
  • Local sandboxing in the GitHub Copilot app — Isolez localement les opérations d'agents pour limiter l'exposition lors des exécutions sensibles.
