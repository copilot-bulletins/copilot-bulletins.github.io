🏆 Top 5 des mises à jour du mois

1. La revue de code Copilot passera à la facturation par minutes Actions le 1er juin 2026

À partir du 1er juin, chaque revue de code Copilot sur des dépôts privés consommera des minutes GitHub Actions en plus des crédits IA. Les administrateurs doivent vérifier leurs quotas, configurer des budgets et informer leurs équipes de facturation. Les runners auto-hébergés et larger runners sont pris en charge. Les dépôts publics ne sont pas concernés.

→ Changelog: GitHub Copilot code review will start consuming GitHub Actions minutes on June 1, 2026

2. Deux nouveaux modèles phares avec activation administrative requise : Claude Opus 4.7 et GPT-5.5

Claude Opus 4.7 (16 avril) et GPT-5.5 (24 avril) sont désormais disponibles pour Copilot Business et Enterprise, avec un multiplicateur de 7,5×. Les administrateurs Enterprise et Business doivent les activer explicitement via les paramètres de politique Copilot avant que leurs utilisateurs puissent y accéder depuis le sélecteur de modèles.

Sources:
→ Changelog: Claude Opus 4.7 is generally available
→ Changelog: GPT-5.5 is generally available for GitHub Copilot

3. Métriques d'utilisation enrichies : revue de code et agent cloud en données exploitables

L'API de métriques Copilot s'enrichit de six nouveaux champs pour la revue de code (utilisateurs actifs vs passifs sur fenêtres journalière, hebdomadaire et mensuelle) et d'un champ used_copilot_cloud_agent pour suivre l'adoption de l'agent cloud. Ces données aident les administrateurs à distinguer usage volontaire et usage déclenché par politique. Note : le champ used_copilot_coding_agent est déprécié au 1er août 2026.

Sources:
→ Changelog: Copilot code review user counts now aggregate in usage metrics API
→ Changelog: Copilot cloud agent fields added to usage metrics

4. Visibilité sur les sessions de l'agent cloud depuis les issues et les projets

Les sessions de l'agent cloud sont désormais visibles et pilotables directement depuis les issues et les tableaux de projet, sans quitter le workflow. Un panneau latéral permet de consulter les journaux, suivre la progression et orienter l'agent en cours d'exécution. La fonctionnalité est activée par défaut dans les vues de projet existantes.

→ Changelog: View and manage agent sessions from issues and projects

5. Copilot pour Jira : nouvelles options de personnalisation pour les équipes

L'intégration Copilot pour Jira s'enrichit d'agents personnalisés par ticket, de la lecture des champs Atlassian sur mesure (critères d'acceptation), de règles de nommage de branches et d'instructions globales configurables au niveau de l'espace. Les équipes déjà sur Jira gagnent un contrôle accru sur le comportement de l'agent sans modifier leur workflow existant.

→ Changelog: GitHub Copilot for Jira: Our latest enhancements
