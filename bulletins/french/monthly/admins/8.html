Monthly #8 · Octobre 2026 · Admins Edition

🎯 Le fil de cette édition

Octobre marque un déplacement du pilotage de Copilot : la gestion des sièges laisse place à la gestion des budgets d'usage, et la gouvernance s'étend des modèles aux agents exécutés localement. Pour les administrateurs, l'enjeu est de définir dès maintenant les politiques, les plafonds de dépenses et les indicateurs qui encadreront une adoption agentique à grande échelle.

⚠️ Attention

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Deadline: 16 novembre 2026 — Claude Opus 4.8, Claude Opus 5 et GPT-5.6 Terra seront retirés. Si vous avez désactivé la politique par défaut, activez les modèles de remplacement via les politiques de modèles et consultez les modèles pris en charge.

🚀 Passez à l'action

  • Préparez la transition vers le nouveau modèle de facturation en lisant ce qui change avec GitHub Enterprise et Copilot et la facturation à l'usage pour les entreprises.
  • Imposez le sandboxing, les modes de permission et les plugins approuvés via les paramètres gérés par l'entreprise.
  • Vérifiez la valeur de la politique par défaut pour les nouvelles fonctionnalités, désormais appliquée aux fonctionnalités non configurées.
  • Activez la comparaison sectorielle dans le tableau de bord d'impact Copilot pour situer votre adoption agentique.
  • Des questions ou besoin d'accompagnement ? Contactez votre équipe GitHub, nous sommes là pour vous aider.

🏆 Top 5 des mises à jour du mois

1. Copilot inclus dans GitHub Enterprise : du siège au budget

Les entreprises accompagnées par une équipe GitHub ou Microsoft peuvent désormais inclure Copilot pour chaque utilisateur GitHub Enterprise. L'usage IA est mesuré dès la première requête sur le budget de l'entreprise ; un budget épuisé ne retire jamais l'accès aux complétions.

→ Changelog: GitHub Enterprise now includes access to GitHub Copilot

2. Gouverner les agents sur les postes de travail

Le sandboxing local est disponible pour tous : accès aux fichiers, au réseau et aux identifiants restreints par politique. S'y ajoutent les permissions assistées, le rafraîchissement forcé des paramètres au démarrage et le contrôle des plugins requis ou bloqués via les paramètres gérés.

Sources:
→ Changelog: Local sandboxing for GitHub Copilot now generally available
→ Changelog: GitHub Copilot assisted permissions generally available
→ Changelog: Enterprise managed settings enforcement updates
→ Changelog: Repository plugin defaults and enterprise plugin controls generally available

3. Copilot Fusion et API de politiques de modèles

Copilot Fusion, disponible pour tous, route automatiquement les tâches vers les modèles autorisés. Les administrateurs choisissent les modèles éligibles et peuvent en faire le modèle par défaut. Une nouvelle API REST gère les politiques de modèles par entreprise, organisation, équipe et application.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: Copilot model policy API for enterprise, orgs, and teams

4. Des métriques d'usage plus complètes

L'API de métriques couvre désormais des clients tiers comme OpenCode, Claude Code ou Codex, et nomme vos skills, agents et serveurs MCP. La télémétrie peut être attribuée aux utilisateurs sans capturer les prompts, et le tableau de bord d'impact propose des comparaisons sectorielles.

Sources:
→ Changelog: Usage metrics API adds usage from tools like OpenCode
→ Changelog: Custom skills, agents, and MCP servers in usage metrics API
→ Changelog: Client telemetry user attribution and configurable capture
→ Changelog: Industry comparisons in the Copilot impact dashboard

5. Sécurité : correction agentique et détection de secrets

L'autofix agentique des alertes de code scanning est disponible pour tous : Copilot propose un correctif, le valide en relançant CodeQL, puis ouvre une pull request. Un modèle dédié améliore la détection des secrets divulgués, notamment les mots de passe sans format reconnaissable.

Sources:
→ Changelog: Agentic autofix for code scanning alerts general availability
→ Changelog: Purpose-built model for leaked secret detection

  • Environ 2 fois moins cher par tâche avec Copilot Fusion Max, pour un score à deux points de Claude Code avec Opus 5.5 Max
