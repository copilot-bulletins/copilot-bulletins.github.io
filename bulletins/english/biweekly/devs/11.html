Biweekly #11 · August 1 to August 14, 2026 · Devs Edition

🎯 This edition's thread

This period was all about a more open, model-flexible agent. Copilot moved toward portable agent plugins that work across clients, a fresh wave of frontier models, and finer control over how agents reason and run. For developers, the takeaway is practical: fewer lock-in constraints, more tuning knobs, and workflows you can trigger and shape directly from where you already work.

🏆 Top 5 updates

1. Build a plugin once, run it everywhere

Agent Plugins 1.0 lets you build a plugin a single time and use it across all compatible agent clients, including VS Code, Copilot CLI, and the Copilot app. Launch partners include AWS, Anysphere, Microsoft, OpenAI, and Vercel, reducing rework and fragmentation across tools.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

2. Persistent memory and local models in JetBrains

GitHub Copilot for JetBrains now brings persistent memory across sessions plus local model access via Ollama. It also improves everyday chat workflows and resolves reliability issues across MCP servers, giving JetBrains developers more context continuity and offline flexibility.

→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains

3. Customize the reasoning level for the cloud agent

When you delegate a task to the Copilot cloud agent, you can now set the reasoning level for models that support it. Dial reasoning up for complex, multi-step problems or down for speed on routine work, giving you control over the depth-versus-latency tradeoff.

→ Changelog: Customize the reasoning level for Copilot cloud agent

4. Trigger Copilot automations from comments

You can now create Copilot cloud agent automations that run when an issue or pull request comment is created. Use it to generate documentation, respond to review feedback, or kick off follow-up tasks, keeping routine automation right inside your normal GitHub conversations.

→ Changelog: Trigger Copilot automations with comments

5. A new wave of frontier models

Several models landed this period: Grok 4.6 for agentic coding and complex multi-step workflows, Gemini 3.7 Flash, and Kimi K3. Together they expand your options for matching model strengths to specific coding tasks across Copilot.
