Biweekly #17 · November 1 to November 14, 2026 · Devs Edition

🎯 This edition's thread

Copilot is moving into the tools developers already use rather than asking them to switch. Native integrations reached JetBrains Air and Xcode's built-in assistant, while new frontier and fast models arrived alongside a December retirement list. The practical effect: more control over where you work and which model fits each task.

⚠️ Heads up

  • Upcoming deprecation of selected GitHub Copilot models in December — Deadline: December 14, 2026 — Move off Claude Fable 5, Claude Haiku 4.5, Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6 and Kimi K3, and check the suggested alternatives in Supported AI models in GitHub Copilot.

🚀 Take action

  • Try Claude Fable 5.2 or Gemini 4 Hydrogen by changing the AI model for Copilot Chat
  • Open the new /settings dashboard after setting up GitHub Copilot CLI to manage plugins and MCP servers in one place
  • Package repeatable team workflows as agent skills so any agent can reuse them
  • Tune review effort and custom instructions per repository by configuring Copilot code review
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates

1. Copilot arrives in JetBrains Air

Delegate tasks to Copilot from JetBrains Air's agent picker using your existing subscription. Track parallel agent sessions, review changes alongside your code, and run cloud tasks in isolated sandboxes through Air Teams, without consuming JetBrains AI credits.

→ Changelog: GitHub Copilot is now available in JetBrains Air

2. Copilot inside Xcode's native coding assistant

Copilot now plugs directly into Xcode's built-in coding assistant, in public preview from Xcode 27.3 beta on macOS Tahoe 26.6+. Enable it under Xcode > Settings > Intelligence. All Copilot plans are supported, and the existing Copilot for Xcode extension remains available.

→ Changelog: GitHub Copilot is now available in Xcode’s coding assistant

3. Claude Fable 5.2 for complex multistep work

Anthropic's newest Fable model is generally available for large-codebase, multistep tasks, solving more tasks than Fable 5.1 with fewer steps and tool calls. Available on Pro+, Max, Business and Enterprise; Business and Enterprise admins must enable its policy first.

→ Changelog: Claude Fable 5.2 in GitHub Copilot

4. Two new Gemini 4 models: Carbon and Hydrogen

Gemini 4 Carbon targets complex agentic and reasoning work with a focus on secure code generation. Gemini 4 Hydrogen, a Flash model, delivers fast, efficient tool use and better instruction following than Gemini 3.8 Flash, including in the Copilot SDK.

Sources:
→ Changelog: Gemini 4 Carbon in GitHub Copilot
→ Changelog: Gemini 4 Hydrogen in GitHub Copilot

5. CLI settings dashboard and VS Code 1.145

Copilot CLI's /settings now opens a searchable dashboard for plugins and MCP servers. VS Code 1.145 adds chat view modes, cron-scheduled local automations with custom agents, remote app previews in the Agents window, and the Copilot app gains Agent Merge improvements.

→ Changelog: GitHub Copilot weekly releases — November 2
