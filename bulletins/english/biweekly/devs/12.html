🏆 Top 5 updates

1. Copilot harness reaches GA in JetBrains

Copilot harness is now generally available in JetBrains, delivering faster feature rollout and better code quality. The update also adds built-in JetBrains MCP server support in public preview, letting you expose IDE capabilities through agent workflows without configuring external servers.

→ Changelog: Copilot harness generally available in Copilot for JetBrains

2. VS Code August releases sharpen agent workflows

Covering v1.132 through v1.135, the Agents window gains new ways to organize related chats, follow agent activity, and jump between prompts and their file changes. Agent Host, the integrated browser, and dictation also improved, making longer agent sessions easier to review and navigate.

→ Changelog: GitHub Copilot in VS Code, August 2026 releases

3. Copilot code review expands coverage and adds resolution reasons

Copilot code review now handles pull requests it previously skipped, including bot-authored PRs and full agentic reviews of Copilot cloud agent PRs. You can also submit a reason when resolving a review comment, giving cleaner signal on why feedback was addressed or dismissed.

→ Changelog: Copilot code review: Resolution reasons and expanded capabilities

4. Customize tab in the Copilot app hits GA

The Customize tab brings MCP servers, plugins, skills, and canvases together in one place. Browse featured customizations by type and tailor Copilot to your team's tools and workflows, with canvases to triage issues, prioritize backlogs, and hand work to Copilot directly.

→ Changelog: GitHub Copilot app Customize tab is generally available

5. Visual Studio August update adds reasoning and model control

The August Visual Studio 2026 update gives you more control over how Copilot reasons, which models you use, how teams share specialized agents, and when reviews run. It's available across all plans, including Free, Pro, Business, and Enterprise, with the latest in the Insiders channel.

→ Changelog: GitHub Copilot in Visual Studio — August update
