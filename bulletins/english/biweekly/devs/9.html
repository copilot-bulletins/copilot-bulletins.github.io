Biweekly #9 · July 1 to July 14, 2026 · Devs Edition

🎯 This edition's thread

The first half of July put agentic development front and center. New model choices, a generally available integrated browser, vision support, and deeper agent providers across VS Code and JetBrains gave developers more ways to delegate real work and stay in flow. The theme is practical autonomy: richer tooling that keeps you in control while agents handle more of the loop.

  • Upcoming deprecation of Gemini 2.5 Pro and Gemini 3 Flash — Deadline: July 31, 2026 — Both models will be removed across all Copilot experiences. Migrate workflows to a supported model such as Gemini 3.1 Pro or Gemini 3.5 Flash before the cutoff.

  • Move off Gemini 2.5 Pro and Gemini 3 Flash now — confirm a supported model is enabled before July 31.

🏆 Top 5 updates

1. VS Code June releases sharpen the agent workflow

Covering VS Code v1.123–v1.127, this update improves the integrated browser, parallel agent sessions and chats, cost visibility, model providers from the Marketplace, and Autopilot. It makes managing concurrent agent work and choosing the right model far easier day to day.

→ Changelog: GitHub Copilot in Visual Studio Code June 2026 releases

2. GPT-5.6 Sol, Terra, and Luna arrive in Copilot

OpenAI's GPT-5.6 family lands in three variants: Sol for deep reasoning over large codebases, Terra as the balanced everyday default, and Luna for fast, cost-efficient help. Match the model to the task, from long-running agentic work to quick edits.

→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot

3. Copilot Vision is generally available

You can now attach images and PDFs directly to chat prompts so Copilot reasons about screenshots, mockups, and diagrams alongside your code. It works across VS Code and other surfaces and is available on all Copilot plans.

→ Changelog: Copilot vision is generally available

4. Codex agent provider and agentic upgrades in JetBrains

JetBrains IDEs gain Codex as a new agent provider in public preview, plus Hooks support, richer MCP server management, custom models set by admins, CLI approval settings, and Inline Chat reaching general availability. A big step for agentic coding outside VS Code.

→ Changelog: Codex as agent provider and agentic enhancements in JetBrains IDEs

5. Browser tools in VS Code are generally available

Agents can now drive a real browser, navigate live web apps, and feed findings back into chat. On by default at GA and shaped by preview feedback, with permission and network domain controls that keep you in charge.

→ Changelog: Browser tools for GitHub Copilot in VS Code are generally available
