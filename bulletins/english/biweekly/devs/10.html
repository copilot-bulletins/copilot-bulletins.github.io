Biweekly #10 · July 15 to July 31, 2026 · Devs Edition

🎯 This edition's thread

This period, Copilot deepened agent-native tooling and expanded model choice. Autonomous agents reached more of your workflow—the VS Code Agents window, Linear, GitHub Issues—while code review gained MCP and skills support. For developers, the practical shift is matching the right model and agent to each task, with richer context flowing directly into everyday coding and review.

⚠️ Heads up

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Deadline: July 31, 2026 — Both models are now retired across all Copilot experiences. Switch to Gemini 3.1 Pro (Preview) or Gemini 3.6 Flash from the Copilot Chat model selector.

🚀 Take action

  • Pin the right model per task from the supported models reference, now including Claude Opus 5, Grok 4.5, and Gemini 3.6 Flash.
  • Bring your team's tools and standards into reviews by configuring Copilot code review with agent skills and MCP.
  • Connect external context to chat and agents by extending Copilot with MCP servers.
  • Delegate background work with the Copilot coding agent, now assignable from Linear.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates

1. A redesigned Agents window lands in VS Code

The July VS Code releases (v1.127–v1.131) revamp how you work with agents: a redesigned Agents window with faster review workflows, plus multi-chat sessions that keep related conversations together so you can compare approaches and run work in parallel.

→ Changelog: GitHub Copilot in Visual Studio Code, July 2026 releases

2. Agent skills and MCP reach GA for code review

Copilot code review now generally supports agent skills and MCP servers for all Pro, Pro+, Business, and Enterprise users. Bring your team's tools, standards, and external context into every review. Setups from the public preview keep working with no changes needed.

→ Changelog: Copilot code review: Agent skills and MCP now generally available

3. GitHub MCP Server adopts the next MCP specification

The GitHub MCP Server now supports the latest, stateless MCP spec ahead of its official release. The stateless core makes MCP deployments far easier to scale, so your integrations and extensions stay ready as the protocol goes stateless.

→ Changelog: GitHub MCP Server supports the next MCP specification

4. Assign Linear issues to the Copilot cloud agent

The Copilot cloud agent for Linear is now generally available. Assign a Linear issue to the asynchronous, autonomous agent and it picks up the work in the background, with per-issue or workspace-wide controls to steer how it runs directly from Linear.

→ Changelog: Copilot cloud agent for Linear is now generally available

5. New frontier models arrive in Copilot

Three new models landed this period: Claude Opus 5 for complex, long-running agentic coding; Grok 4.5; and Gemini 3.6 Flash for fast everyday tasks. More choice means matching heavy reasoning, daily coding, or quick assistance to the right engine.
