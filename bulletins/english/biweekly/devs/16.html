Biweekly #16 · October 15 to October 31, 2026 · Devs Edition

🎯 This edition's thread

Copilot is shifting from a model picker in one editor to a connected agent platform. Sessions now follow you across clients and run in cloud sandboxes, model routing is automated, and agents remember context and act on events. For developers, this means less setup and coordination, and more time reviewing outcomes instead of managing tools.

  • GitHub Copilot in Visual Studio — September update — Action required — Bring Your Own Model now requires the new Agent (Preview); re-add previously configured Ollama models after updating.

🚀 Take action

  • Select Copilot Fusion in the model picker and pick an effort level, as described in About GitHub Copilot Fusion
  • Turn on "Watch and fix" in a pull request merge box using Agent Merge
  • Create a personal or shared workflow with Copilot Automations
  • Teach Copilot your repository conventions with Copilot Memory
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates

1. Copilot Fusion picks the models for you

Copilot Fusion is generally available. Choose Standard, High or Max effort and Copilot routes or combines models per task. Fusion Max scored within two points of a leading frontier setup at about half the cost. It is now in JetBrains IDEs, with experimental local model routing.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot Fusion now supports selection of local models

2. One cloud session, every surface

Start a cloud agent session on mobile, Slack or VS Code and continue it in the Copilot app, CLI or github.com. Sessions run in secure cloud sandboxes with no one-hour limit and resume from snapshots, so closing your laptop no longer stops work.

Sources:
→ Changelog: Work from anywhere with a new, connected Copilot cloud experience
→ Changelog: GitHub Copilot in VS Code, Universe releases

3. Copilot Automations go team-wide

Automations can now be shared at repository level, run in the cloud from VS Code 1.144, and fire on 24 new GitHub events or via the REST API. You can chain automations, use 20 new tools and set AI credit limits per run or period.

Sources:
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: Create and manage Copilot Automations in Visual Studio Code
→ Changelog: New tools, triggers, and cost controls for Copilot Automations

4. From review to merge with less waiting

Agent Merge now works on github.com: Copilot watches your pull request and fixes failing Actions workflows or merge conflicts. Code review adds a Max effort level running multiple models, and Copilot approvals, now GA, count toward required reviews.

Sources:
→ Changelog: Agent Merge watches and fixes pull requests in the cloud
→ Changelog: Copilot code review: Merge with confidence with Max and approvals

5. Copilot Memory remembers how you work

Copilot Memory is generally available on paid plans. It stores personal preferences and repository conventions, such as the right test command, and reuses them across the app, CLI, VS Code, cloud agent and code review, so you stop repeating guidance.

→ Changelog: GitHub intelligence puts your code, context, and history to work
