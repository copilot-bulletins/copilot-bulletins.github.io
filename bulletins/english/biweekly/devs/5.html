🏆 Top 5 updates

1. GitHub Copilot app arrives in technical preview

The GitHub Copilot app is a new desktop application purpose-built for agent-driven development. Start sessions from issues or pull requests, run multiple agents in parallel on separate branches, review diffs, and ship pull requests—without switching between terminal, IDE, and browser. Copilot Business and Enterprise users can install this week; Pro/Pro+ can join the waitlist.

→ Changelog: GitHub Copilot app is now available in technical preview

2. VS Code April releases: semantic search, BYOK, and agents in your terminal

VS Code shipped four weekly releases (v1.116–v1.119) with substantial agentic improvements. Semantic indexing now works in all workspaces. Copilot Business and Enterprise users can connect their own model API keys (BYOK) for any provider. Agents gain read/write access to any open terminal and can share browser tabs for live validation. Copilot CLI sessions can now be monitored remotely from GitHub.com or mobile.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

3. Copilot CLI agent and unified sessions view in JetBrains IDEs

JetBrains IDEs now have the Copilot CLI agent in public preview. Delegate long-running terminal-based tasks directly from the IDE, with worktree or workspace isolation to keep changes separate until you're ready to review. A unified sessions view shows all running and queued agent sessions at a glance. Also new: an ask-question tool for agent mode, global .agent.md support, and GHES sign-in.

→ Changelog: Introducing Copilot CLI agent and unified sessions view in GitHub Copilot for JetBrains IDEs

4. Start Copilot cloud agent tasks via the REST API

Copilot Business and Enterprise users can now trigger cloud agent tasks programmatically through the new Agent tasks REST API (public preview). Fan out refactors across many repositories, set up new repos from an internal developer portal, or automate weekly release notes generation. PAT and OAuth authentication are supported; GitHub App token support is coming soon.

→ Changelog: Start Copilot cloud agent tasks via the REST API

5. Copilot cloud agent now supports auto model selection

Selecting Auto in the cloud agent model picker lets Copilot intelligently choose the best available model based on system health and performance. Beyond convenience, it brings a 10% discount on the model multiplier and removes weekly rate limits. Auto selection is available across Copilot Chat, Copilot CLI, and Copilot cloud agent.

→ Changelog: Copilot cloud agent supports auto model selection
