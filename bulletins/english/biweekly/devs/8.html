Biweekly #8 · June 15 to June 30, 2026 · Devs Edition

🎯 This edition's thread

This period, the agent-native tooling GitHub previewed at Build reached general availability and spread across editors. The desktop app and the CLI's redesigned terminal shipped as GA, JetBrains gained first-class Copilot agents, and model choice both widened and got simpler. For developers, agentic workflows are no longer preview experiments — they're production-ready wherever you code.

⚠️ Heads up

  • Opus 4.6 (fast) deprecated — Action required — Opus 4.6 (fast) has been retired across all Copilot experiences (Chat, inline edits, ask and agent modes, completions) as of June 29, 2026; switch to Opus 4.8 (fast). Confirm availability in the supported models reference.

🚀 Take action

  • Download the GitHub Copilot app for macOS, Windows, or Linux — now generally available — and start your first session from the getting started guide.
  • Update Copilot CLI (copilot update) to get the new tabbed terminal for browsing issues, PRs, and gists without leaving your session.
  • Try the newest models — select Claude Sonnet 5 or Claude Opus 4.8 (fast mode) in the model picker and check availability in the supported models reference.
  • Prefer not to choose? Let Copilot pick the right model per task with auto model selection in Copilot Chat.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates

1. The GitHub Copilot app is now generally available

The desktop home for agent-driven development is now GA for macOS, Windows, and Linux. Start sessions from an issue, PR, or prompt, run parallel agents on isolated worktrees, and review diffs before opening a pull request through your team's existing checks.

→ Changelog: GitHub Copilot app generally available

2. Copilot CLI: a redesigned terminal, now GA

The redesigned CLI terminal previewed at Build is now generally available. Switch between Session, Issues, PRs, and Gists tabs, drop a reference into your prompt with one keystroke, and configure your tools without leaving the terminal — in a cleaner, more accessible interface.

→ Changelog: Copilot CLI: New terminal interface is generally available

3. JetBrains gets deeper Copilot agent integration

Copilot goes deeper in JetBrains: organization and enterprise agents, message queue-and-steer, and Claude as an agent provider (preview) arrive in the plugin. Copilot is also a first-class option in the JetBrains AI Assistant agent picker, with model and reasoning-depth choice in chat.

Sources:
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant

4. New models: Claude Sonnet 5 and Opus 4.8 fast mode

Two new options land in the model picker. Claude Sonnet 5, Anthropic's latest Sonnet-class model, is GA with strong coding and CLI-task performance. Claude Opus 4.8 (fast mode) arrives in preview, delivering the same intelligence as Opus 4.8 at significantly faster token speeds.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot

5. Auto model selection, now for everyone

Auto model selection is generally available in Copilot Chat on github.com and mobile for all plans — Copilot routes each request to the best available model, optimizing cost and quality. Free and Student plans now use auto as their default and only experience.

Sources:
→ Changelog: Auto mode in Copilot Chat available for all users
→ Changelog: Changes to model selection for Free and Student plans
