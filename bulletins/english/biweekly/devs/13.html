Biweekly #13 · September 1 to September 14, 2026 · Devs Edition

🎯 This edition's thread

Model choice dominated this period. GitHub Copilot expanded its lineup with new frontier models, retired older ones, and introduced tiered auto model selection so you can steer the balance of cost, quality, and speed. For developers, this means more control over which engine handles each task—and a need to migrate off soon-to-be-deprecated models before workflows break.

⚠️ Heads up

  • Upcoming deprecation of selected GitHub Copilot models — Deadline: October 2, 2026 — Gemini 3.5/3.6 Flash, Kimi K2.7 Code, and Claude Opus 4.7 will be removed across all Copilot experiences. Update workflows to supported alternatives and confirm access in your model settings.
  • MAI-Code-1-Flash deprecated — Action required — This model was removed on September 10, 2026. Switch any pinned configurations to the suggested alternative in the chat model selector.

🚀 Take action

  • Try tiered auto model selection and pick the efficiency, balance, or intelligence tier that fits your work by changing your chat model.
  • Verify your team respects content boundaries by reviewing content exclusion in the Copilot app and CLI.
  • Let Copilot help review your pull requests—learn how it works in the code review docs.
  • Bring Copilot to your terminal by installing Copilot CLI.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates

1. GPT-6 Astra lands for autonomous coding

OpenAI's GPT-6 Astra is now generally available in Copilot. Built for long-horizon, agentic coding tasks, it's a strong pick when you hand off multi-step work to agent mode. Enable it in your model selector and put it to work on complex refactors.

→ Changelog: GPT-6 Astra is generally available in GitHub Copilot

2. Tune auto model selection to your priorities

Auto model selection now offers three tiers—efficiency, balance, and intelligence—so you decide how Copilot weighs cost, quality, and latency per prompt. All tiers share the same models; auto picks the best fit for each request. Rolling out in VS Code, Copilot CLI, and the Copilot app.

→ Changelog: Configure cost and quality in Copilot auto model selection

3. Weekly releases: Jira, HydraFusion, and VS Code agents

The September 7 release brings Jira integration to the Copilot app, adaptive model orchestration via Project HydraFusion in Copilot CLI (/experimental), new agent automation in VS Code 1.137, and expanded enterprise controls for JetBrains—a broad sweep of day-to-day improvements.

→ Changelog: GitHub Copilot weekly releases — September 7

4. Content exclusions now enforced in app and CLI

The Copilot app and Copilot CLI now respect content exclusion policies set by enterprise, org, and repository admins. Sensitive files you shouldn't see stay out of context everywhere you work, keeping your terminal and desktop workflows compliant by default.

→ Changelog: Content exclusions generally available in Copilot app and CLI

5. Copilot code review can approve your pull requests

Copilot now signals when a pull request is ready and, when admins enable it, can sign off on the approval. That tightens the review loop and helps unblock PRs faster—useful when you're waiting on a second pair of eyes.

→ Changelog: Copilot code review can now approve pull requests
