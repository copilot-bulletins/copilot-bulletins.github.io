🏆 Top 5 updates

1. HydraFusion brings model orchestration to VS Code

HydraFusion, the research preview that picks and combines models per task, now runs in VS Code (1.140+) and the Copilot app, not just the CLI. It appears in the model picker but orchestrates multiple models using capability signals for reasoning, code generation, debugging, and tool use.

→ Changelog: HydraFusion in VS Code and the GitHub Copilot app

2. A wave of new frontier models

Five new models landed in the picker this period: OpenAI's GPT-6 Sol, GPT-6 Luna, and GPT-6.1 Sol, Anthropic's Claude Opus 5.5 and Claude Sonnet 5.5, plus xAI's Grok 4.7. They span everyday coding, agentic tasks, and terminal workflows, giving you more ways to match a model to the job.

3. Copilot for JetBrains 1.18.0

JetBrains 1.18.0 adds assisted approvals, which auto-approve low-risk tool calls while still prompting for higher-risk actions, cutting approval interruptions. You can also re-edit a previous message in an agent session, rewinding both the conversation and file changes, plus shared skills and instructions for your org.

→ Changelog: New features and improvements in Copilot for JetBrains

4. Faster C++ code intelligence in Copilot CLI

Whole codebase indexing builds a persistent symbol index across your C++ project, including unopened files, using the Microsoft C++ Language Server. Definitions, references, implementations, and symbol search resolve faster on million-line repositories, so you spend less time waiting and more time changing code.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

5. Local sandboxing in the Copilot app

Local sandboxing limits an agent session's access to files, network, and credentials on your machine, reducing the blast radius of unintended commands. You configure it per project for local repository and working tree sessions; if your OS can't enforce the policy, the shell fails safely rather than running unprotected.

→ Changelog: Local sandboxing in the GitHub Copilot app
