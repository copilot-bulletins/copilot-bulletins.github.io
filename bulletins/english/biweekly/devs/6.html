🏆 Top 5 updates

1. Claude Opus 4.8 lands across every Copilot surface

Anthropic's latest Opus model is now generally available in GitHub Copilot across all surfaces including VS Code, JetBrains, Visual Studio, CLI, and github.com. It shows clear improvements in code understanding, complex problem-solving, and large-codebase navigation. Available on Pro+, Business, and Enterprise plans.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

2. Auto model selection in VS Code now routes by task complexity

Copilot's "Auto" option in VS Code now routes each request to the optimal model based on task complexity — reserving heavy reasoning for hard problems and faster models for simple tasks. Get a 10% discount on model multipliers vs. manual selection, with full transparency: hover over any response to see which model was used.

→ Changelog: Auto model selection now routes based on your task in VS Code

3. Remote control: take your Copilot sessions anywhere

Start a Copilot CLI or VS Code session, then monitor and steer it from github.com or GitHub Mobile with /remote on. Now generally available, remote control also extends to JetBrains — plan at your desk, approve and merge the PR from your phone, all in one continuous workflow.

→ Blog: Take your local GitHub sessions anywhere

4. "Fix with Copilot" brings more control to code review handoffs

The "Implement suggestion" button in Copilot code review is now "Fix with Copilot," with a new dialog to choose which PR to target, which model to use, and add custom instructions. A new "Fix batch with Copilot" option lets you queue multiple review comments and hand them all to the cloud agent at once.

→ Changelog: Easily apply Copilot code review feedback with Copilot cloud agent

5. Copilot Memory gets CLI commands, a repo off-switch, and clearer scope

Copilot Memory (public preview) now has /memory on|off|show commands in the CLI, a repo-level off switch for repository admins, and explicit scope labels at capture time (user preference vs. repository fact). Plus improved deletion guidance when you ask Copilot to forget something.

→ Changelog: Copilot Memory has more controls for deletion, scope, and the Copilot CLI
