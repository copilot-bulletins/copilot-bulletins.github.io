OpenAI's latest GPT-5.5 is now rolling out to Copilot Pro+, Business, and Enterprise users across VS Code, Visual Studio, JetBrains, the CLI, and github.com. Optimized for complex, multi-step agentic coding, it outperforms prior GPT models on real-world challenges. Note the 7.5× premium request multiplier (promotional pricing).

2. Visual Studio Gets Cloud Agent Integration and a Debugger Agent

The April Visual Studio update brings agentic workflows front and center: launch cloud agent sessions from the IDE, use a new Debugger Agent that validates fixes against live runtime behavior, and build user-level custom agents that follow you across projects. A redesigned chat history panel and customizable keyboard shortcuts round out the release.

→ Changelog: GitHub Copilot in Visual Studio — April update

3. Inline Agent Mode Now in Public Preview for JetBrains

Agent mode capabilities land inside JetBrains' inline chat, letting you invoke powerful, in-context assistance without leaving the editor. This release also adds Next Edit Suggestions with inline previews, far-away edit indicators, and global auto-approve for streamlined tool-call workflows.

→ Changelog: Inline agent mode in preview and more in GitHub Copilot for JetBrains IDEs

4. Bring Your Own Language Model Key in VS Code

Copilot Business and Enterprise users can now supply API keys from Anthropic, Gemini, OpenAI, OpenRouter, Azure, Ollama, and Foundry Local in VS Code. BYOK models appear everywhere in Chat, don't count against Copilot quotas, and are billed directly by your provider.

→ Changelog: Bring your own language model key in VS Code now available

5. Copilot Cloud Agent Starts 20% Faster

Building on the 50% startup improvement in March, the cloud agent now spins up over 20% faster thanks to prebuilt GitHub Actions custom images. Assigning issues, opening the Agents tab, or mentioning @copilot in a PR gets Copilot to work noticeably quicker.

→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images
