🏆 Top 5 updates

1. HydraFusion brings multi-model quality to more surfaces

GitHub's HydraFusion research preview now runs in VS Code and the Copilot app, not just the CLI. By orchestrating multiple models behind one picker entry, it targets frontier-level output quality without forcing teams to pick a single model, a strategic hedge against vendor lock-in.

Sources:
→ Changelog: HydraFusion in VS Code and the GitHub Copilot app
→ Blog: Project HydraFusion: Frontier quality via multi-model orchestration

2. Frontier model choice expands across vendors

In two weeks, Copilot added GPT-6 Sol and Luna, GPT-6.1 Sol, Claude Opus 5.5 and Sonnet 5.5, and Grok 4.7. This rapid, multi-vendor expansion gives organizations best-fit options per task and insulates roadmaps from any one provider's pace or pricing.

Sources:
→ Changelog: OpenAI's GPT-6 Sol and GPT-6 Luna now available
→ Changelog: GPT-6.1 Sol in GitHub Copilot
→ Changelog: Claude Opus 5.5 is now available in GitHub Copilot

3. Impact dashboard now shows feature engagement

The Copilot impact dashboard reveals how many active users regularly use key features, so leaders can see which experiences are widely adopted and which need enablement. This turns Copilot investment into a measurable, feature-level adoption story for stakeholders.

→ Changelog: Copilot impact dashboard now shows feature engagement

4. Default enablement accelerates time-to-value

A new global default policy automatically enables generally available Copilot features for Business and Enterprise, with a 28-day window to opt out. This reduces configuration friction so teams get new capabilities faster, while admins retain governance control.

→ Changelog: Default Enablement of Copilot features for Copilot Business and Enterprise

5. Copilot code review gets a clearer, smarter experience

Copilot code review now tracks how a review evolves over time, auto-resolves its own suggestions more intelligently, and drafts commit messages on accept. Combined with broader plan availability and enterprise defaults, it strengthens consistent code quality at scale.

Sources:
→ Changelog: Copilot code review: An improved review experience
→ Changelog: More ways to request and configure Copilot code reviews
