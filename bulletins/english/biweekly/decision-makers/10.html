The signal for leaders is clear: the conversation is shifting from adoption to measurable return, with financial visibility and governance maturing into the instruments needed to justify and scale investment with confidence.

🏆 Top 5 updates

1. Connect Copilot spend to pull request output

The impact dashboard now includes a "Potential return on investment" section that links AI credit consumption to delivery. It compares cost per developer, cost as a share of payroll, and pull requests per developer across adoption phases, giving leaders a defensible view of value.

→ Changelog: Copilot impact dashboard adds a return on investment section

2. Code review effort levels reach general availability

Lite and Balanced effort levels for Copilot code review are now generally available, with organization-level defaults. Teams match review depth to risk—focused feedback for small changes, deeper scrutiny for complex logic—optimizing both quality outcomes and the cost of automated review at scale.

→ Changelog: Copilot code review effort levels are generally available

3. Usage metrics now include third-party agent activity

The Copilot usage metrics API now reports activity from agent apps like Claude and Codex, broken out by individual agent across enterprise and organization reports. Leaders gain a complete, vendor-agnostic picture of how AI is actually being used inside their workflows.

→ Changelog: Copilot usage metrics API adds agent app activity

4. Agent Plugins 1.0 establishes an open standard

Agent Plugins 1.0 launched with AWS, Anysphere, Microsoft, OpenAI, Vercel, and Google as a core maintainer. This open standard packages agent skills and MCP servers into one installable, vendor-independent plugin—reducing lock-in and letting organizations build once, govern centrally, and reuse across clients.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

5. Expanding model choice reduces strategic lock-in

The period added Kimi K3, Gemini 3.7 Flash, Grok 4.6, and MAI-Code-1.1-Flash to Copilot. A broad, evolving model roster lets organizations match capability and cost to each use case, avoid single-vendor dependence, and adapt as the AI landscape shifts.
