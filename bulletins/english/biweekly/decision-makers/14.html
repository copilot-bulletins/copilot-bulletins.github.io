🏆 Top 5 updates

1. One response, many frontier models

HydraFusion now orchestrates multiple frontier models—including Claude Opus 5.5 and the GPT-6 family—into a single response, tailoring reasoning effort per step. The new Max option targets the highest quality. For leaders, this means top-tier output without betting on any single vendor.

→ Changelog: HydraFusion updates and new Max option

2. Broader frontier model choice

Two more frontier models reached Copilot: Google's Gemini 4 Argon for complex agentic and reasoning tasks, and Anthropic's fast, cost-efficient Claude Haiku 5.5. Wider choice reduces vendor dependence and lets teams match model quality and cost to each workload.

Sources:
→ Changelog: Gemini 4 Argon in GitHub Copilot
→ Changelog: Claude Haiku 5.5 in GitHub Copilot

3. Centralized billing for code review

Organizations can now bill Copilot code reviews to a central cost center instead of consuming members' quotas, and control who may request reviews. This gives finance and platform leaders clearer spend ownership and more predictable budgeting as automated review scales.

→ Changelog: Copilot code review: New organization billing options and controls

4. Purpose-built secret detection

A context-aware model now detects leaked secrets—including passwords without recognizable token formats—across secret scanning, push protection, and Copilot security reviews. It catches exposures earlier in the workflow, strengthening security posture as AI-assisted development accelerates.

→ Changelog: Purpose-built model for leaked secret detection

5. Local sandboxing reaches general availability

Local sandboxing is now generally available in Copilot CLI and the Copilot app, isolating agent-executed commands from the host. For leaders scaling autonomous agents, this adds a safety boundary that supports broader, lower-risk adoption.

→ Changelog: Local sandboxing for GitHub Copilot now generally available
