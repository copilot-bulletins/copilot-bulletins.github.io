🏆 Top 5 updates

1. Copilot now included with GitHub Enterprise

Enterprises working with a GitHub or Microsoft account team can now get Copilot for every GitHub Enterprise licensed user, without separate seats. AI usage is metered against your enterprise budget, and completions keep working even when budget is exhausted.

Sources:
→ Changelog: GitHub Enterprise now includes access to GitHub Copilot
→ Blog: GitHub Universe 2026: Evolving every layer of the stack

2. Copilot Fusion optimizes quality and cost automatically

Copilot Fusion, now generally available, routes and orchestrates models per task. Fusion Max scored within two points of Claude Code with Opus 5.5 Max at about half the API cost and 40% less time per task. Admins control which models it uses.

→ Changelog: Route and orchestrate models with GitHub Copilot Fusion

3. One connected Copilot cloud experience

Cloud agent sessions now start and continue across web, mobile, CLI, the Copilot app, VS Code, Slack, and Teams, running in secure cloud sandboxes. Compute can draw on your existing Actions entitlement, simplifying how infrastructure costs are managed.

→ Changelog: Work from anywhere with a new, connected Copilot cloud experience

4. Shared, self-improving Copilot Automations

Teams can now build AI-powered workflows owned by the repository, billed to the organization, and resilient to staff changes. Automations also learn from real outcomes and propose improvements for human approval, compounding value over time.

Sources:
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: Copilot Automations now learn from outcomes and self-improve

5. Benchmark adoption against industry peers

The Copilot impact dashboard adds opt-in industry comparisons. Leaders can see agentic adoption and pull request merge rates against peers by company size and industry, helping set realistic goals and communicate progress.

→ Changelog: Industry comparisons in the Copilot impact dashboard
