🏆 Top 5 updates

1. GitHub Copilot moves to usage-based billing

Starting June 1, all Copilot plans replace premium requests (PRUs) with GitHub AI Credits. Business plans stay $19/user with credits pooled across your org. Existing Business customers receive a promotional 3,000 credits/user/month through August 2026. Admins gain budget controls at enterprise, cost-center, and user levels.

→ Blog: GitHub Copilot is moving to usage-based billing

2. GPT-5.5 is now available in GitHub Copilot

OpenAI's latest model delivers its strongest performance on complex, multi-step agentic coding tasks and resolves real-world challenges previous GPT models couldn't. Available for Copilot Business and Enterprise users — admins must enable the GPT-5.5 policy in Copilot settings to give teams access.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

3. Claude Opus 4.7 is generally available

Anthropic's newest Opus model delivers stronger multi-step task performance and more reliable agentic execution, replacing Opus 4.5 and 4.6 in the model picker. Available for Business and Enterprise plans — enable it through your Copilot model policy settings.

→ Changelog: Claude Opus 4.7 is generally available

4. Copilot cloud agent now starts 20% faster

Building on March's 50% startup improvement, the cloud agent now starts over 20% faster thanks to optimized GitHub Actions custom images. Every time a team member assigns an issue to Copilot, reduced spin-up time translates directly to shorter feedback loops and faster iteration cycles.

→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images

5. Cloud agent launches directly from Visual Studio

The April Visual Studio update adds cloud agent integration: developers select "Cloud" from the agent picker, describe a task, and Copilot creates a GitHub issue and pull request on remote infrastructure — without leaving the IDE. A new Debugger agent also validates fixes against live runtime behavior.

→ Changelog: GitHub Copilot in Visual Studio — April update
