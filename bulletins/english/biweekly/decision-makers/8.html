🏆 Top 5 updates

1. The GitHub Copilot app opens to everyone

The agent-native desktop app is now generally available to all users, giving teams a dedicated workspace for running and managing Copilot agents outside the IDE. For leaders, it signals Copilot's shift toward autonomous, task-oriented work that can expand productivity beyond individual coding sessions.

Sources:
→ Changelog: GitHub Copilot app available to all
→ Blog: GitHub Copilot app: The agent-native desktop experience

2. GPT-5.6 joins an expanding model lineup

OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in Copilot, widening the frontier-model choice available to teams. Broader model access lets organizations match capability to task and cost, reinforcing Copilot's strategy of vendor-flexible AI rather than single-model lock-in.

→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot

3. Agentic autofix tackles security alerts automatically

Copilot can now propose fixes for code scanning alerts in public preview, turning detected vulnerabilities into ready-to-review remediations. For decision-makers, this compresses the costly gap between finding and fixing security issues, directly improving risk posture and developer throughput.

→ Changelog: Agentic autofix for code scanning alerts in public preview

4. Enterprises can default to auto model selection

Administrators can now set auto model selection as the organization-wide default, routing each request to an appropriate model automatically. This removes guesswork for developers while giving leaders a lever to balance performance and spend at scale.

Sources:
→ Changelog: Enterprises can default to auto model selection
→ Changelog: Copilot CLI auto model selection routes based on task

5. Cost centers gain AI credit pools and per-user budgets

Finance and platform teams can now allocate AI credit pools to cost centers and set per-user budgets in the billing UI. Together these deliver granular, chargeback-ready cost governance—essential for justifying and scaling Copilot investment across large organizations.

Sources:
→ Changelog: Cost centers now support AI credit pools
→ Changelog: Per-user budgets for cost centers in the billing UI
