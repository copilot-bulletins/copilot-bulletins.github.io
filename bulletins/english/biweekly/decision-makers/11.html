🏆 Top 5 updates

1. Copilot arrives in Slack

The GitHub integration in Slack now brings Copilot CLI and Copilot app capabilities into conversations in public preview. Teams can plan changes, investigate problems, and hand off coding tasks where they already coordinate, reducing context switching and accelerating decision-to-delivery.

→ Changelog: The new GitHub Copilot experience in Slack

2. Shared agentic work in Microsoft Teams

Mentioning @GitHub in Teams starts a shared Copilot cloud agent session that everyone can see and steer, turning meeting decisions into ready work. Compliance oversight is maintained, making agentic collaboration viable for regulated and enterprise environments.

→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams

3. Copilot code review expands coverage

Copilot code review now covers pull requests it previously skipped, including bot-authored PRs and very large ones, plus new comment resolution reasons. Broader automated coverage strengthens quality gates and extends the ROI of review automation across more of the codebase.

→ Changelog: Copilot code review: Resolution reasons and expanded capabilities

4. Global model policy generally available

Enterprises can now durably govern which Copilot models are available, with enforcement rolling out through September 1. Open-weight and data-retention models are disabled by default, giving decision-makers consistent, defensible control over AI usage across the organization.

→ Changelog: Global model policy generally available

5. Copilot app Customize tab now GA

The Customize tab in the Copilot app is generally available, letting teams tailor Copilot's behavior to their standards and workflows. Standardized customization at scale drives more consistent, higher-value outcomes across an organization's developers.

→ Changelog: GitHub Copilot app Customize tab is generally available
