🏆 Top 5 updates

1. GitHub Copilot App Enters Technical Preview

The GitHub Copilot app is a dedicated desktop environment for agentic development built natively on GitHub. It supports parallel workstreams across isolated branches, session management from GitHub issues and pull requests, and full PR lifecycle — giving organizations the infrastructure to direct multiple AI agents simultaneously.

→ Changelog: GitHub Copilot app is now available in technical preview

2. AI Adoption Cohort Metrics: A Framework for Measuring Copilot Maturity

The Copilot usage metrics API now classifies each engaged user into one of four AI adoption phases — from code-first usage to multi-agent workflows. Track phase progression across teams, identify where to focus enablement, and quantify how quickly developers are moving from basic completion to autonomous agent workflows.

→ Changelog: Copilot usage metrics API adds cohorts for AI adoption

3. Granular Model Governance: Control Which AI Models Reach Each Organization

Enterprise owners can now define targeted model rules to specify which Copilot models are available to individual organizations, replacing the single enterprise-wide toggle. Controlled rollout of frontier models, cost management by team, and compliance alignment with organizational risk appetites are now configurable from a single enterprise settings page.

→ Changelog: Target Copilot models to organizations with model rules

4. Claude Opus 4.8 Now Available in GitHub Copilot

Anthropic's latest Opus model is now available in GitHub Copilot across VS Code, JetBrains, Visual Studio, CLI, and the cloud agent. It delivers improved code understanding and large-codebase navigation, giving teams access to Anthropic's strongest model for complex engineering tasks within their existing Copilot subscription.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

5. Remote Control for Copilot Sessions: Full Workflow from Any Device

Remote control for GitHub Copilot CLI and VS Code sessions is now generally available on github.com and GitHub Mobile. Start sessions at the desk, monitor and redirect agents mid-task from any device, and complete PR review and merge from a phone — enabling a continuous, end-to-end agentic workflow.

→ Blog: Take your local GitHub sessions anywhere
