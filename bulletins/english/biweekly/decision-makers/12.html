Biweekly #12 · September 1 to September 14, 2026 · Decision-Makers Edition

🎯 This edition's thread

This period, GitHub tightened the enterprise controls around autonomous coding. New model choices, cost-and-quality tiers, agent-permission guardrails, and richer adoption metrics all point to the same direction: giving leadership the levers to scale AI safely while proving return on investment. For decision-makers, the story is maturing governance and measurable value, not just more capability.

🏆 Top 5 updates

1. GPT-6 Astra now generally available

OpenAI's latest general-purpose model lands in Copilot, built for long-horizon, autonomous coding. It plans, validates, and self-checks before finishing tasks, completing complex work in fewer steps. A strategic option for teams pushing agentic workflows further.

→ Changelog: GPT-6 Astra is generally available in GitHub Copilot

2. Copilot code review can now approve pull requests

Copilot now signals when a pull request is ready and, when admins authorize it, can sign off on approval. Off by default and configurable at enterprise, org, and repository level, this accelerates review throughput while keeping human oversight where it matters.

→ Changelog: Copilot code review can now approve pull requests

3. Enterprise-managed permissions for agent operations

Administrators can now centrally control which agent operations are blocked, require approval, or proceed automatically, covering shell commands, file access, and network domains. These guardrails can't be weakened by users, giving leadership confidence to scale agents safely.

→ Changelog: Enterprise managed permissions for GitHub Copilot agent operations

4. VS Code agents added to Copilot usage metrics

Usage metrics reports now include generally available activity from the VS Code Agents window across 1-day and 28-day periods. Leaders can measure agent adoption and engagement at enterprise and organization level, turning AI investment into trackable trends.

→ Changelog: Add VS Code agents to Copilot usage metrics

5. Cost and quality tiers for auto model selection

Auto model selection now offers efficiency, balance, and intelligence tiers, letting teams weigh cost, quality, and speed per prompt. Copilot optimizes each request accordingly, giving organizations a direct lever to manage spend without sacrificing outcomes.

→ Changelog: Configure cost and quality in Copilot auto model selection
