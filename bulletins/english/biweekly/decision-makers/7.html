Biweekly #7 · June 15 to June 30, 2026 · Decision-Makers Edition

🎯 This edition's thread

This period, GitHub focused on turning Copilot from a productivity tool into a governed enterprise investment. New reporting ties adoption directly to merged code, cost controls let leaders cap spend per team, and major general-availability milestones broadened where Copilot delivers value. For decision-makers, the signal is clear: the platform is maturing toward measurable, accountable AI at scale.

⚠️ Heads up

  • Opus 4.6 (fast) is being deprecated — Effective June 29, 2026 — This model has been retired across all Copilot experiences. Confirm your teams have moved to a supported model through your model availability settings.

🚀 Take action

  • Connect adoption to output: review total merges by adoption phase in your usage and adoption reports.
  • Control AI spend at scale: set per-user AI credit budgets on cost centers with budgets for usage-based billing.
  • Give teams the latest models: make sure Claude Sonnet 5 is available through your model availability settings.
  • Set your AI strategy: align teams with GitHub's enterprise AI governance guidance.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates

1. Claude Sonnet 5 lands across every paid plan

Anthropic's latest Sonnet-class model is now generally available in Copilot for Pro, Pro+, Max, Business, and Enterprise. It brings strong coding and agentic performance with competitive latency, keeping your teams on frontier models. Billed at provider list pricing under usage-based billing.

→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot

2. The GitHub Copilot app is generally available

GitHub's agent-native desktop app is now GA on macOS, Windows, and Linux. Teams can run parallel agent sessions across repositories, schedule cloud automations, and bring their own models. It signals GitHub's vision for development that extends well beyond the IDE.

→ Changelog: GitHub Copilot app generally available

3. Measure real impact: merges by adoption phase

Enterprise and organization reports now show total pull requests merged by each AI adoption phase, not just per-user averages. Leaders can finally connect Copilot rollout stages to shipped code, making impact and ROI easier to demonstrate across teams.

→ Changelog: Track total merges by adoption phase in enterprise and organization reports

4. Govern AI spend with per-user credit budgets

Enterprise admins can now set one per-user AI credit budget on a cost center that follows team membership automatically, eliminating thousands of manual budgets. Paired with new per-user credit data in the usage metrics API, leaders gain precise cost control and visibility.

Sources:
→ Changelog: Per-user AI credit budgets available for cost centers
→ Changelog: AI credits consumed per user now in the Copilot usage metrics API

5. GitHub Copilot for Jira reaches general availability

Teams standardized on Atlassian can now run Copilot's coding agent directly from Jira. Track agent progress in real time on the ticket, send follow-up instructions from the Jira panel, and keep work in one pull request — no switching to GitHub.

→ Changelog: GitHub Copilot for Jira is now generally available
