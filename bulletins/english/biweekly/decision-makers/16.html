Biweekly #16 · November 1 to November 14, 2026 · Decision-Makers Edition

🎯 This edition's thread

Measurement caught up with adoption this fortnight. GitHub extended Copilot reporting to show how chat, agents, code review feedback and bring-your-own-key models are actually used, while widening access across new tools and frontier models. For leaders, the conversation shifts from whether teams use Copilot to where it delivers measurable value.

🏆 Top 5 updates

1. A fuller picture of Copilot adoption

The Copilot impact dashboard now tracks Copilot Chat and the VS Code Agents window, covering nine experiences. "Passive users" become "Chat-first users", giving leaders a more accurate view of engagement when reporting adoption and return on investment.

→ Changelog: Copilot impact dashboard adds chat and VS Code agent usage

2. Proof that code review feedback lands

Repository-level usage metrics now report how many Copilot code review comments developers act on, plus merged pull requests with no later human change request. The resulting "addressed rate" turns code review from a usage count into a quality signal.

→ Changelog: Usage metrics API adds code review details and addressed rate

3. Copilot joins the conversation in Slack and Teams

@GitHub in Slack and Teams is now generally available. Teams can investigate bugs, create issues and open pull requests from chat, and review plans and code together with Canvas in Teams, bringing product and business stakeholders closer to delivery.

→ Changelog: @GitHub in Slack and Teams is generally available and more

4. New frontier models for complex work

Claude Fable 5.2 solved more tasks than its predecessor with fewer steps in early testing, while Gemini 4 Carbon targets complex and security-focused coding. Both run on usage-based billing, so model choice is now a direct cost and quality lever.

Sources:
→ Changelog: Claude Fable 5.2 in GitHub Copilot
→ Changelog: Gemini 4 Carbon in GitHub Copilot

5. Copilot reaches Xcode and JetBrains Air

Copilot now works inside Xcode's built-in coding assistant (public preview) and in JetBrains Air, including cloud tasks billed to your Copilot plan. One subscription now covers more of the tools your developers already choose.

Sources:
→ Changelog: GitHub Copilot is now available in Xcode's coding assistant
→ Changelog: GitHub Copilot is now available in JetBrains Air
