🏆 Top 5 updates

1. GitHub Copilot App Launches as a Native Development Platform

The GitHub Copilot app enters technical preview as a dedicated desktop experience for agentic development. It connects directly to GitHub issues, pull requests, and CI pipelines — enabling parallel AI workstreams, session management, and full PR lifecycle in one place without context-switching between tools.

→ Changelog: GitHub Copilot app is now available in technical preview

2. Copilot Cloud Agent Now Programmable via REST API

A new Agent tasks REST API (public preview) lets Copilot Business and Enterprise teams programmatically start and track cloud agent tasks. Use it to fan out migrations across repositories, provision new repos from your developer portal, or automate release note generation — integrating AI-driven development directly into your existing toolchain.

→ Changelog: Start Copilot cloud agent tasks via the REST API

3. June 1 Billing Transition: Preview Your AI Credit Usage Now

April usage reports are now available, giving admins a concrete view of how current Copilot activity maps to GitHub AI Credits ahead of the June 1 shift to usage-based billing. Existing Copilot Business and Enterprise customers receive promotional included credits through August to ease the transition.

Sources:
→ Changelog: April reports are now available to prepare for usage-based billing
→ Blog: GitHub Copilot is moving to usage-based billing

4. Team-Level Copilot Adoption Metrics Now Available

The Copilot usage metrics API gains a new user-teams report, enabling admins to slice adoption data by organizational team for the first time. Identify which teams drive Copilot usage and which need targeted enablement — with full breakdowns by language, IDE, and feature.

→ Changelog: Team-level Copilot usage metrics now available via API

5. Enterprise-Managed Plugins for Copilot CLI in Public Preview

Administrators can now configure and distribute Copilot CLI plugins enterprise-wide from a central settings file. Define baseline MCP configurations, custom agents, and hooks automatically available to every licensed user — reducing onboarding friction and strengthening governance consistency.

→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview
