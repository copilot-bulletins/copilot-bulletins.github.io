🏆 Top 5 updates

1. Organization-level billing and triggering controls for code review

Copilot code review now lets organization owners bill review requests to the repository-owning organization instead of individual member quotas, and restrict review triggering to authorized licensed users. Both controls live under Copilot policies, giving admins clearer cost governance and access enforcement.

→ Changelog: Copilot code review: New organization billing options and controls

2. Enforce fresh managed settings at client startup

Enterprise admins can now require supported Copilot clients to fetch current server-managed settings at startup rather than trusting a cached policy. Setting forceRemoteSettingsRefresh ensures policy changes take effect before Copilot starts — now supported in Copilot CLI, VS Code, and the Copilot app.

→ Changelog: Enterprise managed settings enforcement updates

3. Attribute Copilot activity without capturing content

The new telemetry.capture.identity setting lets enterprise admins attribute OpenTelemetry activity to a user without collecting prompts, responses, or tool content. Identity capture is off by default and separate from the pseudonymous identifier, with five additional content classes individually controllable — balancing auditability and privacy.

→ Changelog: Client telemetry user attribution and configurable capture

4. Purpose-built model for leaked secret detection

GitHub is bringing a fine-tuned, context-aware model to secret scanning alerts, push protection, and Copilot security reviews. It reads surrounding code to catch credentials without a recognizable token format. AI-detected alerts stay included in GHAS at no extra charge; new opt-in checks consume AI Credits.

→ Changelog: Purpose-built model for leaked secret detection

5. Local sandboxing now generally available

Local sandboxing is GA in Copilot CLI, the Copilot app, and VS Code Agent Host. Tools and commands run with restricted filesystem, network, and credential access based on developer- or organization-defined policies, powered by Microsoft eXecution Container across Windows, macOS, and Linux — a secure boundary for agentic workflows.

→ Changelog: Local sandboxing for GitHub Copilot now generally available
