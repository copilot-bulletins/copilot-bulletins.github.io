🏆 Top 5 updates

1. Global model policy reaches general availability

Enforcement of the default model policy is rolling out through September 1. Unconfigured and new generally available models inherit your policy via a dynamic "Delegate to default policy" state, while explicit choices are preserved. Open-weight and non-retention models stay disabled by default — giving admins durable, centralized control over model access.

→ Changelog: Global model policy generally available

2. Enterprise-managed settings arrive in Copilot for JetBrains

Administrators can now enforce plugin governance, MCP server allowlists, managed OpenTelemetry, and permission modes across JetBrains IDEs. Centrally control which MCP servers developers connect to and disable bypass-approval modes — extending consistent enterprise controls beyond VS Code to your JetBrains user base.

→ Changelog: Enterprise managed settings in GitHub Copilot for JetBrains

3. Copilot code review expands coverage and adds resolution reasons

Copilot code review now covers bot- and cloud-agent-authored pull requests and removes the 300-file / 20,000-line limit. Reviewers can tag resolutions as "Addressed," "Won't fix," or "Incorrect." With the license-optional policy enabled, bot-PR reviews bill directly to your org — improving audit trails and review consistency.

→ Changelog: Copilot code review: Resolution reasons and expanded capabilities

4. Auto-update support for approved plugin marketplaces

Enterprise-managed settings now support autoUpdate: true on extraKnownMarketplaces entries. Supported clients automatically update plugins from approved marketplaces — reducing manual maintenance for organization customizations while keeping installs within your strictKnownMarketplaces allowlist across the Copilot app, CLI, and VS Code.

→ Changelog: Enterprise-managed settings now support autoUpdate for plugin marketplaces

5. Shared agentic work in Microsoft Teams

Teams users can mention @GitHub to launch a shared Copilot cloud agent session visible to the whole conversation. Only participants with repository write access can trigger changes, and the work carries compliance oversight across Copilot surfaces — bringing agent collaboration into meetings while preserving access governance.

→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams
