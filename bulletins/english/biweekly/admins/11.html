🏆 Top 5 updates

1. Central MCP allowlists for the enterprise

Enterprise owners can now centrally control which Model Context Protocol servers Copilot clients may run, using new allowedMcpServers and deniedMcpServers keys in managed settings. This closes a key governance gap, letting admins standardize approved tooling and block unvetted servers across the enterprise.

→ Changelog: MCP allowlists in enterprise managed settings

2. Impact dashboard adds a return-on-investment section

The Copilot impact dashboard now ties spend to pull request output, comparing chat/completion users against agent-first developers. A salary selector recalculates cost-derived metrics instantly, so admins can justify continued investment and target enablement at the adoption phases with the most headroom.

→ Changelog: Copilot impact dashboard adds a return on investment section

3. Per-model token breakdown in the usage report

The AI usage report now shows input, output, cache read, and cache write tokens per model alongside the AI credits consumed. Admins on Business and Enterprise can finally trace exactly how each model's cost adds up, making charges explainable and easier to bring down with stakeholders.

→ Changelog: Per-model token breakdown in the usage report

4. Usage metrics API breaks out agent app activity

The Copilot usage metrics API now reports third-party agent activity individually via a new totals_by_3rd_party_agent array, across enterprise and organization reports. Admins can distinctly track each agent, compare adoption, and ground rollout and licensing decisions in real usage instead of assumption.

→ Changelog: Copilot usage metrics API adds agent app activity

5. Team specialization for enterprise managed settings

Enterprise admins can now target specific teams with itemized managed-settings configuration files, letting individual keys take team-specific values. This scales governance without bottlenecking every change centrally—teams adapt Copilot to their workflows while staying inside the boundaries you define.

→ Changelog: Enterprise team specialization for managed settings
