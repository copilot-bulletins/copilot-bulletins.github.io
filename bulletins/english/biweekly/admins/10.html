Biweekly #10 · July 15 to July 31, 2026 · Admins Edition

🎯 This edition's thread

This period was defined by administrative control. GitHub shipped a wave of enterprise governance capabilities — finer model policy targeting, dedicated app access policies, centrally managed settings extending to new surfaces, and richer usage reporting. For admins, the message is clear: Copilot's governance surface is maturing, giving you tighter, more granular control over access, models, and measurable impact across your organization.

🏆 Top 5 updates

1. Model policy targeting for enterprise teams

AI administrators can now set model policies scoped to specific teams and users, not just the whole enterprise. This lets you establish a baseline while granting exceptions where needed, giving Copilot Business and Enterprise admins far more granular control over which models each group can access.

→ Changelog: Enterprise teams model policy targeting in public preview

2. New usage metrics impact dashboard

A new impact dashboard for enterprise administrators and organization owners helps you tell a deeper Copilot story — moving beyond who is using Copilot to how it affects outcomes. It's a stronger foundation for reporting adoption value to leadership and justifying continued investment.

→ Changelog: New Copilot usage metrics impact dashboard

3. Dedicated access policy for the Copilot app

The GitHub Copilot app now has its own policy, letting you control who can access it independently at the enterprise and organization levels. Previously bundled with broader Copilot access, this dedicated control gives admins cleaner, more precise governance over app rollout.

→ Changelog: Manage GitHub Copilot app access with a dedicated policy

4. Enterprise managed settings extend to the Copilot app and cloud agent

You can now govern the GitHub Copilot app and Copilot cloud agent with the same centrally managed enterprise settings you already use elsewhere. This closes a governance gap, ensuring your policies apply consistently across newer Copilot surfaces without separate configuration.

→ Changelog: Enterprise managed settings in the GitHub Copilot app and Copilot cloud agent

5. Copilot code review: agent skills and MCP now generally available

Agent skills and MCP server support for Copilot code review are now GA for Pro, Pro+, Business, and Enterprise. Teams can tailor automated reviews to organizational standards and connect internal context, raising review quality and consistency across repositories.

→ Changelog: Copilot code review: Agent skills and MCP now generally available
