🏆 Top 5 updates

1. AI adoption cohorts in the Copilot usage metrics API

The Copilot usage metrics API now classifies each engaged user into an AI adoption phase — Code first, Agent first, or Multi-agent — based on Copilot surface usage over a rolling 28-day window. Enterprise and org admins can see phase-level aggregates and target enablement programs at the cohorts that need attention most.

→ Changelog: Copilot usage metrics API adds cohorts for AI adoption

2. Per-organization model governance with targeted model rules

Enterprise owners can now allow specific Copilot models for specific organizations, going beyond a single enterprise-wide setting. In public preview, targeted model rules deliver fine-grained governance — ensuring each team accesses only appropriate models — while a refreshed interface simplifies enterprise-wide default management.

→ Changelog: Target Copilot models to organizations with model rules

3. Repository-level off switch for Copilot Memory

Repository administrators now have a direct switch to disable Copilot Memory at the repository level, preventing new repository-level facts from being stored or read. The update also clarifies memory scope at capture time, distinguishing between user-level preferences and repository-level facts visible to all contributors.

→ Changelog: Copilot Memory has more controls for deletion, scope, and the Copilot CLI

4. Claude Opus 4.8 now available — admin policy required

Anthropic's latest Opus model is now generally available for Copilot Pro+, Business, and Enterprise users across all surfaces — IDE, CLI, cloud agent, mobile, and web. Enterprise and Business admins must explicitly enable the Claude Opus 4.8 policy in Copilot settings before users can access it.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

5. Copilot usage metrics reports migrate to GitHub-owned download URLs

Report download links from the Copilot Usage Metrics API have migrated from Azure Front Door domains to the stable copilot-reports.github.com domain. Enterprise security teams with firewall or proxy allowlists should add the new domain; the legacy Azure pattern remains active temporarily but will be deprecated.

→ Changelog: Copilot usage metrics reports now use GitHub-owned download URLs
