🏆 Top 5 updates

1. GitHub Copilot App lands in technical preview

The GitHub Copilot app is now in technical preview — a GitHub-native desktop experience for agentic development, including session management, diff review, pull request integration, and Agent Merge. For Business and Enterprise orgs, admins must enable previews and Copilot CLI in policy settings before users can access it.

→ Changelog: GitHub Copilot app is now available in technical preview

2. April billing reports ready ahead of June 1 AI credits launch

Copilot Business and Enterprise admins can now download the April usage report showing activity in AI credits — the new billing unit going live June 1. Identify top consumers, understand which models and surfaces drive spending, and update budget estimates before the transition.

→ Changelog: April reports are now available to prepare for usage-based billing

3. Enterprise-managed plugins for Copilot CLI in public preview

Enterprise admins can now define plugin standards — including MCP configurations and custom agents — and push them to all Copilot CLI users via a settings.json file in .github-private. Plugins can auto-install on authentication, enforcing governance baselines and reducing developer onboarding friction at scale.

→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview

4. Org-level secrets and variables for Copilot cloud agent

Copilot cloud agent now has dedicated "Agents" secrets and variables — separate from Actions — configurable at both organization and repository level. Admins can share a single secret (e.g., an internal registry token) across all repositories, eliminating the need to duplicate configuration per repo.

→ Changelog: More flexible secrets and variables for Copilot cloud agent

5. Copilot code review usage metrics broken down by comment type

The Copilot usage metrics API now reports code review suggestions by comment type (e.g., security, bug_risk), showing total suggestions and how many were applied per type. Enterprise and org admins can now see not just adoption volume but the categories of feedback Copilot delivers — and how much developers act on it.

→ Changelog: Copilot code review comment types now in usage metrics API
