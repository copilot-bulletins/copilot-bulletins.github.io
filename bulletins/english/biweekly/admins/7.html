🏆 Top 5 updates

1. Usage-based billing goes live with budget controls

June 1 reset how Copilot is paid for: every plan now bills on consumed GitHub AI Credits, and code review also draws GitHub Actions minutes. New user-level budgets let you cap spend per person before overages hit, alongside Copilot Max upgrades for power users.

→ Changelog: Updates to GitHub Copilot billing and plans

2. Security validation now covers third-party coding agents

Code from third-party agents like Claude and OpenAI Codex now receives the same automatic validation as Copilot cloud agent: CodeQL scanning, dependency checks against the GitHub Advisory Database, and secret scanning. Detected issues are resolved before the pull request is finalized, extending consistent security guarantees across agents.

→ Changelog: Security validation for third-party coding agents

3. New configuration controls for Copilot code review

Copilot code review gains organization-level governance: set the runner type (GitHub-hosted, large, or self-hosted) org-wide, apply content exclusion so sensitive paths are skipped, and write repository custom instructions without the old character limit. More ways to align automated reviews with your standards.

→ Changelog: Copilot code review: New configurations and controls

4. Enterprise-managed plugins extend to VS Code

Enterprise admins can now push approved plugins to VS Code, not just Copilot CLI (VS Code 1.122+). Define a plugin marketplace once in .github-private, and every licensed Business or Enterprise user inherits your custom agents, skills, always-on hooks, and MCP configurations—standardizing onboarding and governance.

→ Changelog: Enterprise-managed plugins in VS Code in public preview

5. Agentic workflows drop the personal access token

GitHub Agentic Workflows can now run on the built-in GITHUB_TOKEN instead of a stored PAT, removing the security and operational risk of long-lived tokens at scale. AI credits bill directly to the organization, gated by a Copilot policy you control.

→ Changelog: Agentic workflows no longer need a personal access token
