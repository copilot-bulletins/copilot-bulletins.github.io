Monthly #5 · July 2026 · Devs Edition

🎯 This edition's thread

July was about choice and autonomy at the keyboard. A wave of new frontier models landed in Copilot while the CLI, code review, and IDE agents grew more capable and configurable. For developers, that means more control over which model handles a task and more agentic help across the tools you already use every day.

⚠️ Heads up

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Action required — These models are removed across all Copilot experiences. Switch any pinned workflows to a supported model in your Copilot chat settings.

🚀 Take action

  • Try auto model selection in the Copilot CLI to let Copilot route each task to the best-fit model.
  • Explore the new models and pick your default in your Copilot chat settings.
  • Tailor Copilot Code Review to your team with configuration options.
  • Connect your tools with the GitHub MCP server.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates of the month

1. A new wave of models arrives in Copilot

July brought one of the busiest model months yet: Claude Opus 5, OpenAI's GPT-5.6 (Sol, Terra, and Luna), Grok 4.5, Gemini 3.6 Flash, and Kimi K2.7 all became available. More choice means you can match reasoning depth, speed, and cost to each task.

→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot
→ Changelog: Gemini 3.6 Flash is now available in GitHub Copilot

2. Copilot CLI gets smarter and more autonomous

The CLI now offers auto model selection that routes based on task complexity and real-time model health. It also gained custom agents, real code intelligence via language servers, and no longer needs a personal access token when running in GitHub Actions.

Sources:
→ Changelog: Copilot CLI auto model selection routes based on task
→ Blog: From one-off prompts to workflows: how to use custom agents in GitHub Copilot CLI
→ Changelog: Copilot CLI no longer needs a personal access token in GitHub Actions

3. Copilot Code Review: agent skills, MCP, and customization

Copilot Code Review reached general availability for agent skills and MCP, letting reviews tap custom tools and context. New customization and configurability options let you shape what Copilot flags to fit your team's standards.

Sources:
→ Changelog: Copilot code review agent skills and MCP now generally available
→ Changelog: Copilot code review customization and configurability improvements

4. IDE updates across VS Code, Visual Studio, and JetBrains

All three flagship IDEs shipped July updates. VS Code and Visual Studio landed their monthly releases, while JetBrains added Codex as an agent provider, agentic enhancements, expanded BYOK, and improved OpenTelemetry and model management.

Sources:
→ Changelog: GitHub Copilot in Visual Studio Code July 2026 releases
→ Changelog: GitHub Copilot in Visual Studio July update
→ Changelog: Codex as agent provider and agentic enhancements in JetBrains IDEs

5. Agentic autofix for code scanning alerts

Agentic autofix for code scanning alerts entered public preview, using an agent to propose and validate fixes so you can close security findings faster without leaving your workflow.

→ Changelog: Agentic autofix for code scanning alerts in public preview
