Monthly #6 · August 2026 · Devs Edition

🎯 This edition's thread

August pushed Copilot toward a more open, steerable agent. A cross-client plugin standard, comment-triggered automations, adjustable reasoning, and a fresh wave of frontier models all point the same way: you compose the agent instead of accepting a fixed one. For developers, the day-to-day work increasingly means orchestrating tools, models, and behavior — not just accepting code suggestions.

🏆 Top 5 updates of the month

1. One plugin, every agent client

Agent Plugins 1.0 lets you build a plugin once and run it across VS Code, Copilot CLI, and the Copilot app. Launched with AWS, Anysphere, Microsoft, OpenAI, Vercel, and Google, it standardizes agent extensibility and cuts client-specific lock-in.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

2. A more steerable, automatable cloud agent

You can now set a reasoning level when delegating a task, trading tokens for deeper problem-solving on demand. Copilot automations can also be triggered directly from issue or pull request comments — generate docs, investigate errors, or spin up follow-up tasks without leaving the thread.

Sources:
→ Changelog: Customize the reasoning level for Copilot cloud agent
→ Changelog: Trigger Copilot automations with comments

3. A fresh wave of frontier models

Four new models landed this month: Kimi K3, MAI-Code-1.1-Flash, Gemini 3.7 Flash, and Grok 4.6. More choice means you can tune power, speed, and cost per task instead of settling for one default across every workflow.

Sources:
→ Changelog: Kimi K3 is now available in GitHub Copilot
→ Changelog: MAI-Code-1.1-Flash available in GitHub Copilot
→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot
→ Changelog: Grok 4.6 is now available in GitHub Copilot

4. JetBrains levels up: memory, local models, harness

Copilot for JetBrains gained persistent memory and local model access via Ollama, plus improved chat workflows and MCP reliability. Later in the month, Copilot harness reached general availability, bringing a more capable agentic experience to the JetBrains IDE.

Sources:
→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains
→ Changelog: Copilot harness generally available in Copilot for JetBrains

5. Copilot code review keeps maturing

Code review effort levels reached general availability, letting you dial thoroughness against speed. New resolution reasons and expanded capabilities make review feedback clearer and easier to act on across your pull requests.

Sources:
→ Changelog: Copilot code review effort levels are generally available
