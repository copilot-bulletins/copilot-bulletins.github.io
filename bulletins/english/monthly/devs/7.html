🏆 Top 5 updates of the month

1. A new wave of frontier models

Copilot's model lineup grew substantially this month, with GPT-6 Astra reaching general availability for long-horizon agentic coding, plus Claude Opus 5.5, Claude Sonnet 5.5, Grok 4.7, and OpenAI's GPT-6 Sol and Luna. Pick the model that best fits each task.

2. HydraFusion expands to VS Code and the Copilot app

The HydraFusion research preview is now available in Visual Studio Code and the GitHub Copilot app, beyond Copilot CLI. It appears in the model picker but routes your request across models to combine their strengths, giving you higher-quality results without manual model switching.

→ Changelog: HydraFusion in VS Code and the GitHub Copilot app

3. New agentic features in Copilot for JetBrains

Copilot for JetBrains 1.18.0 brings AI-assisted tool approvals, more control over agent conversations, and shared skills and instructions for your organization. You can also review agent plans before execution, giving JetBrains developers tighter control over autonomous coding sessions.

→ Changelog: New features and improvements in Copilot for JetBrains

4. Faster C++ code intelligence in Copilot CLI

C++ code intelligence in Copilot CLI is now faster thanks to whole-codebase indexing. For repositories spanning millions of lines across deeply connected source files, this means quicker, more accurate context and navigation when working from the command line.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

5. Local sandboxing in the Copilot app

Local sandboxing limits an agent's access to files, network resources, and credentials on your machine, reducing the impact of unintended commands. In the Copilot app you configure it per project for local repository and working-tree sessions, running agents more safely.

→ Changelog: Local sandboxing in the GitHub Copilot app
