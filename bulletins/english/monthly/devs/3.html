🏆 Top 5 updates of the month

1. GPT-5.5 is now available for Copilot

GPT-5.5, OpenAI's most capable model to date, is generally available in Copilot for Pro+, Business, and Enterprise users. It delivers its strongest performance on complex, multi-step agentic coding tasks and is selectable across VS Code, Visual Studio, JetBrains, Copilot CLI, github.com, and GitHub Mobile. Note the 7.5× premium multiplier.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

2. Agent mode goes native across VS Code, JetBrains, and Visual Studio

Three major IDEs gained autonomous agent capabilities this month. VS Code's Autopilot lets agents run end-to-end without manual approval; JetBrains adds inline agent mode directly in the editor; Visual Studio now launches cloud agent sessions natively with a new debugger agent that validates fixes against live runtime behavior.

Sources:
→ Changelog: GitHub Copilot in Visual Studio Code, March Releases
→ Changelog: Inline agent mode in preview and more in GitHub Copilot for JetBrains IDEs
→ Changelog: GitHub Copilot in Visual Studio — April update

3. Copilot CLI: work offline with BYOK, steer remotely from anywhere

Copilot CLI shed its dependency on GitHub-hosted models: configure any OpenAI-compatible, Azure OpenAI, Anthropic, or local Ollama endpoint as your provider, or set COPILOT_OFFLINE=true for fully air-gapped workflows. Separately, start a session with copilot --remote to get a shareable link and steer from any browser or GitHub Mobile.

Sources:
→ Changelog: Copilot CLI now supports BYOK and local models
→ Changelog: Remote control CLI sessions on web and mobile in public preview

4. Copilot SDK is now in public preview

The Copilot SDK makes the production-tested agent runtime behind Copilot cloud agent and CLI available to developers in Node.js, Python, Go, .NET, and Java. Embed agentic capabilities directly in your own applications—the same orchestration layer that powers the tools you already use every day.

→ Changelog: Copilot SDK in public preview

5. Cloud agent gets faster, smarter, and more capable

April brought a wave of cloud agent improvements: a new "Fix with Copilot" button resolves PR merge conflicts in three clicks; startup time dropped another 20% via custom Actions images; GitHub Mobile gained full research and coding capabilities on a branch; and validation tools now run in parallel for faster checks.
