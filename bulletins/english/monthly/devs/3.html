Monthly #3 · May 2026 · Devs Edition

🎯 This edition's thread

May marks the month Copilot became a true multi-surface platform for agentic work. A new desktop app, remote session control going generally available, smarter model routing, and Claude Opus 4.8 landing across all clients signal a shift: developers can now direct parallel agent workflows from any device, in any IDE, without being tied to a single machine or model choice.

⚠️ Heads up

  • Upcoming deprecation of GPT-4.1, GPT-5.2, and GPT-5.2-Codex — Deadline: June 1, 2026 — Update workflows and integrations to GPT-5.5 (replacing GPT-4.1 and GPT-5.2) or GPT-5.3-Codex (replacing GPT-5.2-Codex). See supported models.

🚀 Take action

  • Install the GitHub Copilot app to run parallel agent sessions from a dedicated desktop environment (Business/Enterprise: enable preview features and Copilot CLI; Pro/Pro+: join the waitlist).
  • Use /remote on in a CLI or VS Code session to monitor and steer your work from any browser or GitHub Mobile.
  • Switch to Auto in the model picker for task-based intelligent routing — each request is routed to the best model with a 10% multiplier discount and no rate limits.
  • Select Claude Opus 4.8 in the model picker for complex, large-codebase agentic tasks (Pro+, Business, Enterprise).
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates of the month

1. GitHub Copilot app arrives in technical preview

The GitHub Copilot app is a new desktop application for agent-driven development. Run multiple agent sessions in parallel—each on its own branch—start from an issue or PR, review diffs, run commands from an integrated terminal, and ship pull requests without switching tools. Available for Business/Enterprise (preview features + CLI enabled); Pro/Pro+ can join the waitlist.

→ Changelog: GitHub Copilot app is now available in technical preview

2. Remote control for Copilot CLI and VS Code sessions goes GA

Start a Copilot session in the CLI or VS Code, use /remote on, and monitor it from any browser or GitHub Mobile. See what Copilot is doing in real time, send follow-up instructions, approve permissions, and review proposed changes—all from your phone. Remote control is now generally available on github.com and the GitHub Mobile app.

→ Blog: Take your local GitHub sessions anywhere

3. Smarter auto model selection: routes by task, now across all Copilot surfaces

Copilot Auto model selection now evaluates each request across dimensions like reasoning needs, code complexity, and tool orchestration requirements—then routes to the optimal model in real time. Available in VS Code (task-optimized routing with transparency on model used) and the cloud agent (removes rate limits, 10% multiplier discount). No setup—choose Auto in the model picker.

Sources:
→ Changelog: Auto model selection now routes based on your task in VS Code
→ Changelog: Copilot cloud agent supports auto model selection

4. Claude Opus 4.8 is generally available for Copilot

Anthropic's latest Opus model is now available in Copilot for Pro+, Business, and Enterprise users. Opus 4.8 shows clear improvements in code understanding, generation, and large-codebase navigation. Select it across VS Code, Visual Studio, JetBrains, Copilot CLI, the Copilot app, github.com, GitHub Mobile, Xcode, and Eclipse. Enterprise and Business admins must enable it in Copilot settings.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

5. VS Code April releases: semantic search everywhere, BYOK, and terminal agents

Four weekly VS Code releases (v1.116–v1.119) brought substantial improvements. Semantic indexing now works in all workspaces. Copilot Business and Enterprise users can bring their own API keys (BYOK) for any model provider. Agents gain read/write access to open terminals. A new /chronicle feature lets you search your own chat history for past sessions and referenced files.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases
