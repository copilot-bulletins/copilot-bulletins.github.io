Monthly #8 · October 2026 · Devs Edition

🎯 This edition's thread

October shifted Copilot from single-session assistance toward coordinated agent systems. Model routing, multi-repository projects, shared automations and merge-blocker fixing now run continuously across the app, IDEs, CLI and cloud. For developers, the practical change is less time choosing models and babysitting tasks, and more time reviewing outcomes and setting direction.

🏆 Top 5 updates of the month

1. Copilot Fusion picks and combines models for you

Copilot Fusion is generally available and replaces Auto. Choose Standard, High or Max effort, and Copilot routes or orchestrates one or several models per task. It is available in VS Code, JetBrains and more, and can now include local models.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot Fusion now supports selection of local models

2. Projects and session continuity in the Copilot app

Copilot projects (public preview) let you give Copilot a goal spanning several repositories, plus specs and design context, then run parallel agents. Cloud sessions now follow you across the app, VS Code, the CLI, github.com and mobile.

Sources:
→ Changelog: GitHub Copilot app, Universe releases
→ Changelog: Work from anywhere with a new, connected Copilot cloud experience
→ Changelog: GitHub Copilot in VS Code, Universe releases

3. Copilot Automations become shared and self-improving

Automations combine prompts, triggers and tools to run repo workflows in the cloud. They can now be shared with your team, learn from outcomes to propose improvements, gain new triggers and cost controls, and be managed directly from VS Code.

Sources:
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: Copilot Automations now learn from outcomes and self-improve
→ Changelog: Create and manage Copilot Automations in Visual Studio Code

4. From review to merge: Agent Merge and code review Max

Agent Merge now runs on github.com, fixing failing Actions workflows and merge conflicts in the cloud. Code review adds a Max effort level (public preview) running several review agents across model providers, and Copilot approvals are generally available.

Sources:
→ Changelog: Agent Merge watches and fixes pull requests in the cloud
→ Changelog: Copilot code review: Merge with confidence with Max and approvals

5. Richer context: connectors, memory and code search

GitHub-verified MCP connectors (public preview) let you sign in once to 26 services and reuse them across every Copilot surface. GitHub intelligence adds memory, dreaming and code search beyond your checkout, so agents keep your conventions between sessions.

Sources:
→ Changelog: Connect your tools to Copilot without all the setup
→ Changelog: GitHub intelligence puts your code, context, and history to work
