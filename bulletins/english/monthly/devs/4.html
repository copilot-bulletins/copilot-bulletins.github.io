Monthly #4 · June 2026 · Devs Edition

🎯 This edition's thread

This month, Copilot's center of gravity shifted from inline suggestions toward agent-driven development across dedicated surfaces. A desktop app, a matured command-line experience, more autonomous coding agents, and a broader model roster all landed together. For developers, the practical takeaway is choice: match the surface and model to each task, and let agents handle the repetitive work.

⚠️ Heads up

  • GPT-4.1 deprecated — Deprecated: June 1, 2026 — Migrate workflows and integrations to GPT-5.5, and confirm availability in the supported models list.
  • GPT-5.2 and GPT-5.2-Codex deprecated — Deprecated: June 5, 2026 — Switch to GPT-5.5 and GPT-5.3-Codex respectively.
  • Upcoming deprecation of Opus 4.6 (fast) — Deprecated: June 29, 2026 — Move to Opus 4.8 (fast) across Chat, inline edits, ask and agent modes, and completions.

🚀 Take action

  • Try Claude Sonnet 5 or another new option by changing the chat model in your IDE or on github.com.
  • Install or update the GitHub Copilot CLI to get the new terminal interface, /settings, and /security-review.
  • Download the GitHub Copilot desktop app for macOS, Windows, or Linux.
  • Review the supported models list and migrate any workflows still referencing deprecated models.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates of the month

1. Claude Sonnet 5 headlines an expanded model roster

Copilot's model roster grew fast. Claude Sonnet 5 reached general availability, Claude Opus 4.8 (fast mode) entered preview with quicker output at the same intelligence, and Gemini 3.1 Pro, Gemini 3.5 Flash, and MAI-Code-1-Flash reached more surfaces. Pick the model that fits each task.

→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: Gemini models in Copilot CLI, cloud agent, and the Copilot app
→ Changelog: MAI-Code-1-Flash is now available for GitHub Copilot

2. Copilot CLI's new terminal interface goes GA

The redesigned Copilot CLI terminal interface, previewed at Microsoft Build 2026, is now generally available with a tabbed layout. June also brought a unified /settings command, an experimental /security-review, plus voice input and prompt scheduling — making the CLI a fuller agentic workspace.

Sources:
→ Changelog: Copilot CLI: New terminal interface is generally available
→ Changelog: Copilot CLI: Configure everything from one place with /settings
→ Changelog: Dedicated security review command now available in Copilot CLI
→ Changelog: Copilot CLI: Improved UI, rubber duck, prompt scheduling, and voice input

3. The GitHub Copilot desktop app is now generally available

The GitHub Copilot app reached general availability for macOS, Windows, and Linux. Built natively on GitHub, it's a desktop home for agent-driven development where you can run and manage agent sessions. It also added bring-your-own-key support for your own model providers.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Changelog: GitHub Copilot app support for BYOK
→ Blog: GitHub Copilot app: The agent-native desktop experience

4. Coding agents get more autonomous

Copilot's coding agent gained independence. It can now run in secure local and cloud sandboxes (public preview), execute on schedules or repository events via automations, and be driven programmatically through the new Agent tasks REST API for Pro, Pro+, and Max.

Sources:
→ Changelog: Cloud and local sandboxes for GitHub Copilot now in public preview
→ Changelog: Schedule and automate tasks with Copilot cloud agent
→ Changelog: Agent tasks REST API now available for Copilot Pro, Pro+, and Max

5. IDE updates land across JetBrains, Visual Studio, VS Code, and Eclipse

Every major IDE moved forward. JetBrains AI Assistant now integrates the Copilot Agent directly, JetBrains IDEs gained org and enterprise agents and Claude as an agent provider (preview), VS Code shipped its May releases, Visual Studio sharpened planning, and Eclipse added BYOK and skills.
