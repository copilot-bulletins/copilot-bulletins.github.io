🏆 Top 5 updates of the month

1. The GitHub Copilot app reaches general availability

The desktop home for agent-driven development is now generally available on macOS, Windows, and Linux. Built natively on GitHub, it gives organizations a dedicated surface where agents work alongside developers—marking AI's shift from in-editor assistant to a workspace of its own.

Sources:
→ Blog: GitHub Copilot app: The agent-native desktop experience
→ Changelog: GitHub Copilot app generally available

2. Automation goes agentic across GitHub

GitHub Agentic Workflows entered public preview, letting teams automate reasoning-based work—issue triage, CI failure analysis, documentation—with coding agents inside Actions. Paired with scheduled cloud-agent automations and partner agent apps from the Marketplace, GitHub is turning autonomous agents into always-on members of the delivery pipeline.

Sources:
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Schedule and automate tasks with Copilot cloud agent
→ Changelog: Extend GitHub with agent apps

3. A broader, stronger model lineup

Copilot's model roster expanded again: Claude Sonnet 5 reached general availability, Claude Opus 4.8 (fast mode) entered preview, and auto model selection went generally available for all plans. For leaders, this means best-in-class model choice, faster iteration, and no single-vendor lock-in.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: Auto mode in Copilot Chat available for all users

4. New ways to measure and govern AI spend

Usage-based billing is now live for all customers, and GitHub added the governance leaders need: per-user AI credit budgets that follow cost-center membership and per-user credit consumption in the usage metrics API—making AI ROI easier to prove and contain.

Sources:
→ Changelog: Updates to GitHub Copilot billing and plans
→ Changelog: Per-user AI credit budgets available for cost centers
→ Changelog: AI credits consumed per user now in the Copilot usage metrics API

5. Copilot extends across your existing stack

GitHub widened where Copilot delivers value: the Copilot SDK is generally available for embedding its agentic engine in your own apps, Copilot for Jira reached general availability, and Copilot is now a first-class agent in JetBrains AI Assistant—more return from tools teams already use.

Sources:
→ Changelog: Copilot SDK is now generally available
→ Changelog: GitHub Copilot for Jira is now generally available
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant
