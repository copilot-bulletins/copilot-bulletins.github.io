🏆 Top 5 updates of the month

1. Prove Copilot's impact with deeper adoption metrics

A new impact dashboard groups engaged users by AI adoption phase, while repository-level metrics and expanded report rollups reveal exactly where Copilot drives pull request activity. Together they give leaders defensible data to demonstrate ROI and target enablement where it pays off most.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: GitHub Copilot app usage metrics now expand across report rollups

2. Govern AI spend at scale

Enterprise admins can now set per-user AI credit budgets and share credit pools directly in the billing UI, with cost centers supporting included-usage caps. Budgets stay in sync as membership changes, so finance and platform leaders can cap consumption predictably without constant reconfiguration.

Sources:
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Cost centers now support included usage caps

3. AI that finds and fixes security risk

Copilot code review reached general availability with agent skills and MCP, agentic autofix entered preview for all code scanning alerts, and security reviews came to the desktop app. Copilot now remediates vulnerabilities the way a developer would—shrinking time-to-fix and reducing exposure across the codebase.

Sources:
→ Changelog: Copilot code review: Agent skills and MCP now generally available
→ Changelog: Agentic autofix for code scanning alerts in public preview
→ Changelog: Security reviews now available in the GitHub Copilot app

4. A widening frontier-model lineup

Claude Opus 5, Grok 4.5, and OpenAI's GPT-5.6 all arrived in July, extending an already deep catalog. Broad model choice lets organizations match the right model to each task and avoid lock-in—keeping Copilot competitive as the underlying AI landscape shifts.

Sources:
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot
→ Changelog: OpenAI's GPT-5.6, Sol, Terra, and Luna are now available in GitHub Copilot

5. The GitHub Copilot app for everyone

The desktop GitHub Copilot app is now available on every Copilot plan across macOS, Windows, and Linux. Bringing agent-driven development to the desktop lowers the barrier to autonomous workflows and broadens Copilot's reach beyond the editor for every team.

→ Changelog: GitHub Copilot app available to all
