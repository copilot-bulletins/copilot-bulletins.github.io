🏆 Top 5 updates of the month

1. Enterprise-Grade Compliance: Data Residency and FedRAMP Now Available

GitHub Copilot now supports data residency for US and EU regions, with FedRAMP Moderate-authorized infrastructure for US government customers. All GA features — agent mode, code review, cloud agent, Copilot CLI — route exclusively through region-specific endpoints. Japan and Australia are on the 2026 roadmap.

→ Changelog: Copilot data residency in US, EU, and FedRAMP compliance now available

2. Autonomous Coding, End to End: Research, Plan, and Code with Copilot Cloud Agent

Copilot cloud agent is no longer limited to pull-request creation. Developers can assign tasks where Copilot researches the codebase, generates an implementation plan for review, and then writes code — all before a PR is opened. This shifts Copilot from a coding assistant to a true autonomous development partner.

→ Changelog: Research, plan and code with Copilot cloud agent

3. Two Frontier Models in One Month: GPT-5.5 and Claude Opus 4.7 Now Generally Available

OpenAI's GPT-5.5 and Anthropic's Claude Opus 4.7 are now rolling out for Copilot Business and Enterprise users. Both excel at complex, multi-step agentic workflows and long-horizon reasoning — the capabilities that matter most at scale. Administrators must enable model policies to grant team access.

Sources:
→ Changelog: GPT-5.5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.7 is generally available

4. Embed Copilot in Your Platforms: The Copilot SDK Is Now in Public Preview

The GitHub Copilot SDK gives engineering teams the building blocks to embed Copilot's agentic runtime directly into internal tools, developer portals, and workflows — available in Node.js, Python, Go, .NET, and Java. Organizations can build custom agents powered by the same production-tested engine behind Copilot cloud agent.

→ Changelog: Copilot SDK in public preview

5. Measure the ROI of AI Code Review: New PR Merge Metrics in the API

The Copilot usage metrics API now includes time-to-merge and merge rate data for Copilot-reviewed pull requests. Combined with existing coding agent authorship metrics, organizations can now quantify Copilot's end-to-end impact across the full pull request lifecycle — from first commit to merge.

→ Changelog: Copilot-reviewed pull request merge metrics now in the usage metrics API
