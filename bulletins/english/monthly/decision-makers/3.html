🏆 Top 5 updates of the month

1. Gartner names GitHub a Leader in Enterprise AI Coding Agents — for the third consecutive year

GitHub Copilot is positioned as a Leader in the 2026 Gartner Magic Quadrant for Enterprise AI Coding Agents — and ranked highest in ability to execute. Copilot now serves 140,000 organizations (nearly triple from a year ago), with over 100% year-over-year growth and CLI usage nearly doubling month over month.

→ Blog: GitHub recognized as a Leader in the Gartner® Magic QuadrantTM for Enterprise AI Coding Agents for the third year in a row

2. GitHub Copilot transitions to usage-based billing

Premium request units are replaced by GitHub AI Credits, tying costs directly to token consumption. Base plan pricing stays the same — but enterprises gain pooled credit buckets, granular budget controls at the user, cost-center, and enterprise levels, and a higher promotional allowance for existing customers through August.

→ Blog: GitHub Copilot is moving to usage-based billing

3. New metrics to tell your AI adoption maturity story

The Copilot usage metrics API now classifies each active user into one of four AI adoption phases — from "Code first" to "Multi-agent" — based on rolling 28-day usage. Combined with new team-level breakdowns (also now available via API), decision-makers can show not just who uses Copilot, but how sophisticatedly — turning usage data into a compelling ROI narrative.

Sources:
→ Changelog: Copilot usage metrics API adds cohorts for AI adoption
→ Changelog: Team-level Copilot usage metrics now available via API

4. Remote control: manage Copilot agent sessions from anywhere

Developers can now start a Copilot session in VS Code or the CLI, then monitor, steer, and merge from GitHub Mobile or github.com using /remote on. The GA release of remote control — across mobile, web, VS Code, and JetBrains — reinforces GitHub's position as a full-lifecycle, multi-surface agentic platform.

→ Blog: Take your local GitHub sessions anywhere

5. Enterprise model governance: targeted model rules per organization

Enterprise owners can now assign specific Copilot models to specific organizations — moving beyond a single enterprise-wide setting. Paired with a refreshed default model availability interface, this gives large enterprises the governance precision to balance innovation and compliance across divisions.

→ Changelog: Target Copilot models to organizations with model rules
