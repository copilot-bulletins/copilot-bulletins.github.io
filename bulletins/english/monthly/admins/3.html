🏆 Top 5 updates of the month

1. Data Residency and FedRAMP Compliance Now Available in Copilot

GitHub Copilot now supports data residency in the US and EU, keeping inference within your chosen region. FedRAMP Moderate–authorized model infrastructure is available for US government customers. All GA features are supported. Admins opt-in from Copilot settings; data-resident requests carry a 10% premium request multiplier.

→ Changelog: Data residency (US + EU) and FedRAMP-authorized models now available in Copilot

2. A Wave of New Usage Metrics for Copilot Administrators

April saw the largest single expansion of Copilot observability for admins. New usage metrics now cover code review active/passive user counts, Copilot-reviewed PR merge times, cloud agent user tallies, and Copilot CLI activity—all available in the usage metrics API and dashboard.

Sources:
→ Changelog: Copilot code review user counts now aggregate in usage metrics API
→ Changelog: Copilot-reviewed pull request merge metrics now in the usage metrics API
→ Changelog: Copilot usage metrics now aggregate Copilot cloud agent active user counts
→ Changelog: Copilot CLI activity now included in usage metrics totals and feature breakdowns

3. GPT-5.5 Is Now Generally Available — Admin Enablement Required

OpenAI's latest model is now GA in GitHub Copilot for Pro+, Business, and Enterprise. Business and Enterprise admins must explicitly enable the GPT-5.5 policy in Copilot settings. The model targets complex agentic coding tasks and carries a 7.5× premium request multiplier.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

4. Selective Copilot Cloud Agent Rollout via Organization Custom Properties

Enterprise admins can now enable the Copilot cloud agent for specific organizations using custom properties. Three new API endpoints (PUT, POST, DELETE) allow programmatic management of cloud agent policies per organization, giving enterprises fine-grained control for phased rollouts and compliance-based targeting.

→ Changelog: Enable Copilot cloud agent via custom properties

5. Bring Your Own Language Model Key Now Available in VS Code — Enabled by Default

Copilot Business and Enterprise users can now use their own API keys (BYOK) for models from Anthropic, Gemini, OpenAI, and OpenRouter in VS Code. Enabled by default — admins who want to restrict this must disable the BYOK policy in Copilot settings.

→ Changelog: Bring your own language model key in VS Code now available
