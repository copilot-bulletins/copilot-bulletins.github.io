🏆 Top 5 updates of the month

1. AI Credits billing transition: Copilot usage-based billing launches June 1

Starting June 1, Copilot Business and Enterprise shifts to GitHub AI Credits — token-based billing where Business plans include 1,900 credits/user/month and Enterprise 3,900, pooled at the billing entity level. April usage reports, available since May 12, let admins preview projected costs per model and surface before the cutover.

Sources:
→ Changelog: April reports are now available to prepare for usage-based billing
→ Blog: GitHub Copilot is moving to usage-based billing

2. Per-organization model targeting for enterprise governance

Enterprise owners can now create targeted model rules allowing specific Copilot models for individual organizations — replacing the blunt enterprise-wide setting. Tailor model access per team's compliance requirements or cost targets, with a refreshed interface for managing both default availability and targeted exceptions in one view.

→ Changelog: Target Copilot models to organizations with model rules

3. AI adoption cohorts and team-level metrics reshape adoption analytics

The usage metrics API now classifies each engaged user into one of four AI adoption phases — from code-first completions (Phase 1) to multi-agent workflows (Phase 3). Combined with the new team-level user-teams report, admins can slice maturity data by team, IDE, and language to target enablement where it matters most.

Sources:
→ Changelog: Copilot usage metrics API adds cohorts for AI adoption
→ Changelog: Team-level Copilot usage metrics now available via API

4. Centralized governance: enterprise plugins and cloud agent secrets

Enterprise admins can now distribute Copilot CLI plugins, MCP configurations, and custom agents to all users via a central settings.json in .github-private. Separately, cloud agent gained dedicated org-level secrets and variables — isolated from Actions — eliminating per-repo configuration duplication and simplifying large-scale rollouts.

Sources:
→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview
→ Changelog: More flexible secrets and variables for Copilot cloud agent

5. Copilot code review: deeper analytics and agent-powered remediation

The usage metrics API now surfaces code review suggestions broken down by comment type (security, bug risk, etc.), showing adoption rates per category. A new "Fix with Copilot" workflow adds a dialog to select branch, model, and instructions before handing off batched review feedback to the cloud agent for faster resolution.

Sources:
→ Changelog: Copilot code review comment types now in usage metrics API
→ Changelog: Easily apply Copilot code review feedback with Copilot cloud agent
