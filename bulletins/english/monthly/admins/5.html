Monthly #5 · July 2026 · Admins Edition

🎯 This edition's thread

July centered on operational control. GitHub shipped a wave of administration capabilities—richer usage and adoption metrics, enterprise-managed configuration, and finer-grained cost governance—that give admins clearer visibility into how Copilot is adopted and stronger levers to shape it. For teams scaling Copilot across the organization, this month is about measurement, policy, and predictable spend.

⚠️ Heads up

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Action required — These models have been removed across all Copilot experiences. Review your enterprise model availability policies and steer users to supported alternatives.
  • Copilot Billing Preview app will be retired on August 3 — Deadline: August 3, 2026 — Move spend reviews into your built-in billing settings and budget controls.

🚀 Take action

  • Explore the new adoption cohorts and impact metrics in your Copilot usage and adoption dashboards.
  • Standardize configuration at scale with enterprise-managed settings.json, now generally available.
  • Control spend with cost center budgets and usage caps.
  • Tighten model governance through your enterprise policies.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 5 updates of the month

1. Usage and adoption metrics get a major upgrade

Admins gained a new impact dashboard that groups engaged users by AI adoption phase, plus repository-level metrics reaching general availability and broader API coverage. Together these give clearer, more accurate visibility into where Copilot drives value across teams.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: Add review cycles and time to adoption phases in the usage API

2. Enterprise-managed configuration matures

Enterprise-managed settings.json reached general availability, and admins can now deploy managed Copilot settings via MDM across VS Code and CLI. This lets you enforce consistent, compliant configuration on managed devices without relying on individual user setup.

Sources:
→ Changelog: Enterprise managed settings.json is generally available
→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI
→ Changelog: Enterprise managed settings now apply to the GitHub Copilot app

3. Code review and security reviews advance

Copilot code review agent skills and MCP reached general availability, with new customization and configurability options. Security reviews are now available in the Copilot app, and agentic autofix for code scanning alerts entered public preview—strengthening governed, automated quality and security gates.

Sources:
→ Changelog: Copilot code review agent skills and MCP now generally available
→ Changelog: Copilot code review customization and configurability improvements
→ Changelog: Security reviews now available in the GitHub Copilot app

4. Cost governance tools expand

Cost centers now support included usage caps, AI credit pools, and per-user budgets in the billing UI, while end users can see AI credits used per billing cycle. Admins get finer control over spend allocation and clearer forecasting as Copilot usage scales.

Sources:
→ Changelog: Cost centers now support included usage caps
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI

5. Model governance controls for enterprises

Enterprises can now default to auto model selection, enable default models for Business and Enterprise, and target model policies to specific teams. These controls let admins balance capability, cost, and compliance without managing model access user by user.

Sources:
→ Changelog: Enterprises can default to auto model selection
→ Changelog: Default model enablement for Copilot Business and Enterprise
→ Changelog: Enterprise teams model policy targeting in public preview
