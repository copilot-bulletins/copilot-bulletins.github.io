🏆 Top 5 updates of the month

1. Copilot is now included with GitHub Enterprise

Enterprises working with an account team can get Copilot for every GitHub Enterprise licensed user. Seat counting gives way to usage metered against the enterprise budget. Completions keep working when budget runs out; Chat, code review and cloud agents require available budget.

→ Changelog: GitHub Enterprise now includes access to GitHub Copilot

2. Policy as code for models, features and plugins

Model policies are now manageable via REST at enterprise, team, app and org levels. The global default for new features is enforced on unconfigured settings, and enterprises can require, block or restrict plugins to approved marketplaces.

Sources:
→ Changelog: Copilot model policy API for enterprise, orgs, and teams
→ Changelog: Global default for Copilot features generally available
→ Changelog: Repository plugin defaults and enterprise plugin controls generally available

3. Stronger guardrails for local agents

Local sandboxing is GA, restricting filesystem, network and credential access for agent-run commands. Admins can force clients to refresh managed settings at startup, enforce minimum client versions, and control the new assisted permissions mode.

Sources:
→ Changelog: Local sandboxing for GitHub Copilot now generally available
→ Changelog: Enterprise managed settings enforcement updates
→ Changelog: GitHub Copilot assisted permissions generally available

4. Deeper usage metrics and peer benchmarks

The usage metrics API now names your custom skills, agents and MCP servers, and reports traffic from tools like OpenCode and Claude Code. An opt-in industry comparison benchmarks your agentic adoption against peers by size and sector.

Sources:
→ Changelog: Custom skills, agents, and MCP servers in usage metrics API
→ Changelog: Usage metrics API adds usage from tools like OpenCode
→ Changelog: Industry comparisons in the Copilot impact dashboard

5. Copilot code review: billing controls and approvals

Org owners can bill code reviews to the organization instead of member quotas and restrict review requests to org-issued licenses. Copilot approvals are now GA, and a multi-model Max effort level is in public preview.

Sources:
→ Changelog: Copilot code review: New organization billing options and controls
→ Changelog: Copilot code review: Merge with confidence with Max and approvals
