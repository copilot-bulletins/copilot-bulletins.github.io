Monthly (Long) #4 · July 2026 · Devs Edition

🎯 This edition's thread

July was about choice and autonomy for developers. Copilot's model catalog widened dramatically—frontier releases from Anthropic, OpenAI, Google, xAI, and Moonshot now sit side by side, with auto-selection routing each task to the right one. In parallel, agents matured across the CLI, IDEs, and code review, while vision and browser tooling went generally available. The practical takeaway: you have more ways to delegate real work and match the right model and agent to each task, without leaving your editor.

⚠️ Heads up

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Deadline: July 31, 2026 — Both models are now removed across all Copilot experiences. Switch any pinned configs to a supported model in your Copilot settings.

🚀 Take action

  • Explore the expanded model lineup and pick the best fit per task in your model settings.
  • Try agentic workflows in your terminal with the Copilot CLI.
  • Enable Copilot code review with agent skills and MCP on your pull requests.
  • Extend agents with custom tools using MCP servers.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 8 updates of the month

1. A frontier-model catalog, now with auto selection

Copilot's model choice exploded in July: Claude Opus 5, Grok 4.5, GPT-5.6 (Sol, Terra, Luna), Gemini 3.6 Flash, and Kimi K2.7 Code all landed. Auto model selection can route each task to the best fit, so you optimize for reasoning, speed, or cost without manual switching.

2. Copilot vision is generally available

Copilot vision reaches general availability, letting you drop screenshots, mockups, and diagrams directly into chat. Turn a UI design into markup, debug from an error screenshot, or explain an architecture diagram—multimodal context is now a first-class part of your workflow.

→ Changelog: Copilot vision is generally available

3. Copilot CLI grows up: auto routing, no-PAT Actions, session limits

The terminal agent got a strong month. Auto model selection routes based on task, a new C++ language server skill improves navigation, AI credit session limits add cost control, and the CLI no longer needs a personal access token in GitHub Actions—simplifying CI automation.

4. Copilot code review: agent skills and MCP now GA

Copilot code review now supports agent skills and MCP in general availability, plus customization and configurability improvements. Reviews can tap custom tools and repository context, giving you more relevant, tailored feedback directly on your pull requests.
