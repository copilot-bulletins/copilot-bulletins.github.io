Monthly (Long) #1 · May 2026 · Devs Edition

🎯 This edition's thread

May brought a decisive shift toward agentic development. A new GitHub-native desktop app, one-click CI repair, and cross-surface CLI session control point to Copilot becoming a true asynchronous collaborator — not just a reactive assistant. The signals are consistent: agentic work is moving out of the IDE and into every surface developers already use.

The model layer also matured. A new base model with long-term stability guarantees gives enterprise teams a foundation they can count on, while auto-routing intelligence takes model selection off your plate — matching each task to the right model automatically.

⚠️ Heads up

  • Upcoming deprecation of GPT-4.1 — Deadline: June 1, 2026 — Migrate all workflows and integrations to GPT-5.5 immediately. See supported models and alternatives.
  • Upcoming deprecation of GPT-5.2 and GPT-5.2-Codex — Deadline: June 5, 2026 — Migrate to GPT-5.5 (for GPT-5.2) and GPT-5.3-Codex (for GPT-5.2-Codex). Note: GPT-5.2-Codex in Copilot Code Review is not affected. See supported models.

🚀 Take action

  • Sign up for the GitHub Copilot app technical preview and start your first agentic session from an issue or pull request
  • Switch to Auto in VS Code Copilot Chat for intelligent task-based model routing with a 10% multiplier discount
  • Enable remote control for Copilot CLI sessions to monitor and steer long-running tasks from your phone or browser
  • Migrate integrations off GPT-4.1 (deprecated June 1) and GPT-5.2/GPT-5.2-Codex (June 5) to supported alternatives

🏆 Top 8 updates of the month

1. GitHub Copilot app: A GitHub-native desktop for agentic development

A GitHub-native desktop app for agentic development, now in technical preview. Start sessions from issues or pull requests with full task isolation, steer the agent, validate via integrated terminal and browser, and ship through PR review with Agent Merge.

→ Changelog: GitHub Copilot app is now available in technical preview

2. GPT-5.3-Codex: New base model and first LTS for Copilot Business/Enterprise

Replaced GPT-4.1 as the default model for Copilot Business and Enterprise on May 17. It's GitHub's first long-term support (LTS) model — guaranteed available through February 2027 — giving enterprise teams a stable foundation for internal security and compliance reviews.

→ Changelog: GPT-5.3-Codex is now the base model for Copilot Business and Enterprise

3. VS Code April releases: Smarter context, BYOK, and agent superpowers

Semantic indexing now works in all workspaces and agents can grep across GitHub repos. BYOK extends to Copilot Business and Enterprise users in VS Code. Agents gain read/write terminal access, live browser tab sharing, and /chronicle to query past chat sessions.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

4. Remote control for Copilot CLI sessions is now generally available

Start a Copilot CLI session in your terminal, VS Code, or JetBrains, then monitor and steer it from GitHub Mobile or the web. Now generally available — including support for non-GitHub repositories — making cross-device agentic workflows the default.

→ Changelog: Remote control for Copilot CLI sessions now generally available on mobile, web, and VS Code

5. One-click CI fixes with Copilot cloud agent

When a GitHub Actions job fails, click "Fix with Copilot" on the run logs page. The cloud agent investigates in its own environment, pushes a fix to your branch, and tags you for review — taking time-consuming CI triage off your hands.

→ Changelog: One-click fixes for failing Actions with Copilot cloud agent

6. Auto model selection now routes by task complexity in VS Code

Auto mode in VS Code now evaluates reasoning complexity, code generation needs, and tool orchestration per task to route to the optimal model. Paid subscribers get a 10% discount on the model multiplier when using Auto. No setup required.

→ Changelog: Auto model selection now routes based on your task in VS Code

7. JetBrains: Copilot CLI agent arrives with unified sessions view

JetBrains IDEs gain the Copilot CLI agent in public preview, with worktree or workspace isolation modes and a unified sessions panel to track all running tasks. A new Ask question tool lets agents clarify ambiguity mid-task.

→ Changelog: Introducing Copilot CLI agent and unified sessions view in GitHub Copilot for JetBrains IDEs

8. New frontier models: Claude Opus 4.8 and Gemini 3.5 Flash now GA

Anthropic's Claude Opus 4.8 brings improved code understanding and large-codebase navigation to Copilot Pro+, Business, and Enterprise. Google's Gemini 3.5 Flash delivers near-Pro quality at Flash speed with strong tool use — ideal for fast, iterative agentic workflows.

Sources:
→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot
→ Changelog: Gemini 3.5 Flash is generally available for GitHub Copilot

📌 Also this month

  • Enterprise-managed plugins in GitHub Copilot CLI are now in public preview — Admins can configure and distribute plugins, custom agents, and MCP configurations to all CLI users across the enterprise from a single settings.json.
  • GitHub Copilot for Eclipse is open source — The full Eclipse plugin is now MIT-licensed on GitHub, opening code completion, agent mode, MCP integration, and more to community contributions.
  • Copilot cloud agent: fast, cost-efficient models for simple tasks — Claude Haiku 4.5 and GPT-5.4-mini (both at 0.33x multiplier) are now available for cloud agent tasks — use lighter models for straightforward changes.
  • Semantic issue search in Copilot Chat — Find GitHub issues using natural language in Copilot Chat on web, even without remembering exact keywords or titles.
  • Copilot Spaces API now generally available — Programmatically create, read, update, and delete Spaces to manage shared context at scale from your own applications.
  • Copilot Memory has more controls for deletion, scope, and the Copilot CLI — New /memory CLI commands, a repository-level off switch, and clearer scope labels at memory capture time.
