🏆 Top 8 updates of the month

1. GPT-5.5 and Claude Opus 4.7 join Copilot

Two frontier models arrive in April. GPT-5.5 excels at complex multi-step agentic tasks; Claude Opus 4.7 brings stronger long-horizon reasoning, gradually replacing Opus 4.5 and 4.6 for Pro+ users. Both launch across all major IDEs and the CLI with a 7.5× premium request multiplier.

Sources:
→ Changelog: GPT-5.5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.7 is generally available

2. Research, plan, and code with Copilot Cloud Agent

Copilot cloud agent breaks out of PR-only workflows. Ask for an implementation plan before coding begins, run deep codebase research, or work on a branch without opening a PR. Review the full diff first, iterate with Copilot, and create a pull request when you're ready.

→ Changelog: Research, plan and code with Copilot cloud agent

3. Copilot CLI: BYOK and local model support

Copilot CLI now connects to any OpenAI-compatible endpoint, Azure OpenAI, or Anthropic — plus locally running models like Ollama and vLLM. Set COPILOT_OFFLINE=true for fully air-gapped workflows. GitHub authentication is now optional when using your own model provider.

→ Changelog: Copilot CLI now supports BYOK and local models

4. Remote control: steer CLI sessions from web or mobile

copilot --remote streams your CLI session to GitHub in real time, letting you monitor progress, send follow-up messages, and respond to prompts from any browser or the GitHub Mobile app — all while the session runs on your local machine.

→ Changelog: Remote control CLI sessions on web and mobile in public preview

5. VS Code March releases: Autopilot, nested subagents, and more

Five VS Code releases (v1.111–v1.115) shipped Autopilot mode for fully autonomous agent sessions, nested subagents that can invoke other subagents, integrated browser debugging, image and video support in chat, and a unified customizations editor with MCP marketplace browsing.

→ Changelog: GitHub Copilot in Visual Studio Code – March releases

6. IDE upgrades: Visual Studio April and JetBrains inline agent mode

Visual Studio April adds cloud agent sessions directly from the IDE and a debugger agent that validates bug fixes against live runtime behavior. JetBrains gains inline agent mode in public preview — agent power right in the editor — plus enhanced Next Edit Suggestions with inline previews and far-away edit navigation.

Sources:
→ Changelog: GitHub Copilot in Visual Studio – April update
→ Changelog: Inline agent mode in preview and more in GitHub Copilot for JetBrains IDEs

7. BYOK in VS Code and C++ semantic intelligence for the CLI

Business and Enterprise users can now connect their own LLM API keys (Anthropic, Gemini, OpenAI, Ollama...) in VS Code Chat — billed by your provider, not Copilot quotas. The Microsoft C++ Language Server also enters public preview for Copilot CLI, delivering precise semantic analysis for complex C++ codebases.

Sources:
→ Changelog: Bring your own language model key in VS Code now available
→ Changelog: C++ code intelligence for GitHub Copilot CLI in public preview

8. Copilot CLI: auto model selection GA and enterprise MCP governance

Auto model selection is now GA in Copilot CLI — Copilot picks the most efficient available model with a 10% premium request discount. Enterprise and org admins can also enforce custom registry-based MCP allowlists in the CLI, extending governance controls to terminal-based agentic workflows.

Sources:
→ Changelog: GitHub Copilot CLI now supports Copilot auto model selection
→ Changelog: Copilot CLI supports custom registry-based MCP allowlists
