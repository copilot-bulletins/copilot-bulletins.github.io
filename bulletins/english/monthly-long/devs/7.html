Monthly (Long) #7 · October 2026 · Devs Edition

🎯 This edition's thread

October was shaped by GitHub Universe, and the message for developers is that Copilot is becoming a connected agent platform rather than a set of separate tools. Sessions now follow you across the editor, CLI, app, web and mobile, backed by cloud sandboxes and persistent memory.

Model choice is moving to the platform too: Copilot Fusion routes work across models for you, while new local options and sandboxes give you more control on your own machine. Automations, Agent Merge and stronger code review take on more of the routine work.

⚠️ Heads up

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Deadline: November 16, 2026 — Claude Opus 4.8, Claude Opus 5 and GPT-5.6 Terra are being retired. Move prompts, agents and integrations to a supported model.
  • GitHub Copilot models deprecated on October 19, 2026 — Action required — GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, Gemini 3.7 Flash and Grok 4.5 are no longer available. Update any workflows that still reference them.

🚀 Take action

  • Pick Copilot Fusion in the model picker and choose an effort level. See About GitHub Copilot Fusion.
  • Tell Copilot your preferences once and let Copilot Memory reuse them across sessions and clients.
  • Try the Max effort level on your riskiest pull requests with Copilot code review.
  • Connect Slack, Figma or Sentry once and reuse them everywhere. Start with Model Context Protocol (MCP) in Copilot.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 8 updates of the month

1. Copilot Fusion picks and combines models for you

Copilot Fusion is now generally available. It replaces the Auto option: you choose an effort level (Standard, High or Max) and Copilot decides which models to use. It can use one model, escalate to a stronger one, or have a second model critique the first. It is also available in JetBrains.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot in JetBrains Universe releases

2. One cloud session across every Copilot surface

Start a task on github.com, GitHub Mobile, the CLI, the Copilot app, VS Code, Slack or Teams, then continue the same session anywhere. Sessions run in cloud sandboxes, which are now generally available. They start fast, have no one-hour cap, and keep a snapshot so you can resume later.

Sources:
→ Changelog: Work from anywhere with a new, connected Copilot cloud experience
→ Changelog: GitHub Copilot in VS Code, Universe releases

3. Copilot Memory remembers how you and your team work

Copilot Memory is generally available on paid plans. It keeps your personal preferences and repository conventions, such as the right test command, across the app, CLI, VS Code, cloud agent and code review. Dreaming (public preview) reviews past sessions to keep that context up to date.

→ Changelog: GitHub intelligence puts your code, context, and history to work

4. Copilot Automations become team workflows

You can now share automations with your team. They also gain API and chained triggers, 20 new GitHub tools, custom MCP tools and limits on AI credit spend. Automations can suggest improvements to their own prompts based on real outcomes. In VS Code, you can create cloud automations that keep running after you close the editor.

Sources:

5. From review to merge: Max reviews, approvals and Agent Merge

Copilot code review has a new Max effort level (public preview) that combines review agents built on models from different providers. Copilot approvals are now GA and count toward required approvals. On GitHub.com, Agent Merge can now fix failing Actions workflows and merge conflicts in the cloud until your pull request is ready to merge.

Sources:
→ Changelog: Copilot code review: Merge with confidence with Max and approvals
→ Changelog: Agent Merge watches and fixes pull requests in the cloud

6. Local agents: sandboxes, local models and computer use

Local sandboxing is now GA in the CLI, the Copilot app and VS Code. It limits the files, network and credentials that agent commands can access. The CLI can find local models running in Ollama, and Fusion can route to on-device models (experimental). With computer use (preview), Copilot can operate desktop apps.

Sources:

7. Connectors bring your tools to Copilot with one sign-in

GitHub-verified MCP servers, called connectors, are in public preview. Sign in to a service such as Slack, Figma or Sentry once. That connection then works in the Copilot app, CLI, VS Code and Copilot in the cloud, with no local server to install and no credentials to manage yourself.

→ Changelog: Connect your tools to Copilot without all the setup

8. New models: GPT-6.1 Terra, Gemini 4 Argon and Claude Haiku 5.5

Three new models are now generally available. GPT-6.1 Terra is a lower-cost model for everyday agentic and terminal work. Gemini 4 Argon is built for complex coding and reasoning. Claude Haiku 5.5 is fast and well suited to subagents and quick edits.
