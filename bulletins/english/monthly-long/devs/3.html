Monthly (Long) #3 · June 2026 · Devs Edition

🎯 This edition's thread

June turned agentic development into a place you go, not just a feature you invoke. Copilot's agent gained a dedicated desktop home, a redesigned terminal, and first-class seats inside the IDEs you already use — all reachable from one account.

Underneath, the model layer widened and grew smarter about itself: larger context, configurable reasoning, and routing that picks the model for you. The throughline is consolidation — surfaces, models, and automation primitives settling into one coherent, programmable platform you can build on.

⚠️ Heads up

  • Upcoming deprecation of Opus 4.6 (fast) — Deadline: June 29, 2026 — Opus 4.6 (fast) is retired across all Copilot experiences; switch to Opus 4.8 (fast). Confirm availability in the supported models reference.
  • GPT-4.1 deprecated — Action required — GPT-4.1 is retired across all Copilot experiences; migrate workflows and integrations to GPT-5.5.
  • GPT-5.2 and GPT-5.2-Codex deprecated — Action required — Both are retired (GPT-5.2 remains only in Copilot code review); switch to GPT-5.5 and GPT-5.3-Codex.

🚀 Take action

  • Download the GitHub Copilot app for macOS, Windows, or Linux — now generally available — and run parallel agent sessions from your desktop.
  • Update Copilot CLI (copilot update), explore the new tabbed terminal interface, and run /security-review on your changes — see the Copilot CLI docs.
  • Turn on Auto model selection in Copilot Chat to let Copilot route each request to the right model automatically.
  • Migrate any workflows off Opus 4.6 (fast), GPT-4.1, and GPT-5.2 to supported models.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 8 updates of the month

1. The GitHub Copilot app is now generally available

The desktop home for agent-driven development reached GA for macOS, Windows, and Linux. Start sessions from an issue, PR, or prompt, run parallel agents on isolated worktrees, and validate in the built-in terminal and browser. BYOK now lets each session use your own model via MCP.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Changelog: GitHub Copilot app support for BYOK

2. A new wave of models lands in Copilot

Claude Sonnet 5 reached GA with strong CLI-style coding performance, Claude Opus 4.8 (fast mode) entered preview for faster interactive and agentic work, and Microsoft's purpose-built MAI-Code-1-Flash arrived for lightweight tasks — expanding your model options across the IDE and CLI.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: MAI-Code-1-Flash is now available for GitHub Copilot

3. The Copilot CLI grows up

A big month for the terminal: the redesigned interface previewed at Build 2026 hit GA with tabs for sessions, issues, PRs, and gists; a new /security-review command scans changes across 11 vulnerability categories; and /settings unifies all configuration into one schema-validated surface.

Sources:
→ Changelog: Copilot CLI: New terminal interface is generally available
→ Changelog: Dedicated security review command now available in Copilot CLI
→ Changelog: Copilot CLI: Configure everything from one place with /settings

4. One-million-token context, configurable reasoning, and Auto for all

Copilot now supports one-million-token context windows in VS Code, the CLI, and the Copilot app for working across large, multi-file codebases, plus configurable reasoning levels to trade speed for depth. Auto model selection also went GA for every plan in Copilot Chat.

Sources:
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot
→ Changelog: Auto mode in Copilot Chat available for all users

5. Visual Studio Code goes agent-first

VS Code's May releases (v1.120–v1.123) brought the Agents window to Stable as a preview — an agent-first surface for completing tasks across multiple projects — alongside better remote control of long-running sessions, BYOK for air-gapped environments, and per-task utility model selection.

→ Changelog: GitHub Copilot in Visual Studio Code, May releases

6. JetBrains gets deeper agentic integration

JetBrains IDEs gained org and enterprise custom agents, steerable CLI sessions, and Claude as an agent provider in public preview. Copilot also became a first-class option in the JetBrains AI Assistant agent picker, with model and reasoning-depth selection in AI chat.

Sources:
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant

7. Build your own agents: Agentic Workflows, SDK, and agent tasks API

GitHub Agentic Workflows entered public preview, letting you automate triage, CI analysis, and docs as Markdown that compiles to Actions YAML. The Copilot SDK reached GA in six languages, and a new agent tasks REST API arrived for Pro, Pro+, and Max.

Sources:
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Copilot SDK is now generally available
→ Changelog: Agent tasks REST API now available for Copilot Pro, Pro+, and Max

8. Copilot Chat becomes agent-aware

Chat on the web now tracks your in-progress cloud agent sessions and can pull session logs to explain what changed and why. Session search summarizes past agent work by topic or recency, and /chronicle surfaces insights across sessions for continuity.

Sources:
→ Changelog: Copilot Chat now sees your agent sessions
→ Changelog: Gain insights across your agent sessions with /chronicle
