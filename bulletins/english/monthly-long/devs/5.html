Monthly (Long) #5 · August 2026 · Devs Edition

🎯 This edition's thread

August was about portability and control for developers. A new open plugin standard let you build agent capabilities once and run them everywhere, while a wave of fresh models landed across every surface. Your favorite IDEs — VS Code, JetBrains, Visual Studio — all matured their agentic workflows, and cloud agent gained finer-grained tuning through reasoning levels and comment-triggered automations. The throughline: fewer silos, more consistent behavior, and knobs to match effort and cost to the task in front of you.

⚠️ Heads up

  • Upcoming deprecation of MAI-Code-1-Flash — Deadline: September 10, 2026 — Migrate workflows and integrations to MAI-Code-1.1-Flash; confirm it's enabled in your model settings.
  • Upcoming deprecation of GitHub Spark on github.com — Deadline: August 31, 2026 — New apps are disabled; export any existing apps before Spark retires. Deployed apps keep running.

🚀 Take action

  • Build once, run everywhere: package your skills and MCP servers as an Agent Plugin across compatible clients.
  • Tune complex delegations by setting a reasoning level for cloud agent when you start a task.
  • Automate repetitive follow-ups by creating comment-triggered automations on issues and pull requests.
  • Try the newest models by switching your chat model — see the supported models reference.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 8 updates of the month

1. Agent Plugins 1.0: build once, run across every client

Agent Plugins 1.0 is an open standard that packages agent skills and MCP servers so you build once and use everywhere — VS Code, Copilot CLI, and the Copilot app. Launched with AWS, Anysphere, Microsoft, OpenAI, and Vercel, with Google joining as a core maintainer.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

2. A fresh wave of models

Four new models arrived this month across Copilot surfaces, giving you more choice for speed, reasoning, and cost. Enterprise admins may need to enable them via model policies before they appear in your picker.

Sources:
→ Changelog: Kimi K3 is now available in GitHub Copilot
→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot
→ Changelog: Grok 4.6 is now available in GitHub Copilot
→ Changelog: MAI-Code-1.1-Flash available in GitHub Copilot

3. JetBrains levels up: memory, local models, and Harness GA

Copilot for JetBrains gained persistent memory, local model access via Ollama, and more enterprise controls — then made the Copilot harness generally available for faster feature delivery and better code quality, plus built-in JetBrains MCP server support.

Sources:
→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains
→ Changelog: Copilot harness generally available in Copilot for JetBrains

4. VS Code August releases (v1.132–v1.135)

Four VS Code releases shipped through August, making it easier to organize agent sessions, review changes, and navigate long conversations. Agent Host, the integrated browser, and dictation all got meaningful updates.

→ Changelog: GitHub Copilot in VS Code August 2026 releases

5. Copilot code review keeps investing

Effort levels went generally available — Lite and Balanced replace Low and Medium, selectable per review or as org defaults. Reviews now cover bot-authored and very large PRs, plus comment resolution reasons for clearer feedback loops.

Sources:
→ Changelog: Copilot code review effort levels are generally available
→ Changelog: Copilot code review resolution reasons and expanded capabilities

6. Cloud agent gets tunable and event-driven

You can now set a reasoning level when delegating tasks to cloud agent, trading tokens for deeper thinking on hard problems. And automations can now trigger on issue or PR comments — generate docs, investigate errors, or spin up follow-up tasks automatically.

Sources:
→ Changelog: Customize the reasoning level for Copilot cloud agent
→ Changelog: Trigger Copilot automations with comments

7. Copilot comes to Slack and Teams

The GitHub integration in Slack now brings Copilot CLI and Copilot app agentic capabilities into your channels in public preview, with multiplayer collaboration. Shared agentic work also arrived for Microsoft Teams.

Sources:
→ Changelog: The new GitHub Copilot experience in Slack
→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams

8. Copilot on web expands conversation controls

Copilot Chat on github.com now lets you minimize and resume in-progress conversations, jump back into recent threads, and monitor token usage directly — small ergonomics that add up across a busy day.

→ Changelog: Copilot on web expands conversation controls
