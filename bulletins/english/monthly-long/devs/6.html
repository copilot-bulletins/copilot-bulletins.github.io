Monthly (Long) #6 · September 2026 · Devs Edition

🎯 This edition's thread

September was a model-and-agent month for developers. GitHub Copilot expanded its model lineup across every vendor while sharpening the agentic surfaces where you spend your day: the Copilot CLI, VS Code, JetBrains, and code review. The through-line is choice plus guardrails — more models and orchestration via HydraFusion, paired with local sandboxing, content exclusions, and smarter autofix. For devs, that means faster iteration on large codebases and more autonomy, without giving up control over what the agent can touch.

⚠️ Heads up

  • Upcoming deprecation of selected models in mid-October — Deadline: October 19, 2026 — Several models will be removed across all Copilot experiences. Move workflows and integrations to supported AI models before this date.
  • MAI-Code-1-Flash deprecated — Action required — The model was removed on September 10. Switch to a supported model in your Copilot settings.

🚀 Take action

  • Browse and enable the latest supported AI models in your Copilot settings to try GPT-6, Claude Opus 5.5, and more.

  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 8 updates of the month

1. A new wave of frontier models lands in Copilot

September brought one of the biggest model expansions yet: OpenAI's GPT-6 Astra, GPT-6 Sol/Luna, and GPT-6.1 Sol, plus Claude Opus 5.5, Claude Sonnet 5.5, and Claude Fable 5.1, Gemini 3.8 Flash, and Grok 4.7. More choice means better fit for long-horizon, agentic coding tasks.

→ Changelog: Claude Opus 5.5 is now available in GitHub Copilot
→ Changelog: Claude Sonnet 5.5 in GitHub Copilot
→ Changelog: Grok 4.7 is now available in GitHub Copilot

2. HydraFusion comes to VS Code and the Copilot app

The HydraFusion research preview expanded beyond the CLI into VS Code and the Copilot app. Rather than a single model, it orchestrates multiple models — selecting the most efficient workflow for reasoning, code generation, debugging, and tool use to hit the quality bar.

→ Changelog: HydraFusion in VS Code and the GitHub Copilot app

3. Copilot code review gets smarter and more configurable

Copilot code review can now flag when a PR is ready to approve (and sign off, if admins allow), auto-resolves its own suggestions more intelligently, generates commit messages for batched suggestions, and offers more ways to request and configure reviews across more plans.

Sources:
→ Changelog: Copilot code review can now approve pull requests
→ Changelog: Copilot code review, an improved review experience
→ Changelog: Copilot code review, more ways to request and configure reviews

4. Local sandboxing in the Copilot app

Local sandboxing limits an agent's access to files, network, and credentials on your machine, reducing the blast radius of unintended commands. You configure it per project for local repository and working-tree sessions — autonomy with a safety net.

→ Changelog: Local sandboxing in the GitHub Copilot app

5. Content exclusions reach the Copilot app and CLI

The Copilot app and Copilot CLI now respect content exclusion policies set by enterprise, organization, and repository admins. Your secrets and sensitive paths stay out of agentic sessions, closing a gap between IDE and terminal workflows.

→ Changelog: Content exclusions generally available in Copilot app and CLI

6. Faster C++ code intelligence with whole-codebase indexing

C++ code intelligence in the Copilot CLI is now faster thanks to whole-codebase indexing. Instead of rediscovering project structure as you navigate millions of lines across headers and sources, a reusable index speeds up finding definitions and references.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

7. Copilot for JetBrains 1.18.0

JetBrains 1.18.0 adds assisted approvals (auto-approve low-risk tool calls, prompt on higher-risk ones), more control over agent conversations, shared org skills and instructions, plan review with the Codex agent, and persistent MCP tool controls.

→ Changelog: New features and improvements in Copilot for JetBrains

8. Agentic autofix now uses Copilot Memory

When enabled, agentic autofix reviews existing memories for context to resolve security alerts and stores successful fix patterns as new memories. Over time it learns your repository's secure-development patterns and shares them with other Copilot features.

→ Changelog: Agentic autofix now uses Copilot Memory
