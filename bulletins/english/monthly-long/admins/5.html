Monthly (Long) #5 · July 2026 · Admins Edition

🎯 This edition's thread

July was a governance and visibility month for Copilot administrators. GitHub deepened usage and adoption metrics, expanded enterprise-managed settings across more clients, and gave finance teams finer cost controls through AI credit pools and per-user budgets. Security moved left with in-app security reviews and agentic autofix, while model governance matured with default enablement and policy targeting. The through-line: more precise levers to measure impact, enforce standards, and control spend as agentic Copilot scales across your organization.

⚠️ Heads up

  • Gemini 2.5 Pro and Gemini 3 Flash deprecated — Deadline: July 31, 2026 — These models are removed across all Copilot experiences. Enable Gemini 3.1 Pro and Gemini 3.6 Flash as alternatives through your model policies.
  • Copilot Billing Preview app will be retired on August 3 — Deadline: August 3, 2026 — Move to your GitHub billing settings for richer spend visibility, including budgets and cost centers.

🚀 Take action

  • Explore adoption depth with the new metrics dashboard and Copilot usage metrics.
  • Standardize AI governance across clients by configuring enterprise-managed settings.
  • Roll out consistent quality gates by enabling Copilot code review.
  • Control costs with cost centers and budgets for usage-based billing.
  • Questions or need support? Reach out to your GitHub team, we're here to help.

🏆 Top 8 updates of the month

1. Deeper usage and adoption insights

Copilot metrics matured significantly: repository-level breakdowns, a new impact dashboard showing adoption depth, expanded report rollups, and adoption-phase data in the API. Admins can now tell a richer impact story and target enablement where it counts.

Sources:
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: GitHub Copilot app usage metrics now expand across report rollups
→ Changelog: Add review cycles and time to adoption phases in the usage API

2. Enterprise governance and managed settings

Enterprise managed-settings.json reached GA and now applies to the Copilot app and cloud agent, with MDM deployment for VS Code and CLI. A dedicated policy governs Copilot app access, giving you centralized, enforceable AI standards.

Sources:
→ Changelog: Enterprise managed-settings.json is generally available
→ Changelog: Enterprise managed settings now apply to the GitHub Copilot app
→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI
→ Changelog: Manage GitHub Copilot app access with a dedicated policy

3. Finer cost control with AI credits

Finance and platform teams gained precise spend levers: AI credit pools for cost centers now manageable in the billing UI, per-user budgets, per-cycle credit visibility for users, and session limits in the CLI and SDK.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: Copilot users can now see AI credits used per billing cycle
→ Changelog: Set AI credit session limits in Copilot CLI and SDK

4. Copilot code review at enterprise scale

Agent skills and MCP support for Copilot code review are now generally available, alongside customization and configurability improvements. Teams can embed internal standards, tools, and external context directly into every automated review.

Sources:
→ Changelog: Copilot code review: Agent skills and MCP now generally available
→ Changelog: Copilot code review: Customization and configurability improvements

5. Security shifts left

Security reviews are now available in the GitHub Copilot app via the /security-review command, and agentic autofix for code scanning alerts entered public preview. Vulnerabilities surface and resolve earlier in the developer workflow.

Sources:
→ Changelog: Security reviews now available in the GitHub Copilot app
→ Changelog: Agentic autofix for code scanning alerts in public preview

6. Model governance controls

Model management tightened for administrators: default model enablement for Business and Enterprise, the option to default enterprises to auto model selection, and enterprise teams model policy targeting in public preview for team-level precision.

Sources:
→ Changelog: Default model enablement for Copilot Business and Enterprise
→ Changelog: Enterprises can default to auto model selection
→ Changelog: Enterprise teams model policy targeting in public preview

7. Enterprise-managed observability

Enterprise-managed OpenTelemetry export arrived for VS Code and CLI, and JetBrains added improved OpenTelemetry configuration. Admins can centrally route Copilot telemetry into existing monitoring stacks for compliance and audit needs.

Sources:
→ Changelog: Enterprise-managed OpenTelemetry export for VS Code and CLI
→ Changelog: GitHub Copilot for JetBrains adds improved OpenTelemetry configuration and model management

8. GitHub Copilot app available to all

The standalone GitHub Copilot app is now available to everyone. Combined with enterprise-managed settings and the dedicated access policy, admins can roll it out with governance guardrails already in place.

→ Changelog: GitHub Copilot app available to all
