🏆 Top 8 updates of the month

1. Regional Data Residency and FedRAMP Compliance Now Available

Copilot now keeps all inference and associated data within your designated US or EU region, with FedRAMP Moderate compliance for US government customers. Enterprise and org admins opt in from Copilot settings — all GA features are supported. A 10% model-multiplier surcharge applies for data-resident and FedRAMP-certified requests.

→ Changelog: Copilot data residency in US + EU and FedRAMP compliance now available

2. Centralized Firewall and Runner Controls for Copilot Cloud Agent

Organization admins can now govern the cloud agent's network firewall and Actions runner type from a single org-level policy — replacing fragmented per-repo configurations. Toggle the firewall, manage custom allowlists, restrict per-repo overrides, and lock runner types to ensure agent sessions always run on approved infrastructure.

Sources:
→ Changelog: Organization firewall settings for Copilot cloud agent
→ Changelog: Organization runner controls for Copilot cloud agent

3. Usage Metrics Now Cover Every Copilot Surface

April delivers a complete adoption telemetry picture for the first time. Metrics now distinguish active from passive code review engagement, track merged PRs and median time-to-merge for code review, integrate CLI contributions into top-level totals, and report daily/weekly/monthly active users for the cloud agent — all queryable via the usage metrics API.

Sources:
→ Changelog: Copilot usage metrics now identify active and passive Copilot code review users
→ Changelog: Copilot-reviewed pull request merge metrics now in the usage metrics API
→ Changelog: Copilot CLI activity now included in usage metrics totals and feature breakdowns
→ Changelog: Copilot usage metrics now aggregate Copilot cloud agent active user counts

4. Copilot Organization Custom Instructions Reach General Availability

Organization admins can now set default Copilot Chat, code review, and cloud agent instructions across all repositories — moving from preview to GA. This provides a stable, supported mechanism for enforcing coding standards, security policies, and communication tone uniformly across your entire organization.

→ Changelog: Copilot organization custom instructions are generally available

5. Cloud Agent Can Now Research, Plan, and Code Before Opening a PR

The cloud agent expands beyond PR-centric workflows. Teams can use it for deep codebase research, implementation planning, and branch-level coding without a pull request — reviewing the full diff and iterating before any PR is created. This reduces review queue noise while enabling more autonomous, structured development workflows.

→ Changelog: Research, plan and code with Copilot cloud agent

6. Cloud Agent: Signed Commits and 20% Faster Startup

Cloud agent commits now display as "Verified," enabling compatibility with signed-commit branch protection rules — a key requirement for security-sensitive repositories. Separately, startup time drops another 20% (building on March's 50% improvement) via prebuilt Actions custom images, reducing time-to-first-action for every agent session.

Sources:
→ Changelog: Copilot cloud agent signs its commits
→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images

7. Copilot CLI: MCP Allowlists and Auto Model Selection

Enterprise and org admins can now enforce custom registry-based MCP server allowlists in the Copilot CLI, extending governance controls to terminal-based agentic workflows. Auto model selection simultaneously reaches GA in the CLI — routing requests to the most efficient available model with a 10% premium discount and full model transparency.

Sources:
→ Changelog: Copilot CLI supports custom registry-based MCP allowlists
→ Changelog: GitHub Copilot CLI now supports Copilot auto model selection

8. New Frontier Models Require Admin Enablement: GPT-5.5 and Claude Opus 4.7

Two powerful models became generally available in April. GPT-5.5 excels at complex multi-step agentic tasks; Claude Opus 4.7 delivers stronger long-horizon reasoning. Both carry a 7.5× premium multiplier. For Copilot Business and Enterprise, admins must explicitly enable each model in organization Copilot settings before users can select them in the picker.
