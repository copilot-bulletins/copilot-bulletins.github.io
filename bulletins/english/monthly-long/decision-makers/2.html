🏆 Top 7 updates of the month

1. Copilot transitions to usage-based billing starting June 1

Starting June 1, premium request units are replaced by GitHub AI Credits across all Copilot plans. For Business and Enterprise, credits are pooled organization-wide — power users can draw more without penalizing lighter users. Plan prices don't change, and a 3-month promotional credit increase eases the transition for existing customers.

→ Blog: GitHub Copilot is moving to usage-based billing

2. The agentic demand surge that's reshaping Copilot economics

GitHub paused new sign-ups for Copilot Pro, Pro+, and Student plans and tightened usage limits in April — because long-running agentic sessions now regularly incur costs that exceed the original plan structure. For enterprise leaders, this signals that Copilot's agentic value is proven enough to strain global infrastructure at scale.

→ Blog: Changes to GitHub Copilot Individual plans

3. Two frontier models reach GA: GPT-5.5 and Claude Opus 4.7

OpenAI's GPT-5.5 and Anthropic's Claude Opus 4.7 both reached general availability in April, delivering the strongest multi-step agentic execution and long-horizon reasoning yet available in GitHub Copilot. Both require admin enablement for Business and Enterprise plans.

Sources:
→ Changelog: GPT-5.5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.7 is generally available

4. Cloud agent integrates natively into Visual Studio

The April Visual Studio update embeds cloud agent sessions directly in the IDE: developers select "Cloud" from the agent picker and keep working while the cloud agent handles the task remotely. A new Debugger Agent validates proposed fixes against live runtime behavior, and custom agents gain user-level portability across projects.

→ Changelog: GitHub Copilot in Visual Studio — April update

5. Cloud agent is now over 70% faster to spin up than in February

A 20% startup improvement in April — stacked on March's 50% improvement — means the cloud agent reaches working state in a fraction of the time it needed just 10 weeks ago. Faster feedback loops translate directly to developer productivity and measurable ROI on agentic workflows.

→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images

6. Copilot Chat deepens its pull request understanding

Copilot Chat can now summarize, review, and answer detailed questions about pull requests in github.com — pulling in comments, file changes, commits, and review history as full context. Organizations using Copilot in code review workflows gain richer AI assistance across the entire pull request lifecycle.

→ Changelog: Copilot Chat improvements for pull requests

7. Agent mode arrives in JetBrains IDEs — directly inline

JetBrains developers can now invoke full agent mode capabilities from the inline chat experience, without switching to the chat panel. Combined with Next Edit Suggestions enhancements and global auto-approve controls, this update brings JetBrains to near feature parity with VS Code on agentic workflows.

→ Changelog: Inline agent mode in preview and more in GitHub Copilot for JetBrains IDEs
