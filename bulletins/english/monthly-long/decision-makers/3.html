🏆 Top 8 updates of the month

1. Usage-Based Billing Launches June 1 — With Promotional Credits for Existing Customers

GitHub AI Credits replace premium requests on June 1. Existing Copilot Business and Enterprise customers receive elevated promotional credits through September — 3,000 and 7,000 credits/user/month respectively. Code completions remain unlimited. April usage reports are now available to model projected consumption before the transition takes effect.

Sources:
→ Blog: GitHub Copilot is moving to usage-based billing
→ Changelog: April reports are now available to prepare for usage-based billing

2. GitHub Copilot App: A Dedicated Platform for Agentic Development

The GitHub Copilot app enters technical preview as a GitHub-native desktop for agentic development. Run multiple AI sessions in parallel on isolated branches, manage the full PR lifecycle from issue triage to merge — without switching between terminal, IDE, and browser. It signals that agentic development has a dedicated home on the GitHub platform.

→ Changelog: GitHub Copilot app is now available in technical preview

3. Remote Control for Copilot Sessions Is Now Generally Available

Developers can start a Copilot session on their machine and monitor or steer it from GitHub.com or GitHub Mobile using /remote on. What was desk-bound is now continuous across devices. The capability extends to VS Code and JetBrains, completing a cross-surface agentic platform that follows developers wherever they work.

→ Blog: Take your local GitHub sessions anywhere

4. Agent Tasks REST API: Automate AI-Driven Development at Scale

Copilot Business and Enterprise teams can now trigger cloud agent tasks programmatically via the Agent Tasks REST API (public preview). Fan out refactors across dozens of repositories from a single script, provision repos from internal developer portals, or automate release notes generation — integrating Copilot into existing CI/CD and DevOps pipelines.

→ Changelog: Start Copilot cloud agent tasks via the REST API

5. Team-Level Adoption Analytics: Measure Copilot ROI by Team

The Copilot usage metrics API gains a user-teams report, enabling admins to slice adoption data by organizational team. Identify champions and gaps, with full breakdowns by IDE, language, and feature — the foundational instrument for measuring AI investment returns at scale and targeting enablement where it is needed most.

→ Changelog: Team-level Copilot usage metrics now available via API

6. Enterprise-Managed CLI Plugins: Governance at Scale

Administrators can define and distribute Copilot CLI plugins enterprise-wide via a central settings.json. Custom agents, MCP configurations, and hooks are automatically applied to every licensed user — eliminating per-user setup and ensuring governance consistency for organizations standardizing on agentic development workflows.

→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview

7. Bring-Your-Own-Key for Enterprise: Model Flexibility Without Vendor Lock-In

Copilot Business and Enterprise teams can now connect their own model API keys (OpenAI, Anthropic, Google, and others) in VS Code via BYOK. Admins retain central policy control, giving organizations the flexibility to standardize on preferred models or manage AI costs independently — without abandoning the Copilot platform.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

8. Auto Model Selection: Intelligent Cost Management for Cloud Agent

Auto model selection routes cloud agent tasks to the optimal model based on task complexity and system health in real time. It delivers a 10% discount on the model multiplier, eliminates weekly rate limits, and requires no configuration — the recommended default for cost-efficient agentic workloads.

→ Changelog: Copilot cloud agent supports auto model selection
