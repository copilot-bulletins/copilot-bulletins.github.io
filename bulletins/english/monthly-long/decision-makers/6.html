Monthly (Long) #6 · August 2026 · Decision-Makers Edition

🎯 This edition's thread

August was about turning Copilot from a productivity tool into a measurable business asset. GitHub shipped a return-on-investment view in the impact dashboard, richer usage metrics, and enforced global model governance — giving leaders the numbers and controls to justify and scale their investment. In parallel, agentic collaboration expanded into Slack and Teams, and code review kept maturing. The strategic signal for decision-makers is clear: the platform is optimizing for demonstrable outcomes, governance at scale, and embedding AI where teams already work.

🏆 Top 8 updates of the month

1. Prove Copilot's ROI in the impact dashboard

The Copilot impact dashboard now includes a "Potential return on investment" section that connects what you spend on Copilot to the pull request output you get back — giving leaders a defensible number to justify and expand their investment.

→ Changelog: Copilot impact dashboard adds a return on investment section

2. Deeper measurement across usage and cost

Usage reporting matured this month: the usage metrics API now captures agent app activity from partners like Claude and Codex, and the usage report shows a per-model token breakdown behind your AI credits — sharper visibility into where value and cost accrue.

Sources:
→ Changelog: Copilot usage metrics API adds agent app activity
→ Changelog: Per-model token breakdown in the usage report

3. Governance at scale with global model policy

Enforcement of the default model policy is now rolling out for Copilot Business and Copilot Enterprise, giving organizations consistent, centralized control over which models their teams can use — a key lever for compliance, cost, and risk management.

→ Changelog: Global model policy generally available

4. Code review keeps compounding

GitHub continued heavy investment in Copilot code review: effort levels went GA to match review depth to risk, and reviews now cover bot-authored and very large pull requests with resolution reasons — raising quality and coverage where teams need it most.

Sources:
→ Changelog: Copilot code review effort levels are generally available
→ Changelog: Copilot code review resolution reasons and expanded capabilities
→ Blog: Better tools made Copilot code review worse — here's how we actually improved it

5. Agentic collaboration moves into Slack and Teams

Copilot's agentic capabilities now reach into Slack (public preview) and Microsoft Teams, turning a channel conversation into a shared, steerable agent session — embedding AImomentum directly where distributed teams already coordinate.

Sources:
→ Changelog: The new GitHub Copilot experience in Slack
→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams

6. Broader model choice for every workload

New models — Grok 4.6, Gemini 3.7 Flash, and Kimi K3 — landed in Copilot this month, widening the mix so teams can match capability and cost to each task without leaving the platform.

Sources:
→ Changelog: Grok 4.6 is now available in GitHub Copilot
→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot
→ Changelog: Kimi K3 is now available in GitHub Copilot

7. A portable plugin ecosystem with Agent Plugins 1.0

Agent Plugins 1.0 lets teams build a plugin once and reuse it across compatible agent clients, launched with AWS, Anysphere, Microsoft, OpenAI, and Vercel — reducing lock-in and future-proofing integration investments.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

8. Enterprise-grade managed settings expand

Governance controls deepened with MCP allowlists in enterprise managed settings and managed settings for Copilot in JetBrains — giving security and platform teams consistent guardrails across more of the developer surface.

Sources:
→ Changelog: MCP allowlists in enterprise managed settings
→ Changelog: Enterprise managed settings in GitHub Copilot for JetBrains
