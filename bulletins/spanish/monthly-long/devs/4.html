Monthly (Long) #4 · Julio 2026 · Devs Edition

🎯 El hilo de esta edición

Julio giró en torno a una idea: elegir la herramienta adecuada para cada tarea. El catálogo de modelos creció con nuevas opciones de frontera y selección automática, mientras la línea de comandos, los agentes en los IDE y las integraciones vía MCP maduraron hasta volverse parte natural del flujo diario. Para quien programa, el mensaje es autonomía práctica: delegar más trabajo en agentes sin perder control, con capacidades como visión, herramientas de navegador y revisiones de código cada vez más configurables y conectadas a tu entorno real.

⚠️ Atención

  • Gemini 2.5 Pro y Gemini 3 Flash retirados — Fecha límite: 31 de julio de 2026 — Ya están deprecados en todas las experiencias de Copilot; migra a Gemini 3.1 Pro (Preview) o Gemini 3.6 Flash y revisa los modelos admitidos.

🚀 Pasa a la acción

  • Deja que Copilot escoja por ti activando la selección automática de modelo y compara opciones en la lista de modelos admitidos.
  • Prueba las nuevas capacidades agénticas instalando o actualizando Copilot CLI.
  • Adjunta capturas o diagramas a tu conversación usando Copilot vision en tu IDE.
  • Configura y solicita revisiones de código de Copilot en tus pull requests.
  • ¿Dudas o necesitas apoyo? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. El catálogo de modelos se amplía y aprende a elegir solo

Llegaron Kimi K2.7, GPT-5.6 (sol, terra y luna), Gemini 3.6 Flash, Claude Opus 5 y Grok 4.5. Con la selección automática puedes dejar que Copilot enrute cada tarea al modelo idóneo, desde razonamiento pesado hasta codificación rápida.

Sources:
→ Changelog: OpenAI's GPT-5.6 sol, terra, and luna are now available in GitHub Copilot
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: Kimi K2.7 is now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot
→ Changelog: Gemini 3.6 Flash is now available in GitHub Copilot

2. Copilot vision, ya disponible de forma general

Ahora puedes adjuntar imágenes —capturas de UI, diagramas de arquitectura o errores— directamente en el chat para que Copilot razone sobre ellas. Ideal para depurar interfaces o traducir un boceto en código sin describirlo todo por escrito.

→ Changelog: Copilot vision is generally available

3. Herramientas de navegador en VS Code, ahora generales

Copilot puede abrir un navegador integrado, navegar por tu app en ejecución e inspeccionar la página para verificar cambios. Cierra el bucle entre escribir código y comprobar su comportamiento real sin salir del editor.

→ Changelog: Browser tools for GitHub Copilot in VS Code are generally available

4. Copilot CLI se vuelve más autónomo

La CLI ganó selección automática de modelo, dejó de requerir un token personal en GitHub Actions, sumó límites de sesión de créditos de IA y una nueva skill de servidor de lenguaje C# para mayor precisión en el código.

Sources:
→ Changelog: Copilot CLI auto model selection routes based on task
→ Changelog: Copilot CLI no longer needs a personal access token in GitHub Actions
→ Changelog: New C# language server config skill for Copilot CLI
→ Changelog: Set AI credit session limits in Copilot CLI and SDK

5. JetBrains gana músculo agéntico

Los IDE de JetBrains incorporaron Codex como proveedor de agente con mejoras agénticas, ampliaron el soporte BYOK para traer tus propias claves y mejoraron la configuración de OpenTelemetry y la gestión de modelos.

Sources:
→ Changelog: Codex as agent provider and agentic enhancements in JetBrains IDEs
→ Changelog: GitHub Copilot for JetBrains expands BYOK capabilities
→ Changelog: GitHub Copilot for JetBrains adds improved OpenTelemetry configuration and model management

6. La revisión de código de Copilot, más configurable y extensible

La revisión automática ganó opciones de personalización y configurabilidad, y ahora admite skills de agente y MCP de forma general. Puedes adaptar el criterio de revisión y conectar contexto propio para reseñas más relevantes.

Sources:
→ Changelog: Copilot code review customization and configurability improvements
→ Changelog: Copilot code review agent skills and MCP now generally available

7. Seguridad agéntica que corrige por ti

La corrección automática agéntica para alertas de code scanning entró en vista previa pública, generando arreglos propuestos, y las revisiones de seguridad llegaron a la app de GitHub Copilot para detectar problemas antes de fusionar.

Sources:
→ Changelog: Agentic autofix for code scanning alerts in public preview
→ Changelog: Security reviews now available in the GitHub Copilot app

8. Agentes más conectados vía MCP e integraciones

El servidor MCP de GitHub adoptó la siguiente especificación de MCP, el agente en la nube para Linear pasó a disponibilidad general y llegó el streaming de sesiones de agente en vista previa, para seguir el trabajo del agente en tiempo real.

Sources:
→ Changelog: GitHub MCP server supports the next MCP specification
→ Changelog: Copilot cloud agent for Linear is now generally available
→ Changelog: Copilot agent session streaming is now in public preview
