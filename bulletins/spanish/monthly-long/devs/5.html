Monthly (Long) #5 · Agosto 2026 · Devs Edition

🎯 El hilo de esta edición

Agosto giró en torno a dos ejes para quienes desarrollan: más opciones de modelos y agentes más integrados en el flujo de trabajo. Llegaron varios modelos nuevos al selector de Copilot, mientras VS Code, Visual Studio y JetBrains sumaron mejoras centradas en sesiones de agente, MCP y personalización. La revisión de código con Copilot amplió sus límites y su alcance. En conjunto, el mes consolida un patrón claro: elegir el modelo adecuado y delegar tareas a agentes se vuelve parte natural del día a día, con menos fricción entre el editor, la CLI y la web.

⚠️ Atención

  • Upcoming deprecation of MAI-Code-1-Flash — Deadline: 10 de septiembre de 2026 — Migra tus flujos a MAI-Code-1.1-Flash y confirma su disponibilidad en tu selector de modelos de Copilot Chat.
  • Upcoming deprecation of GitHub Spark on github.com — Deadline: 31 de agosto de 2026 — Spark deja de aceptar nuevas apps; mueve tus proyectos a Copilot en VS Code, la Copilot CLI o la app de Copilot.

🚀 Pasa a la acción

  • Prueba los nuevos modelos desde el selector de modelos de Copilot Chat y compara resultados en tu día a día.
  • Estandariza tus integraciones adoptando MCP y skills portables con la documentación de MCP.
  • Configura la revisión de código automática y sus niveles de esfuerzo para tus pull requests.
  • Personaliza el entorno del agente en la nube para adaptarlo a tu proyecto.
  • ¿Preguntas o necesitas ayuda? Contacta a tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. Más modelos para elegir en Copilot

El selector de modelos creció con Grok 4.6, Gemini 3.7 Flash, Kimi K3 y MAI-Code-1.1-Flash, este último con un precio de lista un 73% menor. Más opciones significan afinar mejor cada tarea entre capacidad, velocidad y coste.

Sources:
→ Changelog: Grok 4.6 is now available in GitHub Copilot
→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot
→ Changelog: Kimi K3 is now available in GitHub Copilot
→ Changelog: MAI-Code-1.1-Flash available in GitHub Copilot

2. Copilot en VS Code: versiones de agosto

La ventana de Agentes facilita organizar chats relacionados, seguir la actividad del agente y navegar entre prompts y cambios de archivos. Agent Host, el navegador integrado y el dictado también reciben mejoras para trabajar de más maneras.

→ Changelog: GitHub Copilot in VS Code, August 2026 releases

3. Agent Plugins 1.0

Ahora un mismo plugin empaqueta skills y servidores MCP con un formato estándar, portable entre VS Code, la Copilot CLI, el SDK y la app de Copilot. Menos duplicación de manifiestos y una sola configuración que conserva el comportamiento de Copilot.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

4. Revisión de código con Copilot: más alcance

Copilot code review elimina el límite de 300 archivos o 20.000 líneas, revisa por completo las pull requests del agente en la nube y ya permite indicar el motivo al resolver un comentario. Los niveles de esfuerzo pasan a disponibilidad general.

Sources:
→ Changelog: Copilot code review: Resolution reasons and expanded capabilities
→ Changelog: Copilot code review effort levels are generally available

5. Copilot para JetBrains

Copilot harness alcanza disponibilidad general con entrega de funciones más rápida, mientras el servidor MCP integrado entra en vista previa pública. Además llegan memoria de Copilot y soporte de Ollama para modelos locales, con una pestaña "What's New" tras cada actualización.

Sources:
→ Changelog: Copilot harness generally available in Copilot for JetBrains
→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains

6. Copilot en Visual Studio

La segunda actualización de agosto trae mejoras a la experiencia de Copilot en Visual Studio, con avances en las capacidades de agente y chat directamente en el IDE.

→ Changelog: GitHub Copilot in Visual Studio — August update

7. Dispara automatizaciones con comentarios

Ahora puedes activar automatizaciones de Copilot directamente desde comentarios, integrando acciones del agente en tu flujo de colaboración sin salir del contexto de la conversación en el pull request o la incidencia.

→ Changelog: Trigger Copilot automations with comments

8. Controla el nivel de razonamiento del agente en la nube

Puedes ajustar el nivel de razonamiento del Copilot cloud agent para equilibrar profundidad y rapidez según la tarea. La pestaña Customize de la app de Copilot alcanza además disponibilidad general para personalizar tu experiencia.

Sources:
→ Changelog: Customize the reasoning level for Copilot cloud agent
→ Changelog: GitHub Copilot app Customize tab is generally available
