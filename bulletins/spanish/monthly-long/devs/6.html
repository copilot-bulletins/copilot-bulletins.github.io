Monthly (Long) #6 · Septiembre 2026 · Devs Edition

🎯 El hilo de esta edición

Septiembre giró en torno a la elección: más modelos de frontera y, sobre todo, mejores formas de orquestarlos. HydraFusion y los tres niveles de selección automática te dejan equilibrar coste, calidad y velocidad por cada prompt, en lugar de fijar un único modelo. En paralelo, maduró el flujo agéntico: revisión de código que aprueba pull requests, sandboxing local en la app de Copilot y mayor control en JetBrains. Para quien programa a diario, el mensaje es claro: más potencia bruta, pero con controles finos para aplicarla con criterio y seguridad.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models — Fecha límite: 2 de octubre de 2026 — Migra tus flujos a los modelos sustitutos; revisa las alternativas en los modelos soportados.
  • Upcoming deprecation of selected GitHub Copilot models in mid-October — Fecha límite: 19 de octubre de 2026 — Actualiza integraciones que dependan de modelos retirados antes de esa fecha.
  • MAI-Code-1-Flash deprecated — Action required — Si usabas este modelo, cambia a uno soportado desde el selector de modelos.

🚀 Pasa a la acción

  • Prueba la vista previa de HydraFusion en VS Code (1.140+) o la app de Copilot desde el selector de modelos.
  • Elige el nivel de eficiencia, equilibrio o inteligencia en la selección automática de modelos.
  • Activa el sandboxing local por proyecto en la app de Copilot para limitar acceso a archivos, red y credenciales.
  • Deja que Copilot code review te indique cuándo un PR está listo para aprobar; revisa cómo configurarlo en la documentación de code review.

🏆 Top 8 de actualizaciones del mes

1. HydraFusion: orquestación multimodelo en tu editor

La vista previa de investigación HydraFusion llega a VS Code y a la app de Copilot. No es un modelo único: orquesta varios y trata la selección como un problema de optimización, usando señales de razonamiento, generación, depuración y uso de herramientas para elegir la ejecución más eficiente.

Sources:
→ Changelog: HydraFusion in VS Code and the GitHub Copilot app
→ Blog: Project HydraFusion: frontier quality via multi-model orchestration

2. Una ola de nuevos modelos de frontera

Septiembre amplió el catálogo con fuerza: GPT-6 Astra (GA), GPT-6 Sol y Luna, GPT-6.1 Sol, Claude Opus 5.5, Claude Sonnet 5.5, Claude Fable 5.1, Gemini 3.8 Flash y Grok 4.7. Más opciones para ajustar cada tarea al modelo adecuado desde el selector.

Sources:
→ Changelog: GPT-6 Astra is generally available in GitHub Copilot
→ Changelog: Claude Opus 5.5 is now available in GitHub Copilot
→ Changelog: OpenAI's GPT-6 Sol and GPT-6 Luna now available
→ Changelog: Grok 4.7 is now available in GitHub Copilot

3. Copilot code review, más autónomo y útil

La revisión de código dio un salto: ahora incluye una evaluación de aprobación en cada revisión e incluso puede aprobar PRs si un admin lo autoriza. Se suman auto-resolución, una experiencia de revisión mejorada, más formas de solicitarla y memoria compartida en autofix agéntico.

Sources:
→ Changelog: Copilot code review can now approve pull requests
→ Changelog: Auto-resolution and analysis updates in Copilot code review
→ Changelog: Copilot code review: An improved review experience
→ Changelog: More ways to request and configure Copilot code reviews

4. Sandboxing local en la app de Copilot

Ya puedes limitar el impacto de comandos no deseados restringiendo acceso a archivos, red y credenciales de tu máquina. Se configura por proyecto para sesiones locales de repositorio y árbol de trabajo; si el sistema no puede aplicar la política, la sesión falla en vez de ejecutarse sin protección.

→ Changelog: Local sandboxing in the GitHub Copilot app

5. Más control en Copilot para JetBrains

La versión 1.18.0 trae aprobaciones de herramientas asistidas por IA (las de bajo riesgo se aprueban solas, las de mayor riesgo siguen pidiendo confirmación), reedición de mensajes previos que rebobina conversación y cambios, revisión de planes con el agente Codex y controles persistentes para MCP. Suma el sandbox gestionado por la empresa.

Sources:
→ Changelog: New features and improvements in Copilot for JetBrains
→ Changelog: Enterprise-managed sandbox in Copilot for JetBrains

6. Indexación de todo el código para C++ más rápido

La inteligencia de código C++ en Copilot CLI acelera con whole codebase indexing: un índice persistente de símbolos en todo el proyecto, incluidos archivos no abiertos. Menos espera para definiciones, referencias e implementaciones en bases de millones de líneas.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

7. Selección automática de modelos con tres niveles

La selección automática ahora ofrece niveles de eficiencia, equilibrio e inteligencia. Eliges cómo quieres que Copilot pondere coste, calidad y tiempo de respuesta en cada prompt, usando el mismo conjunto de modelos. Disponible en VS Code, Copilot CLI y la app de Copilot.

→ Changelog: Configure cost and quality in Copilot auto model selection

8. Exclusiones de contenido en la app y el CLI

La app de Copilot y el CLI ya respetan las políticas de exclusión de contenido definidas por administradores. Copilot no usará los archivos excluidos como contexto, protegiendo código sensible también en flujos agénticos para clientes de Copilot Business y Enterprise.

→ Changelog: Content exclusions generally available in Copilot app and CLI
