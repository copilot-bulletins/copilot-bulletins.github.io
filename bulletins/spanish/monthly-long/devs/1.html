Monthly (Long) #1 · Mayo 2026 · Devs Edition

🎯 El hilo de esta edición

Mayo 2026 marca la llegada de Copilot como plataforma agéntica de pleno derecho. La nueva app de escritorio, el control remoto disponible en todos los dispositivos, el agente CLI en JetBrains y la API REST del agente cloud consolidan un ecosistema donde los agentes actúan en paralelo, en cualquier entorno y desde cualquier lugar. Al mismo tiempo, VS Code y Copilot CLI reciben actualizaciones que amplían contexto, modelos y acceso a terminal. El resultado: un flujo de trabajo agéntico continuo, de la idea al pull request, sin interrupciones.

⚠️ Atención

🚀 Pasa a la acción

  • Instala la app de GitHub Copilot para gestionar sesiones agénticas en paralelo desde el escritorio.
  • Activa el control remoto de sesiones CLI con /remote on para supervisar y dirigir tu sesión desde github.com o la app móvil.
  • Selecciona Auto en el selector de modelos del agente cloud para aprovechar el enrutamiento inteligente y el 10 % de descuento.
  • Automatiza tareas agénticas con la API REST de Agent Tasks para integraciones y flujos de trabajo programáticos.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. La app de GitHub Copilot llega en preview técnica

La app de Copilot es una aplicación de escritorio nativa para el desarrollo agéntico. Inicia sesiones desde issues o pull requests, ejecuta varios agentes en paralelo sobre ramas aisladas, revisa diffs y abre pull requests sin cambiar de herramienta. Disponible para Business/Enterprise; lista de espera para Pro/Pro+.

→ Changelog: GitHub Copilot app is now available in technical preview

2. Control remoto para sesiones de Copilot: disponibilidad general

El control remoto de sesiones CLI llega a disponibilidad general y se extiende a VS Code y JetBrains. Con /remote on, supervisa y dirige tu sesión desde github.com o la app móvil. Aprueba permisos, envía instrucciones y crea pull requests desde cualquier dispositivo, en tiempo real.

→ Blog: Take your local GitHub sessions anywhere

3. GitHub Copilot en VS Code: versiones de abril

VS Code pasa a ciclo semanal de publicaciones. Las actualizaciones de abril traen indexación semántica en cualquier workspace, Bring Your Own Key para Business/Enterprise, acceso de agentes a terminales abiertas y compartición de pestañas del navegador como contexto. /chronicle permite consultar el historial de sesiones anteriores.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

4. Agente CLI de Copilot y vista unificada de sesiones en JetBrains

JetBrains recibe el agente CLI de Copilot en preview pública: delega tareas largas directamente desde el IDE con aislamiento en worktree o workspace. Una nueva vista unificada centraliza el estado de todas las sesiones. Se añaden la herramienta de preguntas en modo agente y el soporte global de .agent.md.

→ Changelog: Introducing Copilot CLI agent and unified sessions view in GitHub Copilot for JetBrains IDEs

5. Inicia tareas del agente cloud mediante la API REST

Los usuarios de Business y Enterprise pueden lanzar tareas del agente cloud de forma programática con la nueva API REST en preview pública. Automatiza refactorizaciones masivas, configura repositorios desde tu portal interno o genera release notes semanales. Autenticación con PAT y OAuth; soporte para GitHub App tokens próximamente.

→ Changelog: Start Copilot cloud agent tasks via the REST API

6. El agente cloud soporta selección automática de modelo

Al elegir Auto en el selector de modelos del agente cloud, Copilot elige el mejor disponible según el rendimiento en tiempo real. Bonus: 10 % de descuento sobre el multiplicador normal y sin impacto en los límites semanales de tasa. Disponible también en Copilot Chat y Copilot CLI.

→ Changelog: Copilot cloud agent supports auto model selection

7. Plugins gestionados por la empresa en Copilot CLI, en preview pública

Los administradores pueden distribuir agentes personalizados, configuraciones MCP y hooks a todos los usuarios de Copilot CLI mediante un settings.json centralizado en .github-private. Los plugins se instalan automáticamente al autenticarse, reduciendo la fricción de incorporación y estandarizando el entorno de desarrollo.

→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview

8. Rubber Duck en Copilot CLI: ahora con más modelos

El agente Rubber Duck, revisor de segundo nivel en Copilot CLI, llega a sesiones GPT con un agente Claude como crítico. Las sesiones Claude pasan a usar GPT-5.5 como revisor. Esto crea una red de revisión cruzada entre familias de modelos para detectar bugs, deuda técnica y conflictos entre archivos.

→ Changelog: Rubber Duck in GitHub Copilot CLI now supports more models
