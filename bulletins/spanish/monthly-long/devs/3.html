Monthly (Long) #3 · Junio 2026 · Devs Edition

🎯 El hilo de esta edición

Junio consolidó un cambio de fondo: Copilot deja de vivir solo en el editor para convertirse en un agente que trabaja en el terminal, el escritorio y tu CI. La app de GitHub Copilot y la nueva interfaz del Copilot CLI alcanzaron disponibilidad general, mientras los sandboxes, las automatizaciones del agente en la nube y los agentic workflows aportaron autonomía bajo control. Una oleada de modelos nuevos amplió tus opciones. Para quien programa, el reto pasa de autocompletar a orquestar agentes.

⚠️ Atención

  • GPT-4.1 retirado de GitHub Copilot — Fecha límite: 1 de junio de 2026 — El modelo ya no está disponible en Chat, ediciones en línea, modos ask/agent ni finalización de código; migra a un modelo compatible.
  • GPT-5.2 y GPT-5.2-Codex retirados — Fecha límite: 5 de junio de 2026 — Actualiza tus flujos a un modelo compatible; GPT-5.2 sigue disponible solo dentro de Copilot code review.
  • Opus 4.6 (fast) en proceso de retirada — Fecha límite: 29 de junio de 2026 — Cambia a Opus 4.8 u otro modelo compatible antes de esa fecha.

🚀 Pasa a la acción

  • Instala la app de GitHub Copilot para macOS, Windows o Linux y arranca tu primera sesión de desarrollo con agentes.
  • Actualiza tu Copilot CLI y usa la nueva interfaz de terminal para navegar por issues, PRs y gists sin salir de la consola.
  • Explora los modelos más recientes —Sonnet 5, MAI-Code-1-Flash, Gemini— y deja que el modo auto elija por ti.
  • Prueba los sandboxes locales y en la nube para dar a Copilot un entorno aislado antes de concederle acceso a tu código.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. La app de GitHub Copilot llega a disponibilidad general

La app de escritorio de Copilot ya es GA en macOS, Windows y Linux: el hogar nativo del desarrollo con agentes. Lanza sesiones desde un issue, PR o prompt, ejecútalas en paralelo y abre una PR con tus checks.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

2. El Copilot CLI estrena interfaz de terminal (GA) y nuevas capacidades

La interfaz rediseñada del Copilot CLI, presentada en Build 2026, ya es GA, con pestañas para issues, PRs y gists. El mes también trajo rubber duck, entrada por voz, configuración con /settings y un comando /security-review local.

Sources:
→ Changelog: Copilot CLI: New terminal interface is generally available
→ Changelog: Copilot CLI: Improved UI, rubber duck, prompt scheduling, and voice input

3. Nuevos modelos: Claude Sonnet 5, Opus 4.8 (fast), MAI-Code-1-Flash y Gemini

El catálogo creció: Sonnet 5 llegó a GA con buen rendimiento en CLI, Opus 4.8 (fast) entró en preview, MAI-Code-1-Flash debutó en VS Code y dos modelos Gemini llegaron al CLI, el agente en la nube y la app.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: MAI-Code-1-Flash is now available for GitHub Copilot
→ Changelog: Gemini models in Copilot CLI, cloud agent, and the Copilot app

4. El agente en la nube se vuelve autónomo: automatizaciones y sandboxes

El agente en la nube ya puede ejecutarse solo, por horario o ante eventos del repositorio, gracias a las automatizaciones. Los nuevos sandboxes locales y en la nube le dan un entorno aislado para trabajar con seguridad.

Sources:
→ Changelog: Schedule and automate tasks with Copilot cloud agent
→ Changelog: Cloud and local sandboxes for GitHub Copilot now in public preview

5. GitHub Agentic Workflows entra en public preview

Automatiza tareas de razonamiento —triage de issues, análisis de fallos de CI, documentación— con agentes dentro de GitHub Actions. Defines la automatización en Markdown y se compila a YAML. Ya no necesitas un PAT: basta con el GITHUB_TOKEN integrado.

Sources:
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Agentic workflows no longer need a personal access token

6. Contexto de 1 millón de tokens y selección automática de modelo

Copilot admite ahora contexto de un millón de tokens y niveles de razonamiento configurables en VS Code, el CLI y la app, ideales para bases de código grandes. Además, el modo auto llegó a Copilot Chat en todos los planes.

Sources:
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot
→ Changelog: Auto mode in Copilot Chat available for all users

7. Copilot code review: más configuración, contexto y eficiencia

Copilot code review sumó controles de runners de organización, exclusión de contenido e instrucciones personalizadas sin límite de caracteres. También aprovecha tu AGENTS.md y las herramientas de exploración del CLI y el SDK para revisiones más ajustadas y eficientes.

Sources:
→ Changelog: Copilot code review: New configurations and controls
→ Changelog: Copilot code review: AGENTS.md support and UI improvements
→ Changelog: Copilot code review: Analysis depth and efficiency updates

8. Novedades en los IDEs: VS Code, Visual Studio y JetBrains

Los IDEs se pusieron al día: VS Code llevó la ventana de Agents a Stable como preview (v1.120–v1.123), Visual Studio 2026 afinó la planificación del trabajo, y JetBrains estrenó agentes de organización y Claude como proveedor de agente en preview.

Sources:
→ Changelog: GitHub Copilot in Visual Studio Code, May releases
→ Changelog: GitHub Copilot in Visual Studio — May update
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs
