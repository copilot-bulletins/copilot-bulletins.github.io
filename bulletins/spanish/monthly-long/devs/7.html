Monthly (Long) #7 · Octubre 2026 · Devs Edition

🎯 El hilo de esta edición

Octubre, marcado por GitHub Universe, consolida a Copilot como un sistema de agentes que trabaja en paralelo contigo. La selección de modelos pasa a ser automática y orquestada, las sesiones se ejecutan en sandboxes en la nube y continúan en cualquier superficie, y los flujos recurrentes se convierten en automatizaciones compartidas por el equipo.

Al mismo tiempo, el contexto se vuelve persistente: memoria, conectores verificados y revisiones de código más exhaustivas. Para los desarrolladores, esto significa menos configuración repetitiva y más tiempo dedicado a validar resultados en lugar de dirigir cada paso.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Fecha límite: 16 de noviembre de 2026 — Claude Opus 4.8, Claude Opus 5 y GPT-5.6 Terra se retiran; migra tus flujos e integraciones a Claude Opus 5.5, GPT-6.1 Sol o GPT-6 Luna según los modelos compatibles.
  • GitHub Copilot models deprecated on October 19, 2026 — Acción requerida — GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, Gemini 3.7 Flash y Grok 4.5 ya no están disponibles; actualiza scripts y configuraciones que los referencien.

🚀 Pasa a la acción

  • Selecciona Copilot Fusion en el selector de modelos y elige el nivel de esfuerzo adecuado; consulta Acerca de GitHub Copilot Fusion.
  • Activa "Watch and fix" en el cuadro de merge de tus pull requests siguiendo la guía de Agent Merge.
  • Crea tu primera automatización programada o basada en eventos con Copilot Automations.
  • Pide a Copilot que recuerde tus convenciones y revisa cómo funciona Copilot Memory.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. Copilot Fusion: deja que Copilot elija y combine los modelos

Copilot Fusion, ya disponible de forma general, enruta cada prompt al modelo adecuado y puede orquestar varios (cascada, crítica). Tú solo eliges el esfuerzo: Standard, High o Max. Ahora también puede seleccionar modelos locales.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot Fusion now supports selection of local models

2. Una sola sesión en la nube, en todas tus superficies

Inicia una tarea desde github.com, GitHub Mobile, la CLI, la app de Copilot, VS Code, Slack o Teams y retómala en cualquier otro lugar. Cada sesión se ejecuta en un sandbox en la nube que guarda un snapshot y se reanuda donde la dejaste.

Sources:
→ Changelog: Work from anywhere with a new, connected Copilot cloud experience
→ Changelog: GitHub Copilot in VS Code, Universe releases

3. Copilot Automations: flujos en la nube, compartidos y que mejoran solos

Combina prompts, triggers y herramientas para automatizar tareas recurrentes: reproducir bugs al abrir un issue o capturar pantallas en cada PR. Ahora se ejecutan en la nube desde VS Code, se comparten a nivel de repositorio y proponen mejoras a partir de sus resultados.

Sources:
→ Changelog: Create and manage Copilot Automations in Visual Studio Code
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: New tools, triggers, and cost controls for Copilot Automations
→ Changelog: Copilot Automations now learn from outcomes and self-improve

4. Agent Merge: Copilot desbloquea tus pull requests

Selecciona "Watch and fix" en el cuadro de merge y Copilot corrige workflows de Actions fallidos y conflictos de merge en un entorno en la nube. Combinado con auto-merge, tu PR se fusiona en cuanto cumple todos los requisitos.

→ Changelog: Agent Merge watches and fixes pull requests in the cloud

5. Code review: nivel Max y aprobaciones de Copilot

El nuevo nivel Max (vista previa pública) ejecuta varios agentes de revisión con modelos de distintos proveedores y reconcilia sus hallazgos. Las aprobaciones de Copilot, ya disponibles de forma general, cuentan para las aprobaciones requeridas del repositorio.

→ Changelog: Copilot code review: Merge with confidence with Max and approvals

6. Copilot Memory y dreaming: contexto que persiste

Copilot Memory ya está disponible de forma general: recuerda tus preferencias y convenciones del repositorio entre sesiones y clientes. Dreaming (vista previa, opt-in) revisa el trabajo pasado y propone mejoras a skills e instrucciones mediante pull requests.

→ Changelog: GitHub intelligence puts your code, context, and history to work

7. Conectores: servidores MCP verificados sin configuración

Conecta servicios como Slack, Figma, Notion, Sentry o Linear una sola vez y úsalos en la app de Copilot, la CLI (/mcp, pestaña Connectors), VS Code, la nube y GitHub Mobile. Sin instalar servidores ni gestionar credenciales.

→ Changelog: Connect your tools to Copilot without all the setup

8. Agentes locales más seguros y modelos locales en la CLI

El sandboxing local ya está disponible de forma general en la CLI, la app y VS Code: restringe sistema de archivos, red y credenciales para los comandos del agente. Además, /model en la CLI descubre modelos de una instancia local de Ollama.

Sources:
→ Changelog: Local sandboxing for GitHub Copilot now generally available
→ Changelog: Discover local models in GitHub Copilot CLI
