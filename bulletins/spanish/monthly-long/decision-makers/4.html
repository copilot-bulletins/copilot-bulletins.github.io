Monthly (Long) #4 · Junio 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Junio consolidó el giro de Copilot de asistente a plataforma agéntica de nivel empresarial. Llegó la app de escritorio pensada para agentes, se ampliaron los flujos autónomos (Agentic Workflows, agentes en la nube, SDK) y creció el catálogo de modelos de frontera. En paralelo, GitHub reforzó los controles que exigen las direcciones: gobierno de costes con presupuestos por usuario, métricas de adopción para medir el retorno y una revisión de código cada vez más configurable. El mensaje para quien decide es claro: la autonomía escala, pero acompañada de visibilidad, gobernanza y elección.

⚠️ Atención

  • Opus 4.6 (fast) se retira de Copilot — Fecha límite: 29 de junio de 2026 — Habilite una alternativa compatible desde las políticas de modelos.
  • GPT-5.2 y GPT-5.2-Codex retirados — Retirados: 5 de junio de 2026 — GPT-5.2 sigue disponible en la revisión de código; junto con GPT-4.1 (retirado el 1 de junio), migre los flujos afectados ajustando el acceso a modelos.

🏆 Top 8 de actualizaciones del mes

1. Llega la app de GitHub Copilot, pensada para agentes

Copilot estrena app de escritorio en disponibilidad general: un centro de control para dirigir varios agentes en paralelo, de la incidencia al pull request, con lienzos y automatizaciones en la nube. Desarrollo agéntico más allá del IDE.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

2. Más modelos de frontera, y con más contexto

El catálogo creció con Claude Sonnet 5 (GA), Claude Opus 4.8 (fast, preview) y Claude Fable 5 (GA), más ventanas de contexto de un millón de tokens y razonamiento configurable. Flexibilidad para elegir el modelo idóneo en cada tarea.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: Claude Fable 5 is generally available for GitHub Copilot
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot

3. La automatización agéntica madura

GitHub Agentic Workflows entró en preview pública: automatizaciones en Markdown que se compilan a Actions y reutilizan sus controles, ya sin PAT y con tareas programadas del agente en la nube. Carvana y Marks & Spencer convierten horas de trabajo repetitivo en minutos.

Sources:
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Agentic workflows no longer need a personal access token
→ Changelog: Schedule and automate tasks with Copilot cloud agent

4. Medir la adopción y el retorno

Nuevas señales para cuantificar el valor: los informes captan más usuarios activos con telemetría de servidor, muestran los pull requests fusionados por fase de adopción e incorporan los créditos de IA por usuario. Datos para conectar consumo y resultados.

Sources:
→ Changelog: Copilot usage metrics now include more of your active users
→ Changelog: Track total merges by adoption phase in enterprise and organization reports
→ Changelog: AI credits consumed per user now in the Copilot usage metrics API

5. Gobierno de costes más granular

Con la facturación por consumo activa en todos los planes, GitHub añadió presupuestos por usuario, también para los centros de coste vía API REST. Las direcciones financian cada equipo según su uso real y frenan el gasto antes de agotar la bolsa incluida.

Sources:
→ Changelog: Updates to GitHub Copilot billing and plans
→ Changelog: Per-user AI credit budgets available for cost centers

6. Inversión sostenida en la revisión de código

La revisión de código de Copilot sumó profundidad de análisis configurable, valores por defecto de organización, soporte de AGENTS.md y nuevos controles. GitHub sostiene una fuerte cadencia de inversión en calidad automatizada del código, palanca directa de velocidad y menor riesgo.

Sources:
→ Changelog: Copilot code review: Analysis depth and efficiency updates
→ Changelog: Copilot code review: AGENTS.md support and UI improvements
→ Changelog: Copilot code review: New configurations and controls

7. Copilot for Jira en disponibilidad general

El agente de codificación se integra de lleno en Jira: progreso en tiempo real dentro de la incidencia, instrucciones de seguimiento desde el chat de Jira y configuración más sencilla. Menos cambios de contexto y más control donde ya operan los equipos.

→ Changelog: GitHub Copilot for Jira is now generally available

8. Construir sobre la plataforma Copilot

Copilot se abre como plataforma: el SDK alcanza GA en seis lenguajes con acceso directo al runtime del agente, las agent apps de terceros amplían los flujos y la API REST de tareas de agente habilita integraciones propias. Base para soluciones de IA a medida.

Sources:
→ Changelog: Copilot SDK is now generally available
→ Changelog: Extend GitHub with agent apps
→ Changelog: Agent tasks REST API now available for Copilot Pro, Pro+, and Max
