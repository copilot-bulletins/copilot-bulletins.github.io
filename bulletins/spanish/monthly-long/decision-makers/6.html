Monthly (Long) #6 · Agosto 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Agosto consolidó una idea central para quienes deciden: Copilot deja de medirse por adopción y empieza a medirse por retorno. El nuevo apartado de retorno de inversión en el panel de impacto, junto con métricas de uso más granulares, permiten conectar el gasto en IA con la producción real de código. En paralelo, la gobernanza madura —política global de modelos, ajustes de políticas y facturación— y la oferta se amplía a Slack y Teams. El mensaje estratégico: la IA agéntica ya es un activo gobernable y cuantificable a escala empresarial.

⚠️ Atención

  • Upcoming deprecation of GitHub Spark on github.com — Fecha límite: 31 de agosto de 2026 — Spark ya no admite nuevos usuarios; los existentes deben exportar sus apps antes de esa fecha. Migre sus flujos a Copilot en VS Code, CLI y la app de Copilot.
  • Upcoming deprecation of MAI-Code-1-Flash — Fecha límite: 10 de septiembre de 2026 — El modelo se retira en todas las experiencias de Copilot; actualice a MAI-Code-1.1-Flash desde sus políticas de modelos.

🚀 Pasa a la acción

  • Cuantifique el valor de Copilot con el nuevo apartado de ROI en el panel de impacto.
  • Estandarice qué modelos están disponibles en su organización con la política global de modelos.
  • Siga la adopción real por equipos con las métricas de uso de Copilot.
  • Active y ajuste el nivel de esfuerzo de la revisión de código de Copilot para sus repositorios clave.
  • ¿Preguntas o necesita apoyo? Contacte con su equipo de GitHub, estamos aquí para ayudar.

🏆 Top 8 de actualizaciones del mes

1. El panel de impacto ahora mide el retorno de inversión

El panel de impacto incorpora un apartado de "retorno de inversión potencial" que conecta el gasto en Copilot con los pull requests generados. Compara usuarios pasivos frente a desarrolladores "agent-first", con coste por desarrollador y porcentaje de nómina. Una herramienta directa para justificar la inversión.

→ Changelog: Copilot impact dashboard adds a return on investment section

2. Gobernanza de modelos madura con política global

La política global de modelos alcanza disponibilidad general, permitiendo estandarizar qué modelos usa toda la organización. Se suma a una oferta que este mes creció con Kimi K3, Gemini 3.7 Flash, Grok 4.6 y MAI-Code-1.1-Flash: más elección, bajo control central.

Sources:
→ Changelog: Global model policy generally available
→ Changelog: Kimi K3 is now available in GitHub Copilot
→ Changelog: Grok 4.6 is now available in GitHub Copilot

3. La revisión de código de Copilot gana madurez empresarial

La revisión de código de Copilot alcanza disponibilidad general en niveles de esfuerzo y añade motivos de resolución y capacidades ampliadas. Un control de calidad automatizado más transparente y ajustable, que reduce carga de revisión sin sacrificar rigor.

Sources:
→ Changelog: Copilot code review effort levels are generally available
→ Changelog: Copilot code review resolution reasons and expanded capabilities

4. Cambios en políticas y facturación de Copilot

GitHub reabre las altas de Copilot Business y Enterprise con facturación actualizada, converge las experiencias de agente y chat en una sola política, y cambia el nivel de esfuerzo por defecto de revisión a "Balanced". Cambios que conviene planificar con antelación.

→ Changelog: Upcoming changes to GitHub Copilot policies and billing

5. Copilot llega a Slack y Microsoft Teams

Copilot amplía su alcance con una nueva experiencia en Slack y trabajo agéntico compartido en Microsoft Teams. La IA se integra donde ya colaboran los equipos, acercando el valor de Copilot más allá del IDE a toda la organización.

Sources:
→ Changelog: The new GitHub Copilot experience in Slack
→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams

6. Métricas más finas para medir el impacto

La API de métricas de uso añade actividad de las agent apps y el informe de uso incorpora desglose de tokens por modelo. Más visibilidad para atribuir consumo, optimizar costes y demostrar el valor de cada inversión en IA.

Sources:
→ Changelog: Copilot usage metrics API adds agent app activity
→ Changelog: Per-model token breakdown in the usage report

7. Agent plugins 1.0 y personalización del ecosistema

Agent plugins 1.0 llega a VS Code, Copilot CLI y la app de Copilot, y la pestaña de personalización de la app alcanza disponibilidad general. Copilot se convierte en una plataforma extensible y adaptable a los procesos de cada empresa.

Sources:
→ Changelog: Agent plugins 1.0 in VS Code, Copilot CLI, and the Copilot app
→ Changelog: GitHub Copilot app customize tab is generally available

8. Caso real: el equipo legal de GitHub con Copilot CLI

El propio equipo legal de GitHub usó Copilot CLI para agilizar sus flujos de trabajo. Una prueba concreta de que el valor de Copilot trasciende la ingeniería y aporta productividad en funciones de negocio.

→ Blog: How the GitHub legal team used Copilot CLI to streamline their workflows
