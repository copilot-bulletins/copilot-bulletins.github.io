Monthly (Long) #5 · Julio 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Julio consolidó una tendencia clara: Copilot deja de medirse por adopción y empieza a medirse por impacto. GitHub reforzó las métricas de uso, los controles de coste por centro y la gobernanza empresarial, dando a las organizaciones instrumentos concretos para justificar la inversión y contenerla. En paralelo, la oferta de modelos se amplió y las capacidades autónomas —revisión de código, seguridad y agentes— alcanzaron disponibilidad general. Para quien decide, el mensaje es estratégico: la infraestructura para escalar Copilot con visibilidad de ROI y control financiero ya está madura.

⚠️ Atención

  • Gemini 2.5 Pro y Gemini 3 Flash quedan obsoletos — Fecha límite: 31 de julio de 2026 — Migra los equipos a modelos vigentes desde la disponibilidad de modelos.
  • La app de vista previa de facturación de Copilot se retira — Fecha límite: 3 de agosto de 2026 — Traslada tus flujos de coste a la gestión de gasto de la empresa.

🚀 Pasa a la acción

  • Cuantifica el retorno con el nuevo panel de impacto y las métricas de uso de Copilot.
  • Controla el gasto con centros de coste y límites configurando presupuestos de facturación por uso.
  • Revisa tu marco de gobernanza de IA empresarial para alinear políticas y cumplimiento.
  • Estandariza los ajustes gestionados con la gestión empresarial de Copilot.
  • ¿Preguntas o necesitas apoyo? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. Medir el impacto real de Copilot

GitHub convirtió la medición del ROI en una capacidad de primera clase: un nuevo panel de impacto, métricas por repositorio en disponibilidad general y datos de ciclos de revisión y tiempo de adopción vía API. Ahora la dirección puede vincular la inversión con resultados verificables.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: Add review cycles and time to adoption phases in the usage API

2. Gobernanza financiera con centros de coste

La gestión del gasto dio un salto: fondos de créditos de IA por centro de coste, presupuestos por usuario, topes de uso incluido y visibilidad de créditos por ciclo de facturación. Un conjunto de controles que permite escalar Copilot sin perder previsibilidad presupuestaria.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: Cost centers now support included usage caps

3. Más opciones de modelos de IA

La cartera de modelos se amplió con Claude Opus 5, GPT-5.6, Grok 4.5, Gemini 3.6 Flash y Kimi K2.7, además de la selección automática de modelo por tarea. Mayor elección y enrutamiento inteligente que optimizan calidad y coste según el caso de uso.

Sources:
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available
→ Changelog: Enterprises can default to auto model selection

4. Revisión de código y seguridad autónomas

Copilot Code Review alcanzó disponibilidad general con agent skills y MCP, y se sumaron las revisiones de seguridad en la app y el autofix agéntico para alertas de análisis de código. La calidad y la seguridad pasan a ser parte automática del flujo de entrega.

Sources:
→ Changelog: Copilot code review agent skills and MCP now generally available
→ Changelog: Security reviews now available in the GitHub Copilot app
→ Changelog: Agentic autofix for code scanning alerts in public preview

5. La app de GitHub Copilot, disponible para todos

La app de GitHub Copilot pasó a estar disponible para todos los usuarios, ampliando el alcance de Copilot más allá del IDE. Un paso relevante para llegar a perfiles no técnicos y difundir el valor de la IA en toda la organización.

→ Changelog: GitHub Copilot app available to all

6. Copilot Vision en disponibilidad general

Copilot Vision alcanzó disponibilidad general, permitiendo trabajar a partir de imágenes, capturas y diseños. Abre casos de uso —de la maquetación a la documentación visual— que aceleran el paso de la idea al código y amplían la productividad multimodal.

→ Changelog: Copilot Vision is generally available

7. Gobernanza empresarial reforzada

La administración de Copilot se consolidó: managed settings JSON en disponibilidad general, despliegue vía MDM en VS Code y CLI, políticas dedicadas de acceso a la app y segmentación de políticas de modelo por equipos. Control granular y coherente a escala de empresa.

Sources:
→ Changelog: Enterprise managed settings JSON is generally available
→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI
→ Changelog: Enterprise Teams model policy targeting in public preview

8. Agentes autónomos en el flujo de trabajo

Los agentes ganaron autonomía y alcance: el cloud agent para Linear alcanzó disponibilidad general, el streaming de sesiones de agente entró en vista previa pública y llegaron controles de automatización de agentes en GitHub Issues. La ejecución autónoma se integra en las herramientas de trabajo diario.

Sources:
→ Changelog: Copilot cloud agent for Linear is now generally available
→ Changelog: Copilot agent session streaming is now in public preview
→ Changelog: Agent automation controls in GitHub Issues in public preview
