Monthly (Long) #2 · Abril 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Abril de 2026 consolida a GitHub Copilot como plataforma empresarial de referencia. Tres ejes definen el mes: la residencia de datos en EE.UU. y la UE junto con la certificación FedRAMP acerca Copilot a los requisitos de soberanía y cumplimiento más exigentes; la expansión del agente en la nube hacia ciclos completos de investigación, planificación e implementación amplía el alcance de la automatización; y el SDK abre el motor de IA de GitHub al ecosistema propio. La ampliación de las métricas de uso cierra el ciclo: datos para medir y escalar con confianza.

⚠️ Atención

  • GitHub Copilot code review will start consuming GitHub Actions minutes on June 1, 2026 — Plazo: 1 de junio de 2026 — A partir de esa fecha, cada revisión de código en repositorios privados consumirá minutos de GitHub Actions del plan contratado (Pro, Pro+, Business y Enterprise). Revisa y ajusta tus presupuestos de Actions antes de esa fecha y comparte el aviso con tus equipos de facturación e ingeniería.

🚀 Pasa a la acción

  • Activa la política de residencia de datos en EE.UU. o la UE para garantizar que toda la inferencia de Copilot permanezca dentro de tu región; consulta la documentación de residencia de datos.
  • Habilita GPT-5.5 en la configuración de Copilot de tu empresa u organización para dar acceso a tus equipos al modelo con mejor rendimiento en tareas agénticas complejas; consulta los modelos compatibles.
  • Revisa tus presupuestos de GitHub Actions antes del 1 de junio para gestionar el consumo de minutos de la revisión de código y evitar sorpresas en la factura.
  • Configura instrucciones personalizadas para tu organización para estandarizar el comportamiento de Copilot en todos los repositorios de tu empresa.
  • ¿Tienes preguntas o necesitas apoyo? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. Residencia de datos en EE.UU. y la UE + certificación FedRAMP

Copilot ya procesa toda la inferencia dentro de la región geográfica designada —EE.UU. o la UE (incluyendo países EFTA)— con infraestructura autorizada FedRAMP Moderate para clientes del gobierno de EE.UU. Todas las funciones GA de Copilot están cubiertas, con un 10% de incremento en el multiplicador de modelo por los costes de endpoints de conformidad regional.

→ Changelog: Data residency (US + EU) and FedRAMP-authorized models now available in Copilot

2. GPT-5.5 disponible de forma general en GitHub Copilot

GPT-5.5, el último modelo de OpenAI, llega a GitHub Copilot con un multiplicador promocional de 7.5× y rendimiento superior en tareas agénticas complejas. Disponible para Pro+, Business y Enterprise en todos los entornos principales: IDEs, CLI, agente en la nube y github.com.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

3. El agente en la nube trasciende los pull requests: investigación, planificación y código

Copilot cloud agent ya no está limitado a flujos de pull request. Puede trabajar en una rama sin crear PR, generar planes de implementación revisables antes de escribir código, y realizar investigaciones profundas en el repositorio. Además, se pueden gestionar sesiones del agente directamente desde issues y proyectos sin cambiar de contexto.

Sources:
→ Changelog: Research, plan, and code with Copilot cloud agent
→ Changelog: View and manage agent sessions from issues and projects

4. SDK de Copilot en preview pública: integra IA agéntica en tus propias aplicaciones

El SDK de Copilot —disponible en Node.js, Python, Go, .NET y Java— expone el mismo motor de agente que impulsa el agente en la nube. Las organizaciones pueden incrustar capacidades agénticas en sus propias herramientas internas, con soporte para herramientas personalizadas, streaming, OpenTelemetry y BYOK.

→ Changelog: Copilot SDK in public preview

5. Reestructuración de los planes individuales y pausa en registros de Business

GitHub ha pausado los nuevos registros en Pro, Pro+ y Student para priorizar la fiabilidad de los clientes de pago existentes. Copilot Business para organizaciones en planes Free y Team también pausa los registros de autoservicio. Los clientes empresariales actuales no se ven afectados y pueden continuar añadiendo licencias con normalidad.

Sources:
→ Changelog: Changes to GitHub Copilot plans for individuals
→ Changelog: Pausing new self-serve signups for GitHub Copilot Business

6. Instrucciones personalizadas de organización GA + control por propiedades personalizadas

Las instrucciones personalizadas de organización, ahora en disponibilidad general, permiten a los administradores de Business y Enterprise definir directrices que guían el comportamiento de Copilot en todos los repositorios (Chat, revisión de código, agente). El agente en la nube también puede habilitarse de forma selectiva por organización mediante propiedades personalizadas, facilitando pilotos progresivos y una adopción controlada.

Sources:
→ Changelog: Copilot organization custom instructions are generally available
→ Changelog: Enable Copilot cloud agent via custom properties

7. Métricas de uso expandidas: agente, revisiones de código y CLI

Abril amplía significativamente las capacidades de medición del ROI de Copilot. La API de métricas incluye ahora el merge rate y tiempo de merge de PRs revisadas por Copilot, conteo de usuarios activos del agente en la nube y actividad de Copilot CLI por usuario y organización. Visibilidad completa del ciclo de vida del PR: de la autoría agéntica a la revisión y el merge.

Sources:
→ Changelog: Copilot-reviewed pull request merge metrics now in the usage metrics API
→ Changelog: Copilot cloud agent fields added to usage metrics
→ Changelog: Copilot CLI activity now included in usage metrics totals and feature breakdowns

8. Claude Opus 4.7 GA y selección de modelo para agentes

Claude Opus 4.7 de Anthropic está ahora disponible de forma general en GitHub Copilot, con mejor rendimiento en tareas de varios pasos y razonamiento de largo alcance. Además, los administradores pueden configurar qué modelo impulsa los agentes Claude y Codex directamente desde github.com, con control granular sobre las capacidades desplegadas en los flujos agénticos de la organización.

Sources:
→ Changelog: Claude Opus 4.7 is generally available
→ Changelog: Model selection for Claude and Codex agents on github.com

📌 También este mes

  • El agente en la nube firma sus commits — Todos los commits del agente aparecen como Verified en GitHub, reforzando la trazabilidad y permitiendo su uso en repositorios con firma obligatoria.
  • Controles de runners por organización para el agente en la nube — Define runners predeterminados y bloquea la configuración a nivel de repositorio para un control operativo centralizado.
  • Resolución de conflictos de merge en tres clics con el agente en la nube — El nuevo botón "Fix with Copilot" en github.com delega la resolución de conflictos al agente, que verifica builds y tests antes de hacer push.
  • Bring Your Own Language Model Key (BYOK) en VS Code — Usuarios de Business y Enterprise pueden conectar sus propias claves de API de Anthropic, OpenAI, Gemini y otros proveedores directamente en VS Code.
  • El agente en la nube arranca un 20% más rápido — Mejora de rendimiento adicional para reducir los tiempos de espera en sesiones agénticas de alta frecuencia.
