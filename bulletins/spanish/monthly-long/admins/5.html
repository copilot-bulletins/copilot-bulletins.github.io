Monthly (Long) #5 · Julio 2026 · Admins Edition

🎯 El hilo de esta edición

Julio consolidó a Copilot como una plataforma gobernable a escala empresarial. El mes giró en torno a dos ejes: mayor visibilidad operativa —paneles de impacto, métricas por repositorio y ampliaciones de la API de uso— y un control financiero más granular con créditos de IA, presupuestos por usuario y topes en centros de coste. En paralelo, la gobernanza de modelos y los ajustes gestionados por la empresa maduraron hacia disponibilidad general. Para los administradores, esto significa herramientas concretas para medir adopción, contener gasto y estandarizar políticas.

⚠️ Atención

  • Gemini 2.5 Pro y Gemini 3 Flash retirados — En vigor: 31 de julio de 2026 — Ya no están disponibles en Copilot. Revise sus políticas de modelos y habilite alternativas.
  • La app de vista previa de facturación se retirará el 3 de agosto — Fecha límite: 3 de agosto de 2026 — Migre a la facturación estándar antes de esa fecha.

🚀 Pasa a la acción

  • Cuantifique el retorno de Copilot con el nuevo panel de impacto.
  • Contenga el gasto con presupuestos de facturación por uso y topes en centros de coste.
  • Estandarice la configuración de su organización con los ajustes gestionados por la empresa.
  • Revise su gobernanza de modelos y valore la selección automática por defecto.
  • ¿Preguntas o necesita apoyo? Contacte con su equipo de GitHub, estamos aquí para ayudar.

🏆 Top 8 de actualizaciones del mes

1. Métricas de uso más completas y verificables

Nuevo panel de impacto, métricas por repositorio en disponibilidad general, cobertura de la GitHub Copilot App en la API de uso, fases de adopción y ciclos de revisión, y mayor precisión en los informes. Un conjunto sólido para demostrar valor y guiar la adopción.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: GitHub Copilot app now available in the usage metrics API
→ Changelog: Add review cycles and time to adoption phases in the usage API

2. Control financiero granular con créditos de IA

Bolsas de créditos de IA y presupuestos por usuario para centros de coste, topes de uso incluido y límites de sesión de créditos en la CLI y el SDK. Los administradores contienen el gasto y asignan recursos con reglas claras por equipo.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: Cost centers now support included usage caps
→ Changelog: Set AI credit session limits in Copilot CLI and SDK

3. Gobernanza de modelos para empresas

Segmentación de políticas de modelo por equipos de empresa (vista previa), habilitación de modelos por defecto para Business y Enterprise, selección automática de modelo como predeterminada y disponibilidad general de settings.json gestionado. Más control central sobre qué modelos usan sus equipos.

Sources:
→ Changelog: Enterprise Teams model policy targeting in public preview
→ Changelog: Default model enablement for Copilot Business and Enterprise
→ Changelog: Enterprises can default to auto model selection
→ Changelog: Enterprise managed settings.json is generally available

4. Copilot code review madura y se personaliza

Agent skills y MCP en disponibilidad general, mejoras de personalización y configurabilidad, y revisiones de seguridad en la GitHub Copilot App. Los administradores pueden estandarizar criterios de revisión en toda la organización.

Sources:
→ Changelog: Copilot code review agent skills and MCP now generally available
→ Changelog: Copilot code review customization and configurability improvements
→ Changelog: Security reviews now available in the GitHub Copilot app

5. Autofix agéntico para alertas de code scanning

El autofix agéntico para alertas de code scanning entra en vista previa pública y propone correcciones automáticamente, acelerando la remediación de vulnerabilidades sin salir del flujo de trabajo habitual.

→ Changelog: Agentic autofix for code scanning alerts in public preview

6. Configuración gestionada y telemetría a escala

Distribución de ajustes gestionados vía MDM en VS Code y CLI, exportación de OpenTelemetry gestionada por la empresa, aplicación de ajustes a la GitHub Copilot App y límite del control remoto a dispositivos gestionados. Gobernanza coherente en todo el parque.

Sources:
→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI

7. La GitHub Copilot App, general y gobernable

La GitHub Copilot App queda disponible para todos y suma una política dedicada de acceso. Los administradores pueden controlar quién la usa y bajo qué condiciones, integrándola en su marco de políticas.

Sources:
→ Changelog: GitHub Copilot app available to all

Se suman Claude Opus 5, Grok 4.5, la familia GPT-5.6 (Sol, Terra y Luna), Gemini 3.6 Flash y Kimi K2.7. Más opciones para ajustar rendimiento, coste y cumplimiento por equipo mediante las políticas de modelos.
