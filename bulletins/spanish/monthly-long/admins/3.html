Monthly (Long) #3 · Mayo 2026 · Admins Edition

🎯 El hilo de esta edición

Mayo de 2026 marca el umbral de la transición a la facturación por uso de Copilot. Con los créditos de IA activos desde el 1 de junio, los administradores han contado este mes con herramientas inéditas: informes de consumo previo, métricas de madurez de adopción por equipo y fase, y reglas de modelos por organización. En paralelo, la gobernanza del cloud agent se ha reforzado con secretos centralizados, una API de auditoría y plugins gestionados para Copilot CLI. Mayo consolida el control sobre una plataforma en expansión acelerada.

⚠️ Atención

  • Claude Sonnet 4 deprecated — Efectivo desde el 6 de mayo — Claude Sonnet 4 fue retirado. Actualiza los flujos de trabajo para usar Claude Sonnet 4.6 y habilita el modelo de reemplazo en las políticas de Copilot de tu empresa. Grok Code Fast 1 fue igualmente retirado el 15 de mayo.

  • Upcoming deprecation of GPT-4.1, GPT-5.2, and GPT-5.2-Codex — Plazo: 1 de junio de 2026 — GPT-4.1 (→ GPT-5.5), GPT-5.2 (→ GPT-5.5) y GPT-5.2-Codex (→ GPT-5.3-Codex) se retiran hoy. Activa los modelos alternativos en las políticas de modelos de Copilot de tu empresa inmediatamente.

🚀 Pasa a la acción

  • Descarga el informe de uso de abril en créditos de IA para estimar el impacto presupuestario de la transición de facturación activa desde hoy.
  • Utiliza las métricas de Copilot por equipo para identificar equipos con baja adopción y planificar acciones de habilitación.
  • Crea reglas de modelos por organización para controlar qué modelos son accesibles en cada parte de tu empresa, incluidos Claude Opus 4.8 y Gemini 3.5 Flash.
  • Configura los estándares de plugins de empresa para Copilot CLI para distribuir agentes, configuraciones MCP y herramientas personalizadas a todos los usuarios.
  • Audita la configuración del cloud agent de tus repositorios mediante la API REST de configuración del cloud agent.
  • ¿Preguntas o necesitas soporte? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 8 de actualizaciones del mes

1. Facturación por uso: los informes de abril allanan el camino

Los administradores de Business y Enterprise pueden descargar el informe de consumo de abril traducido a créditos de IA — la nueva unidad de facturación vigente hoy, 1 de junio. El informe identifica principales consumidores, modelos y superficies de uso para ajustar presupuestos con datos reales antes del cambio.

→ Changelog: April reports are now available to prepare for usage-based billing

2. Métricas de adopción Copilot: por equipo y por fase de madurez

Dos actualizaciones consecutivas de la API de métricas amplían radicalmente la visibilidad. El desglose por equipos (14 de mayo) cruza la actividad por usuario con la pertenencia a equipos de la organización. Los cohortes de adopción (29 de mayo) clasifican a cada usuario en una de cuatro fases — code first, agent first o multi-agent — con métricas de productividad agregadas por cohorte.

Sources:
→ Changelog: Team-level Copilot usage metrics now available via API
→ Changelog: Copilot usage metrics API adds cohorts for AI adoption

3. Reglas de modelos por organización

Los administradores de empresa pueden crear reglas que permiten modelos específicos de Copilot a organizaciones concretas, superando el control global único. La interfaz de disponibilidad de modelos también se ha renovado para facilitar la configuración de modelos Enabled vs. Optional a nivel de organización.

→ Changelog: Target Copilot models to organizations with model rules

4. Plugins gestionados por empresa en Copilot CLI

Los administradores definen estándares de plugins en .github-private y estos se distribuyen automáticamente a todos los usuarios al autenticarse en Copilot CLI. Soporte para servidores MCP, agentes personalizados y hooks: una base de gobernanza coherente aplicada a escala, sin intervención manual por desarrollador.

→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview

5. Gobernanza del cloud agent: secretos centralizados y auditoría por API

Dos novedades complementarias refuerzan el control operativo. Los secretos y variables de tipo "Agents" se configuran a nivel de organización y se comparten en todos los repositorios. Una nueva API REST devuelve el perfil de seguridad de cada repositorio: servidores MCP habilitados, herramientas activas, política de Actions y estado del firewall.

Sources:
→ Changelog: More flexible secrets and variables for Copilot cloud agent
→ Changelog: Audit repository Copilot cloud agent configuration via the REST API

6. GPT-5.3-Codex como modelo base y llegada de Claude Opus 4.8 y Gemini 3.5 Flash

GPT-5.3-Codex (primer modelo LTS de Copilot, garantizado hasta febrero de 2027) reemplaza a GPT-4.1 como modelo base en todos los planes Business y Enterprise desde el 17 de mayo. Claude Opus 4.8 y Gemini 3.5 Flash se incorporan al catálogo en las últimas semanas del mes: ambos requieren activación explícita por parte del administrador en las políticas de modelos.

Sources:
→ Changelog: GPT-5.3-Codex is now the base model for Copilot Business and Enterprise
→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot
→ Changelog: Gemini 3.5 Flash is generally available for GitHub Copilot

7. Code review de Copilot: niveles de severidad y métricas por tipo de comentario

Las sugerencias de code review incluyen ahora etiquetas de severidad (High/Medium/Low) y se agrupan para reducir el ruido en las revisiones. La API de métricas añade copilot_suggestions_by_comment_type para medir el volumen y la tasa de adopción de sugerencias por categoría (seguridad, riesgo de errores, etc.) a nivel de empresa y organización.

Sources:
→ Changelog: Copilot code review comment experience improvements
→ Changelog: Copilot code review comment types now in usage metrics API

8. GitHub Copilot app en vista previa técnica: requisitos de activación

La nueva app de escritorio nativa de GitHub para desarrollo agéntico — sesiones aisladas, revisión de diffs, integración con pull requests y Agent Merge — ya está en vista previa técnica. En planes Business y Enterprise, los administradores deben activar "Previsualizaciones" y "Copilot CLI" en las políticas de empresa antes de que los usuarios puedan acceder.

→ Changelog: GitHub Copilot app is now available in technical preview

📊 El mes en cifras

  • +60 millones de revisiones de código procesadas por Copilot code review desde su lanzamiento, con un crecimiento de 10x en menos de un año
  • 1 de cada 5 revisiones de código en GitHub ya involucra a un agente

📌 También este mes

  • Remote control para sesiones de Copilot CLI, ahora disponible de forma general — Los administradores de Business y Enterprise deben habilitar las políticas de CLI y control remoto para que sus usuarios puedan controlar sesiones desde el móvil, la web o VS Code.
  • Copilot cloud agent ahora puede corregir fallos de Actions en un clic — El cloud agent investiga el fallo, aplica la corrección en rama y etiqueta al desarrollador para revisión; requiere cloud agent habilitado en la organización.
  • Modelos ligeros y económicos disponibles para el cloud agent — Claude Haiku 4.5 y GPT-5.4-mini (multiplicador 0.33x) permiten asignar tareas simples a un costo significativamente menor que los modelos de frontera.
  • Inicia tareas del cloud agent vía API REST — Las organizaciones pueden automatizar el despacho de tareas del agente desde portales de desarrolladores o pipelines internos (preview público).
  • Copilot Spaces API, ahora de disponibilidad general — Gestión programática de Spaces: creación, actualización, eliminación y gestión de colaboradores y recursos sin intervención manual.
  • Copilot Memory: más controles para administradores de repositorios — Los administradores de repositorios pueden desactivar Copilot Memory a nivel de repositorio para que no se almacenen ni lean hechos de contexto.
