Monthly (Long) #2 · Abril 2026 · Admins Edition

🎯 El hilo de esta edición

Abril de 2026 marca un punto de inflexión en la gobernanza de Copilot para las organizaciones. La próxima facturación de minutos de GitHub Actions para el Code Review exige planificación presupuestaria anticipada. En paralelo, la llegada del modelo GPT-5.5 y la función BYOK amplían las decisiones de configuración que recaen sobre los administradores. Las mejoras en la API de métricas de uso —con nuevos campos para el cloud agent y el Code Review— ofrecen la visibilidad granular necesaria para fundamentar decisiones de adopción y expansión con datos reales.

⚠️ Atención

  • GitHub Copilot Code Review consumirá minutos de GitHub Actions a partir del 1 de junio de 2026 — Fecha límite: 1 de junio de 2026 — Revisa tu consumo de Actions y prepara los presupuestos de tu organización con la documentación de facturación del Code Review antes de que entre en vigor la nueva facturación sobre repositorios privados.
  • Cambio de dominio en las URLs de descarga de métricas de uso de Copilot — Fecha límite: 20 de mayo de 2026 — Añade copilot-reports.github.com a la lista de permitidos de Copilot en los cortafuegos y proxies de tu organización antes de la migración.

🚀 Pasa a la acción

  • Activa la política de GPT-5.5 en los ajustes de políticas y modelos de tu organización para que los usuarios de Business y Enterprise puedan seleccionarlo.
  • Revisa la política de BYOK en VS Code desde la configuración de claves de API de tu organización (habilitada por defecto; puedes desactivarla si no deseas que los miembros usen claves propias).
  • Establece presupuestos para GitHub Actions en tu organización o empresa antes del 1 de junio para gestionar el consumo de minutos de Code Review.
  • Supervisa el panel de métricas de uso de Copilot para analizar la adopción del Code Review y del cloud agent con los nuevos campos disponibles.
  • ¿Tienes preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos para ayudarte.

🏆 Top 7 de actualizaciones del mes

1. Métricas de uso de Copilot enriquecidas: usuarios activos/pasivos en Code Review y seguimiento del cloud agent

La API de métricas de uso incorpora seis nuevos campos que distinguen entre usuarios activos y pasivos del Code Review, y el campo used_copilot_cloud_agent para identificar qué usuarios utilizan el agente cloud. Datos esenciales para medir el retorno de la inversión y planificar la expansión de licencias.

Sources:
→ Changelog: Copilot code review user counts now aggregate in usage metrics API
→ Changelog: Copilot cloud agent fields added to usage metrics

2. GPT-5.5 disponible en Copilot Business y Enterprise — los administradores deben activar la política

GPT-5.5, el último modelo de OpenAI, ya está disponible con un multiplicador de 7,5× sobre las solicitudes premium. Diseñado para tareas complejas y multipasos, supera a modelos anteriores en desafíos de código reales. Los administradores deben activar la política de GPT-5.5 en la configuración de modelos de la organización para que los usuarios puedan seleccionarlo.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

3. BYOK: trae tu propia clave de modelo de lenguaje en VS Code para Business y Enterprise

Los planes Business y Enterprise pueden configurar claves de API propias de proveedores como Anthropic, OpenAI, Azure o Google, disponibles en Copilot Chat de VS Code. La política está habilitada por defecto. El uso se factura directamente al proveedor elegido, sin contar contra las cuotas de Copilot, lo que amplía las opciones de gobernanza del modelo.

→ Changelog: Bring your own language model key in VS Code now available

4. Pausa en la incorporación automática de Copilot Business para organizaciones en planes Free y Team

GitHub ha pausado temporalmente los registros de autoservicio para GitHub Copilot Business en organizaciones bajo GitHub Free y GitHub Team. Los clientes existentes no se ven afectados y pueden seguir añadiendo licencias. Se comunicará cuándo se reanuden los nuevos registros; planifica la expansión de licencias en consecuencia.

→ Changelog: Pausing new self-serve signups for GitHub Copilot Business

5. GitHub Copilot para Jira: personalización organizativa avanzada del cloud agent

El conector de Jira incorpora instrucciones personalizadas a nivel de espacio —que definen repositorios, convenciones de nomenclatura y modelos por defecto—, soporte para campos personalizados de Atlassian, reglas de ramificación y agentes personalizados por ticket. Mayor integración del flujo de trabajo sin configuración repetitiva por cada ticket.

→ Changelog: GitHub Copilot for Jira: Our latest enhancements

6. Visibilidad y control de sesiones del cloud agent desde problemas y proyectos

Los administradores y líderes de equipo pueden ahora ver y dirigir sesiones activas del cloud agent directamente desde los problemas y tableros de proyectos de GitHub, sin salir del flujo de trabajo. Las sesiones del agente aparecen por defecto en todos los tableros, facilitando la supervisión de la actividad agéntica a escala organizativa.

→ Changelog: View and manage agent sessions from issues and projects

7. El agente cloud de Copilot arranca un 20% más rápido con imágenes personalizadas de Actions

Tras la mejora del 50% lograda en marzo, el cloud agent reduce aún más el tiempo de arranque gracias a entornos de ejecución preconfigurados con imágenes personalizadas de GitHub Actions. Menor latencia entre la asignación de una tarea y el inicio del trabajo del agente, lo que se traduce en ciclos de iteración más ágiles.

→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images
