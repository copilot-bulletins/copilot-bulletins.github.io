Monthly #4 · Junio 2026 · Devs Edition

🎯 El hilo de esta edición

En junio, Copilot afianzó el desarrollo agéntico en las herramientas que los desarrolladores ya usan a diario: la terminal, el escritorio y el IDE. Su madurez, sumada a una oferta de modelos más amplia y configurable, desplaza el foco de las funciones aisladas hacia flujos de trabajo autónomos, con más autonomía y elección sin cambiar de contexto.

⚠️ Atención

  • GPT-4.1 deprecated — Fecha límite: 1 de junio de 2026 — GPT-4.1 se retiró de todas las experiencias de Copilot; cambia a GPT-5.5 desde el selector de modelos de Copilot Chat.
  • GPT-5.2 and GPT-5.2-Codex deprecated — Fecha límite: 5 de junio de 2026 — migra a GPT-5.5 y GPT-5.3-Codex; revisa los modelos disponibles.
  • Upcoming deprecation of Opus 4.6 (fast) — Fecha límite: 29 de junio de 2026 — sustituye Opus 4.6 (fast) por Opus 4.8 (fast) en tus configuraciones.

🚀 Pasa a la acción

  • Instala la nueva Copilot CLI y ejecuta tus primeros flujos agénticos desde la terminal.
  • Descarga la app de escritorio de GitHub Copilot para macOS, Windows o Linux.
  • Compara los modelos disponibles y ajusta el modelo de chat según cada tarea.
  • Activa el agente de Copilot en tus IDE de JetBrains.
  • ¿Preguntas o necesitas ayuda? Contacta a tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones del mes

1. Copilot CLI alcanza la disponibilidad general con nueva interfaz

La nueva interfaz de terminal de Copilot CLI, presentada en Microsoft Build 2026, ya está en disponibilidad general con diseño por pestañas. El mes también trajo el comando /security-review, un panel unificado de /settings, soporte de modelos BYOK y entrada por voz.

Sources:
→ Changelog: Copilot CLI: New terminal interface is generally available
→ Changelog: Dedicated security review command now available in Copilot CLI
→ Changelog: Copilot CLI: Configure everything from one place with /settings
→ Changelog: Copilot CLI supports enterprise bring your own key (BYOK) models
→ Changelog: Copilot CLI: Improved UI, rubber duck, prompt scheduling, and voice input

2. Nueva oleada de modelos: Claude Sonnet 5, Opus 4.8 (fast) y más contexto

Más opciones para desarrolladores: Claude Sonnet 5 en disponibilidad general y Claude Opus 4.8 (fast mode) en vista previa con mayor velocidad. Copilot suma además ventanas de contexto de hasta un millón de tokens y niveles de razonamiento configurables para tareas más profundas.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot
→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot

3. La app de GitHub Copilot llega a disponibilidad general

La app de escritorio de GitHub Copilot ya está disponible para macOS, Windows y Linux. Es el hogar nativo del desarrollo dirigido por agentes: gestiona sesiones de agentes, issues y pull requests desde una experiencia construida sobre GitHub.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

4. El desarrollo agéntico da un salto: sandboxes, tareas programadas y API

El agente en la nube gana automatizaciones que se ejecutan por horario o eventos del repositorio, una API REST de tareas y un agent finder que selecciona herramientas y servidores MCP automáticamente. Los sandboxes locales y en la nube entran en vista previa pública.

Sources:
→ Changelog: Cloud and local sandboxes for GitHub Copilot now in public preview
→ Changelog: Schedule and automate tasks with Copilot cloud agent
→ Changelog: Agent tasks REST API now available for Copilot Pro, Pro+, and Max
→ Changelog: Agent finder for GitHub Copilot now available
→ Changelog: GitHub Agentic Workflows is now in public preview

5. Copilot se integra más a fondo en los IDE de JetBrains

JetBrains AI Assistant y GitHub Copilot estrechan su integración: el agente de Copilot ya está disponible dentro de AI Assistant. El mes también incorporó Claude como proveedor de agentes en vista previa y llevó Copilot CLI y capacidades agénticas a los IDE de JetBrains.

Sources:
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs
→ Changelog: Introducing Copilot CLI and agentic capabilities enhancements in JetBrains IDEs
