🎯 El hilo de esta edición

Mayo marca el mes de la plataforma agéntica distribuida: la app nativa de escritorio de Copilot, el control remoto de sesiones desde cualquier dispositivo y la expansión de la selección automática de modelos en VS Code consolidan un giro fundamental. Copilot no es ya solo un asistente en el editor: es una superficie de trabajo que actúa aunque no estés frente al teclado.

  • Prueba Fix with Copilot en tu próxima revisión de código para aplicar sugerencias del cloud agent directamente sobre tu PR con un solo clic.
  • ¿Tienes preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones del mes

1. La app de GitHub Copilot llega en preview técnica

La app de Copilot es una aplicación de escritorio nativa diseñada para el desarrollo agéntico: inicia sesiones desde issues o PRs, ejecuta múltiples agentes en paralelo sobre ramas separadas y revisa diffs antes de enviar a GitHub. Disponible para Business y Enterprise (con previews y Copilot CLI habilitados); lista de espera para Pro y Pro+.

→ Changelog: GitHub Copilot app is now available in technical preview

2. Control remoto de sesiones Copilot: disponibilidad general

Arranca una sesión en VS Code o en Copilot CLI, activa /remote on y monitorea su progreso desde github.com o GitHub Mobile en tiempo real. También puedes enviar instrucciones adicionales y aprobar permisos desde el teléfono, sin estar delante del portátil. Disponible para todos los planes de pago.

→ Blog: Take your local GitHub sessions anywhere

3. Claude Opus 4.8 disponible en Copilot

Claude Opus 4.8, el último modelo de Anthropic, llega a Copilot con mejoras notables en comprensión de código y razonamiento complejo. Disponible en VS Code, JetBrains, CLI, cloud agent y la nueva app de Copilot para planes Pro+, Business y Enterprise. Multiplicador de solicitudes premium: 15x.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

4. Selección automática de modelos: ahora enruta por tarea en VS Code

La selección automática de modelos en VS Code evalúa la complejidad de tu tarea —razonamiento, generación de código, depuración— para elegir el modelo óptimo en tiempo real. Funciona en chat, modo agente y completado, con transparencia sobre qué modelo se usó en cada respuesta. Incluye un 10% de descuento sobre el multiplicador del modelo seleccionado.

→ Changelog: Auto model selection now routes based on your task in VS Code

5. "Fix with Copilot": aplica sugerencias de code review directamente con el cloud agent

El botón "Implement suggestion" se ha renombrado a Fix with Copilot y ahora abre un diálogo donde puedes elegir modelo, añadir instrucciones y decidir si el fix va al PR actual o a uno nuevo. El nuevo botón Fix batch with Copilot permite delegar múltiples comentarios a la vez al cloud agent para resolverlos en una sola tarea.

→ Changelog: Easily apply Copilot code review feedback with Copilot cloud agent
