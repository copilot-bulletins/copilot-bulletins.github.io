Monthly #8 · Octubre 2026 · Devs Edition

🎯 El hilo de esta edición

Octubre, marcado por GitHub Universe, consolida a Copilot como un sistema de agentes y no solo como un asistente en el editor. La selección de modelos, la ejecución en la nube y la integración con herramientas externas se automatizan cada vez más. Para los desarrolladores, esto implica delegar tareas completas y dedicar más tiempo a revisar y decidir.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Fecha límite: 16 de noviembre de 2026 — Claude Opus 4.8, Claude Opus 5 y GPT-5.6 Terra se retiran; migra a las alternativas indicadas en los modelos compatibles.
  • GitHub Copilot in Visual Studio — September update — Acción requerida — BYOM ahora requiere el nuevo Agent (Preview); los modos Ask y Agent anteriores ya no lo admiten y los modelos de Ollama deben volver a añadirse.

🚀 Pasa a la acción

  • Selecciona Copilot Fusion en el selector de modelos y elige el nivel de esfuerzo según la tarea con la guía About GitHub Copilot Fusion.
  • Activa «Watch and fix» en tus pull requests siguiendo la guía de Agent Merge.
  • Conecta Slack, Figma o Sentry una sola vez con los conectores de Copilot.
  • Protege tus sesiones de agente locales con el sandboxing local.
  • ¿Preguntas o necesitas ayuda? Contacta a tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones del mes

1. Copilot Fusion: deja de elegir modelo manualmente

Copilot Fusion ya está disponible de forma general: eliges un nivel de esfuerzo (Standard, High o Max) y Copilot enruta u orquesta varios modelos por tarea. En vista previa experimental, también puede usar modelos locales en CLI, la app y VS Code.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot Fusion now supports selection of local models

2. Copilot app: proyectos multi-repo y sesiones continuas

Los proyectos (vista previa pública) agrupan contexto, agentes y resultados de un trabajo que abarca varios repositorios. La continuidad de sesión permite iniciar una tarea en la nube desde el móvil y retomarla en VS Code, CLI o github.com sin perder el hilo.

Sources:
→ Changelog: GitHub Copilot app, Universe releases
→ Changelog: GitHub Copilot in VS Code, Universe releases
→ Changelog: Work from anywhere with a new, connected Copilot cloud experience

3. De la revisión al merge: code review Max y Agent Merge

El nuevo nivel Max de code review (vista previa pública) combina varios agentes revisores con modelos de distintos proveedores, y las aprobaciones de Copilot ya son GA. Agent Merge vigila tu PR y corrige workflows fallidos o conflictos de merge en la nube.

Sources:
→ Changelog: Copilot code review: Merge with confidence with Max and approvals
→ Changelog: Agent Merge watches and fixes pull requests in the cloud

4. Copilot Automations compartidas y que aprenden

Las automatizaciones combinan prompts, triggers y herramientas para ejecutar flujos en la nube, por ejemplo, reproducir un bug al abrirse un issue. Ahora pueden compartirse con el equipo, crearse desde VS Code y proponer mejoras basadas en sus resultados.

Sources:
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: Copilot Automations now learn from outcomes and self-improve
→ Changelog: Create and manage Copilot Automations in Visual Studio Code

5. Conectores: MCP verificados sin configuración

Los servidores MCP verificados por GitHub (vista previa pública) permiten conectar 26 servicios, como Slack, Figma, Notion o Sentry, iniciando sesión una sola vez. Funcionan en la app, CLI, VS Code, Copilot en la nube y GitHub Mobile, sin instalar nada localmente.

→ Changelog: Connect your tools to Copilot without all the setup
