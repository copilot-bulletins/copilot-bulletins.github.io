🎯 El hilo de esta edición

Septiembre consolidó a Copilot como plataforma multimodelo y agéntica. Llegaron nuevos modelos de OpenAI, Anthropic, Google y xAI, junto con mejoras profundas en la app de Copilot, VS Code y JetBrains. Para quienes programan, el mensaje es claro: más opciones de modelo, mejor comprensión del código y ejecución agéntica más segura y controlable en el día a día.

🏆 Top 5 de actualizaciones del mes

1. Una oleada de nuevos modelos para cada tarea

Septiembre amplió enormemente el catálogo: GPT-6.1 Sol para flujos agénticos y de terminal, Claude Sonnet 5.5 y Claude Opus 5.5, GPT-6 Sol y GPT-6 Luna, y Grok 4.7. Ahora puedes ajustar coste, calidad y velocidad según la complejidad de cada tarea.

Sources:
→ Changelog: GPT-6.1 Sol in GitHub Copilot
→ Changelog: Claude Sonnet 5.5 in GitHub Copilot
→ Changelog: Configure cost and quality in Copilot auto model selection

2. HydraFusion llega a VS Code y a la app de Copilot

La vista previa de investigación HydraFusion se expande más allá de Copilot CLI y aparece ahora en el selector de modelos de VS Code y la app de Copilot. Su enfoque de fusión busca respuestas más robustas directamente en tu entorno de desarrollo habitual.

→ Changelog: HydraFusion in VS Code and the GitHub Copilot app

3. Sandboxing local en la app de Copilot

El sandboxing local reduce el impacto de comandos no deseados limitando el acceso a archivos, red y credenciales de tu máquina. Se configura por proyecto para sesiones sobre repositorios y árboles de trabajo locales, dando más confianza a los flujos agénticos.

→ Changelog: Local sandboxing in the GitHub Copilot app

4. Inteligencia de código C++ más rápida con indexación completa

La inteligencia de código C++ en Copilot CLI ahora es más rápida gracias a la indexación de todo el repositorio. Los proyectos C++ con millones de líneas y archivos profundamente conectados obtienen contexto más preciso y respuestas más certeras.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

5. Novedades en Copilot para JetBrains 1.18.0

La versión 1.18.0 incorpora aprobaciones de herramientas asistidas por IA, mayor control sobre las conversaciones del agente y habilidades e instrucciones compartidas para tu organización. También puedes revisar planes antes de ejecutarlos, mejorando la supervisión del trabajo agéntico.

→ Changelog: New features and improvements in Copilot for JetBrains
