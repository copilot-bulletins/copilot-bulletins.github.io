Monthly #2 · Abril 2026 · Devs Edition

🎯 El hilo de esta edición

Abril sienta las bases de una nueva etapa: Copilot ya no es un asistente ligado a un único IDE. Las capacidades agénticas llegan a VS Code, Visual Studio y JetBrains con el mismo nivel de autonomía, mientras GPT-5.5 y Claude Opus 4.7 elevan el techo de rendimiento disponible en cada uno de ellos.

⚠️ Atención

  • GitHub Copilot code review consumirá minutos de GitHub Actions desde el 1 de junio — Fecha límite: 1 de junio de 2026 — Cada revisión de código en repositorios privados comenzará a consumir minutos de Actions; revisa tu presupuesto y ajusta los límites de gasto con la documentación de facturación.
  • Cambios en los planes de Copilot para individuos — Acción requerida — Los modelos Opus han sido eliminados del plan Pro y los límites de uso se han reducido; si no estás de acuerdo, puedes cancelar y solicitar un reembolso hasta el 20 de mayo de 2026.

🚀 Pasa a la acción

  • Selecciona GPT-5.5 o Claude Opus 4.7 en el selector de modelos de Copilot para tus tareas de codificación más complejas.
  • Activa la selección automática de modelo en la CLI para ahorrar un 10% en el multiplicador de peticiones premium.
  • Conecta tu proveedor de LLM preferido en VS Code con BYOK: Anthropic, OpenAI, Gemini u Ollama, sin consumir tu cuota de Copilot.
  • Controla tus sesiones de agente CLI desde cualquier dispositivo con acceso remoto.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones del mes

1. GPT-5.5 y Claude Opus 4.7 disponibles en GitHub Copilot

GPT-5.5 es el modelo más potente de OpenAI para tareas agénticas complejas, ahora disponible en todos los entornos de Copilot. Claude Opus 4.7 llega en el mismo mes y sustituirá progresivamente a Opus 4.5 y 4.6 en el selector de modelos.

Sources:
→ Changelog: GPT-5.5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.7 is generally available

2. VS Code: modo Autopilot y BYOK

VS Code estrena el modo Autopilot (preview): el agente aprueba sus propias acciones y trabaja de forma autónoma hasta completar la tarea. Además, Business y Enterprise ya pueden usar BYOK para conectar modelos de Anthropic, OpenAI, Gemini u Ollama directamente en VS Code Chat.

Sources:
→ Changelog: GitHub Copilot in Visual Studio Code, March Releases
→ Changelog: Bring your own language model key in VS Code now available

3. JetBrains: modo agente en el chat inline

El modo agente llega al chat inline de JetBrains en public preview: ejecuta tareas agénticas sin abandonar el editor. También llegan Next Edit Suggestions con previsualizaciones inline y saltos a ediciones lejanas, y nuevas opciones de auto-aprobación global con controles granulares para terminales y archivos.

→ Changelog: Inline agent mode in preview and more in GitHub Copilot for JetBrains IDEs

4. Visual Studio 2026 – actualización de abril

La actualización de abril integra el cloud agent en Visual Studio: elige «Cloud» en el selector de agentes y el cloud agent crea el issue y el PR mientras sigues trabajando. También llega un agente depurador que reproduce bugs, instrumenta el código en tiempo real y propone correcciones.

→ Changelog: GitHub Copilot in Visual Studio — April update

5. Copilot CLI: selección automática de modelo y MCP allowlists

La CLI soporta ahora auto model selection (GA): Copilot elige el modelo más eficiente en tiempo real con un 10% de descuento en el multiplicador para planes de pago. Las allowlists de MCP basadas en registro permiten controlar qué servidores MCP pueden usar los agentes CLI según políticas propias.

Sources:
→ Changelog: GitHub Copilot CLI now supports Copilot auto model selection
→ Changelog: Copilot CLI supports custom registry based MCP allowlists
