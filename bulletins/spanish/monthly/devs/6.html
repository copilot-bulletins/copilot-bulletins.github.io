Monthly #6 · Agosto 2026 · Devs Edition

🎯 El hilo de esta edición

Agosto giró en torno a la elección: nuevos modelos, más superficies de trabajo (IDE, CLI, JetBrains) y agentes más configurables. Para quienes desarrollan, el mensaje es claro: Copilot se adapta a tu flujo, no al revés. Elegir el modelo y el nivel de esfuerzo adecuados para cada tarea se vuelve parte del día a día.

⚠️ Atención

  • Upcoming deprecation of MAI-Code-1-Flash — Fecha límite: 10 de septiembre de 2026 — Migra tus flujos a MAI-Code-1.1-Flash y confirma su disponibilidad en tu configuración de modelos.
  • Upcoming deprecation of GitHub Spark on github.com — Fecha límite: 31 de agosto de 2026 — Exporta antes de esa fecha las apps que hayas creado en Spark; las ya desplegadas seguirán funcionando.
  • Upcoming changes to GitHub Copilot policies and billing — Acción requerida — El nivel de esfuerzo por defecto de code review pasa a Balanced; revisa el impacto en tus revisiones automáticas.

🚀 Pasa a la acción

  • Prueba los nuevos modelos (Grok 4.6, Gemini 3.7 Flash, Kimi K3) desde el selector de modelos y compara resultados por tipo de tarea.
  • Configura el nivel de esfuerzo de Copilot code review para equilibrar profundidad y rapidez en tus PRs.
  • Amplía Copilot Chat con servidores MCP para conectar tus herramientas favoritas.
  • Delega tareas de fondo al agente de programación ajustando su nivel de razonamiento.
  • ¿Tienes preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones del mes

1. Más modelos para elegir

Agosto sumó una tanda de modelos a Copilot: Grok 4.6, Gemini 3.7 Flash, Kimi K3 y MAI-Code-1.1-Flash. Más opciones significan poder ajustar velocidad, coste y calidad de razonamiento a cada tarea directamente desde el selector de modelos.

→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot
→ Changelog: Kimi K3 is now available in GitHub Copilot
→ Changelog: MAI-Code-1.1-Flash available in GitHub Copilot

2. Actualizaciones en VS Code y Visual Studio

Las entregas de agosto para VS Code y Visual Studio traen mejoras al modo agente, al chat y a la experiencia diaria de codificación. Si trabajas en estos IDEs, merece la pena revisar las novedades y activar lo que encaje en tu flujo.

Sources:
→ Changelog: GitHub Copilot in VS Code, August 2026 releases
→ Changelog: GitHub Copilot in Visual Studio — August update

3. Agent Plugins 1.0 en VS Code, Copilot CLI y la app

Agent Plugins 1.0 llega a VS Code, Copilot CLI y la app de Copilot con un formato unificado para extender las capacidades del agente. Empaqueta y reutiliza herramientas y contexto de forma coherente en todas tus superficies de trabajo.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

4. Copilot para JetBrains sube de nivel

JetBrains recibe el harness de agente en disponibilidad general, además de memoria de Copilot y soporte de Ollama para modelos locales. Los desarrolladores en IntelliJ y familia obtienen una experiencia agéntica más completa y flexible.

Sources:
→ Changelog: Copilot harness generally available in Copilot for JetBrains
→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains

5. Copilot code review, más ajustable

Los niveles de esfuerzo de Copilot code review pasan a disponibilidad general, y las revisiones ahora incluyen razones de resolución y capacidades ampliadas. Puedes calibrar cuánta profundidad quieres en cada PR sin ruido innecesario.

Sources:
→ Changelog: Copilot code review effort levels are generally available
→ Changelog: Copilot code review: Resolution reasons and expanded capabilities
