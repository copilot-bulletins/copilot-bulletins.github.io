🎯 El hilo de esta edición

Julio consolidó a Copilot como plataforma agéntica: una oleada de nuevos modelos (Claude Opus 5, GPT-5.6, Grok 4.5) convive con capacidades extensibles vía MCP y agent skills que llegan a producción. Para quienes desarrollan, el mensaje es claro: elegir el modelo adecuado y conectar herramientas propias ya no es experimental, sino parte del flujo diario de trabajo.

🏆 Top 5 de actualizaciones del mes

1. Más modelos de frontera para cada tarea

Julio amplió el catálogo con Claude Opus 5, GPT-5.6, Grok 4.5, Gemini 3.6 Flash y Kimi K2.7. Cada modelo destaca en escenarios distintos —desde tareas agénticas de larga duración hasta respuestas rápidas—, así que puedes elegir el equilibrio ideal entre potencia y latencia.

Sources:
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: OpenAI's GPT-5.6, Sol, Terra, and Luna are now available in GitHub Copilot
→ Changelog: Grok 4.5 is now available in GitHub Copilot

2. Code review con agent skills y MCP, ya en general

La revisión de código de Copilot ahora admite agent skills y servidores MCP de forma general para Pro, Pro+, Business y Enterprise. Puedes incorporar las herramientas, estándares y contexto externo de tu equipo directamente en cada revisión, sin configuración adicional si ya los usabas en preview.

→ Changelog: Copilot code review agent skills and MCP now generally available

3. El servidor GitHub MCP adopta la nueva especificación

El protocolo MCP pasa a ser sin estado y el servidor GitHub MCP ya soporta la última especificación. Gracias a la compatibilidad hacia atrás de los SDK tier 1, no necesitas hacer nada para mantener el funcionamiento, y ganas validación estricta y pruebas de conformidad oficiales.

→ Changelog: GitHub MCP server supports the next MCP specification

4. Copilot CLI más autónomo

Copilot CLI incorpora selección automática de modelo según la tarea, deja de requerir un token personal en GitHub Actions y suma una nueva skill de configuración de language server para C. Menos fricción para automatizar flujos desde la terminal y en CI.

Sources:
→ Changelog: Copilot CLI auto model selection routes based on task
→ Changelog: Copilot CLI no longer needs a personal access token in GitHub Actions
→ Changelog: New C language server config skill for Copilot CLI

5. Copilot vision, ya disponible para todos

Copilot vision es general y está activo por defecto para todos los suscriptores. Adjunta imágenes y PDFs a tus prompts para que Copilot razone sobre diagramas, capturas o maquetas junto a tu código, sin cambios de política ni acciones de administrador.

→ Changelog: Copilot vision is generally available
