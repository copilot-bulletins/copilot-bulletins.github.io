🏆 Top 5 de actualizaciones del mes

1. Medición de uso e impacto más completa

Copilot amplió sus capacidades de medición para administradores: un panel de impacto, métricas a nivel de repositorio en disponibilidad general y datos de uso de la app agregados en los resúmenes de informes. Permite justificar la inversión y detectar dónde falta adopción.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: GitHub Copilot app usage metrics now expand across report rollups

2. Configuración gestionada de forma centralizada

Los ajustes gestionados para empresas (managed-settings.json) alcanzaron disponibilidad general, con despliegue vía MDM en VS Code y CLI, y exportación gestionada de OpenTelemetry. Los administradores pueden imponer configuración coherente y recopilar telemetría en toda la organización de forma controlada.

Sources:
→ Changelog: Enterprise managed settings JSON is generally available
→ Changelog: Deploy managed Copilot settings via MDM in VS Code and CLI
→ Changelog: Enterprise-managed OpenTelemetry export for VS Code and CLI

3. Revisión de código y seguridad reforzadas

La revisión de código de Copilot sumó habilidades de agente y soporte MCP en disponibilidad general, las revisiones de seguridad llegaron a la app de Copilot y el autofix agéntico para alertas de escaneo de código entró en vista previa pública. Un paso firme hacia controles de seguridad más automatizados.

Sources:
→ Changelog: Copilot code review agent skills and MCP now generally available
→ Changelog: Security reviews now available in the GitHub Copilot app
→ Changelog: Agentic autofix for code scanning alerts in public preview

4. Gobernanza de costes más granular

La gestión del gasto ganó precisión: grupos de créditos de IA para centros de coste, presupuestos por usuario en la interfaz de facturación y topes de uso incluido en los centros de coste. Los administradores pueden asignar y limitar el consumo de IA con mayor exactitud por equipo y persona.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: Cost centers now support included usage caps

5. Políticas de modelos para empresas

El control sobre qué modelos usan los equipos se refinó: habilitación de modelos por defecto para Copilot Business y Enterprise, segmentación de políticas de modelos por equipos empresariales en vista previa pública, y la opción de que las empresas usen por defecto la selección automática de modelo.

Sources:
→ Changelog: Default model enablement for Copilot Business and Enterprise
→ Changelog: Enterprise teams model policy targeting in public preview
→ Changelog: Enterprises can default to auto model selection
