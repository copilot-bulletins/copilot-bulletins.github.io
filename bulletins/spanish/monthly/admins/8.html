Monthly #8 · Octubre 2026 · Admins Edition

🎯 El hilo de esta edición

Octubre consolida la gobernanza centralizada de Copilot. Las licencias se simplifican en torno a un presupuesto de empresa, las políticas por defecto y de modelos se vuelven programables, y los agentes locales quedan sujetos a controles que el desarrollador no puede debilitar. Para los administradores, esto significa menos configuración manual y más visibilidad sobre el uso real.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Deadline: 16 de noviembre de 2026 — Claude Opus 4.8, Claude Opus 5 y GPT-5.6 Terra se retiran; confirma que las alternativas están habilitadas en tus políticas de modelos.
  • GitHub Copilot models deprecated on October 19, 2026 — Action required — GPT-5.5, GPT-5.4, GPT-5 mini y otros ya no están disponibles; actualiza flujos e integraciones según los modelos compatibles.
  • Enterprise managed settings enforcement updates — Action required — Si usas la clave sandbox, los clientes anclados a versiones antiguas deberán actualizarse para seguir usando Copilot; revisa el despliegue de la configuración gestionada.

🚀 Pasa a la acción

  • Revisa tu política global en AI Controls → Copilot y entiende su efecto con la guía de disponibilidad por defecto.
  • Evalúa el nuevo modelo de acceso consultando qué cambia con GitHub Enterprise y Copilot.
  • Exige el sandbox local y las restricciones de permisos mediante la configuración gestionada por la empresa.
  • Activa la comparación con el sector en el panel de impacto de Copilot.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones del mes

1. Copilot incluido en GitHub Enterprise

Las empresas que trabajan con un equipo de cuentas de GitHub o Microsoft pueden incluir Copilot para cada usuario con licencia de GitHub Enterprise. Ya no se gestionan puestos: el uso de IA se mide contra el presupuesto de la empresa con las políticas y alertas existentes.

→ Changelog: GitHub Enterprise now includes access to GitHub Copilot

2. Políticas por defecto y de modelos, ahora aplicadas y programables

La política global por defecto se aplica a las funciones sin configurar en Copilot Business y Enterprise. Además, nuevos endpoints REST permiten leer y modificar las políticas de modelos a nivel de empresa, equipos, apps de agentes y organizaciones.

Sources:
→ Changelog: Global default for Copilot features generally available
→ Changelog: Copilot model policy API for enterprise, orgs, and teams

3. Controles empresariales para agentes locales

El sandbox local, los permisos asistidos y los controles de plugins alcanzan disponibilidad general. Mediante la configuración gestionada puedes exigir el sandbox, bloquear el modo «Allow All», y requerir o bloquear plugins y marketplaces aprobados.

Sources:
→ Changelog: Local sandboxing for GitHub Copilot now generally available
→ Changelog: GitHub Copilot assisted permissions generally available
→ Changelog: Repository plugin defaults and enterprise plugin controls generally available

4. Métricas de uso más completas y comparables

El panel de impacto incorpora comparaciones opcionales con el sector por tamaño de empresa e industria. La API de métricas añade el desglose por cliente (OpenCode, Claude Code, Codex...) y muestra los nombres de skills, agentes y servidores MCP personalizados.

Sources:
→ Changelog: Industry comparisons in the Copilot impact dashboard
→ Changelog: Usage metrics API adds usage from tools like OpenCode
→ Changelog: Custom skills, agents, and MCP servers in usage metrics API

5. Seguridad: detección de secretos y autofix agéntico

Un modelo específico mejora la detección de secretos sin formato reconocible, incluido sin coste en GHSP y GHAS. El autofix agéntico para alertas de code scanning ya está disponible: valida la corrección con CodeQL antes de abrir un pull request.

Sources:
→ Changelog: Purpose-built model for leaked secret detection
→ Changelog: Agentic autofix for code scanning alerts general availability
