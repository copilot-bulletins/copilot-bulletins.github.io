Monthly #7 · Septiembre 2026 · Admins Edition

🎯 El hilo de esta edición

Septiembre consolidó el control empresarial sobre Copilot. Los nuevos ajustes gestionados, los permisos sobre operaciones de agentes y la ampliación de las métricas de uso dan a los administradores más capacidad para gobernar la adopción, acotar costes y auditar el impacto. Para equipos de plataforma y seguridad, el mensaje es claro: la gobernanza escala al mismo ritmo que las capacidades.

🏆 Top 5 de actualizaciones del mes

1. Gobernanza empresarial más granular

Los administradores pueden ahora fijar permisos para las operaciones de agentes, imponer cualquier modelo predeterminado mediante ajustes gestionados, validar configuraciones antes de aplicarlas y ofrecer un sandbox gestionado en JetBrains. Un conjunto coherente de controles para desplegar Copilot con límites claros.

Sources:
→ Changelog: Enterprise managed permissions for GitHub Copilot agent operations
→ Changelog: Enterprise managed settings support any default model
→ Changelog: Enterprise managed settings in product validator
→ Changelog: Enterprise managed sandbox in Copilot for JetBrains

2. Métricas de uso e impacto ampliadas

El panel de impacto ahora muestra el engagement por función y la API de métricas incorpora las etapas de revisión de pull requests, los agentes de VS Code y las personalizaciones de la CLI agéntica. Mayor visibilidad para medir adopción real y justificar la inversión.

Sources:
→ Changelog: Copilot impact dashboard now shows feature engagement
→ Changelog: Usage metrics API adds pull request review stages
→ Changelog: Add VS Code agents to Copilot usage metrics
→ Changelog: Agentic CLI customizations now in the usage metrics API

3. Controles de presupuesto y coste

La ampliación de presupuestos pasa a estar disponible de forma general, se pueden fijar fechas de caducidad para presupuestos individuales y configurar coste y calidad en la selección automática de modelo. Herramientas concretas para acotar el gasto sin frenar la productividad.

Sources:
→ Changelog: Copilot budget increase requests are generally available
→ Changelog: Set an expiration date for individual user budgets
→ Changelog: Configure cost and quality in Copilot auto model selection

4. Exclusiones de contenido disponibles en la app y la CLI

Las exclusiones de contenido alcanzan disponibilidad general en la app de Copilot y en la CLI. Los administradores pueden impedir que archivos y rutas sensibles se usen como contexto, reforzando el cumplimiento y la protección de datos en todas las superficies.

→ Changelog: Content exclusions generally available in Copilot app and CLI

5. Copilot Code Review madura como control de calidad

Copilot Code Review puede aprobar pull requests, resolver y analizar comentarios automáticamente, y ofrece más formas de solicitar y configurar revisiones junto a una experiencia mejorada. Para la gobernanza del código, amplía la cobertura de revisión sin sumar carga manual.

Sources:
→ Changelog: Copilot code review can now approve pull requests
→ Changelog: Auto-resolution and analysis updates in Copilot code review
→ Changelog: Copilot code review: more ways to request and configure reviews
→ Changelog: Copilot code review: an improved review experience
