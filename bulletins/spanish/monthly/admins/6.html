Monthly #6 · Agosto 2026 · Admins Edition

🎯 El hilo de esta edición

Agosto consolidó el control empresarial de Copilot. Las novedades giraron en torno a la gobernanza a escala: aplicación de políticas de modelos, ampliación de la configuración administrada empresarial y mayor visibilidad de consumo y retorno. Para los administradores, el mensaje es claro: estandarizar, medir y justificar el uso de Copilot es cada vez más gestionable desde controles centralizados.

🏆 Top 5 de actualizaciones del mes

1. La política global de modelos ya está disponible de forma general

Copilot Business y Enterprise pueden aplicar una política de modelos predeterminada para todos los modelos disponibles de forma general. La aplicación se despliega gradualmente hasta el 1 de septiembre; los modelos nuevos y sin configurar heredan el estado global, dando a los administradores control duradero y consistente.

→ Changelog: Global model policy generally available

2. La configuración administrada empresarial se amplía

La configuración administrada empresarial gana alcance: listas de permitidos y denegados de servidores MCP, soporte en JetBrains, autoactualización de plugins de marketplaces y especialización por equipos. En conjunto, los administradores obtienen controles más granulares y coherentes en todas las superficies.

Sources:
→ Changelog: MCP allowlists in enterprise managed settings
→ Changelog: Enterprise managed settings in GitHub Copilot for JetBrains
→ Changelog: Enterprise managed settings now support autoupdate for plugin marketplaces
→ Changelog: Enterprise team specialization for managed settings

3. Copilot code review refuerza su gobernanza

Copilot code review ahora revisa pull requests de bots (incluido el agente en la nube) y PRs muy grandes, e incorpora motivos de resolución de comentarios. Además, los niveles de esfuerzo son de disponibilidad general, permitiendo estandarizar la profundidad de revisión por organización.

Sources:
→ Changelog: Copilot code review: Resolution reasons and expanded capabilities
→ Changelog: Copilot code review effort levels are generally available

4. Mayor visibilidad del consumo de IA

El informe de uso ahora desglosa los tokens por modelo (entrada, salida, lectura y escritura de caché) junto a los créditos de IA consumidos. Combinado con la actividad de agentes en la API de métricas de uso, los administradores pueden explicar cargos y optimizar costes con datos precisos.

Sources:
→ Changelog: Per-model token breakdown in the usage report
→ Changelog: Copilot usage metrics API adds agent app activity

5. El panel de impacto añade retorno de inversión

El panel de impacto de Copilot incorpora una sección de retorno de inversión potencial que conecta el gasto con la producción de pull requests. Dos tarjetas comparan a los desarrolladores según su nivel de adopción, ayudando a los administradores a justificar la inversión ante sus responsables.

→ Changelog: Copilot impact dashboard adds a return on investment section
