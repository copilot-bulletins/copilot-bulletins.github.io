Monthly #3 · Abril 2026 · Admins Edition

🎯 El hilo de esta edición

En abril, GitHub Copilot avanzó hacia un modelo de facturación por consumo: los cambios en el code review, la llegada de GPT-5.5 con habilitación explícita por parte del administrador, y las nuevas métricas de uso consolidan una plataforma donde la gobernanza empresarial cobra protagonismo. Visibilidad, control y responsabilidad van de la mano.

⚠️ Atención

  • La revisión de código de Copilot consumirá minutos de GitHub Actions desde el 1 de junio de 2026 — Deadline: 1 de junio de 2026 — Revise el consumo actual de Actions de su organización y configure límites de gasto antes de esa fecha; comparta el aviso con sus administradores de facturación.
  • Cambio de dominio en las URL de descarga de métricas de uso de Copilot — Deadline: 20 de mayo de 2026 — Si su organización usa firewall o proxy, agregue copilot-reports.github.com a su lista de dominios permitidos antes de esta fecha.

🚀 Pasa a la acción

  • Habilite GPT-5.5 para su organización o empresa en la configuración de políticas de modelos de Copilot.
  • Actualice su lista de dominios permitidos para incluir copilot-reports.github.com antes del 20 de mayo de 2026. Consulte la referencia de allowlist de Copilot.
  • Evalúe si habilitar o deshabilitar BYOK (traiga su propia clave de modelo de lenguaje) para su organización. Más información en la documentación de BYOK para organizaciones.
  • Migre sus integraciones de used_copilot_coding_agent al nuevo campo used_copilot_cloud_agent en la API de métricas de uso antes del 1 de agosto de 2026.
  • ¿Preguntas o necesita soporte? Contacte a su equipo de GitHub, estamos aquí para ayudar.

🏆 Top 5 de actualizaciones del mes

1. GPT-5.5 disponible en Copilot: requiere habilitación por el administrador

GPT-5.5, el modelo más potente de OpenAI disponible en GitHub Copilot, ya está en despliegue progresivo para Business y Enterprise. Los administradores deben habilitarlo explícitamente en la configuración de políticas de modelos. Tenga en cuenta que incluye un multiplicador premium de 7,5x en la facturación por consumo.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

2. BYOK: traiga su propia clave de modelo de lenguaje en VS Code

Los usuarios de Copilot Business y Enterprise ahora pueden conectar sus propias claves de API (Anthropic, OpenAI, Azure, Gemini, xAI y más) directamente en VS Code. La función está habilitada por defecto; los administradores pueden deshabilitarla en la configuración de políticas de Copilot.

→ Changelog: Bring your own language model key in VS Code now available

3. Métricas de revisión de código: nuevos conteos de usuarios activos y pasivos

La API de métricas de uso suma seis nuevos campos que distinguen entre usuarios activos (que iniciaron o aplicaron una revisión manualmente) y pasivos (activados automáticamente por política). Esta distinción permite medir el impacto real de las políticas de adopción del code review.

→ Changelog: Copilot code review user counts now aggregate in usage metrics API

4. Nuevo campo para el agente en la nube en las métricas de uso

La API de métricas de uso incorpora el campo used_copilot_cloud_agent, en sustitución gradual de used_copilot_coding_agent, que quedará obsoleto el 1 de agosto de 2026. Los administradores que integren estas métricas en dashboards deben actualizar sus consultas antes de esa fecha.

→ Changelog: Copilot cloud agent fields added to usage metrics

5. Copilot para Jira: mayor personalización y control del agente

La integración de Copilot con Jira incorpora agentes personalizados por ticket, lectura de campos personalizados de Atlassian, reglas de nomenclatura de ramas, instrucciones globales a nivel de espacio y notificaciones de solicitud de revisión. Los administradores obtienen mayor control sobre el comportamiento del agente en los flujos de Jira existentes.

→ Changelog: GitHub Copilot for Jira: Our latest enhancements
