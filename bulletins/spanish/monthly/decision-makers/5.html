🏆 Top 5 de actualizaciones del mes

1. Medir el impacto y el retorno se vuelve tangible

GitHub lanzó un panel de impacto de métricas de uso y llevó a disponibilidad general las métricas a nivel de repositorio, además de ciclos de revisión y tiempo de adopción vía API. Los responsables ya pueden vincular la inversión en Copilot con resultados medibles.

Sources:
→ Changelog: New Copilot usage metrics impact dashboard
→ Changelog: Repository-level GitHub Copilot usage metrics generally available
→ Changelog: Add review cycles and time to adoption phases in the usage API

2. Control financiero con créditos de IA y centros de coste

Los nuevos grupos de créditos de IA por centro de coste, presupuestos por usuario y topes de uso incluido dan a las organizaciones un control predecible del gasto. La IA deja de ser un coste opaco para convertirse en una partida gestionable y presupuestada.

Sources:
→ Changelog: AI credit pools for cost centers in the billing UI
→ Changelog: Per-user budgets for cost centers in the billing UI
→ Changelog: Cost centers now support included usage caps

3. Copilot Code Review alcanza la madurez empresarial

La revisión de código con Copilot llegó a disponibilidad general con soporte de skills de agente y MCP, junto con mayor personalización y revisiones de seguridad en la app. Es una palanca directa de calidad y velocidad de entrega a escala.

Sources:
→ Changelog: Copilot code review agent skills and MCP now generally available
→ Changelog: Copilot code review customization and configurability improvements

4. Elección de modelos de primer nivel, sin dependencia de un único proveedor

Julio amplió el catálogo con Claude Opus 5, GPT-5.6, Grok 4.5, Gemini 3.6 Flash y Kimi K2.7, más la habilitación de modelos por defecto para empresas. Ofrecer lo mejor de cada proveedor reduce el riesgo estratégico y acelera resultados.

Sources:
→ Changelog: Claude Opus 5 is now available in GitHub Copilot
→ Changelog: OpenAI's GPT-5.6 Sol, Terra and Luna are now available
→ Changelog: Default model enablement for Copilot Business and Enterprise

5. La app de GitHub Copilot, disponible para todos

La app unificada de GitHub Copilot pasó a estar disponible para todos, ampliando el alcance de Copilot más allá del IDE. Para los responsables, significa una superficie de adopción más amplia y una experiencia consistente en toda la organización.

→ Changelog: GitHub Copilot app available to all
