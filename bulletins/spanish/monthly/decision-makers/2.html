Monthly #2 · Abril 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Abril marca el salto definitivo de GitHub Copilot hacia infraestructura AI de nivel empresarial. La transición a facturación basada en uso, la certificación FedRAMP y la residencia de datos en EE. UU. y la UE, la llegada de GPT-5.5 y la aceleración del agente cloud definen un mes que consolida Copilot como plataforma preparada para las organizaciones más exigentes.

⚠️ Atención

  • GitHub Copilot code review will start consuming GitHub Actions minutes on June 1, 2026 — Fecha límite: 1 de junio de 2026 — Cada revisión de código en repositorios privados consumirá minutos de Actions del plan contratado; revisa tu presupuesto con la documentación de precios de Copilot.
  • GitHub Copilot is moving to usage-based billing — Fecha límite: 1 de junio de 2026 — Las solicitudes premium se sustituyen por créditos AI; revisa la documentación de facturación basada en uso para preparar la transición.

🏆 Top 5 de actualizaciones del mes

1. Facturación basada en uso: el nuevo modelo de Copilot desde el 1 de junio

A partir del 1 de junio de 2026, los créditos AI sustituyen a las solicitudes premium como unidad de facturación. Los precios de los planes no cambian, el uso se agrupa a nivel de organización y los administradores obtienen nuevos controles de presupuesto.

→ Blog: GitHub Copilot is moving to usage-based billing

2. Copilot cumple los estándares de soberanía de datos y FedRAMP

GitHub Copilot soporta ahora residencia de datos en EE. UU. y la UE, con toda la inferencia confinada a la región designada. Los clientes del gobierno de EE. UU. cuentan con certificación FedRAMP Moderate, eliminando las principales barreras de adopción en sectores regulados.

→ Changelog: Copilot data residency in US + EU and FedRAMP compliance now available

3. GPT-5.5 disponible de forma general en GitHub Copilot

El último modelo de OpenAI, optimizado para tareas agénticas complejas de múltiples pasos, ya está disponible para Copilot Pro+, Business y Enterprise. GPT-5.5 supera a los modelos GPT anteriores en retos reales de código, consolidando el liderazgo de GitHub en el acceso a modelos frontera.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

4. El agente cloud madura: más rápido, más integrado, más accesible

El agente cloud arranca un 20% más rápido (sumando el 50% de mejora de marzo) gracias a imágenes precompiladas de Actions. En abril, se integró también en Visual Studio, en Issues y Projects, y puede supervisarse y redirigirse desde la app móvil de GitHub.

Sources:
→ Changelog: Copilot cloud agent starts 20% faster with Actions custom images
→ Changelog: GitHub Copilot in Visual Studio — April update
→ Changelog: View and manage agent sessions from issues and projects
→ Changelog: Remote control CLI sessions on web and mobile in public preview

5. Ecosistema abierto: BYOK y selección de modelos para agentes de terceros

Copilot Business y Enterprise permiten ahora usar claves de API propias (BYOK) de proveedores como Anthropic, Gemini u OpenAI en VS Code, fuera de las cuotas de Copilot. Los agentes de terceros Claude y Codex también ofrecen selección completa de modelos sin coste adicional.

Sources:
→ Changelog: Bring your own language model key in VS Code now available
→ Changelog: Model selection for Claude and Codex agents on github.com
