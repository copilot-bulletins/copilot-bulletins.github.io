Monthly #6 · Agosto 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Agosto consolidó un cambio de conversación: de la adopción de Copilot al retorno medible. GitHub conectó el gasto con los resultados, amplió el control sobre qué modelos usan los equipos y llevó a disponibilidad general controles de calidad y extensibilidad. Para la dirección, Copilot madura hacia una plataforma gobernable y justificable financieramente ante los comités de inversión.

⚠️ Atención

  • Upcoming changes to GitHub Copilot policies and billing — Acción requerida — Revisa los tres cambios anunciados y su impacto en tus políticas de organización.
  • Upcoming deprecation of GitHub Spark on github.com — Obsolescencia programada — Planifica la migración de los flujos que dependan de Spark antes de su retirada.
  • Retiring the Copilot Billing Preview app — Acción requerida — Traslada tu seguimiento de costes a las herramientas de facturación estándar.

🏆 Top 5 de actualizaciones del mes

1. Del gasto al retorno: visibilidad financiera de Copilot

El panel de impacto incorpora una sección de retorno de la inversión que conecta lo que gastas con los pull requests generados. Sumado al desglose de tokens por modelo y a la actividad de agentes en la API de métricas, la dirección obtiene una trazabilidad clara entre coste y resultado.

Sources:
→ Changelog: Copilot impact dashboard adds a return on investment section
→ Changelog: Copilot usage metrics API adds agent app activity
→ Changelog: Per-model token breakdown in the usage report

2. Gobernanza y elección de modelos

La política global de modelos alcanza disponibilidad general, permitiendo estandarizar qué modelos se habilitan en toda la empresa. En paralelo, la oferta se amplió con Grok 4.6, Gemini 3.7 Flash y Kimi K3, combinando control centralizado con libertad de elección para cada equipo.

Sources:
→ Changelog: Global model policy generally available
→ Changelog: Grok 4.6 is now available in GitHub Copilot
→ Changelog: Kimi K3 is now available in GitHub Copilot

3. Revisión de código con calidad ajustable

La revisión de código de Copilot madura: los niveles de esfuerzo pasan a disponibilidad general y se añaden razones de resolución con capacidades ampliadas. Permite calibrar profundidad frente a coste y auditar por qué se resuelve cada comentario, reforzando la calidad a escala.

Sources:
→ Changelog: Copilot code review effort levels are generally available
→ Changelog: Copilot code review: Resolution reasons and expanded capabilities

4. Copilot donde trabajan tus equipos

El trabajo con agentes se extiende a las herramientas de colaboración corporativa: una nueva experiencia de Copilot en Slack y trabajo agéntico compartido en Microsoft Teams. Acerca la IA al flujo diario de negocio y facilita la adopción más allá del IDE.

Sources:
→ Changelog: The new GitHub Copilot experience in Slack
→ Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams

5. Extensibilidad estandarizada de los agentes

Agent Plugins 1.0 llega a VS Code, Copilot CLI y la app de Copilot, y la pestaña Customize alcanza disponibilidad general. Estandarizar cómo se extienden los agentes reduce el coste de personalización y convierte a Copilot en una plataforma sobre la que construir de forma sostenible.

Sources:
→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app
→ Changelog: GitHub Copilot app Customize tab is generally available
