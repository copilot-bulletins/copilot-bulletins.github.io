Monthly #4 · Junio 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Junio consolidó una tendencia de fondo: Copilot deja de ser un asistente para convertirse en una plataforma agéntica lista para la empresa. GitHub reforzó a la vez la autonomía de los agentes y los controles de gobierno, coste y medición de adopción. Para la dirección, la señal es clara: el desarrollo autónomo se vuelve operativo, gobernable y cuantificable a escala.

⚠️ Atención

  • GPT-4.1 deprecated — Fecha límite: 1 de junio de 2026 — Modelo ya retirado en todas las experiencias de Copilot; comprueba que tus flujos usen un modelo compatible.
  • GPT-5.2 and GPT-5.2-Codex deprecated — Fecha límite: 5 de junio de 2026 — Actualiza tus integraciones para usar modelos compatibles.
  • Upcoming deprecation of Opus 4.6 (fast) — Fecha límite: 29 de junio de 2026 — Los administradores de Enterprise pueden habilitar el modelo alternativo desde las políticas de modelos de la organización.

🚀 Pasa a la acción

  • Evalúa la facturación por consumo y define presupuestos por usuario para controlar el gasto con los presupuestos de facturación.
  • Cuantifica la adopción y el retorno de Copilot con las métricas de uso y adopción.
  • Ofrece a tus equipos un entorno de desarrollo agéntico con la aplicación de GitHub Copilot.
  • Alinea tu estrategia y gobierno de IA con la guía de gobernanza de IA para empresas.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub; estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones del mes

1. La aplicación de GitHub Copilot llega a disponibilidad general

La aplicación de GitHub Copilot ya está disponible con carácter general para macOS, Windows y Linux como el hogar del desarrollo dirigido por agentes. Ejecuta sesiones en paralelo por repositorio, revisa los cambios y abre pull requests respetando los controles y requisitos de tu equipo.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Blog: GitHub Copilot app: The agent-native desktop experience

2. Automatización y extensibilidad más allá del IDE

GitHub extendió los agentes más allá del editor. Los flujos de trabajo agénticos, en vista previa pública, automatizan tareas dentro de Actions; las automatizaciones del agente en la nube ejecutan trabajo recurrente; y el SDK de Copilot, ya general, integra su motor en tus propias herramientas.

Sources:
→ Changelog: GitHub Agentic Workflows is now in public preview
→ Changelog: Schedule and automate tasks with Copilot cloud agent
→ Changelog: Copilot SDK is now generally available

3. Facturación por consumo y control de costes por equipo

La facturación por consumo ya está activa en todos los planes, con presupuestos a nivel de usuario. Los administradores de Enterprise pueden además fijar un presupuesto de créditos de IA por usuario en cada centro de costes, que acompaña a cada persona al cambiar de equipo. Gasto predecible y gobernable.

Sources:
→ Changelog: Updates to GitHub Copilot billing and plans
→ Changelog: Per-user AI credit budgets available for cost centers

4. Medir la adopción y el retorno con métricas más completas

Las métricas de uso ahora combinan telemetría de servidor y de cliente para reflejar a más usuarios activos, y los informes de organización y empresa muestran el total de pull requests fusionadas por fase de adopción. La dirección gana una visión más fiable del impacto real de Copilot.

Sources:
→ Changelog: Copilot usage metrics now include more of your active users
→ Changelog: Track total merges by adoption phase in enterprise and organization reports

5. Más opciones de modelos de primer nivel

El catálogo de modelos siguió ampliándose: Claude Sonnet 5 y Claude Fable 5 alcanzaron disponibilidad general, y Claude Opus 4.8 en modo rápido entró en vista previa. Más opciones de rendimiento y coste permiten a cada organización elegir el equilibrio adecuado sin atarse a un único proveedor.

Sources:
→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot
→ Changelog: Claude Fable 5 is generally available for GitHub Copilot
→ Changelog: Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot

📊 El mes en cifras

  • 1 millón de tokens de contexto disponibles en VS Code, Copilot CLI y la aplicación de Copilot.
  • ~20 % menos de coste en Copilot code review manteniendo la misma calidad de revisión.
  • 6 lenguajes compatibles con el SDK de Copilot para integrar su motor agéntico.

📌 También este mes

  • GitHub Copilot for Jira is now generally available — Copilot llega de forma general a Jira con selección de modelo, contexto de Confluence vía MCP y agentes personalizados.
  • Copilot code review: AGENTS.md support and UI improvements — Un archivo AGENTS.md en la raíz del repositorio ajusta el contexto de las revisiones automáticas.
  • Cloud and local sandboxes for GitHub Copilot now in public preview — Entornos aislados para que los agentes actúen sobre tu código dentro de las políticas que definas.
  • Extend GitHub with agent apps — Instala aplicaciones de agentes desde el Marketplace y actívalas dentro de tus flujos de trabajo.
  • Gain insights across your agent sessions with Chronicle — Visibilidad sobre las sesiones de agentes desde la aplicación de Copilot, github.com, VS Code y JetBrains.
  • Security validation for third-party coding agents — El código de agentes externos se analiza automáticamente con CodeQL, el Advisory Database y secret scanning.
