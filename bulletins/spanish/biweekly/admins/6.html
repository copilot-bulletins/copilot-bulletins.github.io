Biweekly #6 · Del 15 al 31 de mayo de 2026 · Admins Edition

🎯 El hilo de esta edición

Esta quincena consolida el control granular como eje de la gobernanza de Copilot. GitHub avanza en tres ámbitos clave para los administradores: gestión de modelos por organización, auditoría programática del agente en la nube y visibilidad más profunda de la madurez de adopción mediante cohortes. El resultado: más control operativo y mejores herramientas para demostrar el retorno de la inversión.

⚠️ Atención

  • Grok Code Fast 1 deprecated — Retirado el 15 de mayo de 2026 — El modelo ya no está disponible en ninguna experiencia de Copilot. Los administradores de Copilot Enterprise deben habilitar modelos alternativos (GPT-5 mini o Claude Haiku 4.5) en las políticas de modelos.

🚀 Pasa a la acción

  • Configura reglas de modelos por organización desde AI controls en la configuración de tu empresa con reglas de acceso dirigidas.
  • Habilita Claude Opus 4.8 para tu organización en los ajustes de políticas de Copilot si usas Copilot Business o Enterprise.
  • Actualiza tu lista de permisos del cortafuegos para incluir copilot-reports.github.com. Consulta la referencia de la lista de permisos de Copilot.
  • Explora las nuevas fases de adopción de IA en la API de métricas de uso de Copilot para identificar dónde enfocar la formación.
  • ¿Tienes preguntas o necesitas asistencia? Ponte en contacto con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Reglas de modelos dirigidas por organización

Los propietarios de empresa pueden asignar modelos de Copilot específicos a organizaciones concretas mediante reglas de acceso dirigidas. En lugar de una política única a nivel corporativo, es posible habilitar modelos distintos para equipos con requisitos de seguridad diferenciados.

→ Changelog: Target Copilot models to organizations with model rules

2. Cohortes de adopción de IA en la API de métricas de uso

La API de métricas de uso clasifica ahora a cada usuario en cuatro fases de adopción de IA (Code first, Agent first, Multi-agent, Sin cohorte) con una ventana de 28 días. Los informes de empresa y organización incluyen métricas por fase para orientar la formación y demostrar el ROI.

→ Changelog: Copilot usage metrics API adds cohorts for AI adoption

3. GPT-5.3-Codex, nuevo modelo base con soporte a largo plazo

A partir del 17 de mayo, GPT-5.3-Codex reemplaza a GPT-4.1 como modelo base en Copilot Business y Enterprise. Al ser el primer modelo LTS de GitHub, está garantizado durante 12 meses (hasta el 4 de febrero de 2027), proporcionando la estabilidad necesaria para los procesos internos de revisión de seguridad.

→ Changelog: GPT-5.3-Codex is now the base model for Copilot Business and Enterprise

4. Auditoría programática de la configuración del agente en la nube

Un nuevo endpoint de la API REST (public preview) permite auditar la configuración del agente en la nube de Copilot a nivel de repositorio. Los equipos de seguridad y gobernanza pueden integrar estas comprobaciones en sus pipelines para verificar el cumplimiento a escala.

→ Changelog: Audit repository Copilot cloud agent configuration via the REST API

5. Copilot Spaces API disponible de forma general

La API de Copilot Spaces alcanza disponibilidad general, permitiendo crear, leer, actualizar y eliminar Spaces mediante programación. Los equipos empresariales que gestionan múltiples Spaces pueden automatizar la configuración de contextos y colaboradores sin depender de la interfaz de GitHub.

→ Changelog: Copilot Spaces API now generally available
