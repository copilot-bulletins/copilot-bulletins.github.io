Biweekly #5 · Del 1 de mayo al 14 de mayo de 2026 · Admins Edition

🎯 El hilo de esta edición

Esta quincena, la gobernanza de Copilot avanza en tres frentes clave: granularidad a nivel de equipo en las métricas de adopción, herramientas para planificar la transición a créditos de IA prevista para el 1 de junio, y control centralizado de plugins en Copilot CLI a escala de empresa. Varias novedades requieren atención antes de que acabe el mes.

⚠️ Atención

  • Retirada de Grok Code Fast 1 — Plazo: 15 de mayo de 2026 — Migra a GPT-5 mini o Claude Haiku 4.5 habilitándolos en las políticas de modelos de Copilot para evitar interrupciones de servicio.
  • Próxima retirada de GPT-4.1, GPT-5.2 y GPT-5.2-Codex — Plazo: 1 de junio de 2026 — Activa GPT-5.5 o GPT-5.3-Codex en las políticas de modelos de Copilot antes de la fecha límite para evitar que los flujos de trabajo se interrumpan.

🚀 Pasa a la acción

  • Descarga el informe de uso de abril para estimar el impacto de la facturación por créditos de IA antes del 1 de junio.
  • Consulta las métricas de Copilot a nivel de equipo para identificar equipos con baja adopción y planificar acciones de habilitación.
  • Habilita los modelos alternativos (GPT-5.5, GPT-5.3-Codex) en las políticas de modelos de Copilot antes de que venzan los plazos de retirada.
  • Configura los estándares corporativos de plugins en Copilot CLI para distribuir agentes y herramientas a toda tu empresa.
  • ¿Preguntas o necesitas soporte? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Métricas de uso de Copilot a nivel de equipo, ahora vía API

La API de métricas de uso de Copilot expone un nuevo informe de equipos que cruza la pertenencia a equipos con la actividad por usuario. Los administradores pueden identificar qué equipos lideran la adopción y cuáles necesitan impulso, con desglose por IDE, lenguaje, función y modelo.

→ Changelog: Team-level Copilot usage metrics now available via API

2. Informes de abril disponibles para preparar la facturación por uso

A partir del 1 de junio de 2026, Copilot facturará en créditos de IA. Los administradores pueden descargar el informe de abril para estimar el gasto por usuario, modelo y superficie antes del cambio, y ajustar el presupuesto con antelación.

→ Changelog: April reports are now available to prepare for usage-based billing

3. Tipos de comentarios de code review en la API de métricas de uso

La API de métricas de Copilot desglosa ahora las sugerencias de code review por tipo de comentario (seguridad, riesgo de errores, etc.). Los administradores pueden medir el volumen y la tasa de adopción por categoría para demostrar el valor operativo de la revisión automática de código.

→ Changelog: Copilot code review comment types now in usage metrics API

4. Plugins gestionados por empresa en Copilot CLI, ahora en versión pública

Los administradores de empresa pueden configurar y distribuir plugins de Copilot CLI desde un repositorio centralizado. Esto permite establecer estándares corporativos de gobernanza: agentes personalizados, hooks de MCP y configuraciones habilitados por defecto en toda la organización.

→ Changelog: Enterprise-managed plugins in GitHub Copilot CLI are now in public preview

5. GitHub Copilot app disponible en vista previa técnica

La nueva app de escritorio nativa de GitHub para desarrollo agéntico ya está en vista previa técnica. En planes Business y Enterprise, los administradores deben activar las previsualizaciones y la política de Copilot CLI en la configuración para habilitar el acceso a sus usuarios.

→ Changelog: GitHub Copilot app is now available in technical preview
