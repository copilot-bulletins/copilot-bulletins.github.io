Biweekly #13 · Del 1 de septiembre al 14 de septiembre de 2026 · Admins Edition

🎯 El hilo de esta edición

Esta quincena consolida el control administrativo sobre los agentes de Copilot y sus modelos. Entre permisos gestionados a nivel de empresa, exclusiones de contenido generalizadas y nuevas métricas de adopción, el mensaje para administradores es claro: la gobernanza operativa madura al mismo ritmo que las capacidades. Es momento de revisar políticas, presupuestos y controles antes de las próximas retiradas de modelos.

⚠️ Atención

  • Próxima retirada de modelos seleccionados de GitHub Copilot — Fecha límite: 2 de octubre de 2026 — Varios modelos dejarán de estar disponibles en todas las experiencias de Copilot; revise el acceso a modelos de IA y comunique alternativas a sus equipos.
  • MAI-Code-1-Flash retirado — Acción requerida — El modelo ya no está disponible desde el 10 de septiembre de 2026; migre a la alternativa sugerida en la documentación de modelos.

🚀 Pasa a la acción

  • Revise y ajuste los permisos de las operaciones de agentes desde las políticas de empresa.
  • Configure las exclusiones de contenido para que se apliquen también en la app y la CLI de Copilot.
  • Analice la adopción con las métricas de uso de Copilot.
  • Defina fechas de caducidad en los presupuestos de usuarios.
  • ¿Preguntas o necesita ayuda? Contacte con su equipo de GitHub, estamos aquí para ayudarle.

🏆 Top 5 de actualizaciones

1. Permisos gestionados para las operaciones de los agentes de Copilot

Los administradores de Copilot Business y Enterprise ahora controlan de forma centralizada qué operaciones de los agentes se bloquean, requieren aprobación humana o pueden continuar sin intervención. Un avance clave para la gobernanza y la seguridad de flujos automatizados.

→ Changelog: Enterprise-managed permissions for GitHub Copilot agent operations

2. Métricas de uso para los agentes de VS Code

Los informes de métricas de uso de Copilot ya incluyen, de forma generalizada, la actividad de la ventana dedicada de agentes de VS Code. Permite medir adopción y compromiso con mayor precisión en organizaciones y empresas.

→ Changelog: Add VS Code agents to Copilot usage metrics

3. Exclusiones de contenido en la app y la CLI de Copilot

La app y la CLI de Copilot ahora respetan las políticas de exclusión de contenido configuradas por administradores de empresa, organización y repositorio. Cierra una brecha de cumplimiento en las superficies fuera del IDE.

→ Changelog: Content exclusions generally available in Copilot app and CLI

4. Copilot code review puede aprobar pull requests

Copilot ahora indica cuándo un pull request está listo para aprobarse, y los administradores pueden autorizarlo para firmar la aprobación. La capacidad está desactivada por defecto, dando control total sobre este paso de gobernanza.

→ Changelog: Copilot code review can now approve pull requests

5. Fecha de caducidad para presupuestos de usuario individuales

Ahora puede establecer una fecha de caducidad opcional en el presupuesto de un usuario individual, y GitHub lo elimina en esa fecha. Una herramienta útil para gestionar costes temporales y accesos limitados en el tiempo.

→ Changelog: Set an expiration date for individual user budgets
