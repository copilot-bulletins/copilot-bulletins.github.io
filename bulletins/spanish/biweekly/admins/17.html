Biweekly #17 · Del 1 de noviembre al 14 de noviembre de 2026 · Admins Edition

🎯 El hilo de esta edición

Esta quincena, la visibilidad operativa domina: las métricas de uso distinguen ahora el tráfico de modelos propios, miden el impacto real de la revisión de código y detectan brechas de telemetría. Al mismo tiempo, más configuraciones pasan a la API. Para los administradores, esto significa gobernar Copilot con datos más fiables y automatizar sin depender de la interfaz.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models in December — Deadline: 14 de diciembre de 2026 — Claude Fable 5, Claude Haiku 4.5, Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6 y Kimi K3 serán retirados. Si desactivaste la habilitación global por defecto, habilita las alternativas en la política de modelos.

🚀 Pasa a la acción

  • Revisa el uso de BYOK y de modelos personalizados con la API de métricas de uso de Copilot y contrástalo con tu política BYOK.
  • Automatiza la configuración de la revisión de código siguiendo la guía de configuración de Copilot code review.
  • Delega la asignación de licencias a una GitHub App con los endpoints de gestión de usuarios de Copilot.
  • Decide si habilitas Claude Fable 5.2 tras revisar sus condiciones en modelos compatibles.
  • ¿Preguntas o necesitas soporte? Contacta a tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. BYOK y modelos personalizados, visibles en las métricas

La API de métricas de uso separa ahora el uso BYOK local (claves propias, Ollama, LM Studio) y los modelos personalizados de empresa del uso alojado por Copilot. Permite auditar el cumplimiento de la política BYOK y calcular mejor el coste por usuario.

→ Changelog: BYOK and enterprise custom models in the Copilot usage API

2. Medir el impacto real de Copilot code review

Los informes por repositorio incluyen la tasa de comentarios atendidos y los PR fusionados sin solicitud de cambios humana tras la revisión de Copilot, desglosados por severidad y personalización. Un indicador concreto para evaluar el valor de la revisión automática.

→ Changelog: Usage metrics API adds code review details and addressed rate

3. Configuración de code review gestionable por API

Los ajustes de Copilot code review se gestionan vía REST y GraphQL, desde la política empresarial hasta cada repositorio, con campos de atribución explícitos. La regla de revisión automática admite ahora lista de exclusión (bypass) y las sesiones muestran los créditos de IA consumidos.

→ Changelog: Copilot code review: API management and review overview updates

4. GitHub Apps para gestionar licencias empresariales

Las GitHub Apps de empresa pueden llamar a las APIs de gestión de licencias de Copilot para asignar licencias a usuarios y equipos empresariales, mediante el nuevo permiso granular "Enterprise Copilot license management". Automatización sin depender de tokens personales.

→ Changelog: GitHub App support for Enterprise Copilot seat management

5. Claude Fable 5.2: política desactivada por defecto

Claude Fable 5.2 ya está disponible de forma general, pero requiere retención de datos para los clasificadores de seguridad de Anthropic. Su política está desactivada por defecto; habilitarla implica aceptar ese requisito. Las empresas elegibles pueden solicitar retención cero a su equipo de cuenta.

→ Changelog: Claude Fable 5.2 in GitHub Copilot
