Biweekly #9 · Del 15 de julio al 31 de julio de 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

La segunda quincena de julio consolida una idea clave para la dirección: el valor de Copilot ya no se mide solo por la adopción, sino por el impacto demostrable. GitHub refuerza la medición del retorno, amplía el catálogo de modelos de frontera y madura la revisión de código automatizada, situando la inversión en IA en un terreno cuantificable y gobernable.

⚠️ Atención

  • Gemini 2.5 Pro y Gemini 3 Flash retirados — Fecha límite: 31 de julio de 2026 — Estos modelos dejan de estar disponibles en todas las experiencias de Copilot; migre los flujos afectados a un modelo compatible.

  • Cuantifique el retorno de Copilot con el nuevo panel de impacto y las métricas de uso.
  • Revise el catálogo de modelos compatibles y defina qué modelos habilitar para sus equipos.
  • Estandarice la revisión de código de Copilot como control de calidad a escala.
  • Alinee gasto y valor con la gestión del gasto por centro de coste.
  • ¿Preguntas o necesita ayuda? Contacte con su equipo de GitHub, estamos aquí para ayudarle.

🏆 Top 5 de actualizaciones

1. Un panel para contar la historia del impacto

Un nuevo panel de impacto para administradores de empresa y organización va más allá de quién usa Copilot: conecta la actividad con resultados de negocio. Para la dirección, es la palanca para justificar la inversión con datos y comunicar el retorno a las partes interesadas.

→ Changelog: New Copilot usage metrics impact dashboard

2. Revisión de código automatizada, ahora extensible y en disponibilidad general

La revisión de código de Copilot con agent skills y servidores MCP alcanza disponibilidad general para Pro, Pro+, Business y Enterprise. Permite adaptar la revisión al contexto de cada organización, elevando la calidad y la coherencia del código a escala sin ampliar plantilla.

→ Changelog: Copilot code review: Agent skills and MCP now generally available

3. Claude Opus 5 llega a GitHub Copilot

El modelo más avanzado de Anthropic, diseñado para tareas de codificación complejas y de larga duración, ya está disponible en Copilot. Ampliar el acceso a modelos de frontera refuerza la competitividad y garantiza que los equipos dispongan de la mejor capacidad de razonamiento para cada reto.

→ Changelog: Claude Opus 5 is now available in GitHub Copilot

4. Métricas de uso a nivel de repositorio en disponibilidad general

La API de métricas de uso incorpora datos diarios por repositorio para el agente de codificación y la revisión de código de Copilot. Ofrece a la dirección una visión granular de dónde genera valor la IA, facilitando decisiones de inversión y priorización con evidencia.

→ Changelog: Repository-level GitHub Copilot usage metrics generally available

5. Grupos de créditos de IA por centro de coste en la interfaz de facturación

Ahora se pueden gestionar los grupos de créditos de IA de cada centro de coste directamente en la interfaz de facturación. Simplifica el control financiero, alinea el gasto con las unidades de negocio y aporta previsibilidad presupuestaria a la adopción de Copilot.

→ Changelog: AI credit pools for cost centers in the billing UI
