🏆 Top 5 de actualizaciones

1. La app de GitHub Copilot llega a todos los planes

La experiencia de escritorio pensada para agentes ya está disponible en cualquier plan, incluidos Free y Education, en macOS, Windows y Linux. Amplía enormemente el alcance de la plataforma agéntica y facilita estandarizar el desarrollo asistido por IA en toda la organización.

→ Changelog: GitHub Copilot app available to all

2. Nuevos modelos de frontera GPT-5.6 Sol, Terra y Luna

OpenAI incorpora tres variantes que permiten ajustar el modelo a cada tarea: máximo razonamiento (Sol), equilibrio para el día a día (Terra) y respuesta rápida y económica (Luna). Más opciones de frontera refuerzan la competitividad y el control de coste por caso de uso.

→ Changelog: OpenAI's GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot

3. Presupuestos por usuario para centros de coste

Los administradores de empresa pueden fijar presupuestos de créditos de IA por usuario directamente en la interfaz de facturación. La cobertura se ajusta sola cuando cambia la pertenencia a equipos, dando previsibilidad de gasto y gobernanza financiera sin reconfiguraciones manuales.

→ Changelog: Per-user budgets for cost centers in the billing UI

4. Métricas de uso y adopción más precisas

Los informes de uso ganan exactitud y cobertura: el Copilot CLI ya reporta líneas sugeridas y la API de uso añade ciclos de revisión y fases de tiempo hasta la adopción. Datos más fiables para medir el retorno y justificar la inversión en IA.

Sources:
→ Changelog: Improved accuracy and coverage in Copilot usage metrics reports
→ Changelog: Add review cycles and time to adoption phases in the usage API

5. Autocorrección agéntica para alertas de análisis de código

En vista previa pública, Copilot remedia alertas de code scanning como lo haría una persona: explora el código, propone una corrección y revalida con CodeQL antes de abrir un pull request. Reduce el riesgo de seguridad y acelera la resolución a escala.

→ Changelog: Agentic autofix for code scanning alerts in public preview
