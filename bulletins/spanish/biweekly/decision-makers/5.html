🏆 Top 5 de actualizaciones

1. GitHub, Líder en el Cuadrante Mágico de Gartner por tercera vez consecutiva

GitHub Copilot fue posicionado por Gartner como Líder en Agentes de Codificación con IA Empresarial, con el mayor puntaje en "Capacidad de Ejecución" entre 12 proveedores evaluados. La plataforma alcanza 140.000 organizaciones activas —el triple respecto al año pasado— y más del 100 % de crecimiento anual. Un aval independiente que refuerza la apuesta estratégica por Copilot.

→ Blog: GitHub recognized as a Leader in the Gartner® Magic QuadrantTM for Enterprise AI Coding Agents for the third year in a row

2. Las métricas de Copilot revelan la madurez de adopción de IA por usuario

La API de métricas de uso de Copilot clasifica ahora a cada usuario activo en una de cuatro fases de adopción de IA (sin cohort, Code first, Agent first, Multi-agent) en una ventana de 28 días. Esto permite a las organizaciones identificar dónde concentrar la formación y medir la progresión real del ROI por cohorte.

→ Changelog: Copilot usage metrics API adds cohorts for AI adoption

3. Claude Opus 4.8, el modelo más avanzado de Anthropic, disponible en Copilot

Claude Opus 4.8 está disponible con carácter general en GitHub Copilot para los planes Business y Enterprise. Diseñado para tareas complejas de programación y navegación en grandes bases de código, es accesible en todos los modos de VS Code, JetBrains, Copilot CLI, el agente en la nube y GitHub Mobile.

→ Changelog: Claude Opus 4.8 is generally available for GitHub Copilot

4. Control granular de modelos de IA por organización en empresas

Los administradores empresariales pueden crear reglas de modelos específicas por organización, superando la configuración global de empresa. Esto permite adaptar el acceso a modelos de IA a las necesidades de cumplimiento, presupuesto y madurez técnica de cada equipo, con mayor control sobre la gobernanza de IA corporativa.

→ Changelog: Target Copilot models to organizations with model rules

5. Control remoto de sesiones de agentes de Copilot, disponible de forma general

Los desarrolladores pueden iniciar sesiones de Copilot en VS Code o la CLI y monitorizarlas y dirigirlas en tiempo real desde cualquier dispositivo: github.com, aplicación móvil o JetBrains. Esta capacidad, ahora disponible para todos, es una señal clara de madurez de la plataforma agéntica de GitHub como solución empresarial end-to-end.

→ Blog: Take your local GitHub sessions anywhere
