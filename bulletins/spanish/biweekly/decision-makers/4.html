🏆 Top 5 de actualizaciones

1. El GitHub Copilot app llega en technical preview

GitHub lanza una aplicación de escritorio nativa para el desarrollo agéntico. Las sesiones arrancan desde issues o pull requests, permiten trabajar en paralelo y llevan el cambio hasta el merge sin salir del ecosistema GitHub. Copilot Business y Enterprise acceden esta semana.

→ Changelog: GitHub Copilot app is now available in technical preview

2. API REST para automatizar tareas del Copilot cloud agent

Copilot Business y Enterprise pueden automatizar tareas del agente mediante la nueva API pública. Desde un script es posible lanzar refactorizaciones en múltiples repositorios, preparar releases automáticas semanales o integrar el agente con el portal de desarrollo interno de la organización.

→ Changelog: Start Copilot cloud agent tasks via the REST API

3. Métricas de Copilot por equipo disponibles via API

La API de métricas de uso expone ahora datos a nivel de equipo: usuarios activos, completaciones, chat y desgloses por lenguaje, IDE y modelo. Los administradores pueden identificar qué equipos lideran la adopción y dónde concentrar los esfuerzos de habilitación.

→ Changelog: Team-level Copilot usage metrics now available via API

4. Selección automática de modelos en el Copilot cloud agent con descuento del 10%

Copilot cloud agent incorpora la selección automática de modelos: Copilot elige el mejor disponible según rendimiento y estado del sistema. Para planes de pago, esto supone un descuento del 10% en el multiplicador y la eliminación de los límites semanales de uso.

→ Changelog: Copilot cloud agent supports auto model selection

5. Secretos y variables centralizados para el Copilot cloud agent

Hasta ahora, secretos y variables del agente debían configurarse repositorio a repositorio. Ahora es posible definirlos a nivel de organización y compartirlos con todos los repositorios —simplificando la gestión de tokens, registros privados y configuraciones MCP a escala.

→ Changelog: More flexible secrets and variables for Copilot cloud agent
