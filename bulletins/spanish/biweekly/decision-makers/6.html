Biweekly #6 · Del 1 de junio al 14 de junio de 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Esta quincena consolidó un giro estratégico: Copilot deja de ser un asistente individual para convertirse en una plataforma «agent-native» que las organizaciones ejecutan, gobiernan y amplían a escala. Presentado en Microsoft Build 2026, este cambio redefine cómo se mide el valor de la IA: menos sobre sugerencias puntuales y más sobre automatización gobernada, control de costes y retorno medible.

⚠️ Atención

  • GPT-4.1 queda obsoleto en Copilot — Obsoleto desde el 1 de junio de 2026 — Actualiza las integraciones y los flujos fijados a este modelo para usar GPT-5.5; los administradores de Enterprise pueden habilitar la alternativa desde las políticas de modelos.
  • GPT-5.2 y GPT-5.2-Codex quedan obsoletos — Obsoleto desde el 5 de junio de 2026 — Migra a GPT-5.5 y GPT-5.3-Codex; revisa los modelos compatibles antes de ajustar tus políticas.

🚀 Pasa a la acción

  • Revisa la facturación basada en consumo, ya activa para todos los planes, y define presupuestos por usuario para controlar el gasto en Copilot.
  • Pon a disposición de tus equipos la app de GitHub Copilot, disponible con los planes Pro, Pro+, Business y Enterprise que ya tienes.
  • Cuantifica el retorno de la automatización con un piloto del agente en la nube de Copilot en tareas repetitivas como el triaje de incidencias.
  • Evalúa el SDK de Copilot para integrar el motor agéntico de Copilot en tus herramientas internas y productos.
  • ¿Preguntas o necesitas apoyo? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. La app de GitHub Copilot estrena una experiencia «agent-native»

Presentada en Microsoft Build 2026, la nueva app de escritorio da a los agentes un lugar propio en el flujo de trabajo: dirigir varios en paralelo, seguir su actividad y revisar resultados. Disponible con los planes Pro, Pro+, Business y Enterprise actuales.

Sources:
→ Blog: GitHub Copilot app: The agent-native desktop experience
→ Changelog: Expanded technical preview availability for the GitHub Copilot app

2. GitHub Agentic Workflows entra en vista previa pública

Automatiza tareas de razonamiento —triaje de incidencias, análisis de fallos de CI, actualización de documentación— con agentes dentro de GitHub Actions, reutilizando tus runners y políticas. Carvana y Marks & Spencer ya resuelven en minutos trabajo que antes consumía horas.

→ Changelog: GitHub Agentic Workflows is now in public preview

3. La facturación basada en consumo se activa en todos los planes

Desde el 1 de junio, todos los planes facturan según los GitHub AI Credits consumidos, con uso incluido mensual. Llegan los presupuestos por usuario y la mejora a Copilot Max, dando a administración y finanzas control directo sobre el gasto en IA.

→ Changelog: Updates to GitHub Copilot billing and plans

4. El SDK de Copilot alcanza disponibilidad general

Las organizaciones pueden integrar el motor agéntico de Copilot —planificación, edición de archivos, sesiones multironda— en sus propias aplicaciones, con una API estable en seis lenguajes. Convierte a Copilot en una plataforma sobre la que construir, no solo una herramienta.

→ Changelog: Copilot SDK is now generally available

5. Sandboxes en la nube y locales para ejecutar agentes con seguridad

Copilot puede ejecutarse ahora en entornos aislados, locales o alojados por GitHub, dentro de las políticas que definas. Reduce el riesgo de adoptar flujos agénticos y ofrece a las empresas una vía gobernada para escalar el uso de agentes.

→ Changelog: Cloud and local sandboxes for GitHub Copilot now in public preview
