Biweekly #16 · Del 1 de noviembre al 14 de noviembre de 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Esta quincena, GitHub se centró en medir el valor real de Copilot. Las nuevas métricas muestran qué ocurre con las recomendaciones de la IA, cómo se adopta cada experiencia y dónde hay lagunas en los datos. Al mismo tiempo, Copilot llega a más herramientas de colaboración y de desarrollo. Para la dirección, esto significa decisiones de inversión mejor fundamentadas.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models in December — Fecha límite: 14 de diciembre de 2026 — Claude Fable 5, Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6, Kimi K3 y Claude Haiku 4.5 dejarán de estar disponibles. Pida a sus equipos que migren a las alternativas recomendadas y revise la disponibilidad de modelos en su empresa.

🏆 Top 5 de actualizaciones

1. Medir cuánto valor aporta la revisión de código con IA

La API de métricas ahora indica cuántos comentarios de Copilot code review aplican los desarrolladores y cuántas pull requests se fusionan sin cambios solicitados por personas. Una tasa de aceptación por repositorio convierte la revisión con IA en un indicador de ROI medible.

→ Changelog: Usage metrics API adds code review details and addressed rate

2. Una visión completa de la adopción en el panel de impacto

El panel de impacto de Copilot incluye ahora Copilot Chat y la ventana de agentes de VS Code, cubriendo nueve experiencias. Los "usuarios pasivos" pasan a llamarse "usuarios centrados en chat", ofreciendo una imagen más fiel de cómo se usa Copilot.

→ Changelog: Copilot impact dashboard adds chat and VS Code agent usage

3. @GitHub en Slack y Teams, disponible de forma general

Los equipos pueden investigar errores, crear issues y abrir pull requests sin salir de sus conversaciones. Canvas en Teams permite revisar planes y cambios de forma colaborativa, acercando el desarrollo a negocio y producto y reduciendo el tiempo entre idea y entrega.

→ Changelog: @GitHub in Slack and Teams is generally available and more

4. Tres nuevos modelos de frontera para elegir

Claude Fable 5.2, Gemini 4 Carbon y Gemini 4 Hydrogen ya están disponibles de forma general. Fable 5.2 resuelve más tareas con menos pasos; Carbon se orienta a código seguro. La elección multimodelo evita la dependencia de un solo proveedor.

Sources:
→ Changelog: Claude Fable 5.2 in GitHub Copilot
→ Changelog: Gemini 4 Carbon in GitHub Copilot
→ Changelog: Gemini 4 Hydrogen in GitHub Copilot

5. Copilot llega a Xcode y JetBrains Air

Copilot se integra en el asistente nativo de Xcode (vista previa pública) y en JetBrains Air, incluidas tareas en la nube con la suscripción de Copilot. Una sola licencia cubre más entornos de desarrollo, simplificando la gestión de herramientas de IA.

Sources:
→ Changelog: GitHub Copilot is now available in Xcode’s coding assistant
→ Changelog: GitHub Copilot is now available in JetBrains Air
