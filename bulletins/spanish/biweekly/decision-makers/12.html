Biweekly #12 · Del 1 de septiembre al 14 de septiembre de 2026 · Decision-Makers Edition

🎯 El hilo de esta edición

Esta quincena, GitHub reforzó la idea de una IA gobernable y cuantificable. Las novedades dan a las organizaciones palancas para equilibrar coste, calidad y control: niveles de selección de modelo, permisos centralizados sobre las operaciones de los agentes y métricas de adopción más completas. Para la dirección, el mensaje es claro: Copilot madura como una inversión medible, previsible y alineada con los objetivos del negocio.

⚠️ Atención

  • Próxima retirada de varios modelos de GitHub Copilot — Fecha límite: 2 de octubre de 2026 — Gemini 3.5/3.6 Flash, Kimi K2.7 Code y Claude Opus 4.7 dejarán de estar disponibles. Revise sus flujos y habilite los modelos alternativos en las políticas de Copilot.
  • MAI-Code-1-Flash retirado — Acción requerida — El modelo ya no está disponible en ninguna experiencia de Copilot; confirme que sus equipos han migrado a un modelo compatible.

🚀 Pasa a la acción

  • Alinee coste y calidad eligiendo el nivel adecuado en la selección automática de modelo.
  • Centralice el control de los agentes con las políticas de Copilot para su empresa.
  • Mida la adopción y el retorno con los informes de métricas de uso.
  • Controle el gasto definiendo presupuestos por usuario.
  • ¿Preguntas o necesita apoyo? Contacte con su equipo de GitHub, estamos aquí para ayudar.

🏆 Top 5 de actualizaciones

1. GPT-6 Astra, disponible de forma general

El nuevo modelo de OpenAI, diseñado para tareas de codificación autónomas y de largo horizonte, ya está disponible en Copilot. Amplía la frontera de lo que los agentes pueden automatizar, un factor clave para acelerar la entrega de software a escala.

→ Changelog: GPT-6 Astra is generally available in GitHub Copilot

2. La revisión de código de Copilot ahora puede aprobar pull requests

Copilot indica cuándo un pull request está listo para aprobarse y, con autorización del administrador, puede firmar la aprobación. Reduce cuellos de botella en la revisión y acelera el ciclo de entrega, manteniendo el control mediante una activación opcional.

→ Changelog: Copilot code review can now approve pull requests

3. Configure coste y calidad en la selección automática de modelo

La selección automática ofrece ahora tres niveles: eficiencia, equilibrio e inteligencia. Cada organización decide cómo ponderar coste, calidad y tiempo de respuesta, convirtiendo el gasto en IA en una palanca ajustable y previsible.

→ Changelog: Configure cost and quality in Copilot auto model selection

4. Permisos gestionados por la empresa para las operaciones de los agentes

Los administradores de Copilot Business y Enterprise pueden controlar de forma centralizada qué operaciones de los agentes se bloquean, requieren aprobación humana o proceden sin intervención. Un paso decisivo para escalar la IA agéntica con gobernanza y confianza.

→ Changelog: Enterprise managed permissions for GitHub Copilot agent operations

5. Métricas de uso para los agentes de VS Code

Los informes de métricas de uso incluyen ahora la actividad de la ventana de agentes de VS Code. Ofrece a la dirección mayor visibilidad sobre la adopción real del trabajo agéntico y facilita justificar y ampliar la inversión.

→ Changelog: Add VS Code Agents to Copilot usage metrics
