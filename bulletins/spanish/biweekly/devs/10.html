Biweekly #10 · Del 15 de julio al 31 de julio de 2026 · Devs Edition

🎯 El hilo de esta edición

La quincena estuvo marcada por la expansión del catálogo de modelos y la madurez del ecosistema agéntico. Llegaron nuevos modelos de primer nivel y el estándar MCP se estabilizó, mientras las capacidades de agente pasaron a disponibilidad general en más superficies. Para quien programa a diario, significa más opciones de razonamiento y una base de integración más sólida y predecible.

⚠️ Atención

  • Gemini 2.5 Pro y Gemini 3 Flash quedan obsoletos — Efectivo: 31 de julio de 2026 — Ambos modelos ya no están disponibles en ninguna experiencia de Copilot; migra tus flujos e integraciones a un modelo compatible.

🚀 Pasa a la acción

  • Prueba los nuevos modelos y elige el más adecuado por tarea desde tu selector de modelos.
  • Conecta tus herramientas y contexto externo con servidores MCP en Copilot Chat.
  • Delega tareas asíncronas al agente de codificación en la nube.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Claude Opus 5 llega a Copilot

El modelo Opus más reciente de Anthropic ya está disponible. Está diseñado para tareas de codificación complejas y de larga duración que exigen razonamiento cuidadoso, uso eficaz de herramientas y ejecución fiable en múltiples pasos, con buen desempeño en flujos agénticos autónomos.

→ Changelog: Claude Opus 5 is now available in GitHub Copilot

2. VS Code: versiones de julio de 2026

Las versiones v1.127 a v1.131 mejoran el trabajo con agentes, la revisión de cambios y el chat. La ventana Agents, en vista previa pública, estrena diseño renovado, revisiones más rápidas y mejor gestión de múltiples sesiones simultáneas.

→ Changelog: GitHub Copilot in VS Code July 2026 releases

3. El servidor MCP de GitHub adopta la nueva especificación

El protocolo MCP pasó a ser stateless el 28 de julio, y el servidor MCP de GitHub ya soporta la especificación más reciente. Gracias a la compatibilidad retroactiva de los SDK tier 1, no necesitas hacer nada para mantener el soporte.

→ Changelog: GitHub MCP Server supports the next MCP specification

4. Agent skills y MCP en Copilot code review, ya en disponibilidad general

La compatibilidad de la revisión de código con agent skills y servidores MCP pasó a disponibilidad general para usuarios Pro, Pro+, Business y Enterprise. Permite incorporar las herramientas, estándares y contexto externo de tu equipo directamente en las revisiones.

→ Changelog: Copilot code review agent skills and MCP now generally available

5. Agente en la nube para Linear, ya en disponibilidad general

Ya puedes asignar incidencias de Linear al agente de codificación en la nube, autónomo y asíncrono. Ejecuta el trabajo en segundo plano y ofrece más control sobre cómo corre el agente directamente desde tu espacio de Linear.

→ Changelog: Copilot cloud agent for Linear is now generally available
