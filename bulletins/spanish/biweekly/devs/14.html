Biweekly #14 · Del 15 al 30 de septiembre de 2026 · Devs Edition

🎯 El hilo de esta edición

La segunda quincena de septiembre consolidó una idea clara para quien programa: menos elegir un modelo y más dejar que Copilot orquante el trabajo. Llegaron nuevos modelos de varios proveedores, orquestación automática en el editor y mejoras de rendimiento e indexación en el IDE y la CLI. El resultado práctico es más capacidad sin más fricción en el flujo diario.

⚠️ Atención

  • Próxima retirada de modelos seleccionados a mediados de octubre — Fecha límite: 19 de octubre de 2026 — Varios modelos dejarán de estar disponibles en todas las experiencias de Copilot. Actualiza tus flujos e integraciones a los modelos sugeridos antes de esa fecha; revisa las alternativas en Modelos de IA.

🚀 Pasa a la acción

  • Prueba los nuevos modelos desde el selector del editor siguiendo la guía de Modelos de IA.
  • Acelera tu trabajo en terminal con Copilot CLI y su indexación de todo el código base.
  • Afina tus revisiones automáticas con Copilot code review.
  • ¿Tienes preguntas o necesitas apoyo? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. HydraFusion llega a VS Code y a la app de Copilot

HydraFusion, en research preview, se amplía más allá de la CLI. Aparece en el selector de modelos, pero en lugar de ser un único modelo orquesta varios: trata la selección del flujo como un problema de optimización según razonamiento, generación de código, depuración y uso de herramientas.

→ Changelog: HydraFusion in VS Code and the GitHub Copilot app

2. Nueva oleada de modelos disponibles

Llegan varios modelos para codificación agéntica y trabajo diario: Claude Sonnet 5.5 (eficiente en tareas bien acotadas), GPT-6.1 Sol (fuerte en flujos multistep y terminal) y Grok 4.7 (razonamiento para flujos complejos). Todos se seleccionan desde el model picker del editor.

Sources:
→ Changelog: Claude Sonnet 5.5 in GitHub Copilot
→ Changelog: GPT-6.1 Sol in GitHub Copilot
→ Changelog: Grok 4.7 is now available in GitHub Copilot

3. Copilot para JetBrains 1.18.0

La versión 1.18.0 incorpora aprobaciones asistidas por IA (las acciones de bajo riesgo se aprueban solas y las de mayor riesgo siguen pidiendo tu decisión), re-edición de mensajes previos que rebobina conversación y cambios, skills e instrucciones compartidas, y controles persistentes para herramientas MCP.

→ Changelog: New features and improvements in Copilot for JetBrains

4. Indexación de todo el código base para C++ en la CLI

La inteligencia de código C++ en Copilot CLI ahora es más rápida gracias a la indexación persistente de símbolos en todo el proyecto, incluidos archivos no abiertos. Menos espera para definiciones, referencias e implementaciones en repos grandes con millones de líneas.

→ Changelog: Faster C++ code intelligence with whole codebase indexing

5. Sandboxing local en la app de Copilot

El sandboxing local reduce el impacto de comandos no deseados al limitar el acceso a archivos, red y credenciales de tu máquina. Se configura por proyecto para sesiones sobre el repositorio local y el working tree, dándote una capa extra de seguridad al trabajar en local.

→ Changelog: Local sandboxing in the GitHub Copilot app
