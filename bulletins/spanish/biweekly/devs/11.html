🎯 El hilo de esta edición

Para quien programa a diario, el mensaje es claro: más opciones para ajustar potencia, coste y comportamiento del agente según cada tarea.

🏆 Top 5 de actualizaciones

1. Un plugin, todos tus agentes

Agent Plugins 1.0 permite crear un plugin una sola vez y usarlo en todos los clientes de agente compatibles: VS Code, Copilot CLI y la app de Copilot. Se publicó con AWS, Anysphere, Microsoft, OpenAI y Vercel, reduciendo el trabajo de integración duplicado.

→ Changelog: Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

2. Memoria persistente y Ollama en JetBrains

Copilot para JetBrains suma memoria persistente, acceso a modelos locales vía Ollama y más controles de empresa. También mejora los flujos de chat cotidianos y resuelve problemas de fiabilidad en servidores MCP. Un salto notable para quien programa en IntelliJ y otros IDEs de JetBrains.

→ Changelog: Copilot memory and Ollama in GitHub Copilot for JetBrains

3. Nueva oleada de modelos

Grok 4.6, Gemini 3.7 Flash y Kimi K3 llegan a GitHub Copilot. Grok 4.6 está pensado para codificación agéntica y flujos multi-paso; Gemini 3.7 Flash mejora en desarrollo web y de apps. Más opciones para equilibrar velocidad, coste y capacidad.

Sources:
→ Changelog: Grok 4.6 is now available in GitHub Copilot
→ Changelog: Gemini 3.7 Flash is now available in GitHub Copilot
→ Changelog: Kimi K3 is now available in GitHub Copilot

4. Controla el nivel de razonamiento del agente en la nube

Al delegar una tarea en el agente en la nube de Copilot, ya puedes fijar el nivel de razonamiento en los modelos que lo admiten. Así controlas cuánto "piensa" el agente, equilibrando profundidad de análisis, latencia y consumo según la complejidad del trabajo.

→ Changelog: Customize the reasoning level for Copilot cloud agent

5. Automatizaciones activadas por comentarios

Ahora puedes crear automatizaciones del agente en la nube que se ejecutan cuando se crea un comentario en una issue o pull request. Casos típicos: generar documentación o disparar tareas repetitivas directamente desde el hilo, sin salir de tu flujo de revisión.

→ Changelog: Trigger Copilot automations with comments
