Biweekly #4 · Del 15 al 30 de abril de 2026 · Devs Edition

🎯 El hilo de esta edición

Las dos últimas semanas de abril consolidan dos tendencias complementarias: la llegada de modelos de última generación (GPT-5.5 y Claude Opus 4.7) y la profundización de las capacidades agénticas en todos los entornos. JetBrains, Visual Studio, VS Code y la CLI reciben mejoras significativas que convierten a Copilot en un colaborador autónomo integrado en el flujo de trabajo del desarrollador.

⚠️ Atención

  • Copilot Code Review comenzará a consumir minutos de GitHub Actions el 1 de junio de 2026 — Fecha de inicio: 1 de junio de 2026 — Las revisiones en repositorios privados consumirán minutos de Actions a partir de esa fecha; revisa tu consumo actual de GitHub Actions y ajusta los límites de gasto antes del 1 de junio.

🚀 Pasa a la acción

  • Selecciona GPT-5.5 o Claude Opus 4.7 en el selector de modelos de Copilot, o activa auto para que Copilot elija el modelo óptimo automáticamente.
  • Activa BYOK en VS Code para conectar tus propias claves de Anthropic, OpenAI, Gemini o modelos locales: consulta la lista de modelos soportados en Copilot y la documentación de tu proveedor.
  • Instala la última versión del plugin de Copilot para JetBrains y activa el modo agente inline desde Inline Chat (Shift+Ctrl+I / Shift+Cmd+I).
  • [Descarga Visual Studio 2026]((visualstudio.microsoft.com/redacted) para probar el agente cloud integrado y el nuevo agente depurador con tus issues de GitHub.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. GPT-5.5 ya disponible en GitHub Copilot

GPT-5.5, el último modelo de OpenAI, llega a todos los clientes de Copilot —VS Code, JetBrains, CLI, GitHub.com, Visual Studio, Xcode y móvil. Diseñado para tareas agénticas complejas de múltiples pasos, supera los retos de codificación que sus predecesores no podían resolver. Se aplica un multiplicador premium de 7,5× durante la fase inicial.

→ Changelog: GPT-5.5 is generally available for GitHub Copilot

2. Visual Studio — actualización de abril: agentes en todas partes

La actualización de abril de Visual Studio integra sesiones del agente cloud directamente en el IDE, añade soporte de agentes personalizados a nivel de usuario y estrena un agente depurador que valida correcciones contra el comportamiento real en tiempo de ejecución. Las skills de agente ahora se descubren desde múltiples directorios (.claude/skills/, .agents/skills/).

→ Changelog: GitHub Copilot in Visual Studio — April update

3. BYOK en VS Code: conecta tus propios modelos de IA

Los usuarios de Copilot Business y Enterprise pueden usar sus propias claves API —Anthropic, Gemini, OpenAI, OpenRouter, Azure o modelos locales vía Ollama— directamente en VS Code Chat. Los modelos BYOK no consumen cuota de requests de Copilot; la facturación va directamente a tu proveedor.

→ Changelog: Bring your own language model key in VS Code now available

4. Claude Opus 4.7 disponible en GitHub Copilot

Claude Opus 4.7, el nuevo modelo flagship de Anthropic, trae mayor fiabilidad agéntica y mejor razonamiento de larga distancia respecto a sus predecesores. Disponible para Copilot Pro+, Business y Enterprise, reemplazará progresivamente a Opus 4.5 y 4.6 en el selector de modelos de Pro+. Lanzado con un multiplicador premium de 7,5×.

→ Changelog: Claude Opus 4.7 is generally available

5. Modo agente inline en JetBrains IDEs (public preview)

El modo agente inline llega a JetBrains en public preview: invoca capacidades agénticas directamente desde el chat inline sin salir del editor. La actualización incluye también previsualizaciones inline de Next Edit Suggestions, aprobación automática global y controles granulares para comandos de terminal y edición de archivos.

→ Changelog: Inline agent mode in preview and more in GitHub Copilot for JetBrains IDEs

📌 También en esta edición

  • Inteligencia de código C++ para Copilot CLI en public preview — El Microsoft C++ Language Server añade semántica de código precisa (definiciones, referencias, jerarquías de llamadas) a la CLI de Copilot.
  • La CLI de Copilot ya soporta selección automática de modelo — Auto elige el modelo más eficiente para cada tarea, con un descuento del 10% sobre el multiplicador del modelo seleccionado.
  • Gestiona las skills de agente con GitHub CLI — El nuevo comando gh skill permite descubrir, instalar y publicar skills de agente compatibles con Copilot, Claude Code, Cursor y otros entornos.
  • Depuración mejorada con Copilot en la web — Pega un stack trace en Copilot Chat en github.com y obtén un análisis estructurado de causa raíz con referencias al código fuente.
  • Visualiza y gestiona sesiones de agente desde issues y proyectos — Un nuevo panel lateral en issues y tableros de proyectos muestra el progreso del agente cloud y permite dirigirlo sin salir de tu flujo de trabajo.
