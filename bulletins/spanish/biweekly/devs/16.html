Biweekly #16 · Del 15 de octubre al 31 de octubre de 2026 · Devs Edition

🎯 El hilo de esta edición

GitHub Universe marcó la quincena: Copilot deja de ser un asistente ligado a una ventana y pasa a ser un sistema de agentes que eligen sus propios modelos, recuerdan el contexto del equipo y siguen trabajando en la nube. Para los desarrolladores, esto significa menos configuración manual y más tareas delegadas de principio a fin, desde cualquier cliente.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models in mid-November — Fecha límite: 16 de noviembre de 2026 — Claude Opus 4.8, Claude Opus 5 y GPT-5.6 Terra se retiran; migra tus flujos a Claude Opus 5.5, GPT-6.1 Sol o GPT-6 Luna según los modelos compatibles.
  • Turn notifications into code with GitHub Copilot in Teams — Fecha límite: 16 de noviembre de 2026 — La app heredada de GitHub para Microsoft Teams se retira; instala la nueva app consolidada para seguir usando Copilot en Teams.
  • GitHub Copilot in Visual Studio — September update — Acción requerida — BYOM en Visual Studio ahora requiere el nuevo Agent (Preview); los modos Ask y Agent anteriores ya no lo admiten y deberás volver a añadir tus modelos.

🚀 Pasa a la acción

  • Selecciona Copilot Fusion en el selector de modelos y elige un nivel de esfuerzo; consulta cómo funciona Copilot Fusion.
  • Activa «Watch and fix» en tus pull requests siguiendo la guía de Agent Merge.
  • Reduce las interrupciones en CLI, app y VS Code activando los permisos asistidos (/permissions → assisted en Copilot CLI).
  • Conecta Slack, Figma, Sentry o Linear una sola vez con los conectores de Copilot.
  • ¿Preguntas o necesitas ayuda? Contacta a tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Copilot Fusion: deja de elegir modelo en cada tarea

Copilot Fusion ya está disponible de forma general en VS Code, la app de Copilot, Copilot CLI y JetBrains. Eliges un nivel (Standard, High o Max) y Copilot decide qué modelos usar y cómo combinarlos, con un 30 % de descuento temporal en planes de pago.

Sources:
→ Changelog: Route and orchestrate models with GitHub Copilot Fusion
→ Changelog: GitHub Copilot Fusion now supports selection of local models

2. Una sesión de agente, todos tus clientes

Inicia una sesión en la nube desde VS Code, el móvil, la CLI o Slack y retómala en cualquier otro cliente. El nuevo Agent Host de VS Code mantiene los agentes activos tras cerrar la ventana, incluso en máquinas remotas vía SSH o dev tunnels.

Sources:
→ Changelog: Work from anywhere with a new, connected Copilot cloud experience
→ Changelog: GitHub Copilot in VS Code, Universe releases

3. Copilot Automations: flujos compartidos y nuevos disparadores

Las automatizaciones ahora pueden compartirse con el equipo, ejecutarse en la nube desde VS Code 1.144, dispararse vía API REST o 24 nuevos eventos de GitHub, y respetar límites de créditos por ejecución. Además, proponen mejoras a su propio prompt según los resultados.

Sources:
→ Changelog: Build shared workflows for your team with Copilot Automations
→ Changelog: New tools, triggers, and cost controls for Copilot Automations
→ Changelog: Create and manage Copilot Automations in Visual Studio Code

4. Agent Merge desbloquea tus pull requests en la nube

Selecciona «Watch and fix» en el merge box y Copilot corrige automáticamente workflows de Actions fallidos y conflictos de merge. Combínalo con auto-merge para que tu PR se fusione en cuanto cumpla todos los requisitos.

→ Changelog: Agent Merge watches and fixes pull requests in the cloud

5. Copilot Memory, ya disponible de forma general

Copilot recuerda tus preferencias y las convenciones del repositorio entre sesiones y clientes. Dreaming (vista previa) actualiza memorias, skills e instrucciones a partir del trabajo pasado, y la búsqueda de código permite consultar repositorios relacionados sin clonarlos.

→ Changelog: GitHub intelligence puts your code, context, and history to work
