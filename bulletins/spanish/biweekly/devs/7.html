Biweekly #7 · Del 1 al 14 de junio de 2026 · Devs Edition

🎯 El hilo de esta edición

Esta quincena, marcada por Microsoft Build 2026, consolidó un cambio de fondo: el desarrollo agéntico deja de ser una función del editor para convertirse en un flujo de trabajo cotidiano y controlable en todas las superficies. Para quienes programáis, esto se traduce en más contexto, razonamiento ajustable y entornos aislados que permiten delegar tareas autónomas sin renunciar al control.

⚠️ Atención

  • GPT-4.1 obsoleto — Obsoleto desde el 1 de junio de 2026 — Migra tus flujos e integraciones a un modelo compatible como GPT-5.5; puedes cambiarlo desde la configuración de modelos de Copilot Chat.
  • GPT-5.2 y GPT-5.2-Codex obsoletos — Obsoletos desde el 5 de junio de 2026 — Cambia a GPT-5.5 y GPT-5.3-Codex respectivamente; consulta los modelos compatibles. GPT-5.2 sigue disponible en Copilot code review.

🚀 Pasa a la acción

  • Aprovecha las ventanas de contexto de un millón de tokens y los niveles de razonamiento configurables; usa la comparativa de modelos de IA para elegir el adecuado a cada tarea.
  • Instala o actualiza el CLI para probar rubber duck, la entrada de voz y el nuevo /settings siguiendo la guía de instalación de Copilot CLI.
  • Explora el desarrollo agéntico con el agente en la nube de Copilot y los nuevos sandboxes aislados.
  • ¿Preguntas o necesitas soporte? Contacta a tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Ventanas de contexto de un millón de tokens y razonamiento configurable

Copilot admite ahora ventanas de contexto de un millón de tokens para trabajar en bases de código y proyectos multiarchivo sin perder el hilo, con niveles de razonamiento configurables que equilibran velocidad y profundidad. Disponible en VS Code, Copilot CLI y la app de Copilot.

→ Changelog: Larger context windows and configurable reasoning levels for GitHub Copilot

2. Copilot CLI estrena interfaz, rubber duck y entrada de voz

El CLI recibe una renovación importante: rubber duck (para razonar en voz alta sin editar código) y la entrada de voz pasan a disponibilidad general, mientras que una nueva interfaz de terminal con pestañas para issues, PRs y gists llega a /experimental.

→ Changelog: Copilot CLI: Improved UI, rubber duck, prompt scheduling, and voice input

3. GitHub Copilot en VS Code: ventana de Agentes y BYOK en entornos aislados

Las versiones de mayo (v1.120–v1.123) llevan la ventana de Agentes a VS Code Stable como vista previa, con una experiencia centrada en completar tareas más que en editar. También mejora el control remoto de sesiones largas y amplía BYOK a entornos sin conexión (air-gapped).

→ Changelog: GitHub Copilot in Visual Studio Code, May releases

4. Sandboxes aislados, locales y en la nube, en vista previa pública

Copilot puede ejecutarse ahora en sandboxes seguros y aislados, en tu máquina o en la nube. Ofrecen un entorno controlado para que el agente interactúe con tu código, herramientas, sistema de archivos y red dentro de las políticas que definas, adoptando flujos agénticos sin renunciar al control.

→ Changelog: Cloud and local sandboxes for GitHub Copilot now in public preview

5. La app de GitHub Copilot: una experiencia de escritorio nativa para agentes

GitHub presentó en Microsoft Build 2026 la app de Copilot, una experiencia de escritorio diseñada en torno a los agentes: lanza, supervisa y retoma sesiones desde una superficie dedicada. Su disponibilidad en vista previa técnica se amplía ahora a más usuarios.
