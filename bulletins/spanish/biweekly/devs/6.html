🏆 Top 5 de actualizaciones

1. La selección automática de modelos en VS Code elige según tu tarea

Copilot Auto evalúa la complejidad de tu tarea —razonamiento, generación de código, diagnóstico de errores— y enruta al modelo óptimo en tiempo real. Puedes ver qué modelo se usó pasando el cursor sobre la respuesta. Los suscriptores de pago obtienen un 10% de descuento al usar Auto.

→ Changelog: Auto model selection now routes based on your task in VS Code

2. GPT-5.3-Codex es ahora el modelo base para Copilot Business y Enterprise

El modelo base ha pasado de GPT-4.1 a GPT-5.3-Codex, el primer modelo LTS de Copilot garantizado hasta el 4 de febrero de 2027. Los datos de GitHub muestran una tasa de supervivencia de código significativamente más alta entre clientes empresariales con este modelo.

→ Changelog: GPT-5.3-Codex is now the base model for Copilot Business and Enterprise

3. Control remoto para sesiones de Copilot CLI: disponible en móvil, web, VS Code y JetBrains

Inicia una sesión en tu terminal, VS Code o JetBrains y síguela desde el móvil o github.com. Aprueba permisos, ajusta el rumbo o detén la sesión desde cualquier dispositivo. Esta versión GA también añade soporte para repositorios externos a GitHub.

Sources:
→ Changelog: Remote control for Copilot CLI sessions now generally available on mobile, web, and VS Code
→ Blog: Take your local GitHub sessions anywhere

4. Correcciones con un clic para Actions fallidas con el agente en la nube

Cuando falla un job de GitHub Actions, haz clic en Fix with Copilot en los logs: el agente investiga el error, aplica la corrección en una rama y te notifica para revisión. Ideal para corregir tests o fallos de linter sin perder el foco en lo que importa.

→ Changelog: One-click fixes for failing Actions with Copilot cloud agent

5. GitHub Copilot para Eclipse es código abierto

El plugin de Copilot para Eclipse está ahora disponible bajo licencia MIT. Puedes explorar la implementación de completaciones de código, chat, modo agente, MCP y BYOK. La comunidad ya contribuye activamente. Es una ventana abierta al funcionamiento interno de un asistente de IA en un IDE.

→ Changelog: GitHub Copilot for Eclipse is open source
