Biweekly #13 · Del 1 al 14 de septiembre de 2026 · Devs Edition

🎯 El hilo de esta edición

Esta quincena la elección de modelo pasa a primer plano. Con nuevos modelos generales disponibles, niveles de optimización para la selección automática y varias deprecaciones en marcha, el desarrollador gana control sobre el equilibrio entre coste, calidad y velocidad en cada prompt. Conviene revisar qué modelos usas hoy y adaptar tus flujos antes de que cambien las opciones disponibles.

⚠️ Atención

  • MAI-Code-1-Flash deprecated — Deadline: 10 de septiembre de 2026 (ya aplicado) — El modelo dejó de estar disponible en todas las experiencias de Copilot; migra a un modelo compatible.
  • Upcoming deprecation of selected GitHub Copilot models — Deadline: 2 de octubre de 2026 — Actualiza tus integraciones y flujos a modelos compatibles antes de esa fecha; consulta los modelos disponibles.

🚀 Pasa a la acción

  • Prueba GPT-6 Astra seleccionándolo en el selector de modelos de Copilot Chat.
  • Ajusta la selección automática al nivel que prefieras y compara opciones en la referencia de modelos.
  • Protege código sensible en la app y la CLI con exclusiones de contenido.
  • Aprovecha la revisión de código de Copilot en tus pull requests; revisa cómo funciona en la documentación de code review.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. GPT-6 Astra ya disponible de forma general

El nuevo modelo de OpenAI llega a Copilot orientado a tareas de código autónomas y de largo alcance: planifica, valida y confirma sus resultados antes de darlos por terminados. Disponible para Pro+, Max, Business y Enterprise en el selector de modelos, con despliegue gradual.

→ Changelog: GPT-6 Astra is generally available in GitHub Copilot

2. Niveles de coste y calidad en la selección automática de modelo

La selección automática ahora ofrece tres niveles —eficiencia, equilibrio e inteligencia— para indicar cómo debe ponderar Copilot coste, calidad y tiempo de respuesta en cada prompt. Se despliega en VS Code, Copilot CLI y la app de Copilot, con un 10% de descuento para suscriptores de pago.

→ Changelog: Configure cost and quality in Copilot auto model selection

3. La revisión de código de Copilot ya puede aprobar pull requests

Cada revisión incluye ahora una valoración de aprobación en el comentario general, indicando si Copilot considera el PR listo. Los administradores pueden autorizar que su aprobación cuente para las reglas de merge; está desactivado por defecto y es configurable a nivel de empresa, organización y repositorio.

→ Changelog: Copilot code review can now approve pull requests

4. Novedades semanales: Jira, HydraFusion y automatización de agentes

Esta entrega trae integración con Jira en la app de Copilot, orquestación adaptativa de modelos con Project HydraFusion en /experimental de Copilot CLI, nueva automatización de agentes en VS Code y controles ampliados para JetBrains. Todo pensado para llevar más contexto a tus flujos de trabajo.

→ Changelog: GitHub Copilot weekly releases — September 7

5. Exclusiones de contenido disponibles en la app y la CLI de Copilot

La app de Copilot y Copilot CLI ya respetan las políticas de exclusión de contenido definidas por administradores de empresa, organización y repositorio. Copilot no usará los archivos excluidos como contexto, protegiendo código sensible en flujos agénticos. Disponible para Copilot Business y Enterprise.

→ Changelog: Content exclusions generally available in Copilot app and CLI
