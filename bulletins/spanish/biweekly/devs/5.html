🎯 El hilo de esta edición

La app de Copilot en preview técnica, el agente CLI en JetBrains, la API REST para el agente cloud y las actualizaciones de VS Code convergen en un mismo rumbo: Copilot pasa de asistente de chat a plataforma autónoma y programable que actúa en todos tus entornos.

🏆 Top 5 de actualizaciones

1. La app de GitHub Copilot llega en preview técnica

La app de GitHub Copilot es una experiencia de escritorio nativa para el desarrollo agéntico. Inicia sesiones desde issues, pull requests o prompts; itera sobre el código; y lleva los cambios a revisión directamente en GitHub. Disponible en preview técnica para Pro/Pro+, Business y Enterprise.

→ Changelog: GitHub Copilot app is now available in technical preview

2. GitHub Copilot en VS Code: versiones de abril

VS Code migró a versiones semanales. Las actualizaciones de abril traen búsqueda semántica en cualquier workspace, Bring Your Own Key para Copilot Business y Enterprise, y continuidad de sesiones CLI entre dispositivos. El agente también gana acceso a terminales abiertas y compartición de tabs del navegador como contexto.

→ Changelog: GitHub Copilot in Visual Studio Code, April releases

3. Agente CLI de Copilot y vista unificada de sesiones en JetBrains

El agente CLI de Copilot llega a JetBrains en preview pública: delega tareas largas desde el IDE con aislamiento en worktree o workspace. Una nueva vista unificada centraliza el estado de todas las sesiones activas. También se añaden soporte global de .agent.md y la herramienta de preguntas en modo agente.

→ Changelog: Introducing Copilot CLI agent and unified sessions view in GitHub Copilot for JetBrains IDEs

4. El agente cloud de Copilot admite selección automática de modelo

El agente cloud ahora soporta la selección automática de modelo. Al elegir Auto en el selector de modelos, Copilot elige el mejor disponible según el rendimiento en tiempo real. Bonus: un descuento del 10% sobre el multiplicador normal y sin afectación por los límites semanales de tasa.

→ Changelog: Copilot cloud agent supports auto model selection

5. Inicia tareas del agente cloud mediante la API REST

Los usuarios de Copilot Business y Enterprise pueden ahora lanzar tareas del agente cloud de forma programática con la nueva API REST en preview pública. Automatiza refactorizaciones masivas, configura repositorios desde tu portal interno o prepara releases semanales sin intervención manual.

→ Changelog: Start Copilot cloud agent tasks via the REST API
