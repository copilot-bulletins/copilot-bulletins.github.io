Biweekly #12 · Del 15 de agosto al 31 de agosto de 2026 · Devs Edition

🎯 El hilo de esta edición

La segunda quincena de agosto reforzó a Copilot dentro del entorno de desarrollo: VS Code, Visual Studio y JetBrains recibieron mejoras centradas en sesiones de agentes, revisión de código y personalización mediante MCP. Para quienes desarrollan, el mensaje es claro: menos cambios de contexto y más control sobre modelos, agentes y flujos de trabajo directamente en el IDE.

🚀 Pasa a la acción

  • Prueba las nuevas sesiones de agentes y la revisión integrada actualizando tu extensión de Copilot en el IDE.
  • Solicita revisiones automáticas con Copilot code review en tus pull requests, incluidas las de gran tamaño.
  • Amplía Copilot con servidores MCP y personalizaciones para conectar tus herramientas.
  • Revisa los modelos disponibles y elige el más adecuado para cada tarea.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Copilot en VS Code: sesiones de agentes más organizadas

Las versiones v1.132 a v1.135 facilitan organizar sesiones de agentes, comparar chats en paralelo y navegar conversaciones largas. La ventana de Agentes, el navegador integrado y el dictado reciben mejoras para trabajar de más formas sin salir de VS Code.

→ Changelog: GitHub Copilot in VS Code, August 2026 releases

2. Copilot en Visual Studio: más control sobre razonamiento y agentes

La actualización de agosto añade más control sobre cómo razona Copilot, qué modelos usas y cómo compartir agentes especializados. Las organizaciones pueden publicar agentes personalizados detectados automáticamente en el selector de agentes.

→ Changelog: GitHub Copilot in Visual Studio — August update

3. Copilot code review: motivos de resolución y más cobertura

Copilot code review ahora revisa pull requests que antes no cubría: las creadas por bots (incluido el agente de Copilot) y las muy grandes. Además, puedes indicar el motivo al resolver un comentario de revisión.

→ Changelog: Copilot code review: Resolution reasons and expanded capabilities

4. Copilot harness disponible de forma general en JetBrains

Copilot harness llega a disponibilidad general en JetBrains, con entrega de funciones más rápida y mejor calidad de código. También se estrena el soporte integrado del servidor MCP de JetBrains en vista previa pública para flujos con agentes.

→ Changelog: Copilot harness generally available in Copilot for JetBrains

5. Pestaña Customize en la app de Copilot, ya disponible

La nueva pestaña Customize reúne servidores MCP, plugins, skills y canvases en un solo lugar. Explora personalizaciones destacadas, navega por tipo y adapta Copilot a las herramientas y flujos que tu equipo ya utiliza.

→ Changelog: GitHub Copilot app Customize tab is generally available
