Biweekly #17 · Del 1 de noviembre al 14 de noviembre de 2026 · Devs Edition

🎯 El hilo de esta edición

Esta quincena, Copilot llega a más entornos de trabajo de los desarrolladores. Se integra en entornos nativos de terceros, y el catálogo de modelos se renueva con varias opciones más capaces o más rápidas. Para los desarrolladores, esto significa elegir el agente y el modelo adecuados sin cambiar de herramienta ni de suscripción, y planificar las migraciones de modelos antes de diciembre.

⚠️ Atención

  • Upcoming deprecation of selected GitHub Copilot models in December — Deadline: 14 de diciembre de 2026 — Claude Fable 5, Claude Haiku 4.5, Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6 y Kimi K3 serán retirados. Actualiza tus flujos e integraciones con las alternativas indicadas en los modelos compatibles.

🚀 Pasa a la acción

  • Prueba Claude Fable 5.2 o Gemini 4 Hydrogen desde el selector de modelos siguiendo la guía para cambiar el modelo de Copilot Chat.
  • Revisa el coste de cada modelo antes de adoptarlo en la página Models and pricing for GitHub Copilot.
  • Centraliza tus plugins y servidores MCP con el nuevo comando /settings de Copilot CLI.
  • Empaqueta tus tareas repetitivas en agent skills reutilizables entre agentes.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Claude Fable 5.2: más tareas resueltas con menos pasos

El nuevo modelo de Anthropic ya está disponible de forma general para tareas complejas de varios pasos en bases de código grandes. Resuelve más tareas que Fable 5.1 con menos llamadas a herramientas. Disponible en VS Code, CLI, JetBrains, Xcode y el agente de codificación.

→ Changelog: Claude Fable 5.2 in GitHub Copilot

2. Gemini 4 Carbon y Hydrogen llegan al selector de modelos

Gemini 4 Carbon está orientado al razonamiento complejo y a la generación de código seguro. Gemini 4 Hydrogen, modelo Flash, prioriza la velocidad en flujos agénticos y uso de herramientas, con mejor seguimiento de instrucciones que Gemini 3.8 Flash.

Sources:
→ Changelog: Gemini 4 Carbon in GitHub Copilot
→ Changelog: Gemini 4 Hydrogen in GitHub Copilot

3. Copilot disponible en JetBrains Air

Delega tareas, sigue varias sesiones en paralelo y revisa los cambios junto a tu código en JetBrains Air, mediante Agent Client Protocol. Las tareas en la nube de Air Teams consumen tu plan de Copilot en lugar de créditos de JetBrains AI.

→ Changelog: GitHub Copilot is now available in JetBrains Air

4. Copilot en el asistente de codificación nativo de Xcode

En vista previa pública desde Xcode 27.3 beta, puedes usar Copilot directamente en el asistente integrado de Xcode (Settings > Intelligence). Es compatible con todos los planes, y la extensión GitHub Copilot for Xcode sigue disponible como alternativa.

→ Changelog: GitHub Copilot is now available in Xcode’s coding assistant

5. VS Code 1.145, app de Copilot y CLI: menos fricción diaria

VS Code añade automatizaciones locales con expresiones cron y modos de vista del chat. La app de Copilot mejora Agent Merge y permite compactar conversaciones al alcanzar el límite de contexto. En la CLI, /settings unifica la configuración en un solo panel.

→ Changelog: GitHub Copilot weekly releases — November 2
