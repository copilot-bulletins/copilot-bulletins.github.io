Biweekly #8 · Del 15 de junio al 30 de junio de 2026 · Devs Edition

🎯 El hilo de esta edición

Esta quincena consolida a Copilot como una plataforma de desarrollo agéntica, multimodelo y multiplataforma. La tendencia dominante es la madurez: nuevas capacidades pasan de vista previa a disponibilidad general y los agentes se integran más a fondo en cada superficie. Para los desarrolladores, se traduce en más libertad para elegir modelo y en asistentes más capaces allí donde ya programan.

⚠️ Atención

  • Baja de Opus 4.6 (fast) — Fecha de baja: 29 de junio de 2026 — El modelo se retiró de todas las experiencias de Copilot. Si lo tenías seleccionado, cámbiate a una alternativa compatible como Opus 4.8 (fast) o Claude Sonnet 5 desde el selector de modelos.

🚀 Pasa a la acción

  • Prueba Claude Sonnet 5 desde el selector de modelos de Copilot en tu IDE, la CLI o github.com.
  • Descarga la app de GitHub Copilot para macOS, Windows o Linux y ejecuta tu primera sesión.
  • Actualiza tu Copilot CLI y explora la nueva interfaz con pestañas de incidencias, pull requests y gists.
  • Activa el modo automático de selección de modelo en Copilot Chat para optimizar coste y calidad.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. Claude Sonnet 5 llega a disponibilidad general

El último modelo Sonnet de Anthropic ya está disponible de forma general en Copilot. Destaca en tareas de codificación, sobre todo en flujos de tipo CLI, con buena latencia. Selecciónalo desde el selector de modelos en VS Code, Visual Studio, la CLI, JetBrains y más.

→ Changelog: Claude Sonnet 5 is generally available for GitHub Copilot

2. La app de escritorio de GitHub Copilot ya es general

La app de escritorio de GitHub Copilot ya es de disponibilidad general en macOS, Windows y Linux. Es el hogar del desarrollo dirigido por agentes: ejecuta sesiones en paralelo por repositorio, valida en la terminal integrada y abre pull requests. Ahora suma canvases, automatizaciones en la nube y BYOK.

Sources:
→ Changelog: GitHub Copilot app generally available
→ Changelog: GitHub Copilot app support for BYOK

3. Nueva interfaz de terminal de Copilot CLI, ya general

La interfaz de terminal rediseñada de Copilot CLI ya es de disponibilidad general. Incorpora pestañas para trabajar con incidencias, pull requests y gists sin salir del terminal, y una configuración guiada de herramientas dentro de la sesión, incluida la gestión de servidores MCP con /mcp add.

→ Changelog: Copilot CLI: New terminal interface is generally available

4. El agente de Copilot llega a JetBrains AI Assistant

GitHub Copilot es ahora una opción nativa en el selector de agentes de JetBrains AI Assistant: elígelo como agente activo, escoge su modelo y ajusta la profundidad de razonamiento sin salir del chat. Una actualización previa añadió agentes de organización y empresa y Claude como proveedor en versión preliminar.

Sources:
→ Changelog: Copilot Agent is now available in JetBrains AI Assistant
→ Changelog: New features and Claude as agent provider preview in JetBrains IDEs

5. El modo automático llega a Copilot Chat para todos

La selección automática de modelo ya es de disponibilidad general en Copilot Chat —en github.com y la app móvil— para todos los planes. Elige el modelo según la complejidad de la tarea y la disponibilidad en tiempo real, y aplica un 10 % de descuento en la facturación.

→ Changelog: Auto mode in Copilot Chat available for all users

📌 También en esta edición

  • Claude Opus 4.8 (fast mode) en versión preliminar — Velocidad de salida notablemente mayor manteniendo la inteligencia de Opus 4.8, ideal para trabajo interactivo y agéntico.
  • MAI-Code-1-Flash, general para Business y Enterprise — El modelo de codificación propio de Microsoft AI, optimizado para respuestas rápidas y de baja latencia en flujos agénticos.

  • GitHub Copilot para Jira, ya en disponibilidad general — Sigue el progreso del agente en streaming dentro de tus incidencias de Jira, con selección de modelo y agentes personalizados.
  • Reapertura de altas en los planes individuales — Vuelven de forma gradual las altas para nuevos suscriptores de los planes Copilot Student, Pro, Pro+ y Max.
