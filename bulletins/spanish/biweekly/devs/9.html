Biweekly #9 · Del 1 al 14 de julio de 2026 · Devs Edition

🎯 El hilo de esta edición

La primera quincena de julio estuvo marcada por la ampliación de opciones para desarrolladores: nuevos modelos, más proveedores de agentes y mejoras en los IDE. Copilot avanza hacia un flujo más flexible, donde eliges el modelo adecuado para cada tarea y automatizas trabajo con agentes, tanto en tu editor como en tus canalizaciones de CI/CD.

⚠️ Atención

  • Próxima retirada de Gemini 2.5 Pro y Gemini 3 Flash — Fecha límite: 31 de julio de 2026 — Ambos modelos dejarán de estar disponibles en todas las experiencias de Copilot (chat, ediciones en línea, modos ask y agente, y autocompletado). Cambia a un modelo compatible desde la lista de modelos admitidos.

🚀 Pasa a la acción

  • Prueba la nueva familia GPT-5.6 y elige la variante adecuada consultando la lista de modelos admitidos.
  • Ejecuta Copilot CLI en tus flujos de GitHub Actions usando el GITHUB_TOKEN integrado; consulta cómo usar Copilot CLI.
  • Compara el rendimiento de los modelos disponibles con la comparativa de modelos antes de migrar tus flujos.
  • ¿Preguntas o necesitas ayuda? Contacta con tu equipo de GitHub, estamos aquí para ayudarte.

🏆 Top 5 de actualizaciones

1. GPT-5.6 llega a Copilot en tres variantes

La familia GPT-5.6 de OpenAI ya se despliega en Copilot con tres variantes: Sol, Terra y Luna. Puedes escoger la que mejor se ajuste a cada tarea, equilibrando velocidad y capacidad de razonamiento según el trabajo que tengas entre manos.

→ Changelog: OpenAI's GPT-5.6 (Sol, Terra, and Luna) are now available in GitHub Copilot

2. Nuevas versiones de junio de Copilot en VS Code

Las versiones v1.123 a v1.127 de VS Code, publicadas durante junio y principios de julio, refuerzan la experiencia diaria de Copilot. Mejoras en el modo agente, personalización y flujos de trabajo que los desarrolladores usan a diario.

→ Changelog: GitHub Copilot in Visual Studio Code, June 2026 releases

3. Codex como proveedor de agentes en JetBrains

Copilot para JetBrains incorpora Codex como nuevo proveedor de agentes en versión preliminar pública. Además, amplía el editor de personalizaciones con soporte para Hooks, mejor gestión de servidores MCP y modelos personalizados configurables.

→ Changelog: Codex as agent provider and agentic enhancements in JetBrains IDEs

4. Pide a Copilot un resumen de cualquier repositorio

Ahora puedes solicitar a Copilot una visión general de alto nivel de cualquier repositorio que explores por primera vez. Al visitar la página principal de un repo desconocido, obtienes un resumen que acelera tu comprensión del proyecto.

→ Changelog: Ask Copilot for a repository overview

5. Copilot CLI ya no requiere un token personal en Actions

Ya puedes ejecutar Copilot CLI en GitHub Actions con el GITHUB_TOKEN integrado. Se acabó crear y almacenar tokens de acceso personal (PAT), lo que simplifica la configuración y mejora la seguridad de tus canalizaciones.

→ Changelog: Copilot CLI no longer needs a personal access token in GitHub Actions
